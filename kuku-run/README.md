# 九九ラン（仮称）

九九の **こたえの パネルに とびこんで 走る 3D ランナーゲーム** です（小学2年生むけ）。
走る 道の 先に ゲートが あらわれ、上に 問題（`7 × 8 = ?`）、下に こたえの パネルが 2まい ならんでいます。
◀ ▶ で レーンを えらんで、正しい パネルに とびこむと パネルが こなごなに なります。
はじめは ゆっくりですが、**走るほど どんどん 速く なり、上限は ありません**。かならず どこかで まちがえる ので、
「どこまで れんぞくで いけるか」を きそいます。ミスは 3かいまで。

**音は いっさい 出しません**（授業で 児童が ひとりずつ しずかに つかう ため。効果音・よみあげ なし）。

> もとに した もの：X に 投稿されていた「九九を おぼえきれて いない 子のための ランナーゲーム」の 動画（2026-10-08 に 画面録画を 解析）。
> 見た目と あそびかたは その 動画に あわせ、**学習の 効果を 高める しくみ**（下の「まなびの しくみ」）を たしました。

## ひらきかた

**https://hirocelica0307-sketch.github.io/kobako/kuku-run/**

`index.html` を ブラウザ（Chrome・Safari・Edge）で 開くだけ。インストールも ログインも いりません。
ファイルとして 開いても（`file://`）動きます。3D の ライブラリ（Three.js）も フォルダーの 中に あるので、ネットが なくても 遊べます
（字の かたち〔M PLUS Rounded 1c〕だけ ネットから。ない ときは 端末の 丸い 字に なります）。

```
cd kuku-run
python3 -m http.server 8000    # → http://localhost:8000
```

## あそびかた

1. **はじめの 画面**で コースを えらんで「スタート」
2. 「3・2・1・GO!」で 走りだす
3. ◀ ▶ ボタン（キーボードの ← →・A D、画面を 左右に なでても OK）で レーンを えらぶ
4. ゲートを とおった しゅんかんに はんてい
   - **正解**：パネルが こなごなに なり、「○ れんぞく！」が ふえる
   - **まちがい**：ばくはつして ころぶ・♥ が 1つ へる・はやさが はじめの ゆっくりに もどる
5. ♥ が 3つとも なくなったら **おしまい**。きろくは さいこうの れんぞく数

### はやさ（上限なし）

はやさは「さいごに まちがえてから 走った 時間」だけで きまります。正解しても まちがえても ゲートの 数では かわりません。

| 走った 時間 | 1つの ゲートに つくまで | 表示の はやさ | めやす |
|---|---|---|---|
| 0びょう | 4.0びょう | 100km/h | ゆっくり。よゆうが ある |
| 10びょう | 2.2びょう | 180km/h | |
| 20びょう | 1.2びょう | 320km/h | 子どもには きびしく なる |
| 30びょう | 0.7びょう | 590km/h | **大人でも くるしい** |
| 40びょう | 0.4びょう | 1050km/h | ほぼ むり |

- ゲートに つくまでの 時間 ＝ 4.0 × e^(−t ÷ 17)（t ＝ 走った びょう数）。`logic.js` の `GATE_T0`・`GATE_TAU` で かえられます
- 上限が ないので、**かならず どこかで まちがえます**
- まちがえると はじめの ゆっくりに もどり、ころんで いる 間（約1.3びょう）は 時間を すすめません

### コース（12しゅるい）

| コース | 出る 九九 | 問題の しゅるい |
|---|---|---|
| 1のだん 〜 9のだん（9コース） | その だん だけ | 9しゅるい |
| 2〜5のだん | 2・3・4・5の だん | 36しゅるい |
| 6〜9のだん | 6・7・8・9の だん | 36しゅるい |
| ぜんぶ | 1〜9の だんを まぜこぜ | 81しゅるい |

ほかに、にがての きろくが ある ときだけ **「にがて れんしゅう」** の ボタンが 出ます（下を 見てください）。

### せってい

せっていは「がめん」だけです（ミス 3かい・パネル 2まい・はやさは きまっています）。

| こうもく | えらべる もの | はじめ |
|---|---|---|
| がめん | ふつう ／ かるい（ふるい タブレット むけ。こまかさと けしきを へらし、スピード線を 出さない） | ふつう |

えらんだ コースと がめんは、つぎに 開いた ときも のこります。

## まなびの しくみ

ただ はやく 走る だけで なく、**まちがえた 九九を その場で なおして おぼえる** ように つくっています。

1. **まちがえた しゅんかんに 正しい 九九を 見せる**
   ころんだ 直後、画面の 下に `8 × 9 = 72` と となえかた「はっく しちじゅうに」を 大きく 出します（約2.4びょう）。
   正しい パネルは みどりに かわります。この あいだ スピードは ゆっくりに なるので、落ちついて 見られます。
   はやさも はじめに もどるので、つづく「もういちど！」は ゆっくりの うちに こたえられます。
2. **まちがえた 九九は「もういちど！」で また 出る**
   まちがえた 九九は 約3問 あとに ピンクの ゲート「もういちど！」で 出ます。正解すると、さらに 約6問 あとに もう1回。
   **2回 つづけて 正解するまで** くりかえし 出ます（とちゅうで まちがえたら やりなおし）。
3. **にがてな 九九ほど よく 出る**
   九九ごとの 正解・まちがいの 数を この 端末に のこし、にがてな ものほど 出やすく します（まちがい 1回で 2・正解 1回で 1 へる「にがて度」0〜6）。
   たくさん 正解すると にがて度は 0 に もどります。
4. **まちがえ やすい パネルを ならべる**
   まちがいの パネルは でたらめな 数では なく、**おなじ だんの となり**（7×8 なら 49・63）を いちばん 多く、
   つぎに となりの だん（48・64）・数字の いれかえ（65）・1や 2 ちがい を まぜます。あてずっぽうでは あたりにくく します。
5. **おわった あとの「おさらい」と「まちがえた 九九を れんしゅう」**
   おしまい の 画面に まちがえた 九九と となえかたを ならべます。
   「まちがえた 九九を れんしゅう」を おすと、その 九九だけを 2回ずつ 正解するまで 走る コースに なります
   （あいだには おなじ だんの 九九が まざります）。
6. **はじめの 画面の「にがて れんしゅう」**
   これまでの きろくから にがて度の 高い 九九（9こ まで）を あつめて れんしゅうします。

## 演出

- 正解の たびに「せいかい！」→ 5れんぞくで「いいね！」→ 10「すごい！」→ 20「ちょうはやい！」→ 30「でんせつ！！」
- **5れんぞく ごと**に 画面が ピカッと 光って 音が 鳴る
- 速く なると スピード線が とび、カメラが すこし ひろがる
- まちがえると 画面が 赤く 光って ゆれる

## おもく しない くふう

- 3D は Three.js（r158 の `build/three.min.js` を `lib/` に 同梱。さいしょの「ふるい 形式」の 警告 1行だけ はずしています）
- かげの 計算は しない（足もとに まるい 影の 板を おくだけ）。ライトは 2つ・かるい 材質（Lambert）
- 木・ブロック・道の 点線・かけら・スピード線は **InstancedMesh**（何十こ あっても 1回で かく）
- けしきは グループごと うごかし、うしろへ ぬけた ものだけ 前へ もどす。点線は 1しゅうき ぶん ずらすだけ
- ゲートは 4つを つかいまわす
- **数字は さいしょに 1まいだけ つくった 字の 絵**（0〜9・×・＝・？ の 13字）を 組みあわせて 出す。
  あそんで いる 間は 絵を かきなおさず、GPU へ 絵を おくりなおさない（ゲートが 来るたびの 一瞬の 止まりを なくす）
- **あそぶ まえに ぜんぶの 材質を じゅんび**して おく（スピード線などが はじめて 出た ときに 止まらない）
- 画面の こまかさは 1.5倍まで。**おそい フレームが ずっと つづく ときだけ 1回 下げ、上げなおさない**
  （こまかさの きりかえは 一瞬 止まるので、上げ下げを くりかえさない）
- 音・よみあげは ない（ブラウザの 音声合成は 端末に よって 画面が 止まる 原因にも なる）
- はじめの 画面・おしまいの 画面の うしろの 走る 絵は 1びょう 30コマに おとす。ひとやすみ中は かかない
- 文字（問題・れんぞく・ほめことば）は 3D では なく HTML で 重ねる
- ほかの タブに うつると じどうで ひとやすみ

## きろく

この 端末の ブラウザ（localStorage の `kuku-run-v1`）に のこります。サーバーには おくりません。

- せってい・えらんだ コース
- ベスト（コースごとの さいこう れんぞく数）
- 九九ごとの 正解・まちがいの 数（にがて度に つかう）

はじめの 画面の いちばん 下の「きろくを けす」で けせます。
