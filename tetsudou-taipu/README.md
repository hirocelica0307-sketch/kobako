# 岡山鉄道タイピング（OKAYAMA RAIL TYPING）

岡山県内を走る鉄道の駅名を、ローマ字で打って進むタイピングゲームです。

岡山駅を起点に路線を選び、駅に着くたびに駅名を打ち込みます。打ち切ると発車して次の駅へ。
駅を通過するごとに**運賃**が積み上がり、制限時間内にどこまで行けるか＝いくら稼げるかを競います。
難読駅名の読みを覚えながら、自然と打鍵速度が上がるように作っています。

> **Phase 1（現在）**: 山陽本線 下り（岡山→笠岡）・60秒モードが遊べます。
> 残り14路線・路線選択画面・音・所見…は Phase 2 以降で追加します。

## 遊び方

| キー | 動作 |
|---|---|
| `Space` | タイトル → 路線をえらぶ（地図） |
| `↑ ↓` | 路線をえらぶ |
| `← →` | 制限時間（60/120/180秒）をえらぶ |
| `Enter` | つぎへ／発車 |
| `M` | 音の ON / OFF（入力中は打鍵として扱われます） |

ゲーム中はいつでも `Esc` でメニューが開きます（つづける／さいしょから／音の ON・OFF／タイトルへもどる）。
| `A`〜`Z` | 駅名をローマ字で入力 |
| `Esc` | 一時停止（メニューから再開・最初から・タイトルへ戻る） |
| `R` | もう一度／`T` タイトルへ戻る |

**日本語入力（IME）は OFF にしてください。** ON のままだと1打鍵ごとの判定ができないため、
検知して警告を出し、ゲームを一時停止します。

本作は**PCキーボード専用**です。スマートフォンのソフトキーボードでは打鍵判定が成立しません。

### 打ち方は1つではありません

複数のローマ字表記をすべて受け付けます。自分の打ち慣れた方式で構いません。

| 読み | 受け付ける綴りの例 |
|---|---|
| 新倉敷（しんくらしき） | `shinkurashiki` / `sinnkurasiki` / `shinnkurashiki` |
| 茶屋町（ちゃやまち） | `chayamachi` / `tyayamati` / `cyayamati` |
| 備中神代（びっちゅうこうじろ） | `bicchuukoujiro` / `bittyuukouziro` / `biltuchuukoujiro` |

ヒント表示は**打ち始めた綴りに追従**します。`し` に `s` を打った時点では `shi` のまま表示され、
`si` 派の人が `i` を打った瞬間だけ切り替わります。正攻法で打つ人のヒントは一切揺れません。

### 撥音「ん」に注意

「ん」を `n` ひとつで打てるのは、**次のかながあ行・な行・や行・ん以外**のときだけです。
語尾の「ん」も `nn` が必要です。

- 金光（こんこう）→ `konkou` でも `konnkou` でも可
- 早雲の里荏原（そううんのさとえばら）→ 「ん」の次が「の」なので `souunnnosatoebara`（`n` が3つ）

## 開発

```bash
npm install
npm run dev     # 開発サーバ
npm test        # ローマ字エンジンの検証（ここが本プロジェクトの生命線）
npm run build   # 本番ビルド
```

### 設計の要点

- **かなが唯一の真実**。駅データには読み（かな）だけを書き、ローマ字は `src/engine/kana/` が導出します。
  ローマ字を手で持つと必ずテーブルと食い違うため、型レベルで分離しています。
- **促音は次のチャンクに吸収**します。`っち` を `cchi` と打つとき重ねる子音は次チャンクで選ばれた
  綴りに依存するので、ノードを分けるとノード間の制約が必要になり判定器が破綻します。
- **撥音は次の「かな」を先読み**して単独 `n` の可否を決めます。
- **判定器は commit-and-retry 方式**。現ノードを伸ばせなくても既に完成形なら確定して、
  同じキーを次ノードの先頭として解釈し直します（`ん` を `n` で打った直後に子音が来るケース）。
- **ドット絵はすべてコード内で定義**しています（外部画像なし）。形状を「意味」で塗り分け、
  色はリバリー（塗装）で与えるので、形状5種 × 塗装9種で多数の車両を賄えます。
  → `src/render/sprites/` と `src/render/palette.ts`
- **Canvas に日本語を描きません。** 背景・線路・列車は Canvas（320×180 を整数倍拡大）、
  駅名と HUD は DOM。打鍵ごとの部分着色とレイアウトは DOM のほうが圧倒的に扱いやすいためです。

### テスト

`npm test` には、全駅名＋今後投入予定の難読駅に対して
「各ノードからランダムに綴りを選んで連結した打鍵列」を100回ずつ流し、
**必ずミス0で完走する**ことを検証するプロパティテストが含まれます。
駅データを増やしたときにエンジンが破綻したら、ここで落ちます。

## 収録路線（15路線・190駅）

やさしい順に、東山本線（岡電）・吉備線（桃太郎線）・水島本線・宇野線・瀬戸大橋線・
山陽本線・山陽新幹線・赤穂線・津山線・因美線・智頭線・伯備線・芸備線・姫新線・井原線。

瀬戸大橋線では実際に**瀬戸大橋を渡る画**になり、区間ごとに海・川・山・トンネル・
街なかと風景が変わります。天気は晴れ・くもり・夕焼け・雨・雪から**プレイのたびに**
引き直され、山あいの路線ほど雪が出やすくなっています。

## 運賃と乗客

運賃は**実際のきっぷと同じ通し計算**（発駅からの累計営業キロで引く）で、
事業者ごとに運賃表を分けています。JR は幹線と地方交通線で水準が違い、
岡山電気軌道は均一運賃、水島臨海・井原鉄道・智頭急行は独自の運賃表、
山陽新幹線は運賃に自由席特急料金を上乗せします。

> **実際の額に近づけてはいますが、完全に一致することは保証しません。**
> 運賃は改定されますし、特定区間運賃や幹線と地方交通線をまたぐ計算など
> 細かい規則があるため、「営業キロの帯 × 事業者ごとの水準」で近似しています。
> 正確な額は各事業者の案内で確認してください。
> なお画面の「うんちん」は実際の運賃、ボーナスは別に表示しています。

駅に着くたびにお客さんが乗り降りします。大きな駅ほど多く乗り、
ノーミスで打てた駅は多めに乗ります。**のべ何人をのせて走ったか**が記録に残ります。

## 音について

効果音も BGM も、**音声ファイルを一切持たず Web Audio で合成**しています。
路線ごとに違う曲が流れます。

**実在の駅メロディ（各駅の発車・到着メロディ）は著作権で保護された楽曲なので使用していません。**
本作の曲はすべて、この作品のために書き下ろしたオリジナルです。

## 注意事項

- **運賃はゲーム用の簡易計算**であり、実際の運賃とは異なります。
  擬制キロ・特定区間運賃などは再現していません。
- 駅名の読みには誤りが含まれている可能性があります。お気づきの点は Issue でお知らせください。
- 本作は**非公式のファンメイド作品**であり、各鉄道事業者とは一切関係ありません。
  事業者のロゴ・マーク・実在車両の図面は使用しておらず、ドット絵はすべてオリジナルの表現です。
