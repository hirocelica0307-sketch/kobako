# かいて あてて

お題を 絵に かいて、みんなに あててもらう ゲームです。
**さいしょから さいごまで、画面を さわるだけ**で あそべます
（キーボードは つかいません）。

## いま できること（段階4／全5段階）

- なまえを **画面の ひらがなキーボード**で いれる
- **へやを つくる**（4けたの ばんごうが 出ます）
- **4けたの ばんごう**を 画面の テンキーで いれて、へやに はいる
- へやに あつまった 人が、**入ってきた じゅんに ならんでいく**
- へやの **ぬしが「はじめる」を おすと、みんなの 画面が いっせいに** おえかきに かわる
  - ぬしは「あつまるに もどる」で いつでも 戻せます
  - あとから 入ってきた人は、もう はじまっていれば すぐ おえかきの 画面に なります
- **じゅんばんに かく**（はじめる ときに 順番を シャッフルします）
  - **むずかしさ**（3つ）と **なんしゅう**（1しゅう／2しゅう）を ぬしが えらびます
  - 「2 / 8 かいめ　◯◯さんの ばん」と 出ます
  - **1かい 90びょう**。のこり 15びょうで 赤く なります
  - ぜんいんが あてるか、時間が くると その かいは おしまい
- **おだい**
  - **かく人にだけ** おだいが 見えます
  - ほかの人は **ひらがなの キーボードで こたえます**
  - あたれば「せいかい！」、ちがえば「ちがうみたい。もういちど！」
  - おわると **こたえが みんなに 出ます**
- **とくてん と けっか はっぴょう**
  - こたえた 人 … はやい順に **5・4・3てん**、そのあとは **2てん**
  - かいた 人 … あてて もらえた 人 1人に つき **2てん**
  - さいごに **じゅんいと てんすう**が 出ます（🥇🥈🥉）
  - ぬしは とちゅうでも「おわりに する」で けっかに いけます
- **絵を かく**（かく人 だけ）
  - かいている とちゅうの 線が、**のびていく ようすが そのまま** ほかの人に 見える
  - いろ 7つ ／ ふとさ 3つ ／ けしゴム
  - **もどす**（じぶんが かいた 線を 1本ずつ）／**ぜんぶ けす**
  - あとから 入ってきた人にも、**それまでの 絵が ぜんぶ** 出る

先生用の 進行画面と 音は まだです（段階5）。

## お題（ぜんぶで 340語）

| むずかしさ | 数 | ねらい |
|---|---|---|
| ていがくねん | 120語 | 1・2年。身の まわりの もの |
| ちゅうがくねん | 110語 | 3・4年。ようすや 場所も |
| こうがくねん | 110語 | 5・6年。考えれば 絵に できる もの |

お題を 足すときの きまりは `odai.js` の 先頭に 書いてあります。

- **ひらがな だけ**（こたえるのも ひらがなの キーボードなので）
- **6文字 いない**（時間内に 入れられる 長さ）
- **絵に かける もの**（「しお」「べんきょう」のような ものは 入れない）
- **同じ ものを 2回 入れない**

## 画面タッチだけで 入力する しくみ

| いれるもの | つかう キーボード |
|---|---|
| なまえ | **ひらがな 五十音表**（47文字）＋「てんてん」「まる」「ちいさく」「けす」「ぜんぶけす」 |
| へやばんごう | **テンキー**（0〜9・けす）。4けた そろうと ボタンが 光ります |

「てんてん」「まる」「ちいさく」は、**最後の 1文字**を かえます。
もう一度 おすと 元に もどります（`し` →「てんてん」→ `じ` →「てんてん」→ `し`）。
記号（゛゜）ではなく 言葉で 出しているのは、低学年でも 意味が わかるようにするためです。

## この作りに した 理由

**① だれかを あらわす ID は、タブごとに 作ります**

名前から ID を 作る やり方だと、**同じ名前の子が 2人 いると 席が ぶつかります**。
このアプリは タブごとに べつの ID を 出すので、同じ名前が 何人 いても だいじょうぶです。
先生が 1台で **いくつも タブを 開いて ためす**ことも できます。

**② つうしんが できなくても、画面は 出ます**

Firebase の 読みこみを 後まわしに しているので、ネットが つながらない 場所でも
キーボードは 出ます。「まっしろで 何も 起きない」状態に なりません。

**③ おだいの ことばは、そのまま おきません**

ことばを そのまま おくと、こたえる人の 画面から 見えてしまいます。
そこで **数字に かえた もの（hash）だけ**を おき、ことばは
**かく人の タブだけ**が おぼえています。こたえも 数字に かえて くらべるので、
こたえる人の 画面に ことばは 一度も 来ません。

（とても むずかしい 暗号では ありませんが、ふつうに 遊ぶ ぶんには 十分です）

**④ 線は 2まいの canvas に 分けて かきます**

下の ばんに「かき おわった 線」、上の ばんに「かいている とちゅうの 線」。
こうすると、線が 何百本に ふえても、**かいている あいだの 画面が おそく なりません**
（とちゅうの 線だけ かきなおせば よいため）。

**⑤ 切れても 席は のこります**

とちゅうで つうしんが 切れた人は「はなれて います」と 出ますが、席は のこります。
同じ タブで 開きなおせば、同じ席に もどれます。

## ためし方（1人で 3人ぶん）

1. **タブを 3つ**ひらく（タブの「複製」は つかわず、**新しい タブに URL を はる**）
2. 1つ目で なまえを いれて **「へやを つくる」** → 4けたの ばんごうが 出る
3. 2つ目・3つ目で、**ちがう なまえ**を いれて、その ばんごうで **「へやに はいる」**
4. 3つの 画面すべてに、3人の なまえが ならべば せいこうです

Firebase の **Realtime Database →「データ」**タブを 見ると、
`rooms/（ばんごう）/members` の下に 3人 ならんでいるのが わかります。

## Firebase の 設定

いまは プロジェクト **`hiro-kobako`**（ロケーション `asia-southeast1`）を つかいます。
つくりなおすときは **`firebase-config.js` の 5行**だけ 書きかえます。

### ルールを はる

Realtime Database の **「ルール」**タブに、`database.rules.json` の 中身を はって
**「公開」**を おしてください。

```json
{
  "rules": {
    "rooms": {
      "$code": {
        ".read": "auth != null",
        ".write": "auth != null",
        ".validate": "$code.matches(/^[0-9]{4}$/)"
      }
    }
  }
}
```

サインインした 人だけが 読み書きでき、**4けたの 数字いがいの 場所には
何も 書けません。**

### 匿名サインインを 有効に する

**Authentication →「ログイン方法」→「匿名」**を 有効に してください。
これを わすれると、**ボタンを おしても 何も 起きない**ように 見えます。

## データの かたち

```
rooms/
  0725/
    info/     createdAt（作った 時こく）／hostId（へやの ぬし）
              phase … 'waiting'（あつまる）／'playing'（おえかき）
                      ぬしが かえると みんなの 画面が いっせいに かわります
    members/
      m1a2b3c4/  name（なまえ）／color（色）／isHost／online／joinedAt
    live/
      m1a2b3c4/  いま かいている とちゅうの 線（ふでを はなすと 消えます）
    strokes/
      -Nxxxx/    かき おわった 線　color／w（ふとさ）／pts（点の ならび）
    game/
      order[]    かく じゅんばん（はじめる ときに シャッフル）
      laps       なんしゅう するか
      turn       いま なんかいめか
    scores/
      m1a2b3c4   その人の てんすう
    round/
      drawer     かく人の メンバーID
      level      むずかしさ（low／mid／high）
      hash       おだいを 数字に かえた もの（※ ことばは 入れません）
      startedAt  はじまった 時こく
      endsAt     おわる 時こく（のこり時間は ここから 計算します）
      answered/  あてた人の メンバーID → あてた 時こく
      word       おわった あとだけ、こたえを ここに 出します
      done       この かいが おわったか
```

## だれが 何を きめるか

みんなが かってに 書きこむと ぶつかるので、**やる人を 1つに しぼって**います。

| すること | する人 |
|---|---|
| ゲームを はじめる（じゅんばん・リセット） | へやの ぬし |
| おだいを えらぶ・時間を セットする | **その かいの かく人** |
| とくてんを つける・こたえを 出す | **その かいの かく人** |
| つぎの 人へ すすめる | かく人（ぬしも できます） |

かく人の タブが きゅうに いなくなっても、**ぬしが「つぎの 人へ」で すすめられます。**

線の 点は **0〜1000 の 整数**で もちます。画面の 大きさが ちがっても
同じ かたちに なるようにするためです（ばんの たて よこの 比は 4:3 に そろえています）。

部屋番号は **4けた**。作るときに、すでに つかわれている 番号は とばします
（6時間 たった 部屋は つかいまわします）。
