# かいて あてて

お題を 絵に かいて、みんなに あててもらう ゲームです。
**さいしょから さいごまで、画面を さわるだけ**で あそべます
（キーボードは つかいません）。

## いま できること（段階6）

- なまえを **画面の ひらがなキーボード**で いれる
- **へやを つくる**（4けたの ばんごうが 出ます）
- **4けたの ばんごう**を 画面の テンキーで いれて、へやに はいる
- へやに あつまった 人が、**入ってきた じゅんに ならんでいく**
- へやの **ぬしが「はじめる」を おすと、みんなの 画面が いっせいに** おえかきに かわる
  - ぬしは「あつまるに もどる」で いつでも 戻せます
  - あとから 入ってきた人は、もう はじまっていれば すぐ おえかきの 画面に なります
- **あそびかたを 4つから えらべます**（ぬしが えらびます）
  - **じゅんばん** … みんなが おなじ かいすう かきます（1・2・3しゅう）
  - **ランダム** … つぎに かく人を くじびきで きめます。
    かいすうの かぎりが ないので、**ぜんたいの じかん**で おわります
  - **チームせん** … あかぐみ・あおぐみに わかれます（4人 いじょう）。
    かいた人と **同じ チームの 人だけ**が こたえます。あいての チームは 見て おうえん（👍 など）
    - かく じゅんばんは あか → あお → あか … と こうたい。人数が ちがっても、どちらも 同じ 回数 かきます
    - チームの てんすうは「あてた 人の **わりあい**」で つけます（ぜんいん あてたら 10てん、半分なら 5てん）。
      人数が 多い チームが とくを しない ためです
    - けっかで **かった チーム**を 出します（🏆）
  - **でんごん** … おえかき でんごんゲーム（2人 いじょう）。みんな **同時に** あそびます
    1. じぶんの おだいを 絵に かく →「できた！」
    2. となりの 人の 絵が まわってくるので、なにか こたえる
    3. まわってきた ことばを 絵に かく … を くりかえします
    - 何だん あそぶかは 人数で きまります（2・3人 → 2だん、4・5人 → 4だん … さいだい 8だん）。
      さいごは かならず「ことば」で おわり、じぶんの すじが じぶんに もどって こないように しています
    - 絵を かく 時間は「1かいの じかん」、こたえる 時間は 40びょう。時間が くると、そこまでの 絵や ことばが じどうで でます
    - ぬしの「つぎの だんへ」は、**時間を いま おわりに する** ボタンです（とちゅうの 絵も ちゃんと とどきます。もう一度 おすと すぐ すすみます）
    - さいごに すじを 1本ずつ ならべて はっぴょう。**もとの ことばに もどったら 🎉**
- **じかんは ぜんぶ ボタンで きめます**（キーボードは つかいません）
  - **ぜんたいの じかん** … 1〜99ふん、1ふん きざみ。**はじめは 5ふん**（ランダムの とき）
  - **1かいの じかん** … 30〜120びょう、1びょう きざみ。**はじめは 60びょう**
  - 「－10 －1 ＋1 ＋10」を おして かえます
  - のこり 3ぶんの1 に なると 赤く なります
  - ぜんいんが あてるか、時間が くると その かいは おしまい
- **おだい**
  - **かく人にだけ** 見えます。しかも **画面の 下の 左はしに 小さく** 出します
    （まわりの 席から 見えて しまわない ように）
  - **「かくす」ボタン**で ● に できます。えらんだ ことは おぼえます
  - ほかの人は **ひらがなの キーボードで こたえます**
  - あたれば「せいかい！」、ちがえば「ちがうみたい。もういちど！」
  - おわると **こたえが みんなに 出ます**
- **ポップな 文字**（Google Fonts の Mochiy Pop One ／ M PLUS Rounded 1c）
  - タイトルは 1文字ずつ 色を かえて、ふわふわ うごきます
  - フォントが よみこめない ときは、まるい 文字で 出ます
- **どの 画面でも スクロールしません**
  - 絵・キーボード・ボタンの 大きさが、画面の あきに 合わせて かわります
  - ギャラリーと でんごんの はっぴょうは、はこの 中だけ スクロールします（ページは うごきません）
- **おと**（音の ファイルは つかわず、その場で つくります）
  - あたった／ちがった／のこり3びょうの カウントダウン／かいの おわり／
    じぶんの ばん／けっかの ファンファーレ
  - 上の帯の **「おと」ボタン**で 入り・切り（**その 端末だけ**の せってい）
- **ぬし（先生）は 2つの 入り方を えらべます**
  - **あそぶ** … みんなと いっしょに さんかします
  - **かんりする** … ゲームには 入らず、すすめる 役に まわります
- **ボタンは ぜんぶ ぬしが おします**（かく人は 絵を かくことに 集中できます）
  - **つぎの 人へ** … とちゅうでも 交代できます
  - **おだいを かえる** … むずかしすぎる ときに 引きなおします
  - **いちじ ていし ／ さいかい** … 時計も 止まります
  - **おわりに する** … けっかに すすみます
- **かんりする ときの 画面**
  - みんなの **ようす**（かいています／◯ばんめに せいかい／まだ／はなれて います）
  - **まちがえた 回数**（✕3 など）… こまっている子が わかります
  - 絵は みんなと 同じ ものが 見えます
- **とくてん と けっか はっぴょう**
  - こたえた 人 … はやい順に **5・4・3てん**、そのあとは **2てん**
  - かいた 人 … あてて もらえた 人 1人に つき **2てん**
  - さいごに **じゅんいと てんすう**が 出ます（🥇🥈🥉）。かみふぶきも ふります
  - ぬしは とちゅうでも「おわりに する」で けっかに いけます
- **みんなの え（ギャラリー）**
  - けっかの 画面で「みんなの え」を おすと、その ゲームで かいた 絵が ぜんぶ ならびます
    （おだい・かいた人・もらった リアクションの 数つき）
  - 絵を おすと 大きく 見られます（まえ／つぎ で めくれます）
- **ヒント**
  - 絵の 上に、はじめは **文字の 数**だけ「○」が 出ます（例：ヒント ○○○ 3もじ）
  - 時間が たつと 1文字ずつ 見えて きます（3分の1で 1文字、3分の2で 2文字め。ぜんぶは 見せません）
- **おしい！**
  - 1文字 ちがう・1文字 たりない・1文字 おおい ときは「おしい！ もうすこし！」と 出ます
    （例：おだいが「りんご」で「りんこ」「りご」「りんごう」）
- **せいかいの おいわい**
  - じぶんが あたると **かみふぶき**、こたえに「🥇 1ばん！」などの じゅんいが つきます
  - ほかの人が あたると、絵の 上に「はなこ さん せいかい！ 🥇 1ばん！」と ふきだしが 出ます
  - ぜんいん あたると「ぜんいん せいかい！ 🎉」
- **リアクション**
  - 絵を 見ている 人は、絵の 右下の **👍 😂 😮 ❤️ 👏** を おせます。みんなの 絵の 上に ふわっと うかびます
  - 絵が にがてな 子も ほめて もらえます（つづけて おせるのは 0.6びょう おき）
- **絵を かく**（かく人 だけ）
  - かいている とちゅうの 線が、**のびていく ようすが そのまま** ほかの人に 見える
  - いろ 7つ ＋ **にじいろ** ／ ふとさ 3つ ／ けしゴム
  - **どうぐ**：ペン ／ **ぬる（バケツ）** ／ **ほし・ハートの スタンプ**（大きさは ふとさで かわります）
    - にじいろの ペンは すすむ ほど 色が かわり、スタンプ・バケツは おすたびに ちがう 色に なります
  - **もどす**（じぶんが かいた 線を 1本ずつ）／**ぜんぶ けす**
  - あとから 入ってきた人にも、**それまでの 絵が ぜんぶ** 出る

## 画面タッチだけで 入力する しくみ

| いれるもの | つかう キーボード |
|---|---|
| なまえ | **ひらがな 五十音表**（47文字）＋「てんてん」「まる」「ちいさく」「けす」「ぜんぶけす」 |
| へやばんごう | **テンキー**（0〜9・けす）。4けた そろうと ボタンが 光ります |

キーは **行ごとに うすく 色を かえて**います（あ行・か行・さ行 …）。
ぜんぶ 同じ色だと 目が すべって 文字を さがしにくく なるためです。
文字の 色は 変えず、うしろだけ 染めているので 読みやすさは そのままです。

「てんてん」「まる」「ちいさく」には、**しるしも いっしょに** 出しています
（゛ と ゜ は 1文字で 出すと とても 小さく なるので、線と まるで えがいています）。
読む まえに 見て わかります。

「てんてん」「まる」「ちいさく」は、**最後の 1文字**を かえます。
もう一度 おすと 元に もどります（`し` →「てんてん」→ `じ` →「てんてん」→ `し`）。
記号（゛゜）ではなく 言葉で 出しているのは、低学年でも 意味が わかるようにするためです。

## この作りに した 理由

**① だれかを あらわす ID は、タブごとに 作ります**

名前から ID を 作る やり方だと、**同じ名前の子が 2人 いると 席が ぶつかります**。
このアプリは タブごとに べつの ID を 出すので、同じ名前が 何人 いても だいじょうぶです。
先生が 1台で **いくつも タブを 開いて ためす**ことも できます。

**② つうしんが できなくても、画面は 出ます**

Firebase の 読みこみを 後まわしに しているので、ネットが つながらない 場所でも
キーボードは 出ます。「まっしろで 何も 起きない」状態に なりません。

**③ おだいの ことばは、そのまま おきません**

ことばを そのまま おくと、こたえる人の 画面から 見えてしまいます。
そこで **数字に かえた もの（hash）だけ**を おき、ことばは
**かく人の タブだけ**が おぼえています。こたえも 数字に かえて くらべるので、
こたえる人の 画面に ことばは 一度も 来ません。

（とても むずかしい 暗号では ありませんが、ふつうに 遊ぶ ぶんには 十分です）

**④ 線は 2まいの canvas に 分けて かきます**

下の ばんに「かき おわった 線」、上の ばんに「かいている とちゅうの 線」。
こうすると、線が 何百本に ふえても、**かいている あいだの 画面が おそく なりません**
（とちゅうの 線だけ かきなおせば よいため）。

**⑤ 「みんなの 画面」を うつす ひつようは ありません**

先生が 見たいのは「だれが どう こまっているか」ですが、
**絵は みんな 同じ ものを 見ています**。ちがうのは こたえの ようす だけ。
そこで 画面を うつすのでは なく、**ようすを ならべて 見せて**います。
かるくて、通信も ふえません。

**⑥ 入力する ところの 高さは 固定です**

高さを 中身に あわせると、1文字目を 入れた とたんに 高さが かわり、
下の キーボードが すこし ずれます。**height で 固定**して ずれを なくしています。

**⑦ 画面から はみ出さない ように、大きさを 計算で きめています**

CSS の のびちぢみ だけだと、せまい 画面で **絵が ばしょを とりすぎて
キーボードが つぶれます**。そこで 絵と キーボードは、**のこりの ばしょを
はかって 大きさを きめて**います（`board.js` と `keypad.js`）。

たての ばしょが たりない ときは、かざり（見出しや しらせ）を へらして
キーボードに まわし、それでも たりなければ **キーを よこ長**に します。
たて よこ 両方を ちぢめると、キーが 小さすぎて 押せなく なるためです。

**8つの 大きさ × 5つの 画面 ＝ 40とおり**で、
（段階6 では さらに、あそびかた 4つの せってい・チームせん（かく人／こたえる人／おうえん）・
けっか・ギャラリー・でんごん（かく／こたえる／はっぴょう）も 8つの 大きさで たしかめています）

ページの はみ出し・キーボードの 切れが ないことを たしかめています
（1092×614・1152×648・1366×640・1024×768・1280×720・1280×800・
1366×768・1920×1080）。どの ばあいも キーは 45px いじょう です。

**⑧ おだいは 小さく、下の 左はしに**

大きく まん中に 出すと、となりの 席からも 読めて しまいます。
下の 左はしに 小さく 出し、**「かくす」**で ● に できるように しました。

**⑨ 切れても 席は のこります**

とちゅうで つうしんが 切れた人は「はなれて います」と 出ますが、席は のこります。
同じ タブで 開きなおせば、同じ席に もどれます。

## ためし方（1人で 3人ぶん）

1. **タブを 3つ**ひらく（タブの「複製」は つかわず、**新しい タブに URL を はる**）
2. 1つ目で なまえを いれて **「へやを つくる」** → 4けたの ばんごうが 出る
3. 2つ目・3つ目で、**ちがう なまえ**を いれて、その ばんごうで **「へやに はいる」**
4. 3つの 画面すべてに、3人の なまえが ならべば せいこうです

Firebase の **Realtime Database →「データ」**タブを 見ると、
`rooms/（ばんごう）/members` の下に 3人 ならんでいるのが わかります。

## Firebase の 設定

いまは プロジェクト **`hiro-kobako`**（ロケーション `asia-southeast1`）を つかいます。
つくりなおすときは **`firebase-config.js` の 5行**だけ 書きかえます。

### ルールを はる

Realtime Database の **「ルール」**タブに、`database.rules.json` の 中身を はって
**「公開」**を おしてください。

```json
{
  "rules": {
    "rooms": {
      "$code": {
        ".read": "auth != null",
        ".write": "auth != null",
        ".validate": "$code.matches(/^[0-9]{4}$/)"
      }
    }
  }
}
```

サインインした 人だけが 読み書きでき、**4けたの 数字いがいの 場所には
何も 書けません。**

### 匿名サインインを 有効に する

**Authentication →「ログイン方法」→「匿名」**を 有効に してください。
これを わすれると、**ボタンを おしても 何も 起きない**ように 見えます。

```
      endsAt     おわる 時こく（のこり時間は ここから 計算します）
      answered/  あてた人の メンバーID → あてた 時こく
      misses/    まちがえた 回数（先生が こまっている子を 見つける ため）
      reroll     ぬしが「おだいを かえて」と たのんだ 時こく
      word       おわった あとだけ、こたえを ここに 出します
      done       この かいが おわったか
```

## だれが 何を きめるか

みんなが かってに 書きこむと ぶつかるので、**やる人を 1つに しぼって**います。

| すること | する人 |
|---|---|
| ゲームを はじめる（じゅんばん・リセット） | へやの ぬし |
| **ボタンの そうさ ぜんぶ**（つぎへ・おだい・ていし・おわり） | **へやの ぬし** |
| 止まった ときに すすめる（かく人が いなく なった とき） | へやの ぬし |
| おだいを **えらぶ**・時間を セットする | その かいの かく人 |
| とくてんを つける・こたえを 出す | その かいの かく人 |
| ヒントを 出す（ことばを 知って いるのは かく人だけ） | その かいの かく人 |
| 絵を ギャラリーに のこす（つぎへ すすむ まえに） | へやの ぬし |
| でんごん：だんを すすめる・まだの 人の ぶんを うめる | へやの ぬし |

ぬしは おだいの **ことばを 知りません**。だから「おだいを かえる」は、
**「かえて」と たのむ しるしを おく**だけ。それを 見た かく人の タブが
えらびなおします。こうすれば ぬしに ことばが 見えません。

かく人の タブが きゅうに いなくなっても、**ぬしが「つぎの 人へ」で すすめられます。**

さらに、**止まったままに ならない 見はり**を 入れています。

| こうなったら | どうする |
|---|---|
| おだいが 8びょう たっても 出ない（かく人が いない） | ぬしが つぎの 人に すすめます |
| 時間が すぎて 3びょう たっても おわらない（かく人が いない） | ぬしが とくてんを つけて おわらせます |

「つぎの 人へ」が おせない ときは、だまって 何も しないのでは なく、
**わけを 画面に 出します**。

線の 点は **0〜1000 の 整数**で もちます。画面の 大きさが ちがっても
同じ かたちに なるようにするためです（ばんの たて よこの 比は 4:3 に そろえています）。

部屋番号は **4けた**。作るときに、すでに つかわれている 番号は とばします
（6時間 たった 部屋は つかいまわします）。
