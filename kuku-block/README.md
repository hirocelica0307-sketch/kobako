# ブロック おはじき

2年生の **九九（かけ算）** の学習で、**数図ブロックや さくらの おはじきを ならべたり、まるで かこんだり、
教科書の しゃしんに かさねたり** できるアプリです。Chromebook での利用を想定しています。
正解・不正解の判定はなく、子どもが **自由に さわって 考える** ための道具です。

（はじめは「くく ブロック」という なまえでした。URL が かわらない ように、フォルダー名は `kuku-block/` の ままです）

## ひらきかた

**https://hirocelica0307-sketch.github.io/kobako/kuku-block/**

`index.html` をブラウザ（Chrome）で開くだけ。インストールもログインも不要です。
ファイルとして開いても（`file://`）、Web サーバーに置いても動きます
（コードで くばる「きょうゆう」だけは Web の ほうで つかってください）。

```
cd kuku-block
python3 -m http.server 8000    # → http://localhost:8000
```

つくえ（ページ）の ようすは その端末の ブラウザに 自動で のこり、次に開くと つづきから 使えます。

## できること

### ページ（タブ）
**いちばん うえ** に、Chromebook の ブラウザと おなじ かたちの タブが あります。
- タブを おすと その ページへ。1ページ ずつ、ブロック・しゃしん・もどすの れきしを べつべつに もちます
- **＋** で まっしろな ページを ふやす（20まい まで）。**✕** で とじる（なにか ある ページは「とじますか？」と きく）
- **しゃしんを 入れた とき、いまの ページに もう はいけいが あれば、あたらしい タブに なります**。
  「まえの はいけいに もどしたい」「まっしろに したい」ときは、タブを おすだけです
- タブの なまえは はいけいの なまえ（ファイル名・おさら 4まい など）。まっしろの ページは「まっしろ」

### つくえを 大きく・小さく
- **2本ゆびで ピンチ**（ひろげる → 大きく、つまむ → 小さく・ひろく）。うごかす ことも できる（30%〜300%）
- 1本めの ゆびで なにか はじめていても、2本めが ふれたら その そうさは とりけして ズームに なります
- 右下の **−／＋**、**％** を おすと 100% に もどる、**⤢** で ぜんぶ 見える ように
- タッチパッドの ピンチ・<kbd>Ctrl</kbd>＋ホイール でも かわる（ホイールだけ なら うごく）
- ブロックばこを タップした ときや、ならべる・だん は、**いま 見えている ところ** に おきます

### ブロック と さくらの おはじき
- ひだりの はこの **ブロック**（正方形に 青丸・赤丸）と **さくらの おはじき**（青・赤。まるい はなびら 5まいの さくらの かたちで、まん中に じっさいの おはじきと おなじ くろい じしゃく）を **ドラッグして おく**
- はこを **タップ** すると、見えている ところの ひだり うえから じゅんに ならぶ（1だん 10こ）
- **タップ** すると うらがえる（あお ⇔ あか、さくらの あお ⇔ さくらの あか）
- ブロックを **ながおし**（0.5びょう）すると、**くっついている ブロックを まとめて** もてる
- **ごみばこ** に もっていくと すてる（ごみばこを おすと「ぜんぶ けす」）
- **ならべる**：「よこに □こ・たてに □だん」と いろ（ブロック・おはじき）を えらぶと、長方形（アレイ図）で まとめて 出る（1〜10）
- マス目に ぴたっと そろう（せっていで オフにすると 自由な 場所に おける）。かさなった ときは となりの あいた マスへ

### かこむ
- **かこむ** を えらんで ゆびで ぐるっと かくと、**まる（かこみ）** に なる（とじていなくても むすびます）
- かこみの 右うえに **中の ブロックの かず** が 出る（せっていで かくせる）
- **さきに まるを かいて、あとから ブロックを 入れる**（おさらに 3こずつ …）ことも できる
- **うごかす** で かこみを ドラッグすると、**中の ブロックも いっしょに** うごく。ごみばこへ もっていくと 中身ごと すてる
- せっていの **「しきを 見せる」** を オンにすると、かこみから しきを つくって 下に 出す
  - おなじ かず → `3 × 4 = 12`（3こずつ 4つぶん で 12こ）
  - ちがう かず → `3 + 2 + 3 = 8`
  - かこみの 外の ブロックは「のこり □こ」

### くるくる まわす（かこみの つまみ）
かこみの **数字の すぐ 右の ● つまみ** を つまんで、ぐるっと うごかすと、
かこみと 中の ブロックが **すきな かくどに くるくる** まわります。ゆびを はなすと そこで とまります。
- **90°・180° の ちかく**（12° いない）で はなすと **ぴたっと** まっすぐに なり、マス目に そろいます
  （`3 × 4` の ならびが `4 × 3` に。ほかの ものに かさなる ときは まとまりごと あいている ところへ）
- それ いがいの かくどは かたむいた まま（かたむいた ブロックも うごかす・うらがえす・かぞえる が できます）
- つまみは **うごかす** の ときだけ 出ます

### かこみの メニュー（まわす・ふやす）
**うごかす** で かこみを **タップ** すると メニューが 出ます。
- **まわす**：まとまりを 90° まわす（`3 × 4` の ならびが `4 × 3` に。かけ算の じゅんばんを かえても こたえが おなじ ことを 見る）
- **ふやす**：おなじ まとまり（かこみ＋中の ブロック）を あいている ところに もう1つ。「3こずつ」を 1つ つくって 3回 おすと「4つぶん」
- **かこみを けす**：かこみだけ けす（ブロックは のこる）

まわした ときに ほかの ブロックと かさなる ときは、まとまりごと あいている ところへ うつります。

### かぞえる（123）
- **1こずつ**：ブロックを じゅんに タップすると 1、2、3 … と 番号が つく（なぞっても かぞえられる）。まちがえたら さいごの ブロックを もう一度 タップで とりけし
- **まとまりで**：かこみを タップすると 3、6、9 … と **まとまりごとに たして** いく
- 🔈 で かずを よみあげる（🔇 で むおん）。🔁 いちから で やりなおし。ほかの どうぐに かえると 番号は きえます

### くくの だん
- ひだりの **くくの だん** で 1〜9 の だんを えらぶと、1つぶん（1だん）が 出る
- **＋** を おす たびに 1つぶん ずつ ふえ、`3 × 4 = 12`・となえかた（さんし じゅうに）・`3 → 6 → 9 → 12（3ずつ ふえる）` が 出る。**−** で へらす
- となえかたを よみあげる（おとが オンの とき）。81こ ぜんぶ 入っています
- **× 9 まで** かならず おけます。はじめに 9だん ぶんの ばしょを とり、見えない ときは つくえを 小さく して 9だん ぜんぶ 見える ように します
- 「1つぶんを かこむ」（はじめは オン）・いろ（ブロック あお／あか／こうたい、おはじき あお／あか／こうたい）を えらべる
- ✕ で おわると、ブロックは その まま のこる

### おだい
- ひだりの **おだい** から カードを えらぶと、つくえの 左うえに 出る（✕ で しまう）
  - かけ算の いみ（おさら・ながいす・くるま・はこ の ぶんしょうもんだい など）
  - 九九の きまり（まわして くらべる・かける数が 1 ふえると・わけて かんがえる）
  - さがそう（12こを おなじ かずずつ かこむ・こたえが 18 に なる ならべかた など）
- ブロックや イラストが つく カードは、つくえを あたらしく して じゅんびします（「もどす」で もどせる）
- **じぶんで かく**：先生が おだいを 入力して 出せる

### かく・けす
- **かく**：4色（くろ・あか・あお・みどり）× ほそい／ふとい
- **けす**：なぞった ところの 線と かこみを けす（ブロックは けさない）
- **もどす／すすむ**：なんでも もとに もどせる（<kbd>Ctrl</kbd>+<kbd>Z</kbd>／<kbd>Ctrl</kbd>+<kbd>Y</kbd>）

### はいけいの しゃしん（教科書を とって すぐ つかう）
右うえの **📷 しゃしん** から、どれでも **1回の そうさで** はいけいに なります。

| やりかた | そうさ |
|---|---|
| **カメラで とる** | カメラの 画面で まるい ボタンを おすと、その まま はいけいに なる（うしろ／まえの カメラを 🔄 で きりかえ） |
| **ファイルから** | Chromebook の「ファイル」や Google ドライブの しゃしんを えらぶ |
| **はりつける** | コピーした がぞうを はる（<kbd>Ctrl</kbd>+<kbd>V</kbd> なら まどを 開かなくても はいる） |
| **ドラッグ** | ファイルを つくえに ドラッグ＆ドロップ |
| **さいきんの しゃしん** | まえに つかった しゃしん（24まいまで）を タップで すぐ よびだす |
| **イラスト** | おさら・ながいす・くるま・はこ を 1〜9こ ならべた 絵を はいけいに する |

いまの ページに もう はいけいが ある ときは、**あたらしい タブ** に 入ります（まえの はいけいは その まま のこります）。

- 入れた しゃしんは **つくえに ぴったり** の 大きさに なります
- **いち・大きさを かえる**：1本ゆびで うごかす・2本ゆびで 大きく／小さく（マウスは ホイール）・🔄 で 90° まわす・🔲 で ぴったりに もどす
- **うすく**：しゃしんを うすくして、ブロックを 見やすく できる
- しゃしんは 長い 辺 2400px まで 小さくして ブラウザ（IndexedDB）に しまいます。**インターネットには 送りません**

### せってい
せんせいの **🧑‍🏫 → つくえの せってい** に あります（クラスに はいって いる こどもは クラスの せっていが つかわれます）。

| 項目 | 初期値 | 内容 |
|---|---|---|
| マス目に そろえる | オン | ブロックを マス目に そろえ、かさならない ように する |
| かこみの 中の かずを 見せる | オン | かこみの 右うえの 数字 |
| しきを 見せる | オフ | 子どもに 考えさせたい ときは オフの まま |
| おと（こうかおん・よみあげ） | オン | ブロックを おく おと・かぞえる／九九の よみあげ。教室では 音量に ご注意ください |
| ブロックの 大きさ | 48 | 24〜96。教科書の しゃしんの 大きさに 合わせる。ならびかたは そのまま |
| （☰ メニュー）がぞうで ほぞん | — | 見えている つくえを PNG で「ダウンロード」に ほぞん（`block-ohajiki-日づけ.png`。Classroom への 提出などに） |
| ぜんがめん | — | 画面いっぱいに する（テレビや 電子黒板に うつす とき） |
| つかいかた | — | そうさの 一覧 |
| ぜんぶ けす | — | ブロック・かこみ・線を けす（しゃしんは のこる。「もどす」で もどせる） |

### せんせい（🧑‍🏫）
右うえの **🧑‍🏫 せんせい** から ひらきます。はじめて ひらく ときに **せんせいの あいことば（4けた）** を きめます
（こどもが せんせいの がめんを ひらかない ための もの。この たんまつに のこり、タブを とじるまで もう きかれません）。

- **📺 テレビに うつす**：タブ・ボタン・ひだりの はこ を ぜんぶ かくして、つくえ だけを 画面いっぱいに（のって いる もの ぜんぶが 見える 大きさ）。<kbd>Esc</kbd> か 右うえの ✕ で もどる
- **クラス**：クラスを つくる・かえる・けす、**👀 みんなの つくえ**、URL の コピー
- **🔗 コード・ファイルで くばる**（まえの「きょうゆう」）
- **つくえの せってい**（マス目・かず・しき・おと・大きさ。まえの ⚙️ から うつしました）

こどもの ☰ メニュー には「がぞうで ほぞん・ぜんがめん・つかいかた・ぜんぶ けす」だけが のこります。

### クラス（せんせいが きめた じょうたいで こどもが つかう）
1. せんせい → **＋ あたらしい クラスを つくる**
   - クラスの なまえ（2年1組 など）
   - **こどもが つかえる きのう**：ブロック・おはじき・かこむ・かく・けす・かぞえる・まわす／ふやす・ならべる・くくの だん・おだい・しゃしん・ページを ふやす／とじる・ズーム・ぜんぶ けす。
     🔒 に した ものは こどもの 画面から **かくれます**
   - つくえの せってい（マス目・かず・しき・おと・ブロックの 大きさ）
   - はじめに くばる ページ（いまの ページ／ぜんぶの ページ／まっしろ）
   - こどもの つくえを せんせいに 見せる（みんなの つくえ）
2. **URL を つくる** → 出た URL（`…/kuku-block/?class=123456`）を Google Classroom などに はる
3. こどもは URL を ひらいて、**しゅっせき ばんごう**（がめんの すうじボタン）と **なまえ** を いれて「はいる」
   - せんせいの ページが とどき、せんせいが ゆるした ボタン だけが 出ます
   - 左うえに「2年1組 12ばん はると」と 出ます（おすと ばんごう・なまえを なおせる）。● が みどり なら せんせいに つながって います
   - つぎに ひらいた ときも、おなじ クラスの ままです
4. あとから クラスの **せっていを かえると、ひらいて いる こどもの 画面にも すぐ つたわります**（ロックを はずす・かける）。
   「はじめに くばる ページ」を えらんで ほぞん すると、こどもに **あたらしい タブ** として とどきます

**ほかの クラス** は、その クラスの せんせいが じぶんの たんまつで べつの クラスを つくって、べつの URL を くばります
（おなじ 時間に いくつの クラスが つかっても まざりません）。

- クラスの せっていを かえられる のは、**つくった たんまつ（ブラウザ）だけ** です
- こどもの たんまつで せんせいが 🧑‍🏫 を おして あいことばを いれると、**ロックを はずす（その タブ だけ）**・**クラスから ぬける** が できます

### みんなの つくえ（こどもの 画面を テレビに）
せんせい → クラスの **👀 みんなの つくえ**（せんせいが じぶんの クラスの URL を ひらいても 出ます）
- クラス ぜんいんの つくえが **しゅっせき ばんごう じゅんに ならび**、こどもが うごかすと すぐ かわります
  （つくえの データは 数KB。しゃしんは こどもが じぶんで 入れた ときだけ 1かい おくります）
- 1人を **タップ → 大きく**。**🔍 えらんで くらべる** で 2〜4人を ならべて 大きく
- **📺 ボタンを かくす** で 名前と つくえ だけに（テレビに うつす とき）。<kbd>Esc</kbd> か ✕ で もどる
- ● みどり＝つながって いる、グレー＝いまは つながって いない
- **🧹 あとかたづけ**：こどもの つくえの データを けす（クラスの URL・せっていは のこる）
- こどもどうしは ほかの 子の つくえを 見られません（Firebase の ルールで せんせい だけ）

### きょうゆう（せんせい → こども）
🧑‍🏫 せんせい → **🔗 コード・ファイルで くばる** から、先生が つくった ページ（しゃしん・ブロック・かこみ・線・おだい）を
**そのまま 子どもの 端末に くばれます**。ちがう クラスでも つかえます。

| やりかた | せんせい | こども |
|---|---|---|
| **コード** | 「ぜんぶの ページ」か「いまの ページだけ」を おす → **6けたの コード** が 出る | 🔗 → コードを 入れて「よみこむ」 |
| **リンク** | 出た リンクを コピーして Google Classroom などに はる | リンクを おす →「よみこみますか？」→ よみこむ |
| **ファイル** | 「ファイルに ほぞん」（`.json`）→ Google ドライブ などで くばる | 「ファイルから よみこむ」（つくえに ドラッグ でも よい） |

- よみこんだ ページは **あたらしい タブ** に なります（子どもの いまの ページは きえません。まっしろ 1まい だけの ときは おきかえ）
- しゃしんは 長い 辺 1600px に 小さくして いっしょに おくります
- コードと リンクは Firebase（「かいて あてて」と おなじ `hiro-kobako`）を つかいます。**ネットが ない ときや、
  `file://` で ひらいた ときは ファイルで** やりとり してください
- コードは 1回 つくると かわりません（おなじ コードで 何回でも よみこめます）。つくった 人いがいは 書きかえられません
- Firebase の 無料プランは **同時に つながる のは 100まで**（3つの アプリ あわせて）。この アプリは くばる・よみこむ ときだけ つないで、おわったら すぐ きるので、ひらいた ままでも 1つ ぶんを つかい つづけません。100を こえても お金は かかりません（その ときは 101こめが つながらない だけです）
- **クラスに はいって いる こどもと、みんなの つくえを ひらいて いる せんせいは、ずっと つながります**（1クラス 36台 くらい）。
  つながらない ときも アプリ（ブロックを おく など）は ふつうに うごき、せんせいへ おくる のは つながった ときに なります

## Firebase の ルール（コードで くばる ために 1回だけ）

Firebase コンソールの **Realtime Database →「ルール」** に、このフォルダーの
`database.rules.json` の 中身を ぜんぶ はって **「公開」** を おしてください。
（「かいて あてて」の `rooms`、「タイピング つなひき」の `tsunahiki` も 入っています。
3つの フォルダーの `database.rules.json` は おなじ 中身なので、どれを はっても だいじょうぶです）

```json
"ohajiki": {
  "shares": {
    "$code": {
      ".read": "auth != null",
      ".write": "auth != null && (!data.exists() || data.child('owner').val() === auth.uid)",
      ".validate": "$code.matches(/^[0-9]{6}$/) && newData.hasChildren(['owner', 't', 'data'])",
      ...
```

- 匿名サインインは「かいて あてて」で もう 有効です
- はって いないと、コードを つくる ときに「Firebase の ルールが まだ はられて いません」と 出ます（ファイルでの やりとりは つかえます）

データの かたち
```
ohajiki/shares/{コード}        owner・t・data（ページと しゃしんの JSON）
ohajiki/classes/{コード}/
  owner                        クラスを つくった せんせいの 匿名ID
  cfg                          なまえ・あいことば（ハッシュ）・allow（つかえる きのう）・set（せってい）・live・pv（ページの ばんごう）
  pages                        はじめに くばる ページ（JSON 文字）
  kids/{こどもID}              uid・no（しゅっせき ばんごう）・name・on（つながり）・t・tab・n・st（いまの ページの JSON）・ref（はいけい）
  imgs/{こどもID}/{しゃしんID} こどもが じぶんで 入れた しゃしん（長い 辺 1200px）
```
- `cfg`・`pages` を かける のは クラスを つくった せんせい だけ。`kids`・`imgs` を 見られる のも せんせい だけ
- こどもは じぶんの `kids/{こどもID}` だけ かけます（ほかの 子の ものは かけない・見られない）

## カメラが うごかない とき
- はじめて つかう ときは「カメラの 使用を 許可」を おしてください
- 「ゆるされていません」と 出たら、アドレスバーの 🔒 → カメラ → 許可
- 学校の 管理設定で カメラが 止められている 場合は、Chromebook の カメラアプリで とってから **ファイルから** で 入れてください

## ファイル構成

```
kuku-block/
├── README.md     このファイル
├── index.html    画面の骨組み
├── style.css     見ため（1366×768 の よこ長画面を きじゅん。せまい 画面でも くずれない）
├── logic.js      画面を つかわない 計算（かこみの 中・マス目・あいた 場所・しき・九九の となえかた・まわす・ズーム・よみこんだ データの チェック）
├── photos.js     しゃしんの とりこみ・しまう（IndexedDB）・カメラ
├── share.js      コードで くばる・よみこむ・クラス（Firebase。さいしょに つかう ときに 読みこむ）
├── database.rules.json  Realtime Database に はる ルール（3つの アプリ ぶん）
├── scenes.js     イラストの はいけい（おさら・ながいす・くるま・はこ を canvas で かく）
├── cards.js      おだいカード
├── sound.js      こうかおん（その場で つくる）・よみあげ（speechSynthesis）
├── app.js        ページ（タブ）・ズーム・つくえの 絵・ゆびの うごき・どうぐ・かぞえる・くくの だん・おだい・きょうゆう・せんせい・クラス・みんなの つくえ・テレビ・もどす
├── tests.html    きまりの たしかめ 55こ（ブラウザで 開く）
└── tests.js      〃（`node tests.js` でも 動く）
```

ES モジュールを 使わず ふつうの `<script>` で 読みこんでいるので、`file://` でも 動きます。
