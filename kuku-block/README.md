# くく ブロック

2年生の **九九（かけ算）** の学習で、**数図ブロックを ならべたり、まるで かこんだり、
教科書の しゃしんに かさねたり** できるアプリです。Chromebook での利用を想定しています。
正解・不正解の判定はなく、子どもが **自由に さわって 考える** ための道具です。

## ひらきかた

`index.html` をブラウザ（Chrome）で開くだけ。インストールもログインも不要です。
ファイルとして開いても（`file://`）、Web サーバーに置いても動きます。

```
cd kuku-block
python3 -m http.server 8000    # → http://localhost:8000
```

つくえの ようすは その端末の ブラウザに 自動で のこり、次に開くと つづきから 使えます。

## できること

### ブロック
- ひだりの **あお・あか** の ブロック（正方形に 青丸・赤丸）を **ドラッグして おく**
- ブロックばこを **タップ** すると、ひだり うえから じゅんに ならぶ（1だん 10こ）
- ブロックを **タップ** すると あお ⇔ あか が **うらがえる**
- ブロックを **ながおし**（0.5びょう）すると、**くっついている ブロックを まとめて** もてる
- **ごみばこ** に もっていくと すてる（ごみばこを おすと「ぜんぶ けす」）
- **ならべる**：「よこに □こ・たてに □だん」を えらぶと、長方形（アレイ図）で まとめて 出る（1〜10）
- マス目に ぴたっと そろう（せっていで オフにすると 自由な 場所に おける）。かさなった ときは となりの あいた マスへ

### かこむ
- **かこむ** を えらんで ゆびで ぐるっと かくと、**まる（かこみ）** に なる（とじていなくても むすびます）
- かこみの 右うえに **中の ブロックの かず** が 出る（せっていで かくせる）
- **さきに まるを かいて、あとから ブロックを 入れる**（おさらに 3こずつ …）ことも できる
- **うごかす** で かこみを ドラッグすると、**中の ブロックも いっしょに** うごく。ごみばこへ もっていくと 中身ごと すてる
- せっていの **「しきを 見せる」** を オンにすると、かこみから しきを つくって 下に 出す
  - おなじ かず → `3 × 4 = 12`（3こずつ 4つぶん で 12こ）
  - ちがう かず → `3 + 2 + 3 = 8`
  - かこみの 外の ブロックは「のこり □こ」

### かく・けす
- **かく**：4色（くろ・あか・あお・みどり）× ほそい／ふとい
- **けす**：なぞった ところの 線と かこみを けす（ブロックは けさない）
- **もどす／すすむ**：なんでも もとに もどせる（<kbd>Ctrl</kbd>+<kbd>Z</kbd>／<kbd>Ctrl</kbd>+<kbd>Y</kbd>）

### はいけいの しゃしん（教科書を とって すぐ つかう）
右うえの **📷 しゃしん** から、どれでも **1回の そうさで** はいけいに なります。

| やりかた | そうさ |
|---|---|
| **カメラで とる** | カメラの 画面で まるい ボタンを おすと、その まま はいけいに なる（うしろ／まえの カメラを 🔄 で きりかえ） |
| **ファイルから** | Chromebook の「ファイル」や Google ドライブの しゃしんを えらぶ |
| **はりつける** | コピーした がぞうを はる（<kbd>Ctrl</kbd>+<kbd>V</kbd> なら まどを 開かなくても はいる） |
| **ドラッグ** | ファイルを つくえに ドラッグ＆ドロップ |
| **さいきんの しゃしん** | まえに つかった しゃしん（24まいまで）を タップで すぐ よびだす |

- 入れた しゃしんは **つくえに ぴったり** の 大きさに なります
- **いち・大きさを かえる**：1本ゆびで うごかす・2本ゆびで 大きく／小さく（マウスは ホイール）・🔄 で 90° まわす・🔲 で ぴったりに もどす
- **うすく**：しゃしんを うすくして、ブロックを 見やすく できる
- しゃしんは 長い 辺 2400px まで 小さくして ブラウザ（IndexedDB）に しまいます。**インターネットには 送りません**

### せってい（⚙️）
| 項目 | 初期値 | 内容 |
|---|---|---|
| マス目に そろえる | オン | ブロックを マス目に そろえ、かさならない ように する |
| かこみの 中の かずを 見せる | オン | かこみの 右うえの 数字 |
| しきを 見せる | オフ | 子どもに 考えさせたい ときは オフの まま |
| ブロックの 大きさ | 48 | 24〜96。教科書の しゃしんの 大きさに 合わせる。ならびかたは そのまま |
| がぞうで ほぞん | — | つくえを PNG で「ダウンロード」に ほぞん（Classroom への 提出などに） |
| ぜんぶ けす | — | ブロック・かこみ・線を けす（しゃしんは のこる。「もどす」で もどせる） |

## カメラが うごかない とき
- はじめて つかう ときは「カメラの 使用を 許可」を おしてください
- 「ゆるされていません」と 出たら、アドレスバーの 🔒 → カメラ → 許可
- 学校の 管理設定で カメラが 止められている 場合は、Chromebook の カメラアプリで とってから **ファイルから** で 入れてください

## ファイル構成

```
kuku-block/
├── README.md     このファイル
├── index.html    画面の骨組み
├── style.css     見ため（1366×768 の よこ長画面を きじゅん。せまい 画面でも くずれない）
├── logic.js      画面を つかわない 計算（かこみの 中・マス目・あいた 場所・しき）
├── photos.js     しゃしんの とりこみ・しまう（IndexedDB）・カメラ
├── app.js        つくえの 絵・ゆびの うごき・どうぐ・まど・もどす
├── tests.html    きまりの たしかめ（ブラウザで 開く）
└── tests.js      〃（`node tests.js` でも 動く）
```

ES モジュールを 使わず ふつうの `<script>` で 読みこんでいるので、`file://` でも 動きます。
