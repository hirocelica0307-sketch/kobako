# 週案ノート

学校の先生のための週案アプリです。1週間の授業予定を書くと、授業時数まで自動で数えます。
Google Apps Script（GAS）のウェブアプリとして動きます。データは使う人それぞれの Google ドライブに保存されます。

## ファイル

| ファイル | なかみ |
|---|---|
| `Code.gs` | サーバー側（読み込み・保存・控え・添付） |
| `index.html` | 画面の骨組み。下の3つを読み込む |
| `style.html` | 見た目 |
| `script.html` | 画面の動き |
| `help.html` | ヘルプ（使い方）の画面 |

## 入れかた（はじめて・作り直すとき）

1. スプレッドシートの「拡張機能」→「Apps Script」を開く（または script.google.com で新しいプロジェクトを作る）。
2. `Code.gs` の中身を、エディタの `コード.gs` にまるごと貼り付ける。
3. 「＋」→「HTML」で、次の4つのファイルを作り、それぞれの中身を貼り付ける。
   名前は **拡張子なし** で `index`・`style`・`script`・`help` にする（エディタが自動で `.html` を付ける）。
4. 「デプロイ」→「新しいデプロイ」→ 種類「ウェブアプリ」。
   - 次のユーザーとして実行：**ウェブアプリケーションにアクセスしているユーザー**
   - アクセスできるユーザー：学校のドメイン内など、各校の決まりに合わせる
5. 表示された URL を開く。

### 開かないとき

開けないときは、画面に理由が出るようにしてあります。

- **「次の HTML ファイルが見つかりません」**：`index`・`style`・`script`・`help` のどれかがない、または名前がちがう（`style.html.html`・`Style` など）
- **「画面の動き（script）が読みこめていません」**：`script` を貼りつけたときに途中で切れている。最後の `</script>` まで貼りなおす
- **「Code.gs が古いまま／古い doGet が残っている」**：`.gs` のファイルがほかにもあり、古い `doGet` が残っている。古いファイルを消す
- 古い `doGet` が残っていても `Code.gs` が新しければ、部品をサーバーから読みこんで開く（そのうえで、古いファイルは消しておく）
- 直したあとは、「デプロイを管理」→ 編集 →「新バージョン」で更新しないと、URL の画面は変わらない

### 前の版（`index.html` 1ファイルの版）から入れかえるとき

- `Code.gs` と `index.html` を新しいものに置きかえ、`style`・`script`・`help` の3つを足す。
- **データの移しかえはいりません。** これまでのドライブのファイル（`weekly_plan_data_…json`）をそのまま読みます。
- 「デプロイを管理」→ いまのデプロイを編集 →「バージョン：新バージョン」で更新すると、URL は変わりません。

## ToDo・日課・月の予定・単元の時数・端末の下書き

- **ToDo**：上の「ToDo」で、週案を右に寄せて左に一覧を出す（「先週と比べる」とはどちらか片方）。
  チェックするもの／文章のメモ、しめきり（今日・明日・金曜のボタン）、★重要、チェック項目、ドラッグで並べかえ、
  すべて／今日まで／この週／★／メモの絞りこみ、終わったものの一覧、元に戻す。しめきりの日は曜日の見出しに「ToDo n」。
  データは `settings.todos[id]`（年度に関係なく共通）。記録の「やること」は、はじめて開いたときに ToDo へ移る
- **日課**：設定で通常・短縮・特別（名前は変えられる）の時刻と下校時刻を決め、曜日の見出しのメニューで日ごとにえらぶ。
  通常の時刻は表の左はし、短縮・特別はその日の見出しと各時間の右上に出る。時刻のない空いた時間は授業なしにするか聞く。印刷にも出る。
  時刻は `configByYear[年度].nikka`、日ごとの日課は `data[日付-nikka]`
- **月の予定**：1か月ぶんの行事・期間の矢印・日課・ToDo のしめきり・祝日をカレンダーで見る。日を押すとその週へ。A4横で印刷できる
- **単元の時数**：単元名の登録で「かけ算(2)（12時間）」「大きなかず 8時間」のように書くと、コマに「5/12」と出る（分割は配分どおり、こえると赤）。
  単元一覧と印刷にも出る
- **端末の下書き**：クラウドに保存できなかったときだけ、ブラウザ（localStorage）に残し、保存できたら消す。
  アカウントごとの鍵（メールアドレスのハッシュ）で分けるので、同じパソコンのほかの先生とは混ざらない。
  次に開いたとき、クラウドが変わっていなければ読み込み、変わっていれば書き出しをすすめる

## 期間の取り組み（〇〇週間）の矢印

あいさつ週間・読書週間のように何日も続く取り組みを、行事の欄に「始まりから終わりまでの矢印」で出せます。

- 入れかた：曜日の見出しを押す →「この日から『期間の取り組み』を入れる」。行事のマスを開いた画面や、設定の「期間の取り組み」からも入れられる
- 1〜4週間のボタンで終わりの日が入る（土日にかかるときは金曜日まで）。色は5色
- 週をまたいでも続けて出る。重なるときは段を分ける。矢印を押すと直す・消す（元に戻すも効く）
- 印刷・「先週と比べる」・検索にも出る
- 行事のCSVで終了日のある行事を、まとめて矢印として取り込める
- データは `settings.periodsByYear[年度][id]`。2台の端末で別々の取り組みを入れても自動で合わさる

## この版で直したこと

- 文字かざりの消毒（サニタイザー）を作り直した。細工したバックアップなどに入ったスクリプトが動かないようにした。
  データのキーや記録の日付も、読み込むときに形を確かめる。
- 時数の「着地見込み」で、「調整」の数を毎週のペースとして伸ばしていたのを直した。
- 休業日・祝日の自動入力を、1日につき1回だけにした（取り消しても、表示し直すたびに戻っていた）。
- ボタンにフォーカスがあるとき、Enter・スペースでコマが開いてしまうのを直した。
- 設定画面の年度欄を表示だけにした（年度は「年度切替」で変える）。保存したとたん全部のコマが書けなくなるのを防ぐ。
- 入力画面と記録を、書きかけのまま閉じようとすると確認するようにした。
  「この時間の記録を書く」は、書きかけのコマを先に保存する。コマの添付が記録に混ざる不具合も直した。
- 添付と毎日の控えは、本人が持ち主のフォルダにだけ入れる（同名の共有フォルダに入らない）。
- 自動の控えを「直前の1回分」に加えて、「毎日の控え」を14日分残すようにした。復元するときは時点をえらべる。
- 2台の端末で同時に書いても、ちがうところなら自動で合わせて保存する。同じところのときだけ止める。
  タブに戻ったときにも、ほかの端末の保存を読みこむ。
- 件数が半分より少なくなる保存は、本人に確かめてから保存する。
- 1つの大きな HTML を、見た目・動き・ヘルプに分けた。使っていないコードを片づけた。
- そのほか：検索で「amp」などを光らせると表示がこわれる、学年を変えると前の学年の教科が時数から消える、
  祝日のデータが取れても計算の祝日が残る、消したタグが読み込みのたびに戻る、
  今週の目標に余分な項目が付く、スマホで表を横になぞれない、ヘルプと動きのずれ、を直した。
