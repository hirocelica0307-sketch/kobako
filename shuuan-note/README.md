# 週案ノート

学校の先生のための週案アプリです。1週間の授業予定を書くと、授業時数まで自動で数えます。
Google Apps Script（GAS）のウェブアプリとして動きます。データは使う人それぞれの Google ドライブに保存されます。

## ファイル

| ファイル | なかみ |
|---|---|
| `Code.gs` | サーバー側（読み込み・保存・控え・添付） |
| `index.html` | 画面の骨組み。下の3つを読み込む |
| `style.html` | 見た目 |
| `script.html` | 画面の動き |
| `help.html` | ヘルプ（使い方）の画面 |

## 入れかた（はじめて・作り直すとき）

1. スプレッドシートの「拡張機能」→「Apps Script」を開く（または script.google.com で新しいプロジェクトを作る）。
2. `Code.gs` の中身を、エディタの `コード.gs` にまるごと貼り付ける。
3. 「＋」→「HTML」で、次の4つのファイルを作り、それぞれの中身を貼り付ける。
   名前は **拡張子なし** で `index`・`style`・`script`・`help` にする（エディタが自動で `.html` を付ける）。
4. 「デプロイ」→「新しいデプロイ」→ 種類「ウェブアプリ」。
   - 次のユーザーとして実行：**ウェブアプリケーションにアクセスしているユーザー**
   - アクセスできるユーザー：学校のドメイン内など、各校の決まりに合わせる
5. 表示された URL を開く。

### 前の版（`index.html` 1ファイルの版）から入れかえるとき

- `Code.gs` と `index.html` を新しいものに置きかえ、`style`・`script`・`help` の3つを足す。
- **データの移しかえはいりません。** これまでのドライブのファイル（`weekly_plan_data_…json`）をそのまま読みます。
- 「デプロイを管理」→ いまのデプロイを編集 →「バージョン：新バージョン」で更新すると、URL は変わりません。

## この版で直したこと

- 文字かざりの消毒（サニタイザー）を作り直した。細工したバックアップなどに入ったスクリプトが動かないようにした。
  データのキーや記録の日付も、読み込むときに形を確かめる。
- 時数の「着地見込み」で、「調整」の数を毎週のペースとして伸ばしていたのを直した。
- 休業日・祝日の自動入力を、1日につき1回だけにした（取り消しても、表示し直すたびに戻っていた）。
- ボタンにフォーカスがあるとき、Enter・スペースでコマが開いてしまうのを直した。
- 設定画面の年度欄を表示だけにした（年度は「年度切替」で変える）。保存したとたん全部のコマが書けなくなるのを防ぐ。
- 入力画面と記録を、書きかけのまま閉じようとすると確認するようにした。
  「この時間の記録を書く」は、書きかけのコマを先に保存する。コマの添付が記録に混ざる不具合も直した。
- 添付と毎日の控えは、本人が持ち主のフォルダにだけ入れる（同名の共有フォルダに入らない）。
- 自動の控えを「直前の1回分」に加えて、「毎日の控え」を14日分残すようにした。復元するときは時点をえらべる。
- 2台の端末で同時に書いても、ちがうところなら自動で合わせて保存する。同じところのときだけ止める。
  タブに戻ったときにも、ほかの端末の保存を読みこむ。
- 件数が半分より少なくなる保存は、本人に確かめてから保存する。
- 1つの大きな HTML を、見た目・動き・ヘルプに分けた。使っていないコードを片づけた。
- そのほか：検索で「amp」などを光らせると表示がこわれる、学年を変えると前の学年の教科が時数から消える、
  祝日のデータが取れても計算の祝日が残る、消したタグが読み込みのたびに戻る、
  今週の目標に余分な項目が付く、スマホで表を横になぞれない、ヘルプと動きのずれ、を直した。
