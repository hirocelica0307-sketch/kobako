# かんじ たしかめ（試作）

2年生 こくご「九・十月の かん字の たしかめ」（東京書籍 上108〜下28）の かん字を、
**ゆびで 書くと 自動で しらべて、まちがいを おしえる** れんしゅう アプリです。
テストと おなじ 25もん（1もん 4てん）で、書き・熟語・おくりがな を れんしゅうします。

- 対象：小学2年生（2学期・下（後期））
- タブレット・Chromebook（タッチ・ペン・マウス）で つかえます
- **index.html 1ファイル** だけで うごきます。はんていは 画面の 中だけで して、インターネットには 送りません（字の フォントだけ Google Fonts から よみます）
- 試作なので、まずは この 31字だけです

## ひらきかた

**https://hirocelica0307-sketch.github.io/kobako/kanji-tashikame/**

`index.html` を Chrome で ひらくだけです（ファイルとして ひらいても うごきます）。

## つかいかた

| メニュー | なかみ |
|---|---|
| テストの れんしゅう | 25もん。①〜⑱は 文の 中の ひらがなを かん字で 書く（熟語は 1字ずつ）。⑲〜㉕は まず「どこまでが かん字か」を えらんでから かん字を 書く。さいごに 100てん まんてんの てんすうと、まちがえた 字だけの れんしゅう |
| 1字ずつ れんしゅう | 字を えらぶ。お手本（書きじゅんの アニメーション・画の 番号）を 見たり、うすい お手本を なぞったり できる |
| にがての 字 | さいごに まちがえた 字・正答率が ひくい 字だけ |

書いたら「できた！」。〇 なら 大きな 〇。まちがいは **赤い 線**（なおす）と **黄色い 線**（ポイント）で しめします。
ことばを タップすると その 線だけ 光ります。「じぶんの 字に かさねる」で お手本を じぶんの 字の 大きさに あわせて 重ねて 見られます。

例文は すべて オリジナルです（テストの 文は つかって いません）。

## はんていの しくみ

答えの 字が わかって いるので、「なにの 字か」を 当てるのでは なく、**お手本と 1画ずつ くらべます**。

1. 書いた 字の 大きさ・ばしょを お手本に あわせる（ずれの 大きい 線に ひっぱられない ように、あう 線だけで あわせなおす）
2. 画数を くらべる。1画を とちゅうで はなした・2画を つなげた ときは、わけたり つないだり して しらべる
3. 書いた 線と お手本の 画を むすぶ（ハンガリー法。書きじゅんが ちがっても むすべる）
4. 1画ずつ ばしょ・ながさ・むき・はね を しらべる。とめ・はらいは、書きおわりの はやさと とまって いた 時間（ペンなら 筆圧）で 見る
5. 交わる・つく・はみ出す、ながさの バランス（未と 末・土と 士 の ように 字が かわる ところ）を しらべる

### きびしさ（ホームで えらぶ）

| | やさしい | ふつう（テストに ちかい） | きびしい |
|---|---|---|---|
| ばしょ・ながさ | 大きな ずれだけ × | × | 小さな ずれも × |
| 画数 | 形が にて いれば ポイント | つなげた・はなした は ポイント、たりない・多い は × | × |
| 書きじゅん・むき | ポイント | ポイント（テストの 紙では わからない ため） | × |
| はね | ポイント | はねない ×／よけいな はね ポイント | × |
| とめ・はらい | 見ない | 見ない | × |
| 交わる・つく・出る | 見ない | 大きく 出る・まじわらない は ×、すきま は ポイント | × |
| ながさの バランス | 見ない | ×（妹・工・止・走・歩） | × |

テストの 許容（どちらでも 〇）は データに 入れて あります：才の 3画目の 上（出ても 出なくても よい）、内・図の 右の 画（とめ・はらい どちらでも）、妹の さいごの はらい、楽の 1画目、切の 2画目。
「出ると べつの 字に なる」ところは とくに きびしく 見ます：天の ノ（夫に なる）、工の たての 画。

## お手本データ

- 1字ごとに、100×100 の わくの 中の **画の 通り道（点の ならび）と おわりかた**（とめ・はらい・はね〔むき〕）を もって います
- 筆順は 文部省「筆順指導の手びき」の じゅん。画数と 書きじゅんは KanjiVG（CC BY-SA）で たしかめましたが、**KanjiVG の データ（座標）は つかって いません**
- 線の ばしょは、教科書体に ちかい フォント Klee One（SIL Open Font License）の 字を なぞって つくりました
- ほかの データ（AnimCJK・Hanzi Writer）は Arphic Public License で、リポジトリの きまり（CC0・MIT など）に あわないので つかって いません
- 「せんせいへ」の 画面で 31字ぜんぶの 書きじゅんを 見られます。**教科書の 筆順と ちがう ところが あったら おしえて ください**

## たしかめ

```
node tests.js
```

- お手本データ（31字の 画数・わくの 中・おわりかたの しるし）・もんだい（25もん・よみは ひらがな・例文に 漢字なし）
- ゆびで 書いた ような 線（大きさ・ばしょ・かたむき・1画ずつの ずれ・ゆれ を くわえた もの）を つくって、
  - ていねいな 字（31字×12とおり）が「ふつう」で ぜんぶ 〇 に なる
  - はねない・1画 たりない・1画 ずれる・書きじゅん・むき・はなす・はらいを とめる・天が 夫に なる・未が 末に なる・工の 上が ながい・大の ノが まじわらない を 見つける
  - 才の 許容は 〇 の まま

## まだ たしかめて いない こと・これから

- **実機で 2年生が 書いた 字では まだ ためして いません。** はんていの 数（どれくらい ずれたら × か）は、まねした 線で きめた 仮の 数です。
  「せんせいへ」→「はんていの 数字を 出す」に すると、書いた あとに 画ごとの ずれなどが 出るので、実際の 字で 調整できます
- とめ・はらいは、指で 書くと 正しく 見分けにくいので「きびしい」だけで 見ます
- 1字ずつの お手本データを ふやせば、ほかの 月の かん字にも ひろげられます（2年生 160字）
- 読みクイズ・まちがいさがし・画数クイズ など、ほかの もんだいは まだ ありません
- アイコン・キャラクターの 絵は まだ ありません（入れる ときは 候補を 見せて から きめます）
