# おえかき（準備中）

お絵かきアプリを ここに 作っていきます。
いまは 場所だけ 用意した じょうたいで、まだ 中身は ありません。

## ここに 入れるもの

`hissan-monster/` と 同じように、このフォルダーだけで 完結させます
（隣のフォルダーの ファイルは 読みこまない）。

```
oekaki/
├── README.md      このファイル
├── index.html     画面の骨組み
├── style.css      見ため
└── app.js         おえかきの しくみ
```

## つぎに やること

チャットで 作った お絵かきアプリの コードを ここに 移します。

- コードを はりつけて もらえれば、この形に 分けて 置きます
- 作りなおす ばあいは、キャンバス（えを かく ばしょ）・色えらび・
  ふとさ・けしゴム・やりなおし・ほぞん あたりから 決めていきます
