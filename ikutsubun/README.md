# いくつ分 しきづくり（仮称）

2年生の **かけ算** で、文や 絵の 中から **「1つ分の 数」** と **「いくつ分」** を 見つけて、
`1つ分の 数 × いくつ分` の しきを つくる れんしゅうを **どんどん たくさん** する アプリです。
**こたえ（せき）は もとめません。** しきが つくれたら すぐ つぎの 問題へ すすみます。

- 対象：小学2年生（かけ算(1) の「1つ分の 数」「いくつ分」〜 かけ算(2) の 文章題）
- 子どもの Chromebook・iPad（よこ・たて）で つかえます。タッチ・マウス・キーボード（1〜9・⌫・Enter）
- サーバー・ログイン・外部API は つかいません。ファイルを ひらくだけで うごきます
- 数は いつも **1〜9 ぜんぶ**（1 は すこし 出にくく して あります）
- 絵は ぜんぶ この アプリ用に かいた **手がき ふうの イラスト**（SVG・約100しゅるい）。どの きかいでも おなじ 絵に なります
- **レベルアップ**（かけ算の テストに むけて）：しきと 答え・いらない 数・＋−× えらび・かけ算の きまり・なんばい（テープの 図）・●の 図を くふうして・しきに あう もんだいづくり・**ミニテスト（10もん・100点・いんさつ できる）**。
  ことばは 啓林館「わくわく算数 2下」（かけ算・かけ算の きまり）に あわせて います

## 問題の しゅるい

| モード | ないよう |
|---|---|
| 🌈 ぜんぶ まぜる（おすすめ） | 下の 4しゅるいが まざって 出る（ぶんしょう 3：ぎゃく 3：え 2：えらぶ 2） |
| 📖 ぶんしょう（きほん） | 1つ分が 先に 出て くる 文。「1さらに りんごが **3こずつ** のって います。**4さら分**では、…」 |
| 🔄 ぶんしょう（じゅんばんが ぎゃく） | いくつ分が 先に 出て くる 文。「**5人**に あめを **2こずつ** くばります。」「たこが **3びき** います。1ぴきの 足は **8本** です。」 |
| 🖼️ えを 見て | おさら・はこ・のりもの などの 絵を 見て かぞえ、しきを つくる |
| 🔍 しきから えらぶ | `3 × 4` に なる ばめんを 3つから えらぶ（絵 か 文）。まちがいの せんたくしは **いれかえ（4×3）**・**数が ちがう**・**おなじ 数ずつ で ない（3＋4）** |

### こたえかた（ぶんしょう・え）

```
 1つ分の 数  [ 3 ] こずつ
 いくつ分    [ 4 ] さら分
 しき        [ 3 ] × [ 4 ]
```

- わくを えらんで（はじめは いちばん 上）、下の **数字カード 1〜9** を タップ。つぎの わくへ じどうで すすむ
- ぜんぶ うまったら すぐ はんてい。⭕ なら「3こずつ の 4さら分 → 3 × 4」と 出て **つぎへ ▶**
- わくの うしろの ことばは 数に あわせて よみが かわる（3**びき**ずつ・6**ぴき**分 など）
- ⚙️ で **「しきだけ」**（`□ × □` だけ）にも できる

### まちがえた とき

まちがえた わくだけ 赤く なり、そこから なおせます。まちがいかたに あわせて ことばが かわります。

| まちがい | 出る ことば（れい） |
|---|---|
| 1つ分と いくつ分を いれかえた | 1つ分の 数と いくつ分が いれかわって いるよ。1さらに 何こ？ |
| 「1さらに」の 1 を 入れた | 「1さら」の 1 では ないよ。1さらに 何こ？ |
| しきの じゅんばんが ぎゃく | しきは **1つ分の 数** × **いくつ分** の じゅんばんだよ。 |
| 数が ちがう | 1つ分の 数が ちがうよ。1さらに 何こ？／いくつ分が ちがうよ。おさらは いくつ？ |

- 2かい まちがえると **色の ヒント**（文の 1つ分が 青、いくつ分が だいだい色）、3かいで **絵の ヒント** が じどうで 出る
- 💡 **ヒント** ボタンでも 出せる（1かいめ：色 → 2かいめ：絵。絵では 1つ分の まとまりを 青で かこみ、まとまりに ①②③… を つける）
- 🔊 **よむ** で 問題文を よみあげ（ブラウザの よみあげ。日本語の 声が ある きかいで）

### たくさん とく ための しかけ

- 問題は おわり なし。ばめんは シャッフルした じゅんに 出るので、おなじ ばめんが つづかない
- うえに「◯もん」。**10もん ごとに ⭐** と おいわい
- 🏠 で もどると「◯もん できたね！ 1かいで せいかい ◯もん」
- はじめの 画面に「きょう ◯もん ／ これまで ぜんぶで ◯もん」（この きかいの ブラウザに だけ のこる）

## レベルアップ（かけ算の テストに むけて）

はじめの 画面の 下の だん です。いままでの「れんしゅう」は そのまま のこって います。
レベルアップでは **答え（せき）も もとめます**。数字カードに **0** と **✔ こたえあわせ** が ふえます
（かけ算の きまりの ように 1けたの わく だけの 問題は、うまったら すぐ たしかめます）。

| モード | ないよう | こたえかた |
|---|---|---|
| 📝 **ミニテスト**（おすすめ） | 下の 7つから 10もん（しきと答え 2・いらない 数 1・なんばい 1・＋−× 2・きまり 2・●の 図 1・もんだいづくり 1）。とちゅうは ⭕❌も ヒントも 出ない | 1もん 10点。しきと 答え・なんばいは **しき 5点・答え 5点**、●の 図は **もとめかた 5点・●の 数 5点** |
| 🧮 しきと 答え | いままでの 文章題で、しき・九九の 答え・答えの **たんい** まで | `しき □×□＝□□`・`答え □□` ＋ たんいを 3つから えらぶ（こ／さら／本 など） |
| 🚫 いらない 数に 気をつけて | 文の 前か うしろに **つかわない 数の 文** が 1つ 入る（「えんぴつが 3本 おちて います。」など） | しきと 答えと おなじ |
| ➕ ＋ − × どれかな？ | かけ算 半分・たし算 4分の1・ひき算 4分の1 が まざる。「ずつ」が あっても ひき算（「5人に 1本ずつ くばると、のこりは」）も ある | `しき □□ ○ □□` の ○を ＋・−・× から えらぶ |
| 📏 かけ算の きまり | 7しゅるい（下の 表） | □に 1けたの 数 ／ えらぶ |
| 📐 なんばい | **テープの 図**（1つ分の テープと、それが いくつ分 つながった テープ）を 見て「□cm の □ばい」と 長さ。文だけの 問題（「赤い テープの 3ばい」「みかんの 4ばい」など）も ある | `4cm の □ばい`・`しき □×□＝□□`・`答え □□cm`（こ・まい・本 の 問題も） |
| 🔷 ●の 図を くふうして | **L の 形・凸（でっぱり）の 形** の ●。もとめかたを 4つから **ぜんぶ** えらび、●の 数を 書く | えらぶと、その もとめかたの 四角が 図に 色で 出る（まちがいの もとめかたは 図から はみ出したり、ない ところに かかったり する） |
| 🧩 しきに あう もんだいを つくろう | `4 × 6` に なる もんだいを、ア（1つ分）・イ（いくつ分）・ウ（問い）に ことばカードを 入れて つくる | ア「4こずつ／6こずつ」・イ「6さら分／4さら分」・ウ「ぜんぶで 何こ／のこりは／ちがいは」 |

### かけ算の きまり（啓林館「かけ算の きまり」の ことば）

| しゅるい | れい |
|---|---|
| かける数が 1 ふえると | `6 × 4 の 答えは、6 × 3 の 答えより □ 大きい。`・`6 × 4 ＝ 6 × 3 ＋ □` |
| かける数が 1 へると | `6 × 3 の 答えは、6 × 4 の 答えより □ 小さい。` |
| 入れかえても 答えは おなじ | `3 × 8 ＝ 8 × □`・`□ × 5 ＝ 5 × 7` |
| □を もとめる | `4 × □ ＝ 20`・`□ × 6 ＝ 18` |
| 答えが おなじに なる 九九 | `答えが 12 に なる 九九を ぜんぶ えらびましょう。`（2×6・3×4・4×3・6×2 ＋ まちがい） |
| かけられる数・かける数 | `7 × 3 で、かけられる数は □、かける数は □ です。` |

### まちがえた とき（れんしゅう）

| まちがい | 出る ことば（れい） |
|---|---|
| しきの じゅんばんが ぎゃく | しきは **1つ分の 数** × **いくつ分** の じゅんばんだよ。 |
| いらない 数を つかった | 「えんぴつが 3本 おちて います。」は、この もんだいでは つかわない 数だよ。 |
| 九九の 答えが ちがう | 3 × 4 の 答えを たしかめよう。3の だん：3、6、9、12… |
| たんいが ちがう | きいて いるのは「何こ」だから、たんいは「こ」だよ。 |
| 計算の しゅるいが ちがう | 「のこりは」だから、ひき算 だよ。／ おなじ 数ずつ の いくつ分 だから、かけ算 だよ。 |
| かけ算の きまり | かける数が 1 ふえると、答えは かけられる数だけ ふえるよ。（●の 図で、ふえた 1つ分が だいだい色に なる） |
| なんばいの ばいが ちがう | 4cm の テープが いくつ分 あるかな？ 1つずつ かぞえよう。（ヒントで テープに 1、2、3… の ばんごう） |
| ●の 図の もとめかた | えらんだ 中に、図と あわない もとめかたが あるよ。えらぶと 図に 色が つくので、たしかめよう。 |
| もんだいづくりで ア・イ が ぎゃく | 4 × 6 の 4 は 1つ分の 数（アに 入る）、6 は いくつ分（イに 入る）だよ。 |

💡 ヒントは、1かいめが 色（1つ分・いくつ分・**つかわない 文に せん**・たし算 ひき算の **合図の ことば** に きいろ）、2かいめが 絵です。

### ミニテストの けっか

- 点数・かかった 時間・1もんずつの ⭕△❌・「あなたの 答え」と「せいかい」
- **✏️ まちがえた もんだいを れんしゅう**：おなじ 問題を ヒントつきで やりなおし、その あとは まちがいが 多かった しゅるいを 多めに 出します
- **🖨️ いんさつ**：A4 で テスト用紙（名前・点数らん つき・テープの 図と ●の 図も 入る）と 答えの ページ。はじめの 画面の「ミニテストの 用紙を いんさつ」でも、あたらしい テストを いんさつ できます。
  図が 入るので、テスト用紙・答えは それぞれ 2まいに なる ことが あります
- さいこう点は はじめの 画面に 出ます（この きかいの ブラウザに だけ のこる）

### ばめんを ふやす とき

`scenes.js` に 1つ たします。文の かきかたは ファイルの はじめに あります。

```js
{
    id: 'ringo', name: 'りんご', e: '🍎', box: '🍽️', ua: 'こ', ub: 'さら', one: '1さら', bn: 'おさら', pic: 1,
    t: [
        '1さらに りんごが [#Aこずつ] のって います。{#Bさら分}では、',   // きほん（[ ] が 先）
        '{#Bまい}の おさらに、りんごを [#Aこずつ] のせました。',           // ぎゃく（{ } が 先）
    ],
    q: 'りんごは ぜんぶで 何こ ありますか。',
},
```

`[ ]` が 1つ分（#A）、`{ }` が いくつ分（#B）。`[ ]` が 先なら「きほん」、`{ }` が 先なら「じゅんばんが ぎゃく」に 出ます。
たしかめ（`node tests.js`）で、文の 形・つかって いる 漢字（2年生まで）・出題の かたより・絵が そろって いるか を しらべます。

## きめて ほしい こと

- **アプリの 名前**：いまは 仮称「いくつ分 しきづくり」。`index.html` の `<title>` と `<h1>` を かえます
- **「1」の 出やすさ**：いまは ほかの 数の 3分の1 くらい。`logic.js` の `pickNum` の `0.35` で かえられます
- **せんたくしの 文**：「しきから えらぶ」の 文は「1さらに 3こずつ、4さら分」の 形に そろえて います
- **ミニテストの 点数**：しきと 答えは「しき 5点・答え 5点」に して います。学校の テストに あわせて かえる ときは `levelup.js` の `checkLv` の `score` を かえます
- **ミニテストの くみあわせ**：`levelup.js` の `TEST_PLAN`（10この しゅるいの ならび）を かえると、テストに 出る しゅるいと 数が かわります
- **●の 図の 形**：いまは L の 形と 凸の 形。教科書の 形（かいだん・へこみ など）を ふやす ときは `levelup.js` の `makeZu` に たします
