# いくつ分 しきづくり（仮称）

2年生の **かけ算** で、文や 絵の 中から **「1つ分の 数」** と **「いくつ分」** を 見つけて、
`1つ分の 数 × いくつ分` の しきを つくる れんしゅうを **どんどん たくさん** する アプリです。
**こたえ（せき）は もとめません。** しきが つくれたら すぐ つぎの 問題へ すすみます。

- 対象：小学2年生（かけ算(1) の「1つ分の 数」「いくつ分」〜 かけ算(2) の 文章題）
- 子どもの Chromebook・iPad（よこ・たて）で つかえます。タッチ・マウス・キーボード（1〜9・⌫・Enter）
- サーバー・ログイン・外部API は つかいません。ファイルを ひらくだけで うごきます
- 数は いつも **1〜9 ぜんぶ**（1 は すこし 出にくく して あります）

## ひらきかた

**https://hirocelica0307-sketch.github.io/kobako/ikutsubun/**

`index.html` を Chrome・Safari で ひらくだけです（ファイルとして ひらいても うごきます）。

## 問題の しゅるい

| モード | ないよう |
|---|---|
| 🌈 ぜんぶ まぜる（おすすめ） | 下の 4しゅるいが まざって 出る（ぶんしょう 3：ぎゃく 3：え 2：えらぶ 2） |
| 📖 ぶんしょう（きほん） | 1つ分が 先に 出て くる 文。「1さらに りんごが **3こずつ** のって います。**4さら分**では、…」 |
| 🔄 ぶんしょう（じゅんばんが ぎゃく） | いくつ分が 先に 出て くる 文。「**5人**に あめを **2こずつ** くばります。」「たこが **3びき** います。1ぴきの 足は **8本** です。」 |
| 🖼️ えを 見て | おさら・はこ・のりもの などの 絵を 見て かぞえ、しきを つくる |
| 🔍 しきから えらぶ | `3 × 4` に なる ばめんを 3つから えらぶ（絵 か 文）。まちがいの せんたくしは **いれかえ（4×3）**・**数が ちがう**・**おなじ 数ずつ で ない（3＋4）** |

### こたえかた（ぶんしょう・え）

```
 1つ分の 数  [ 3 ] こずつ
 いくつ分    [ 4 ] さら分
 しき        [ 3 ] × [ 4 ]
```

- わくを えらんで（はじめは いちばん 上）、下の **数字カード 1〜9** を タップ。つぎの わくへ じどうで すすむ
- ぜんぶ うまったら すぐ はんてい。⭕ なら「3こずつ の 4さら分 → 3 × 4」と 出て **つぎへ ▶**
- わくの うしろの ことばは 数に あわせて よみが かわる（3**びき**ずつ・6**ぴき**分 など）
- ⚙️ で **「しきだけ」**（`□ × □` だけ）にも できる

### まちがえた とき

まちがえた わくだけ 赤く なり、そこから なおせます。まちがいかたに あわせて ことばが かわります。

| まちがい | 出る ことば（れい） |
|---|---|
| 1つ分と いくつ分を いれかえた | 1つ分の 数と いくつ分が いれかわって いるよ。1さらに 何こ？ |
| 「1さらに」の 1 を 入れた | 「1さら」の 1 では ないよ。1さらに 何こ？ |
| しきの じゅんばんが ぎゃく | しきは **1つ分の 数** × **いくつ分** の じゅんばんだよ。 |
| 数が ちがう | 1つ分の 数が ちがうよ。1さらに 何こ？／いくつ分が ちがうよ。おさらは いくつ？ |

- 2かい まちがえると **色の ヒント**（文の 1つ分が 青、いくつ分が だいだい色）、3かいで **絵の ヒント** が じどうで 出る
- 💡 **ヒント** ボタンでも 出せる（1かいめ：色 → 2かいめ：絵。絵では 1つ分の まとまりを 青で かこみ、まとまりに ①②③… を つける）
- 🔊 **よむ** で 問題文を よみあげ（ブラウザの よみあげ。日本語の 声が ある きかいで）

### たくさん とく ための しかけ

- 問題は おわり なし。ばめんは シャッフルした じゅんに 出るので、おなじ ばめんが つづかない
- うえに「◯もん」。**10もん ごとに ⭐** と おいわい
- 🏠 で もどると「◯もん できたね！ 1かいで せいかい ◯もん」
- はじめの 画面に「きょう ◯もん ／ これまで ぜんぶで ◯もん」（この きかいの ブラウザに だけ のこる）

## ばめん（77しゅるい・文 166）

教科書や ウェブの 文章題プリントで よく つかわれる ばめんを あつめました（下の「しらべた ところ」）。

- **たべもの**：りんご・いちご・おだんご・ケーキ・みかん（ふくろ／くばる）・たまご・ドーナツ・おにぎり・クッキー・チョコレート・おすし・バナナ・あめ・さくらんぼ・ミニトマト・くり・ぎゅうにゅう・ジュース（dL）・たこやき
- **のりもの・ゆうえんち**：コーヒーカップ・ジェットコースター・かんらん車・ボート・車・電車・長いす・エレベーター・車の タイヤ・三りん車・じてん車・一りん車
- **いきもの**：たこ・くも・てんとうむし・かぶとむし・あり・犬・にわとりの 足、うさぎの 耳、ちょうの はね、ひとでの うで、金魚・ことり・つり
- **がっこう**：えんぴつ・色えんぴつ・おりがみ・本だな・はん・つくえの れつ・ノート・本を 読む ページ・玉入れ・チーム・たんざく・ブロック
- **花・しぜん**：かびん・花だんの チューリップ・さくらの 花びら・よつば・クローバー・どんぐり
- **くらし・あそび**：トランプ・ふうせん・シール・おはじき・ボール・つみ木・じゃんけんの ゆび・いすの 足・1週間・おかいもの（1こ ◯円）・5円玉・まど・ろうそく・がようし

**1つ分が きまって いる ばめん**（たこの 足 8本・1週間 7日・三りん車 3こ など 22しゅるい）は「ずつ」が ない 文に なるので、
「ずつ」に たよらずに 1つ分を 見つける れんしゅうに なります（文の 問題だけに 出ます）。

数が 1〜9 なので、文の 問題だけで **1万 とおり いじょう** の くみあわせが あります。

### ばめんを ふやす とき

`scenes.js` に 1つ たします。文の かきかたは ファイルの はじめに あります。

```js
{
    id: 'ringo', name: 'りんご', e: '🍎', box: '🍽️', ua: 'こ', ub: 'さら', one: '1さら', bn: 'おさら', pic: 1,
    t: [
        '1さらに りんごが [#Aこずつ] のって います。{#Bさら分}では、',   // きほん（[ ] が 先）
        '{#Bまい}の おさらに、りんごを [#Aこずつ] のせました。',           // ぎゃく（{ } が 先）
    ],
    q: 'りんごは ぜんぶで 何こ ありますか。',
},
```

`[ ]` が 1つ分（#A）、`{ }` が いくつ分（#B）。`[ ]` が 先なら「きほん」、`{ }` が 先なら「じゅんばんが ぎゃく」に 出ます。
たしかめ（`node tests.js`）で、文の 形・つかって いる 漢字（2年生まで）・出題の かたより を しらべます。

## せってい（⚙️）

| こうもく | はじめ | ないよう |
|---|---|---|
| こたえかた | 1つ分・いくつ分・しき | **しきだけ** に すると `□ × □` だけ |
| 色の ヒントを はじめから | なし | **あり** に すると、文の 1つ分・いくつ分に はじめから 色が つく（にがてな 子に） |
| おと | あり | ⭕・まちがい・10もんの おと（うえの 🔔 でも きりかえ） |
| リンクを コピー | — | いまの モードと せっていが 入った リンク |

**リンクで くばれます**（Google Classroom など）。URL の うしろに つけます。

| URL の ことば | いみ |
|---|---|
| `m` | モード：`mix`・`kihon`・`gyaku`・`e`・`erabu`（ひらいたら すぐ はじまる） |
| `s=shiki` | しきだけ |
| `c=1` | 色の ヒントを はじめから |

れい：`…/ikutsubun/#m=gyaku&c=1`（じゅんばんが ぎゃくの 文を、色の ヒントつきで）

## きめて ほしい こと

- **アプリの 名前**：いまは 仮称「いくつ分 しきづくり」。`index.html` の `<title>` と `<h1>` を かえます
- **「1」の 出やすさ**：いまは ほかの 数の 3分の1 くらい。`logic.js` の `pickNum` の `0.35` で かえられます
- **せんたくしの 文**：「しきから えらぶ」の 文は「1さらに 3こずつ、4さら分」の 形に そろえて います
