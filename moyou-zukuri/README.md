# もようづくり（仮称）

2年生 算数「三角形と 四角形」（啓林館 わくわく算数2下 12「三角形と四角形」第9時 もようづくり）で、
**正方形・長方形・直角三角形の 色紙を しきつめて もようを つくる** アプリです。

教科書の QR の サイトと おなじ ように **6しゅるいの 色紙を 自由に おける** ことは そのままに、
2年生でも 思った ところに ぴたっと おける ように、**ます目に すいつく・タップで おく・なぞって ならべる** を 中心に しています。

- 対象：小学2年生（Chromebook の タッチ・マウス、電子黒板・大型テレビ）
- **index.html 1ファイル** だけで うごきます。サーバー・ログイン・外部API は つかいません
- つくった もようは その 端末の ブラウザに 自動で のこります（次に ひらくと つづきから）
- 点数・正解・時間制限は ありません

## 色紙（6しゅるい）

| かたち | 色 | 大きさ |
|---|---|---|
| 正方形 | ピンク・うすい ピンク | 2×2 ます |
| 長方形 | みどり・うすい みどり | 2×1 ます（正方形の 半分。まわすと たてながに） |
| 直角三角形 | オレンジ・きいろ | 2×2 ますの 半分（正方形を ななめに 半分。4つの むき） |

教科書 p.135 の「もようづくりの色紙」を 切った 形と おなじ 大きさの 関係です
（正方形 2まいで 長方形、長方形 2まいで 正方形、直角三角形 2まいで 正方形・大きな 直角三角形 が できる）。

## そうさ

### おく（はじめの モード）
- ひだりの はこで 色紙を **えらぶ**（えらんだ 色紙を もう いちど タップ・「むきを かえる」で むきが かわる）
- だいしを **タップ** すると その ところに おける
- だいしを **なぞる** と、なぞった ところに **すきまなく つぎつぎ ならぶ**（れんがや しきつめが すぐ できる）
- はこから だいしへ **ドラッグ** して おく ことも できる
- **すいつき**：ます目に ぴたっと そろう。すこし ずれた ところを タップしても、**ちかくの あいている ところ** に 入る
  （直角三角形の あいている 半分を タップすると、ちょうど 正方形に なる ように 入る）
- かさなる ところには おけない（赤い かげで 知らせる）
- おいた 色紙を **タップ** すると 90° まわる。**ドラッグ** すると うごかせる（はなす ところに 点線の かげが 出る）
- **だいしの 外へ ドラッグ** すると けせる
- マウスの ときは、おく まえに 点線の かげで おく ところが 見える

### けす
- **けす** を えらんで、色紙を タップ・なぞると けせる

### そのほか
- **もどす**（<kbd>Ctrl</kbd>+<kbd>Z</kbd>）：1つ まえに もどす（なぞった 1回ぶんは まとめて 1つ）
- **ぜんぶ けす**：「けしますか？」と きいてから けす（「もどす」で もとに もどせる）
- **ます目**：点の ます目を 出す／かくす
- **ひろさ**：せまい（正方形 8×5まい）・ふつう（12×7まい）・ひろい（16×10まい）。色紙が はみだす ときは せまく できない
- **かざる**：ボタンや はこを かくして、もようだけを 大きく 見せる（みんなで 見あう とき・テレビに うつす とき）
- キーボード：<kbd>R</kbd> で はこの 色紙の むきを かえる、<kbd>Esc</kbd> で かざるを おわる

## しくみ（先生・つくる人 むけ）

- だいしは「ます」（正方形の 1辺の 半分）の あつまり。色紙の いちは ますの 左うえで もつ
- かさなりは、1ますを 対角線で 4つに わけた 小さな 三角（北・東・南・西）で しらべる。
  こうすると 直角三角形 2まいで 正方形を つくる ことが できる
- すいつきは、ゆびの 下に くる いちの うち、おける ところで いちばん ちかい ところ。
  おなじ くらい ちかい ときは、まわりの 色紙と 辺で くっつく 数が おおい ほうを えらぶ
