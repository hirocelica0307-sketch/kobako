# もようづくり（仮称）

2年生 算数「三角形と 四角形」（啓林館 わくわく算数2下 12「三角形と四角形」第9時 もようづくり）で、
**正方形・長方形・直角三角形の 色紙を しきつめて もようを つくる** アプリです。

教科書の QR の サイトと おなじ ように **6しゅるいの 色紙を 自由に おける** ことは そのままに、
2年生でも 思った ところに ぴたっと おける ように、**ます目に すいつく・タップで おく・なぞって ならべる** を 中心に しています。

- 対象：小学2年生（Chromebook の タッチ・マウス、電子黒板・大型テレビ）
- **index.html 1ファイル** だけで うごきます。ログインは いりません
- つくった もようは その 端末の ブラウザに 自動で のこります（次に ひらくと つづきから）
- **みんなの がめん**：せんせいが クラスを つくると、こども（さいだい 30人 くらい）の だいしが テレビに ならび、えらんだ 子の だいしを 大きく 出せます（Firebase。下の「みんなの がめん」）
- 点数・正解・時間制限は ありません

## ひらきかた

**https://hirocelica0307-sketch.github.io/kobako/moyou-zukuri/**

`index.html` を Chrome で ひらくだけです（ファイルとして ひらいても うごきます）。

## 色紙（6しゅるい）

| かたち | 色 | 大きさ |
|---|---|---|
| 正方形 | ピンク・うすい ピンク | 2×2 ます |
| 長方形 | みどり・うすい みどり | 2×1 ます（正方形の 半分。まわすと たてながに） |
| 直角三角形 | オレンジ・きいろ | 2×2 ますの 半分（正方形を ななめに 半分。4つの むき） |

教科書 p.135 の「もようづくりの色紙」を 切った 形と おなじ 大きさの 関係です
（正方形 2まいで 長方形、長方形 2まいで 正方形、直角三角形 2まいで 正方形・大きな 直角三角形 が できる）。

## そうさ

### おく（はじめの モード）
- ひだりの はこで 色紙を **えらぶ**（えらんだ 色紙を もう いちど タップ・「むきを かえる」で むきが かわる）
- だいしを **タップ** すると その ところに おける
- だいしを **なぞる** と、なぞった ところに **すきまなく つぎつぎ ならぶ**（れんがや しきつめが すぐ できる）
- はこから だいしへ **ドラッグ** して おく ことも できる
- **すいつき**：ます目に ぴたっと そろう。すこし ずれた ところを タップしても、**ちかくの あいている ところ** に 入る
  （直角三角形の あいている 半分を タップすると、ちょうど 正方形に なる ように 入る）
- かさなる ところには おけない（赤い かげで 知らせる）
- おいた 色紙を **タップ** すると 90° まわる。**ドラッグ** すると うごかせる（はなす ところに 点線の かげが 出る）
- **だいしの 外へ ドラッグ** すると けせる
- マウスの ときは、おく まえに 点線の かげで おく ところが 見える

### けす
- **けす** を えらんで、色紙を タップ・なぞると けせる

### そのほか
- **もどす**（<kbd>Ctrl</kbd>+<kbd>Z</kbd>）：1つ まえに もどす（なぞった 1回ぶんは まとめて 1つ）
- **ぜんぶ けす**：「けしますか？」と きいてから けす（「もどす」で もとに もどせる）
- **ます目**：点の ます目を 出す／かくす
- **ひろさ**：せまい（正方形 8×5まい）・ふつう（12×7まい）・ひろい（16×10まい）。色紙が はみだす ときは せまく できない
- **かざる**：ボタンや はこを かくして、もようだけを 大きく 見せる（みんなで 見あう とき・テレビに うつす とき）
- キーボード：<kbd>R</kbd> で はこの 色紙の むきを かえる、<kbd>Esc</kbd> で かざるを おわる

## みんなの がめん（テレビに うつす）

### せんせい
1. テレビに つないだ パソコンで アプリを ひらき、右うえの **つなぐ** → **クラスを つくる**
2. テレビに **6けたの コード** が 大きく 出る（「URLを コピー」で `…/moyou-zukuri/?c=コード` を Classroom などで くばっても よい）
3. こどもが つなぐと、**出席番号 じゅんに だいしが ならぶ**（30人なら 6れつ×5だん）。こどもが うごかすと すぐ かわる
   - 一覧では、色紙の ある ところを 大きく して 見せる
   - つながりが きれた 子は うすく なり「つながっていない」と 出る
4. **子どもの だいしを おす と 大きく** なる。「まえの 人」「つぎの 人」（<kbd>←</kbd>・<kbd>→</kbd>）で となりの 子へ、
   「みんなに もどる」（<kbd>Esc</kbd>）で 一覧へ。こどもが うごかすと 大きい がめんも すぐ かわる
5. そのほか
   - **ぜんがめん**：ブラウザの わくも かくす
   - **この ばんごうを はずす**（大きい がめん）：まちがえた 番号を えらんだ 子など、その 番号を あける
   - **あとかたづけ**：こどもの だいしの データを けす（こどもの 端末の もようは のこる）
   - **クラスを おわる**：コードを けす（こどもの 端末は「クラスが おわったよ」で つなぐのを やめる）
   - **もどる**：じぶんの だいしに もどる。また 見る ときは **つなぐ → みんなの がめんを 見る**
     （クラスを つくった 端末・ブラウザ だけが 見られます）

### こども
1. **つなぐ** → **コードを いれる** → 6けたを おす → **じぶんの ばんごう**（1〜40）を おす
   - せんせいが くばった URL（`?c=コード`）で ひらいた ときは、すぐ ばんごうを えらぶ がめんに なる
2. ボタンが「**5ばん**」（みどり）に なれば つながっている。あとは いつも どおり もようを つくるだけ
3. ページを よみなおしても、おなじ ばんごうで つながりなおす
4. **5ばん** の ボタンから「ばんごうを かえる」「つなぐのを やめる」
- ほかの 子が もう つかっている 番号は えらべない（「ほかの 人が つかっているよ」）。
  まちがえた ときは せんせいが「この ばんごうを はずす」
- 名前は つかいません（番号 だけ）。ほかの 子の だいしは 見られません（見られるのは クラスを つくった せんせい だけ）

### つうしんの きまり
- 「ブロック おはじき」「かいて あてて」などと **おなじ Firebase プロジェクト（`hiro-kobako`）** の Realtime Database を つかいます
- おくるのは 色紙の いち だけ（1まい 4文字。だいし 1まい ぶんで 2KB くらい）。うごかすと 0.4びょう いないに とどく
- つながるのは「つなぐ」を おした 子と、みんなの がめんを 見ている せんせい だけ（30人＋1台）。
  Firebase の 無料プランは **同時に 100 まで**（ほかの アプリ あわせて）。こえても お金は かからない（つながらない だけ）
- **ファイルとして ひらいた とき（`file://`）は つなげません**。かならず `https://hirocelica0307-sketch.github.io/kobako/moyou-zukuri/` で ひらいてください

## Firebase の ルール（みんなの がめんを つかう まえに 1回だけ）

Firebase コンソールの **Realtime Database →「ルール」** の 中身を ぜんぶ、このフォルダーの
`database.rules.json` に おきかえて「公開」してください。

- ほかの アプリ（`kuku-block/`・`kaite-atete/`・`taipu-tsunahiki/`・`hanafuda/`・`mahjong/`）の `database.rules.json` も
  **おなじ なかみ** に そろえて あります。いままでの ぶぶんは そのままで、`moyou` の ぶぶんが ふえた だけです
- はって いないと、クラスを つくる・コードを いれる ときに「Firebase の ルールが まだ はられて いません」と 出ます
  （もようづくり そのものは つかえます）

```
moyou/rooms/{コード6けた}/
  owner          クラスを つくった せんせいの 匿名ID（さいしょの 1回 だけ 書ける）
  cfg            { t }
  kids/{1〜40}   { uid, no, st, on, t }  こどもの いまの だいし
```
- `kids` を 見る・けす ことが できるのは owner（せんせい）だけ
- `kids/{番号}` を 書けるのは さいしょに 書いた 端末（uid）だけ。クラスが ない コードには 書けない
- `st` は 2まん文字 まで。きまった 名まえ いがいは 書けない

## しくみ（先生・つくる人 むけ）

- だいしは「ます」（正方形の 1辺の 半分）の あつまり。色紙の いちは ますの 左うえで もつ
- かさなりは、1ますを 対角線で 4つに わけた 小さな 三角（北・東・南・西）で しらべる。
  こうすると 直角三角形 2まいで 正方形を つくる ことが できる
- すいつきは、ゆびの 下に くる いちの うち、おける ところで いちばん ちかい ところ。
  おなじ くらい ちかい ときは、まわりの 色紙と 辺で くっつく 数が おおい ほうを えらぶ

## ファイル

| ファイル | なかみ |
|---|---|
| `index.html` | アプリ 本体（きまりの ぶぶんは `// ==LOGIC==` 〜 `// ==/LOGIC==`、つうしんは `MoyouNet`） |
| `tests.js` | きまりの たしかめ（`node tests.js`） |
| `database.rules.json` | Realtime Database に はる ルール（ほかの アプリと おなじ なかみ） |

ためす とき：ページを ひらく まえに `window.__MOYOU_FAKE__ = true` を おくと、Firebase の かわりに
その ブラウザの 中だけで うごく にせものに なります（タブ どうしで とどくので、せんせい 1つ・こども いくつかの タブで ためせる）。

## これから（案）

- アイコン（ボタンの 絵・アプリの アイコン）を 素材ライブラリから えらんで つける（CLAUDE.md の きまりで、えらぶ まえに 確認）
- もようを 画像で ほぞん・いんさつ
- 「もようの 中に かくれた 正方形・長方形を さがそう」（かこむ どうぐ）
- 1つの まとまり（もようの もと）を えらんで くりかえし おく「スタンプ」
- おてほんの もよう（教科書の 3つの もよう）を 出す
- 本物の Firebase で 30台 つないだ ときの たしかめ（ルールを はった あと）
