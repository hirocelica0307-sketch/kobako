# お絵かきクイズ フレンズ

お題を絵にして、仲間に当ててもらう オンラインの お絵かきゲームです。
部屋を作って、スマホやパソコンから みんなで 遊べます。

**公開先** … `https://hirocelica0307-sketch.github.io/kobako/oekaki-friends/`

## ファイル構成

```
oekaki-friends/
├── README.md              このファイル
├── index.html             ホーム（部屋を つくる／入室する）
├── room.html              部屋の画面（お絵かき・回答・得点）※いちばん大きい
├── firebase-config.js     Firebase の 設定（4つの HTML が ここを 読む）
├── database.rules.json    Realtime Database に 貼る セキュリティルール
├── odailist.js            お題リスト
├── odaieditor.html        お題を 編集する ツール
├── wordstats.html         お題データを 集計する ツール
├── favicon.png            アイコン（64px）
├── favicon-32.png         アイコン（32px）
├── apple-touch-icon.png   ホーム画面に 追加したときの アイコン
└── og-image.png           SNSで 共有したときの プレビュー画像
```

## お題の数

| むずかしさ | 数 | ねらい |
|---|---|---|
| かんたん | 300語 | 小学校 低学年（1〜2年） |
| ふつう | 314語 | 小学校 中学年（3〜4年） |
| むずかしい | 304語 | 小学校 高学年〜中高生 |
| とてもむずかしい | 304語 | 大人レベル |
| 都道府県 | 47語 | 形や とくちょうで 表す |

お題を 足すときの きまりは `odailist.js` の 先頭に 書いてあります
（10文字以上は 入れない、カタカナ・ひらがなの 重複を 作らない など）。

## 動かすのに 必要なもの

**インターネット接続が いります。** 以下を 外から 読みこんでいます。

- **Firebase**（Realtime Database ＋ 匿名サインイン）… 部屋の やりとり
- Google Fonts（Zen Maru Gothic）… 文字の 見ため

**ファイルを 開くだけでは 遊べません。** 部屋の データを やりとりする 相手が
必要なためです。

# Firebase の 設定

いまは **自分の Firebase**（プロジェクト `hiro-kobako`／ロケーション
`asia-southeast1`）を つかっています。よその ところとは 完全に 別なので、
部屋が まざることは ありません。

以下は **つくりなおす ときの 手順**です（ぜんぶで 15分ほど）。
いま つかっている ものを 作った ときの 記録にも なっています。
パソコンの ブラウザで、いつも つかっている Google アカウントで 作業できます。

## 手順1 プロジェクトを つくる

1. **https://console.firebase.google.com/** を ひらいて、Google アカウントで ログイン
2. **「プロジェクトを作成」**（または「プロジェクトを追加」）を おす
3. **プロジェクト名**を 入れる … 例 `oekaki-friends`
   - 名前の 下に `oekaki-friends-a1b2c` のような **プロジェクト ID** が 出ます。
     そのままで かまいません
4. **「続行」**
5. **「このプロジェクトで Google アナリティクスを有効にする」** を **オフ** にして
   **「プロジェクトを作成」**
6. 30秒ほど 待つと できあがります → **「続行」**

## 手順2 Realtime Database を つくる

> ⚠️ **「Firestore」ではなく「Realtime Database」**です。
> 名前が にていますが、別のものです。このアプリは Realtime Database を つかいます。

1. 左メニューの **「構築」**（Build）→ **「Realtime Database」**
2. **「データベースを作成」**
3. **ロケーション** … **`asia-southeast1`（シンガポール）** を えらぶ
   - 日本から いちばん 近い えらべる 場所です
   - **あとから 変えられません**。ここだけ 気をつけてください
4. **セキュリティ保護ルール** … **「ロックモードで開始」** を えらんで **「有効にする」**
   - この時点では だれも 読み書きできません。次の 手順3 で 正しいルールを 入れます
5. できあがった 画面の 上に、こういう URL が 出ます。

   ```
   https://〇〇〇-default-rtdb.asia-southeast1.firebasedatabase.app
   ```

   **これを コピーして、どこかに ひかえておいてください。**
   手順6 で つかいます。

## 手順3 ルールを 貼る

1. Realtime Database の 画面の 上にある **「ルール」** タブを おす
2. 書いてある 中身を **ぜんぶ 消して**、下の 内容を 貼りつける
   （このフォルダーの `database.rules.json` と 同じものです）

   ```json
   {
     "rules": {
       "casual_rooms": {
         "$room": {
           ".read": "auth != null",
           ".write": "auth != null"
         }
       },
       "wordStats": {
         ".read": "auth != null",
         ".write": "auth != null"
       }
     }
   }
   ```

3. **「公開」** を おす（確認が 出たら そのまま 進める）

これは「**サインインした人だけが 読み書きできる**」という 意味です。
アプリが つかう 場所は 次の2つだけで、それ以外は すべて 拒否されます。

| 場所 | なかみ |
|---|---|
| `casual_rooms/部屋番号` | 部屋の 状態・参加者・絵・得点 |
| `wordStats/お題` | お題が 出た回数・当てられた回数 |

## 手順4 匿名サインインを 有効にする

> ⚠️ **ここが いちばんの つまずきポイントです。**
> 忘れると、部屋を 作る ボタンを おしても **何も 起きない** ように 見えます。

1. 左メニューの **「構築」** → **「Authentication」**
2. **「始める」** を おす
3. **「ログイン方法」**（Sign-in method）タブ を ひらく
4. 一覧の 下のほうの **「匿名」**（Anonymous）を おす
5. スイッチを **有効** に して **「保存」**

「匿名」は、名前も パスワードも 聞かずに 番号だけ 配る しくみです。
このゲームは 部屋番号と 名前を 自分で 管理しているので、これで 足ります。

## 手順5 設定の 値を 受けとる

1. 左上の **⚙️（歯車）** → **「プロジェクトの設定」**
2. 画面を 下へ スクロールして **「マイアプリ」** を さがす
3. **`</>`（ウェブ）** の アイコンを おす
4. **アプリのニックネーム** … 例 `oekaki-friends`
   - 「Firebase Hosting も設定する」は **チェックしない**
5. **「アプリを登録」**
6. こういう かたまりが 出ます。**これが ほしい ものです。**

   ```js
   const firebaseConfig = {
     apiKey: "AIza...",
     authDomain: "〇〇〇.firebaseapp.com",
     projectId: "〇〇〇",
     storageBucket: "...",
     messagingSenderId: "...",
     appId: "1:...:web:..."
   };
   ```

この画面は あとから **⚙️ →「プロジェクトの設定」→「マイアプリ」** で
いつでも 見られます。閉じてしまっても だいじょうぶです。

## 手順6 `firebase-config.js` に 書きうつす

**書きかえるのは この1ファイルだけです。** 4つの HTML が ここを 読むので、
HTML は さわらなくて よいです。

```js
const FIREBASE_CONFIG = {
    apiKey: "手順5の apiKey",
    authDomain: "手順5の authDomain",
    databaseURL: "手順2で ひかえた URL",
    projectId: "手順5の projectId",
    appId: "手順5の appId"
};
```

| 入れるもの | どこから |
|---|---|
| `apiKey` | 手順5 |
| `authDomain` | 手順5 |
| **`databaseURL`** | **手順2**（手順5には 出てきません） |
| `projectId` | 手順5 |
| `appId` | 手順5 |

> **`databaseURL` に 注意。** 手順5の `firebaseConfig` には **出てこないことが 多い**です。
> 手順2で ひかえた `https://〜.firebasedatabase.app` を 入れてください。
> ここが ちがうと、部屋が 作れても 中身が やりとりできません。

`storageBucket` と `messagingSenderId` は **このアプリでは つかいません。**
書かなくて だいじょうぶです。

## 手順7 動くか たしかめる

1. 公開した URL を、**2つの 画面**で ひらく
   （べつの 端末どうし、または パソコンの ふつうの窓と シークレット窓）
2. 片方で **部屋を つくる** → 出た 部屋番号を もう片方で **入室する**
3. Firebase の **Realtime Database →「データ」**タブを 見て、
   **`casual_rooms` が 増えていれば 成功**です

## うまく いかないときは

| こうなったら | 見なおすところ |
|---|---|
| 部屋を 作る ボタンを おしても 何も 起きない | **手順4**（匿名サインイン）が 有効か |
| 「Permission denied」と 出る | **手順3**（ルール）を 公開したか |
| 部屋は 作れるが 絵や 回答が 伝わらない | **`databaseURL`**（手順2の URL）が 正しいか |
| サインインで つまずく | Authentication → **「Settings」→「承認済みドメイン」**に `hirocelica0307-sketch.github.io` を 足す |

# GitHub Pages で 公開する

1. リポジトリの **Settings** → 左メニュー **「Pages」**
2. Source を **「Deploy from a branch」**
3. Branch を **`main`** ／ フォルダーを **`/ (root)`** → **Save**

数分で `https://hirocelica0307-sketch.github.io/kobako/oekaki-friends/` が 見られます。

> **注意** … リポジトリを **Private に している ばあい、GitHub Pages での 公開には
> 有料プラン（Pro）が 必要です。** 無料プランで 公開するには Public に 戻します。

# この写しについて

**別の ところで 公開していた 同じアプリを、ここに 写したもの**です（2026-09-22）。

別の URL で 公開できるように、写したあとで 次の 変更を 入れています。
**ゲームの 中身（あそび方・お題・絵をかく しくみ）は 変えていません。**

| 変えたところ | 内容 |
|---|---|
| Firebase の 設定 | 4つの HTML に 同じものが 4回 書かれていたので、`firebase-config.js` の1か所に まとめ、値を 自分の プロジェクト（`hiro-kobako`）に 差しかえた |
| セキュリティルール | `database.rules.json` を 追加（写した時点では ありませんでした） |
| アクセス解析 | Google アナリティクスの タグを 4つの HTML から 削除 |
| canonical ／ OGP ／ 構造化データ | URL 6か所を この 公開先に 書きかえ |
| 閲覧数カウンター | よその Firebase へ 見られた回数を 送る しくみを `index.html` から 削除 |
| もとの サイト名（文字） | 4か所から 削除 … `og:site_name`／構造化データの `publisher`／`meta description` の 最後の一文／画面 下の フッター |
| もとの サイト名（画像） | `og-image.png` の 左下に 焼きこまれていた 文字を 消し、背景の グラデーションで うめた |
