# お絵かきクイズ フレンズ

お題を絵にして、仲間に当ててもらう オンラインの お絵かきゲームです。
部屋を作って、スマホやパソコンから みんなで 遊べます。

## ファイル構成

```
oekaki-friends/
├── README.md              このファイル
├── index.html             ホーム（部屋を つくる／入室する）
├── room.html              部屋の画面（お絵かき・回答・得点）※いちばん大きい
├── odailist.js            お題リスト
├── odaieditor.html        お題を 編集する ツール
├── wordstats.html         お題データを 集計する ツール
├── favicon.png            アイコン（64px）
├── favicon-32.png         アイコン（32px）
├── apple-touch-icon.png   ホーム画面に 追加したときの アイコン
└── og-image.png           SNSで 共有したときの プレビュー画像
```

## お題の数

| むずかしさ | 数 | ねらい |
|---|---|---|
| かんたん | 300語 | 小学校 低学年（1〜2年） |
| ふつう | 314語 | 小学校 中学年（3〜4年） |
| むずかしい | 304語 | 小学校 高学年〜中高生 |
| とてもむずかしい | 304語 | 大人レベル |
| 都道府県 | 47語 | 形や とくちょうで 表す |

お題を 足すときの きまりは `odailist.js` の 先頭に 書いてあります
（10文字以上は 入れない、カタカナ・ひらがなの 重複を 作らない など）。

## 動かすのに 必要なもの

**インターネット接続が いります。** 以下を 外から 読みこんでいます。

- **Firebase**（Realtime Database ＋ Auth）… 部屋の やりとり。
  プロジェクトは `oekaki-quiz-23ab5`
- Google Fonts（Zen Maru Gothic）… 文字の 見ため
- Google アナリティクス … アクセス数の 集計

ひっ算ゲームと ちがい、**ファイルを 開くだけでは 遊べません**（部屋の データを
やりとりする 相手が 必要なため）。

## この写しについて

これは **[otatools/toolbox](https://github.com/otatools/toolbox) の
`oekakifriends/`** を そのまま 写したものです。

- 写した時点のコミット … `2457cb6`（2026-09-22）
- 9ファイルすべて 元と 同一（ハッシュ照合ずみ）
- フォルダーの 外を 参照している ところは ありません

### 公開する ときに 直すところ

この写しを 別の URL で 公開する ばあいは、`index.html` の 次の3つを
直してください（そのままだと 元のサイトの 数字に 混ざります）。

1. **Google アナリティクス** … `G-YTH979WTKL` の タグ
2. **canonical の URL** … `https://otatools.github.io/toolbox/oekakifriends/`
3. **OGP の URL と 画像** … `og:url` と `og:image`

また、**Firebase は 元のサイトと 同じ データベースを 使います。**
両方を 同時に 公開すると、部屋番号が ぶつかることが あります。
分けたい ばあいは Firebase の プロジェクトを 別に つくって、
`index.html` と `room.html` の 設定を 書きかえてください。
