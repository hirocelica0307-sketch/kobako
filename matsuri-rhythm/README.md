# おまつり リズム（仮称）

2年生 音楽「**おまつりの 音楽** ― くりかえしを つかって 音楽を つくりましょう」で つかう アプリです。
リズムカード（ア〜カ）を **4まい えらんで ならべる** と、**たいこの 音** で ならせます。

- **index.html 1ファイル** で うごく（サーバー・ログイン なし。たいこの 音は Web Audio で その場で つくる）
- Chromebook・iPad・電子黒板（テレビ）で つかえる。よこむきが おすすめ
- はやさは **♩＝90** で きまり（かえる ボタンは ない）

## つかいかた

| そうさ | なにが おきるか |
|---|---|
| **カードを おす** | きいろい わくの ところ（○まい目）に ならんで、その カードの 音が なる |
| **カードを ひっぱる** | すきな ところに おく。ならんだ カードを ひっぱると いれかえ、カードおきばに もどすと とれる |
| 🔊（カードの 右うえ） | ならべずに きく だけ |
| ならんだ カード・あいている ところを おす | そこを かえる ところに する（つぎに おした カードが そこに はいる） |
| ✕（ならんだ カード） | とる |
| **▶ ならす**（スペースキー でも） | えらんだ 4まいを たいこの 音で ならす。いま ならしている カード・音符・はく（●）が ひかる |
| **ずっと** | おわったら また はじめから（ならしながら カードを かえると、つぎの まわりから かわる） |
| **はく** | はくを ふちの「カッ」で うつ。はじめに カッ カッ と 2つ かぞえて から はじまる（リズム打ちが にがてな 子の 支援） |
| **れい** | きょうかしょの「1まい目と 2まい目を くりかえした れい」「1まい目と 3まい目を くりかえした れい」を ならべる |
| **ぜんぶ けす** | ならべた カードを けす |

- おなじ カードは おなじ いろ なので、くりかえしが 目で わかる。したに「くりかえし みつけた！ ア 1・3まい目」と でる
- ならべた カード・ずっと・はく は この たんまつに のこる

## たしかめて ほしい こと

- 「れい」の 2つの ならびかた（ア ア イ ウ／ア イ ア ウ）は 写真から 読んだ もの なので、教科書と ちがったら `index.html` の `EXAMPLES` を なおす
- 実機（Chromebook・iPad）での たいこの 音の きこえかた
