# おまつり リズム（仮称）

2年生 音楽「**おまつりの 音楽** ― くりかえしを つかって 音楽を つくりましょう」で つかう アプリです。
リズムカード（ア〜カ）を **4まい えらんで ならべる** と、**たいこの 音** で ならせます。
**ワッショイ・ヤー・ソレソレ** などの **かけごえ** に きりかえて ならす ことも できます。

- **index.html 1ファイル** で うごく（サーバー・ログイン なし。たいこの 音は Web Audio で その場で つくる）
- Chromebook・iPad・電子黒板（テレビ）で つかえる。よこむきが おすすめ

## つかいかた

| そうさ | なにが おきるか |
|---|---|
| **カードを おす** | きいろい わくの ところ（○まい目）に ならんで、その カードの 音が なる |
| **カードを ひっぱる** | すきな ところに おく。ならんだ カードを ひっぱると いれかえ、カードおきばに もどすと とれる |
| 🔊（カードの 右うえ） | ならべずに きく だけ |
| ならんだ カード・あいている ところを おす | そこを かえる ところに する（つぎに おした カードが そこに はいる） |
| ✕（ならんだ カード） | とる |
| **ドンドコ ／ かけごえ**（うえ） | カードの ことばを きりかえる。かけごえ は 赤い 字 |
| **▶ ならす**（スペースキー でも） | えらんだ 4まいを ならす。いま ならしている カード・音符・はく（●）が ひかる |
| **ずっと** | おわったら また はじめから（ならしながら カードを かえると、つぎの まわりから かわる） |
| **はく** | はくを ふちの「カッ」で うつ。はじめに カッ カッ と 2つ かぞえて から はじまる（リズム打ちが にがてな 子の 支援） |
| **たいこ** ／ **こえ** | たいこの 音 ／ ことばを いう こえ を だす・けす（こえ は ドンドコ と かけごえ で べつべつに おぼえる。はじめは かけごえ だけ オン） |
| **－ ♩＝88 ＋** | はやさ（60〜140） |
| **れい** | きょうかしょの「1まい目と 2まい目を くりかえした れい」「1まい目と 3まい目を くりかえした れい」を ならべる |
| **ぜんぶ けす** | ならべた カードを けす |
| **2人で つなげる** | A と B の 2だんに なる。A・B を おして えらび、それぞれ ならべて **A→B ／ B→A** で つなげて ならす（教科書 ④） |

- おなじ カードは おなじ いろ なので、くりかえしが 目で わかる。したに「くりかえし みつけた！ ア 1・3まい目」と でる
- ならべた カード・はやさ・きりかえは この たんまつに のこる

## かけごえの こえ（⚙️ せんせいの せってい）

- ことばが 4まいの カードの 音に あわせて きこえる。**ろくおん が ない ことばは たんまつの よみあげ** で いう
  - よみあげは たんまつに よって こえが ちがい、すこし おくれる ことが ある（おくれを はかって、すこし はやめに いう ように している）
- 🎤 で **先生の こえを ろくおん** すると、その ことばは ろくおんした こえで なる（まえと うしろの しずかな ところは じどうで きる。1.8びょうで とまる）
  - ろくおんは 1はく ぶん ずつ（例：「ワッ」と「ショイ」を べつべつに）。この たんまつの ブラウザ だけに のこる
- かけごえの ことばを かえる・はじめに もどす、よみあげの こえ・こえと たいこの 大きさ も ここで かえる

## たしかめて ほしい こと

- **写真で 読みとれなかった ところ**：ウ・エ・カ の カードの くみあわせは 依頼者に たしかめた（ウ＝ドン（ウン）、エ＝ドコドン、カ＝ドコドコ）。「れい」の 2つの ならびかた（ア ア イ ウ／ア イ ア ウ）は 写真から 読んだ もの なので、教科書と ちがったら `index.html` の `EXAMPLES` を なおす
- 実機（Chromebook・iPad）での たいこの 音の きこえかた・よみあげの おくれ・ろくおん
