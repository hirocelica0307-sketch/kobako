# おれいの てがみ びんせん

校外学習や ゲストの 先生への **お礼の 手紙** などに つかう、けい線つきの 便せんを 作って A4 で いんさつする ツールです。
**わくの 絵と 学年を えらぶだけ** で できあがります。わくは 白黒の 線画なので、子どもが 色を ぬる ことも できます。

- `index.html` を Chrome で ひらくだけで うごきます（ファイルとして ひらいても うごきます）
- えらんだ 設定は **この ブラウザの 中だけ** に のこります。字の フォントだけ Google Fonts から よみます

## できる こと

| 設定 | なかみ |
|---|---|
| ① ようし | A4 たて／A4 よこ |
| ② 1まいに いくつ | 1・2・4・6・8・9・12・16面。1面の 大きさ（mm）を 表示。2面いじょうは 切りはなす 点線つき |
| ③ かきかた | よこ書き／たて書き（たて書きは 右から 左へ） |
| ④ 字の 大きさ（学年） | 1・2年 15mm／3・4年 12mm／5・6年 8mm の 行の はばで、「この 紙には ◯行 はいります」を 自動で 計算。行の 数は −／＋ で かえられる（めやすに もどす）。1行 やく◯字・ぜんぶで やく◯字 の めやす。「＿＿へ」（あて名）・「＿＿より」（なまえ）の 行は つける／つけない を えらべる |
| ⑤ わくの 絵 | にぎやか 1しゅるい（さくらと 小鳥）・シンプル 10しゅるい ＋ むじ。きせつ（はる・なつ・あき・ふゆ・ぎょうじ・見学・通年）で しぼりこみ。「ぜんぶ 同じ」／「じゅんに くりかえす」（1面ずつ ちがう わく） |

- 面の 数・学年・わくなどを かえると、行の 数を 自動で 入れなおし、「◯◯を かえたので、行の 数を ◯行に しました」と しらせます
- 学年の 行の はばで 3行（あて名・本文・なまえ）が はいらない ときは、「面の 数を へらすか、わくを むじに」と 出ます
- こまかい 絵の わく（ひまわり・どんぐり・のりもの・やさい）を 12面・16面で えらぶと、つぶれやすい ことを しらせます
- いんさつは ブラウザの「倍率 100%」「余白 なし」で、行の はばが ぴったりに なります

## わくの しくみ

### にぎやかな わく

- 1つの テーマを **たて長（2:3）・よこ長（3:2）・正方形** の 3まいで 作り（`assets/frames-src/rich/<名前>-tate・yoko・kaku.webp`）、`tools/make_rich.py` で まるごと SVG に して、まん中の 書ける ところを はかります
- アプリは 面の 形に いちばん 近い 1まいを えらび、ゆがめずに おさめて、書ける ところに 行を ひきます
- ふやす とき：3まいを 入れて `python3 binsen/tools/make_rich.py` を うごかし、`frames.js` に `rich: true` の 1行を たす

### シンプルな わく

- もと画像（`assets/frames-src/`、ChatGPT で 作った 正方形の わく）から、`tools/make_frames.py` で **すみの 絵・へんの 絵 A・B** を 切り出して SVG に しています
- アプリでは、すみの 絵を 4すみに（右がわは 左右 はんてん）、A・B を 面の 大きさに あわせて 同じ 間かくで 交互に ならべます。だから 1面でも 16面でも、たて長でも よこ長でも 絵が ゆがみません
- わくを ふやす とき：`assets/frames-src/<きせつ>-<名前>.webp` を 入れて `python3 binsen/tools/make_frames.py` を うごかし、`frames.js` に 1行 たす

## ファイル

| ファイル | なかみ |
|---|---|
| `index.html`・`style.css`・`app.js` | アプリ |
| `frames.js` | わくの いちらん（名前・きせつ） |
| `assets/` | わくの 絵（出どころは `assets/README.txt`） |
| `tools/make_frames.py` | シンプルな わくの 絵を 切り出す プログラム |
| `tools/make_rich.py` | にぎやかな わくを SVG に して 書ける ところを はかる プログラム |
