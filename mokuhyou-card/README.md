# めあてカード こうぼう

新学期・学期の はじめ・運動会・音楽発表会・学期の おわり など、**節目に 子どもが 書く カード** を
えらんで、そのまま **A4 で いんさつ** できる アプリです。

- **白黒の 線画だけ**。書いた あとに 子どもが **色を ぬって 完成** させます
- ただの わくでは なく、ずかん・さくら・たからの ちず・メダル・ステージと チケット・だるま・フィルム・しょうじょう などの **デザインに 書きこむ** かたち
- かおは てんせんの まるに **じぶんで かく** ように して あります
- ふりがな つき（けすことも できる）
- **index.html 1ファイル** だけで うごきます。イラストは すべて その場で かく SVG なので、画像ファイルも ログインも いりません

## ひらきかた

**https://hirocelica0307-sketch.github.io/kobako/mokuhyou-card/**

`index.html` を ブラウザ（Chrome）で ひらくだけ。ファイルとして ひらいても（`file://`）うごきます。

## つかいかた

1. ひだりで カードを えらぶ
2. うえで「学年」「組」を えらぶと、なまえらんに いんさつ されます（空らんの ままでも よい）
3. 「🖨️ この カードを いんさつ」（まいすうも えらべる）／「🖨️ ぜんぶ 1まいずつ」
4. いんさつ がめんで **よはく「なし」・倍率 100%** に すると ぴったり A4 に なります（PDF に ほぞん しても おなじ）

## せってい

- **学年・組**：なまえらんに いんさつ。アルバムの「〇年生に なったら」にも つかう（6年なら「中学生に なったら」）
- **学期**：しょうじょう だけ。「第〇学期」に はいる
- **ふりがな**：かんじの うえの ふりがなを つける／けす
- **手がき ふうの 線**：線を すこし ゆらして 手で かいた ような あじを だす（けすと まっすぐな 線）

せっていと さいごに えらんだ カードは ブラウザに おぼえます（`#quest` の ように URL の うしろに カードの なまえを つけて ひらく ことも できる）。

## しくみ

- 1まい ＝ `viewBox="0 0 210 297"` の SVG（1 ＝ 1mm）。線は くろ、ぬりは しろ だけ
- かざり（わく・イラスト）は `feTurbulence` + `feDisplacementMap` で すこし ゆらす。文字と 書く 線は ゆらさない
- ふりがなの いちは、ブラウザで 文字の はばを じっさいに はかって あわせる（フォントが よみこまれたら かきなおす）
- フォント：Mochiy Pop One（タイトル）・Zen Maru Gothic（ことば）・Klee One（学年・組）。ネットに つながって いない ときは パソコンの フォントで でる
