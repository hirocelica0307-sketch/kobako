# 毎日教養

**大人が一人で、スマートフォンで使う**教養クイズアプリです。
1日10問・5分ほど、20ジャンルの問題を解いて、答えのあとの詳しい解説で知識を広げます。

- 問題は **20ジャンル × 100問 ＝ 2000問**。どの問題にも、解説・まちがいの選択肢ごとの説明・ワンポイントがある
- サーバー・ログイン・外部API なし。記録はそのスマホのブラウザ（localStorage）だけに保存
- 一度ひらけば、インターネットにつながっていなくてもひらける（`sw.js`）
- ホーム画面に追加すると、アプリのように全画面で使える（`manifest.webmanifest`）
- スマートフォン専用の画面（タブバー・下の「次へ」ボタン・戻るボタン・ノッチの余白・暗い画面・文字の大きさ）

## 知識が身につくしくみ（研究の裏づけ）

アプリの「このアプリの考え方」にも、同じ内容を書いています。

| しくみ | なかみ | 裏づけ |
|---|---|---|
| 先にクイズ、あとで解説 | 答える前に考えることで、解説が記憶に残りやすくなる | テスト効果（Roediger & Karpicke 2006）・事前テスト効果 |
| 自信を聞く | 答えを選んだら「自信あり／たぶん／勘」を選ぶ。**自信ありでまちがえた問題は「思い込み」**として印を付け、翌日もう一度出す | 確信度の高い誤りほど直りやすい（ハイパーコレクション効果、Butterfield & Metcalfe 2001） |
| 間をあけてくり返す | 正解するたびに 翌日 → 3日後 → 1週間後 → 3週間後 → 2か月後 → 5か月後。まちがえたら翌日から。3週間後でも正解できたら「覚えた」 | 分散学習（Cepeda ほか 2006）・ライトナー方式 |
| ジャンルをまぜる | 10問は毎日いろいろなジャンルから、となりが同じジャンルにならないように出す | 交互学習（インターリービング） |
| 間違えた問題をもう一度 | 10問のあと、間違えた問題だけその場でもう一度解く（自信は聞かない） | すぐの再テストと正答の確認 |
| 思い出してから選ぶ（設定） | 選択肢をかくし、答えを思い浮かべてから表示する | 再生（思い出す）のほうが再認より記憶を強める |
| 続けるしかけ | 連続日数・7日ごとに「おやすみ券」（最大2枚、1日休んでも記録が切れない） | 習慣化を、きびしすぎない形で支える |

## 画面

- **ホーム**：今日の10問（新しい問題と復習。復習は半分まで）・ジャンルを選ぶ・復習だけ・思い込みを直す・★の問題・おまかせ・これまでの記録
- **問題**：選択肢をタップ → 自信 → 正解・不正解と、選択肢ごとの説明・「なぜ？」・ワンポイント・★印・「あやしい？」印
- **ノート**：解いた問題の解説をジャンルごとに読み返せる（すべて・★印・思い込み・間違えた／検索）
- **記録**：連続日数・覚えた問題・出会った問題・正解率・思い込み（直したい／直した）・6週間のカレンダー・ジャンルごとの記録
- **設定**：1日の問題数（5・10・15・20）・自信を聞く・思い出してから選ぶ・文字の大きさ・画面の明るさ（自動・明るい・暗い）・効果音・振動・出すジャンル・「あやしい」印の問題をコピー・記録の書き出し／読み込み・記録を消す

## ジャンル（各100問）

政治・法律／経済・お金／ビジネス・経営／国際・地理／日本史／世界史／哲学・思想／宗教・神話／心理学・行動経済学／文学／美術・建築／音楽／芸能・映画・伝統芸能／スポーツ／科学・宇宙／生物・医学・健康／IT・テクノロジー／数学・統計・論理／ことば／食・暮らし・マナー

### 問題ファイルの形（`data/<ジャンル>.js`）

```js
MKData.add('kagaku', [
['テーマ', '問題文',
 ['正解', 'まちがい1', 'まちがい2', 'まちがい3'],   // 0番目が正解（画面では毎回ならびかえる）
 '解説',
 ['まちがい1の説明', 'まちがい2の説明', 'まちがい3の説明'],
 'ワンポイント'],
]);
```

- 問題の id は「ジャンル/テーマ」。テーマはジャンルの中で重ならないようにする（記録はこの id で保存）
- 問題を足したり直したりしたら、`node tools/tests.js` でたしかめる（形・空欄・同じ選択肢・テーマや問題文の重なり）

## ファイル

| ファイル | なかみ |
|---|---|
| `index.html` | 画面 |
| `style.css` | 見た目（明るい・暗い、文字の大きさ） |
| `logic.js` | 画面を使わない処理（今日のセット・復習の予定・連続日数・集計・保存データ） |
| `app.js` | 画面の動き |
| `data/` | 問題（`_base.js` にジャンルの一覧） |
| `assets/` | 絵とアイコン（入手もとは `assets/README.txt`） |
| `sw.js`・`manifest.webmanifest` | オフラインとホーム画面 |
| `tools/tests.js` | 問題データと `logic.js` のテスト（`node tools/tests.js`） |
| `tools/e2e.js` | iPhone SE・iPhone 15 Pro・Pixel 7・Galaxy S9+ の画面で通しで動かすテスト（Playwright） |

## 問題の内容について

問題は、事実をできるだけ確かめて書き、何度か見直していますが、まちがいが残っているかもしれません。気づいた問題には「あやしい？」の印を付けておき、設定の「あやしい印の問題」からまとめてコピーできます。
