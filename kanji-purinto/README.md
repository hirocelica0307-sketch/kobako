# かんじプリント（仮）

先生が 入れた 例文から、**漢字テスト（問題と 答え）** と **漢字ノート（なぞり・練習）** を 作って 印刷する ツールです。
まずは **2年・国語（東京書籍）** に あわせて います。

- `index.html` を Chrome で ひらくだけで うごきます（ファイルとして ひらいても うごきます）
- 入れた 例文・単元・作った 問題は、**この ブラウザの 中だけ** に 保存します（インターネットには 送りません）。字の フォントだけ Google Fonts から よみます
- ほかの パソコンや 先生と 分けるときは「例文・単元」→「ファイルに 書き出す／よみこむ」

## 漢字テスト

| 設定 | なかみ |
|---|---|
| 問題の 数 | 5問・10問（**A4 よこ**）／15問・20問（**B4 よこ**）。5問は 1だん、10問から 2だん |
| 問題の しゅるい | 読みがな（漢字 → ひらがな）・漢字を 書く（ひらがな → 漢字）・まぜる（読みの 数を ＋− で きめる。のこりが 書き） |
| 出す はんい | 学期で えらぶ・単元で えらぶ・漢字で えらぶ（2年の 160字）。習う 漢字が かたよらない ように、まだ 出て いない 漢字の 例文から えらびます |
| □の 中の 十字の 点線 | あり／なし |

- 紙は たて書き。右に タイトル・月日・なまえ、左に **れんしゅうの マス（よこ 2れつ・たて 10マス）**
- 書きの 問題：漢字 1字に □ 1つ、右に 読みがな。送りがなが ある ときは（　）で、送りがなも 書く
- 読みの 問題：漢字の 右に 読みを 書く わく
- 答えは 同じ 形で、答えが 赤字で 入ります。「答えも いっしょに 印刷・保存」で 問題の つぎの ページに 入ります
- 問題に マウスを のせると **⇄（ほかの 例文に 入れかえ）・直す・出さない** が 出ます。「出さない」に した 例文は「例文・単元」で もどせます
- 「ちがう問題で 作り直す」で、同じ 設定の まま えらびなおします
- 作った 問題は 名前を つけて 保存し、あとで ひらけます

## 漢字ノート

市販の 漢字練習帳と **同じ マスの 大きさ** です。マスの 寸法は ショウワノート「ジャポニカ学習帳 かんじれんしゅう／漢字練習帳」（B5）の 商品情報に あわせました。
「よこ×たて」は 元の アイデアの 画面と 同じ よみかたに して います。

| 字数 | 1行の 字数 × 行 | マス（よこ×たて） |
|---|---|---|
| 50字 | 10字 × 5行 | 22mm |
| 84字 | 12字 × 7行 | 18×17mm |
| 91字 | 13字 × 7行 | 17mm |
| 104字 | 13字 × 8行 | 17×15mm |
| 120字 | 15字 × 8行 | 14mm |
| 150字 | 15字 × 10行 | 14×12mm |
| 200字 | 20字 × 10行 | 11mm |

- 用紙：**B5（182×257mm。ノートと 同じ）** か **A4（同じ マスで、まわりに 余白）**
- 印刷は 倍率「**100%（実際の サイズ）**」で。B5 の ときは プリンターの 用紙も B5 に
- マスの 中に 十字の 点線、マスの 右に 読みがなの 細い 行
- 「ことば」を 1行に 1つ 入れると、行の 上から うすい 字で 入り（なぞる）、のこりは 練習マス。読みがなも うすい 字で なぞれます
  - `春の風(はるのかぜ)` … 読みの 中の「の」を 目じるしに、春＝はる・風＝かぜ に わけます
  - `花(はな)火(び)` … 1字ずつ 書くと、読みが 字の となりに そろいます
  - `花火大会(はなびたいかい)` … 漢字だけの ことばは、読みを ことば ぜんたいの となりに 入れます
  - 空の 行は 1行 あけます。何も 入れなければ マス目だけの ノート
- 読みがなの 行の はばは、マスが 用紙に おさまる ように 字数ごとに きめて います（150字は 約3mm と 細め）

## 例文・単元の 入れかた

**例文**（1行に 1問）：問題に する ところを `[ ]` で かこみ、すぐ うしろの `( )` に 読みを ひらがなで。

```
[春](はる)に なると 花が さく
[電車](でんしゃ)に のる
[新しい](あたらしい) くつを はく
```

- `[ ]` の ほかの 漢字は そのまま 出ます。1・2年で 習わない 漢字が あると おしえます
- 「例文・単元」に 2年の 160字ごとの 例文の 数が 出ます（0 の 字は 赤）
- 「見本の 例文を 下に たす」で、ためしの 例文（オリジナル）を 入れられます

**単元**（1行に 1単元）：`学期, 単元名, 新しく 習う 漢字`。エクセルの 3列を はりつけても よい（タブ）。
教科書の じゅんに ならべます。前の 単元の 漢字は「習った 漢字」として、熟語の 問題に つかえます。

> 東京書籍の 単元ごとの 新出漢字は、まだ 入って いません。作った ときの 環境から 東京書籍の サイト（東書Eネット）に つながらなかったため、データを たしかめられませんでした。
> 教科書の 巻末の 漢字一覧などから 入れるか、東書Eネットの 資料を もとに あとで 入れます。

## たしかめ

```
node tests.js
```

漢字の 表（1年 80字・2年 160字）、例文と 単元の よみかた、はんい、問題の えらびかた（かたよりなく・同じ 例文を くりかえさない・たりない ときの 数）、入れかえ、紙の 大きさ（5・10問 A4／15・20問 B4）、長い 文の 字の 大きさ、ノートの マス（7しゅるい × B5・A4 が 紙に おさまる）、読みがなの わりふりを しらべます。
印刷の 大きさは Chromium の PDF で たしかめました（A4 よこ 297×210mm・B4 よこ 364×257mm・B5 182×257mm・A4 210×297mm）。

## まだ たしかめて いない こと・これから

- **実際の プリンターでは まだ 印刷して いません。** 市販の ノートと 重ねて マスが あうか たしかめて ください
- 東京書籍の 単元データ（上の とおり）
- 2年 いがいの 学年
