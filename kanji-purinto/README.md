# 漢字プリ＆テスト作成支援

**漢字を えらぶだけで**、**漢字テスト（問題と 答え）** と **漢字ノート（なぞり・練習）** を 作って 印刷する ツールです。
アプリに 2年の 160字 すべての 例文（499文・オリジナル）が 入って います。自分で 作った 例文も つかえます。
まずは **2年・国語（東京書籍）** に あわせて います。

- `index.html` を Chrome で ひらくだけで うごきます（ファイルとして ひらいても うごきます）
- 入れた 例文・単元・作った 問題は、**この ブラウザの 中だけ** に 保存します（インターネットには 送りません）。字の フォントだけ Google Fonts から よみます
- ほかの パソコンや 先生と 分けるときは「例文・単元」→「ファイルに 書き出す／よみこむ」

## 漢字テスト

| 設定 | なかみ |
|---|---|
| 問題の 数 | 5問・10問（**A4 よこ**）／15問・20問（**B4 よこ**）。5問は 1だん、10問から 2だん |
| 問題の しゅるい | 読みがな（漢字 → ひらがな）・漢字を 書く（ひらがな → 漢字）・まぜる（読みの 数を ＋− で きめる。のこりが 書き） |
| 出す はんい | 学期で えらぶ・単元で えらぶ・漢字で えらぶ（2年の 160字）。漢字で えらぶ ときは、えらんでから **「えらんだ 漢字で 文を 自動で 入れる」** を おします。習う 漢字が かたよらない ように、まだ 出て いない 漢字の 例文から えらびます |
| 例文の もと | アプリの 文・自分で 入れた 文（両方 えらべます） |
| □の 中の 十字の 点線 | あり／なし |

- 紙は たて書き。右に タイトル・月日・なまえ、左に **れんしゅうの マス（よこ 2れつ・たて 10マス）**
- 書きの 問題：漢字 1字に □ 1つ、右に 読みがな。送りがなが ある ときは（　）で、送りがなも 書く
- 読みの 問題：漢字の 右に 読みを 書く わく
- 答えは 同じ 形で、答えが 赤字で 入ります。「答えも いっしょに 印刷・保存」で 問題の つぎの ページに 入ります
- 問題に マウスを のせると **⇄ 別の文・直す・出さない** が 出ます
  - **⇄ 別の文**：その 問題の 漢字が 入った 別の 文に かわります（押すたびに かわる。もう ない ときは おしらせ）
  - **直す**：自分の 例文を 直します。アプリの 文を 直すと、直した 文が 自分の 例文に 入り、もとの 文は 出さなく なります
  - **出さない**：その 文を もう 出しません（同じ 漢字の 別の 文に かわる）。「例文・単元」で もどせます
- 「ちがう問題で 作り直す」で、同じ 設定の まま えらびなおします
- 作った 問題は 名前を つけて 保存し、あとで ひらけます

## 漢字ノート

市販の 漢字練習帳と **同じ マスの 大きさ** です。マスの 寸法は ショウワノート「ジャポニカ学習帳 かんじれんしゅう／漢字練習帳」（B5）の 商品情報に あわせました。
「よこ×たて」は 元の アイデアの 画面と 同じ よみかたに して います。

| 字数 | 1行の 字数 × 行 | マス（よこ×たて） |
|---|---|---|
| 50字 | 10字 × 5行 | 22mm |
| 84字 | 12字 × 7行 | 18×17mm |
| 91字 | 13字 × 7行 | 17mm |
| 104字 | 13字 × 8行 | 17×15mm |
| 120字 | 15字 × 8行 | 14mm |
| 150字 | 15字 × 10行 | 14×12mm |
| 200字 | 20字 × 10行 | 11mm |

- 用紙：**B5（182×257mm。ノートと 同じ）** か **A4（同じ マスで、まわりに 余白）**
- 印刷は 倍率「**100%（実際の サイズ）**」で。B5 の ときは プリンターの 用紙も B5 に
- マスの 中に 十字の 点線、マスの 右に 読みがなの 細い 行
- **漢字を えらんで 自動で 入れる**：160字から えらび、「1字に ことば 1つ／2つ／3つ」を きめて「えらんだ 漢字の ことばを 入れる」。
  ことばは アプリの 例文（と 自分の 例文）の [ ] の ことばから、その 字 だけ（春）→ 送りがな つき（新しい）→ 熟語（春風）の じゅんに えらびます。入った あとで 自由に 直せます
- 「ことば」を 1行に 1つ 自分で 入れても よいです。行の 上から うすい 字で 入り（なぞる）、のこりは 練習マス。読みがなも うすい 字で なぞれます
  - `春の風(はるのかぜ)` … 読みの 中の「の」を 目じるしに、春＝はる・風＝かぜ に わけます
  - `花(はな)火(び)` … 1字ずつ 書くと、読みが 字の となりに そろいます
  - `花火大会(はなびたいかい)` … 漢字だけの ことばは、読みを ことば ぜんたいの となりに 入れます
  - 空の 行は 1行 あけます。何も 入れなければ マス目だけの ノート
- 読みがなの 行の はばは、マスが 用紙に おさまる ように 字数ごとに きめて います（150字は 約3mm と 細め）

## 例文・単元の 入れかた

**例文**（1行に 1問）：問題に する ところを `[ ]` で かこみ、すぐ うしろの `( )` に 読みを ひらがなで。

```
[春](はる)に なると 花が さく
[電車](でんしゃ)に のる
[新しい](あたらしい) くつを はく
```

- `[ ]` の ほかの 漢字は そのまま 出ます。1・2年で 習わない 漢字が あると おしえます
- 「例文・単元」に 2年の 160字ごとの 例文の 数が 出ます（0 の 字は 赤）
- 「アプリの 文を ここに コピーして 直す」で、アプリの 文を ぜんぶ 自分の 例文に コピーできます（直したら、テストの「例文の もと」で「アプリの 文」を はずす）

## アプリに 入って いる 例文（`data.js`）

- 2年の 160字 すべてに 3〜5文、ぜんぶで 499文。すべて オリジナルです
- [ ] の ほかの 漢字は **1年の 漢字だけ**（2年の 漢字は ひらがな）。2年の 4月から つかえます
- 読みは 小学校で 習う 読み（学年別漢字配当表・音訓）に あわせました（中学で 習う 読み〔姉妹の シ・マイ、兄弟の キョウ など〕は つかって いません）
- どの 字も、その 字（と 1年の 漢字）だけで できた 文が あるので、1字だけ えらんでも 出せます
- 熟語で 2年の 漢字が 2つ ある 文（公園・算数 など）は、両方の 字を えらんだ ときに 出ます。京・午・黄・算は その 字 だけの 文が 1つなので、1字だけ えらぶと ⇄ で かわる 文が 少ないです
- 弟・妹 は 小学校で 習う 読みが 1つなので、ノートの ことばは 1つだけです

**単元**（1行に 1単元）：`学期, 単元名, 新しく 習う 漢字`。エクセルの 3列を はりつけても よい（タブ）。
教科書の じゅんに ならべます。前の 単元の 漢字は「習った 漢字」として、熟語の 問題に つかえます。

> 東京書籍の 単元ごとの 新出漢字は、まだ 入って いません。作った ときの 環境から 東京書籍の サイト（東書Eネット）に つながらなかったため、データを たしかめられませんでした。
> 教科書の 巻末の 漢字一覧などから 入れるか、東書Eネットの 資料を もとに あとで 入れます。

## たしかめ

```
node tests.js
```

漢字の 表（1年 80字・2年 160字）、アプリの 例文（ぜんぶ よめる・[ ] の ほかは 1年の 漢字だけ・160字 すべてに 3文 いじょう・1字だけで 出せる）、⇄ 別の文（同じ 漢字の 別の 文に なる）、ノートの ことばの 自動、例文と 単元の よみかた、はんい、問題の えらびかた（かたよりなく・同じ 例文を くりかえさない・たりない ときの 数）、入れかえ、紙の 大きさ（5・10問 A4／15・20問 B4）、長い 文の 字の 大きさ、ノートの マス（7しゅるい × B5・A4 が 紙に おさまる）、読みがなの わりふりを しらべます。
印刷の 大きさは Chromium の PDF で たしかめました（A4 よこ 297×210mm・B4 よこ 364×257mm・B5 182×257mm・A4 210×297mm）。
