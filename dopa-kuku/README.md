# ドパ九九

ランダムに 出てくる 九九を **1問 5びょう いないに こたえつづける**、おわりの ない チャレンジ型の アプリです（小学2年生むけ）。
正解が つづくほど、パチンコの 確定演出のように **光・虹色・音が どんどん はげしく** なります。
1回でも まちがえるか、時間ぎれに なったら おしまい。きろくは「何問 れんぞくで 正解できたか」です。

> コンセプト：**「正解するほど、世界が にぎやかに なる」**
> 演出の 強さは「れんぞく正解数」だけで きまります。ランダムに 当たる しくみは 入れていません。
> 演出が 派手に なるのは、かならず 子どもの 実力で 正解を かさねた ときだけです。

- つかう 場面：各段の 意味を 授業で 学んだ あとの 練習・朝学習・すきま時間・家庭学習（九九の 導入には つかいません）
- 端末：Chromebook（よこ画面）が 基本。スマートフォン（たて画面）でも 遊べます
- 企画書「ドパ九九 企画書・ワイヤーフレーム」（2026-09-28）の とおりに 作りました

## ひらきかた

**https://hirocelica0307-sketch.github.io/kobako/dopa-kuku/**

`index.html` を ブラウザ（Chrome・Safari）で 開くだけ。インストールも ログインも いりません。
ファイルとして 開いても（`file://`）動きます。音も プログラムで 作るので、ネットが なくても 遊べます。

```
cd dopa-kuku
python3 -m http.server 8000    # → http://localhost:8000
```

## あそびかた

1. **タイトル** →「▶ はじめる」
2. **コースえらび**（11コース）。ボタンの 下に その コースの さいこう きろく
3. 「3・2・1・スタート！」（各 0.7びょう）の あと、すぐ 1問め
4. 画面の テンキーで こたえを 入れる。**答えの けた数に なった しゅんかんに 自動で はんてい**（「こたえる」ボタンは ありません）
5. 正解すると すぐ つぎの 問題。まちがい・時間ぎれで **ゲームオーバー**
6. ゲームオーバー画面には **さいごの 問題と 正しい 答え**（`7 × 8 = 56`）と となえかた（しちは ごじゅうろく）を 大きく 出します。
   「もういちど」で おなじ コースを すぐ カウントダウンから

| No. | コース | 出題はんい | 問題の しゅるい |
|---|---|---|---|
| 1〜8 | 2のだん 〜 9のだん | 2×1〜2×9 … 9×1〜9×9 | 9しゅるい |
| 9 | ぜんはん | 2の段〜5の段 | 36しゅるい |
| 10 | こうはん | 6の段〜9の段 | 36しゅるい |
| 11 | ぜんぶ | 1の段〜9の段 | 81しゅるい（1の段は ここ だけ） |

- 同じ 問題は 2回 つづけて 出ません。9しゅるいしか ない 段の コースは **直前 3問と 同じ 問題を 出しません**
- **制限時間**：1問ごとに 5びょう（せっていで 3・5・7びょう）。問題が 出た しゅんかんから 数え、正解すると リセット
- **のこり時間**：入力欄の すぐ下の ゲージが 右から へる。のこり 2びょうで 黄色、のこり 1びょうで 赤く 点滅（1びょうに 2回）
- キーボードでも 遊べます（数字キー・Backspace。日本語入力が オンでも 数字キーの 場所で わかります）

## 演出（ドパレベル）

れんぞく正解数（コンボ）だけで きまり、**前の レベルの 演出は けさずに つみあげます**。

| Lv | コンボ | 正解した しゅんかん | つねに かわる 画面 | 音 |
|---|---|---|---|---|
| 0 | 0〜2 | 答えの 数字が 緑に 光る | 暗めの 背景 | ピッ |
| 1 | 3 | 数字が はずむ・星が 5こ とぶ | 画面の ふちに 細い ライト | ピコン（コンボごとに ドレミファソラシドと 上がる） |
| 2 | 6 | 紙吹雪 30まい・ライトが 1周 ながれる | ふちの ライトが 青く | 和音「ピコーン」 |
| 3 | 10 | 画面が 小さく ゆれる・コンボ数が「ドンッ」と とび出す | 背景に 回転する 光線 | 低音の ビート（BGM）開始 |
| 4 | 15 | 左右から ライトが クロス・花火 1発 | ふちの ライトが 緑に、ながれるように | BGM に メロディ |
| 5 | 20 | **【ドパタイム突入】** | 背景が 赤と オレンジの 炎 | ギュイーン → BGM が アップテンポ |
| 6 | 30 | 花火 3発・画面の 四すみから 光線・問題の まわりが 金色に 光る | ふちの ライトが 赤く 高速で ながれる | 正解音が「キュイン！」 |
| 7 | 40 | 金色の 紙吹雪・「激アツ!!」 | 背景が 金色に かがやき、光の 粒が つねに まう | キュインキュイン |
| 8 | 50 | **【虹ドパ到達】** | 画面ぜんたいが 虹色に ゆっくり 色がわり | キュインキュインキュイン＋ファンファーレ |

- **ドパタイム突入（20）**：画面が 一瞬 暗く なり「ドンッ」と 同時に ななめの 帯が 横切って「ドパタイム突入!!」（約 0.8びょう）
- **虹ドパ（50）**：0.3びょうの 無音の「ため」→ 画面の ふちから 虹色の 光が 広がる → キュイン×3 →「にじドパ!!」が 回りながら 着地 → 大きく ゆれて 紙吹雪 300まい（約 1.5びょう。**この ときだけ タイマーを とめます**）
- **確定演出（60・70・80 …）**：虹ドパの みじかい 版（0.8びょう）。**100れんぞく** は 専用の 特大演出
- **節目の テロップ**：5・10・20・30・40・50 … で「○れんぞく!」
- 前の じぶんの きろくを こえた しゅんかんに「きろく こえた！」

### 演出を おく 場所の きまり

- **問題の 数字・のこり時間ゲージ・テンキー には 演出を かさねません**。演出は 背景・画面の ふち・問題の まわり だけ
  （紙吹雪や 光は 問題と テンキーの「うしろ」の 層に かいています）
- 問題・入力欄・ゲージは 白地、テンキーは こい 無地で、どの レベルでも 読みやすさを まもります
- 1回の 正解演出は 0.8びょう いない。演出中も つぎの 問題を 出し、入力を うけつけます

### ゲームオーバー演出

1. ミス・時間ぎれの しゅんかん、BGM が とまり、画面の うごきが 0.3びょう だけ スローに
2. 画面が 灰色に なり「ゲームオーバー」が 上から おちてくる（短い「ポン」だけ。大きな 失敗音や 赤い バツは つかいません）
3. さいごの 問題と 正しい 答えを 大きく（まちがえた ときは 入れた 数を 小さく 灰色で）
4. きろくを 表示。**新記録なら 灰色の 画面が 一気に 虹色に もどり「しんきろく!!」＋ファンファーレ**

### 安全の きまり

- 画面ぜんたいの 強い 明滅は **1びょうに 3回まで**（光過敏の 発作を さける 国際的な めやす）。虹色は 点滅させず、色を なめらかに かえます
- 粒子（紙吹雪・光の 粒）は 同時に **800こ まで**（スマホは **400こ まで**）
- 端末の「視差効果を減らす（動きを減らす）」が オンなら、自動で「ひかえめ」に なります

## せってい（タイトル・コースえらびの 右上）

| 項目 | えらべる もの | 初期値 |
|---|---|---|
| せいげんじかん | 3びょう／5びょう／7びょう | 5びょう |
| こうかおん | オン／オフ | オン（オフに すると BGM も 鳴りません） |
| BGM | オン／オフ | オン |
| えんしゅつ | ド派手／ひかえめ | ド派手（「視差効果を減らす」が オンの 端末は ひかえめ） |
| きろくを けす | ボタン（かくにん つき） | ― |

- 「ひかえめ」：画面の ゆれと 明滅（暗転・ゲージの 点滅）を とめ、粒子の 数を 3分の1 に します。光や 音が 苦手な 子に
- せってい画面の 下に **にがてな九九**（ゲームオーバーに なった 回数が 多い じゅんに 上位 5問）

## きろく（その 端末の ブラウザに 保存）

| キー（localStorage） | なかみ |
|---|---|
| `dopakuku_best` | コース × 制限時間ごとの さいこう れんぞく数（`{"zenbu_5": 37, "dan7_3": 12, …}`） |
| `dopakuku_miss` | 問題ごとの ゲームオーバー回数（`{"7x8": 3, …}`） |
| `dopakuku_settings` | せってい（`{"limit": 5, "sound": true, "bgm": true, "fx": "hade"}`） |

- きろくは 制限時間ごとに わけて 保存します（3びょうの きろくと 5びょうの きろくは べつ）
- とちゅうで「やめる」を おした ときも、それまでの れんぞく数が さいこうを こえていれば きろくします

## 画面

| 画面 | よこ長（Chromebook） | たて長（スマホ） |
|---|---|---|
| A タイトル | ロゴの ふちを ライトが ながれ つづける・ぜんぶコースの さいこう きろく | 同じ |
| B コースえらび | 段は 4れつ × 2だん、ぜんはん・こうはん・ぜんぶ は 3つ ならび | 段は 2れつ、ミックスは 1れつ |
| C プレイ | 左に 問題・右に テンキー（1つ 80×80px いじょう） | 上に 問題・下半分に テンキー（1つ 画面はばの 約28%） |
| D ゲームオーバー | 同じ | 同じ |
| E せってい | 同じ | 同じ |

- 画面の たて よこの 比で 自動で 切りかえます。文字や ボタンの 大きさは 画面に あわせて のびちぢみ（`vmin`・`clamp()`）
- スマホの 高さは `dvh` で きめ、アドレスバーが 出たり 入ったり しても ずれません
- ダブルタップでの 拡大・スクロール・ひっぱって 更新 を とめています（れんだで 画面が うごかない ように）
- iPhone は 画面を さわるまで 音が 鳴らないので、ボタンを おした ときに 音の じゅんびを します
- ゲームオーバー直後の 0.9びょうは ボタンを うけつけません（テンキーの れんだで「もういちど」が 押されない ように）

## ファイル構成

```
dopa-kuku/
├── README.md      このファイル
├── index.html     画面 A〜E の 骨組み
├── style.css      レイアウト（よこ長・たて長）・ボタン・CSS アニメーション・ドパレベルごとの 背景と ふち
├── logic.js       画面を つかわない きまり（11コース・出題・はんてい・ドパレベル・確定演出・きろく・となえかた）
├── main.js        画面の 切りかえ・出題・はんてい・制限時間（performance.now()）・きろく・せってい。できごとを 発行する
├── effects.js     ドパレベル・特別演出・ゲームオーバー演出（できごとを うけとって うごく）
├── particles.js   Canvas の 粒子エンジン（紙吹雪・星・花火・光の 粒）
├── sound.js       効果音・BGM の 合成（Web Audio API。ピッ・ピコン・キュイン・ギュイーン・ドンッ・ファンファーレ・ポン）
├── tests.html     きまりの たしかめ 52こ（ブラウザで 開く）
└── tests.js       〃（`node tests.js` でも 動く）
```

外部ライブラリ・画像・音声ファイルは つかっていません（文字だけ Google Fonts。つながらない ときは 端末の 文字で 出ます）。
ES モジュールを 使わず ふつうの `<script>` で 読みこんでいるので、`file://` でも 動きます。

### 演出を 作りなおす とき（できごとの しくみ）

ゲーム（`main.js`）は 演出を 知りません。できごとを `Dopa.bus` で 知らせるだけで、`effects.js` が それを うけとって 光・音・紙吹雪を 出します。
`effects.js` を 読みこまなくても、ゲームは さいごまで 遊べます。演出だけを 何度でも 派手に 作りなおせます。

| できごと | なかみ |
|---|---|
| `start` | コース・制限時間・さいこう きろく（カウントダウンの 前） |
| `countdown` | 「3」「2」「1」「スタート！」 |
| `question` | 出した 問題（`hold` ＝ タイマーを とめた ミリびょう） |
| `input` | いまの 入力 |
| `correct` | コンボ数・レベル・前の レベル・問題・答え・確定演出の しゅるい（`niji`／`kakutei`／`hyaku`）・節目か・きろくを こえたか |
| `level` | ドパレベルが かわった（Lv0〜8。しきい値 0/3/6/10/15/20/30/40/50） |
| `gameover` | りゆう（`miss`／`time`）・問題・入力・コンボ・新記録か |
| `overShown` | ゲームオーバー画面を 出した |
| `quit`・`screen`・`settings` | やめた・画面が かわった・せっていが かわった |

## ためした こと

- `node tests.js`：きまりの たしかめ 52こ ぜんぶ OK（11コースの はんい、6000問ずつ 出して「直前 3問／1問と 同じ 問題が 出ない」「ぜんぶの 問題が 出る」、はんてい、ドパレベルの しきい値、確定演出、にがてな九九の ならび、せってい など）
- Chromium で 実際に 動かして 画面を たしかめました（1366×650 の よこ長・390×760 の たて長・760×390 の スマホよこ向き）
  - タイトル → コース → カウントダウン → 60れんぞく（Lv0〜8・ドパタイム・虹ドパ・60の 確定演出）→ まちがい → 新記録の 虹色 → もういちど → 時間ぎれ → せってい
  - テンキーの タップ・「けす」・「やめる」（きろくが のこる）・7のだんで 30問 つづけて 直前 3問と かさならない こと
  - 虹ドパの とき タイマーが 1.5びょう のびる こと（5.0びょう → 6.5びょう）
  - 「ひかえめ」で ゆれが 出ない こと・制限時間 3びょうに なる こと
  - 粒子の 数が 上限（800・スマホ 400）を こえない こと
  - アプリの エラーは 0（Google Fonts は ためした 場所から つながらないので 読みこみ エラーが 出ますが、端末の 文字で 表示されます）

**まだ ためして いない こと**

- 音（ためした 場所では 音が 聞けないので、エラーなく 鳴らせる ことだけ たしかめました）。教室の Chromebook での 音量
- 本物の Chromebook・iPhone・Android での 重さ（とくに Lv7〜8 の 紙吹雪と 虹色）と、5びょうの むずかしさ

## 企画書の「決めておきたい こと」への 対応

| こと | この 版での あつかい |
|---|---|
| オリジナルの マスコットキャラクター | 出していません（カットインは 文字と 帯だけ）。出す なら ドパタイム突入の カットインに 入れるのが かんたんです |
