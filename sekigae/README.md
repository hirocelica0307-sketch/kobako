# 席替えアプリ

先生のための席替えアプリです。名簿・配慮事項（席の指定・近づけない組み合わせ）・前回までの席をもとに座席案を作り、手で入れ替えて、スプレッドシートに記録・印刷します。
スプレッドシートにくっついた Google Apps Script（GAS）のウェブアプリとして動きます。データはそのスプレッドシートに入ります。

## ファイル

| ファイル | なかみ |
|---|---|
| `appsscript.json` | GAS の設定（タイムゾーン・権限・ウェブアプリ） |
| `Code.gs` | サーバー側の入口（メニュー・画面を出す・画面から呼ばれる API） |
| `Sheets.gs` | スプレッドシートの読み書き（設定・名簿・配慮_距離・履歴・座席表シート） |
| `index.html` | 画面の骨組み。下の5つを読み込む |
| `styles.html` | 見た目 |
| `core.html` | 座席・ペア・班の共通のきまり |
| `solver.html` | 席替えの計算と、守れなかった条件の説明 |
| `api.html` | サーバーとの受け渡し |
| `app.html` | 画面の動き |

## 入れかた

1. スプレッドシートの「拡張機能」→「Apps Script」を開く。
2. `Code.gs` の中身をエディタの `コード.gs` に、`Sheets.gs` の中身を「＋」→「スクリプト」で作った `Sheets` に貼り付ける。
3. 「＋」→「HTML」で `index`・`styles`・`core`・`solver`・`api`・`app` の6つを作り、それぞれの中身を貼り付ける（名前は拡張子なし）。
4. スプレッドシートを開き直し、メニュー「席替え」→「① 初期設定（シートを作る）」。
5. 「デプロイ」→「新しいデプロイ」→ 種類「ウェブアプリ」、実行「自分」、アクセス「自分のみ」。
6. メニュー「席替え」→「② Web アプリの URL を表示」で URL を開く。

### 前の版から入れかえるとき

- `.gs` 2つと `.html` 6つを、このフォルダの中身に置きかえる。
- **シートの作り直し・データの移しかえはいりません。** シート名・列はそのままです（前の版で書いた履歴もそのまま読めます）。
- 「デプロイを管理」→ 編集 →「新バージョン」で更新する。

## 前の版から削ったもの

使い方（スプレッドシート＋GAS）は変えずに、使われていないもの・重なっていた処理を削りました。

- **読み込み・保存のたびに、シートの確認と見出しの書式設定を何度もしていた**のをやめた（見出しを作るときだけにした）。起動時の読み込みで、シートへの書き込みが 18 回 → 0 回になった
- 「✅ 確定」ボタンと「未確定／確定済み」のしるし、書き出し画面の「まだ確定を押していません」の注意（確定しなくても書き出せたので）
- 画面から直接印刷したときの保険の印刷用スタイル（印刷は「🖨 印刷」の専用の窓で行う）
- ローカル確認用の `MockApi` への切り替え
- どこからも使われていない関数・値・データ（`displayName`・`GENDER_LABEL`・`spreadsheetUrl`・いつも空だった `notices`・`score`・警告の `kind`/`students` など）
- 履歴の「名簿JSON」に入れていた、使っていないひらがな・性別
- 同じ処理の重なり（設定・名簿・配慮事項の保存、名簿表・配慮事項表で同じ入力を2回反映していたところ など）
