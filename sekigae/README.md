# 席替えアプリ

先生のための席替えアプリです。名簿・配慮事項（席の指定・はなす／近くにする組み合わせ）・これまでの席をもとに座席案を作り、手で入れ替えて、スプレッドシートに記録・印刷します。
スプレッドシートにくっついた Google Apps Script（GAS）のウェブアプリとして動きます。データはそのスプレッドシートに入ります。

## 画面の流れ

画面の上に、やることの順番を 4 つ並べています。いま進めるとよい手順は青い枠で示します。

1. **名簿** … 児童を登録する（エクセルから貼り付け可。出席番号は欠番があってもよい）
2. **配慮事項**（なくてもよい） … 席の指定（固定・前後・左右・メモ）と、2 人の組み合わせ（はなす／近くにする）
3. **席替え** … 決め方（ランダム・男女別の列・男女交互）と席の形（隣の人とペア／1人ずつ）を選んで「席替えする」。手で入れ替え・「元に戻す」もできる
4. **記録・印刷** … 「記録する」でスプレッドシートに残す。「印刷する」で A4 横 1 枚。「子どもに見せる」でテレビ用の大きな表示

- はじめて開いたとき（名簿が空のとき）は「使い方」が自動で開きます。右上の「使い方」からいつでも見られます。
- 名簿・配慮事項・設定は、変えたときに**自動で保存**されます（右上に「保存しました」と出ます）。座席表は「記録する」で保存します。
- 守れなかった条件は右の「確認事項」に出ます。「配慮事項」と「できれば避けたいこと」に分けて出します。

## ファイル

| ファイル | なかみ |
|---|---|
| `appsscript.json` | GAS の設定（タイムゾーン・権限・ウェブアプリ） |
| `Code.gs` | サーバー側の入口（メニュー・画面を出す・画面から呼ばれる API） |
| `Sheets.gs` | スプレッドシートの読み書き（設定・名簿・配慮_距離・履歴・座席表シート） |
| `index.html` | 画面の骨組み。下の5つを読み込む |
| `styles.html` | 見た目 |
| `core.html` | 座席・ペア・班の共通のきまり |
| `solver.html` | 席替えの計算と、守れなかった条件の説明 |
| `api.html` | サーバーとの受け渡し |
| `app.html` | 画面の動き |

## 入れかた

1. スプレッドシートの「拡張機能」→「Apps Script」を開く。
2. `Code.gs` の中身をエディタの `コード.gs` に、`Sheets.gs` の中身を「＋」→「スクリプト」で作った `Sheets` に貼り付ける。
3. 「＋」→「HTML」で `index`・`styles`・`core`・`solver`・`api`・`app` の6つを作り、それぞれの中身を貼り付ける（名前は拡張子なし）。
4. スプレッドシートを開き直し、メニュー「席替え」→「① 初期設定（シートを作る）」。
5. 「デプロイ」→「新しいデプロイ」→ 種類「ウェブアプリ」、実行「自分」、アクセス「自分のみ」。
6. メニュー「席替え」→「② Web アプリの URL を表示」で URL を開く。

### 前の版から入れかえるとき

- `.gs` 2つと `.html` 6つを、このフォルダの中身に置きかえる。
- **シートの作り直し・データの移しかえはいりません。** シート名・列はそのままです。前の版の設定・名簿・配慮事項・履歴をそのまま読みます。
- 「デプロイを管理」→ 編集 →「新バージョン」で更新する。

## しくみのメモ

- **出席番号**：名簿シートの「出席番号」の列をそのまま使います。空・重なり・範囲外（1〜99 以外）のときは、空いている番号を付けます。
- **組み合わせ**：配慮_距離シートの「種類」は「周囲のマスに入れない」「同じペアにしない」「同じ班にしない」「周囲のマスに入れる（近くにする）」の 4 つ。空のときは「周囲のマスに入れない」として読みます。
- **席の形**（設定シートの `seatStyle`）：「1人ずつ」のときは、ペアについての条件（同じペアにしない・前回／前々回のペア）は使いません。ペアの設定と登録は残すので、ペアに戻せばまた使われます。
- **1 年間を通して**（設定シートの `balanceYear`）：今年度（4 月はじまり）の記録を数え、前のほう（前から 2 列）・後ろのほう（後ろから 2 列）の席や、同じペアが続かないようにします（縦が 4 席以上のとき）。3 回目になるときは「できれば避けたいこと」に出ます。
- **男女の人数**：男女別の列・男女交互のとき、男女の人数と席の数が合わなければ、席替えのあとに「何人が反対の席に座るか」を知らせます。
- **子どもに見せる**：名前と班だけを大きく出します。配慮事項のしるし・メモ・席の名前・出席番号・確認事項は出しません。黒板はいつも上です。
- **履歴の ID**：ミリ秒まで入れ、それでも重なれば番号を足すので、続けて記録しても重なりません。
