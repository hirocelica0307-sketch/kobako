# ゆびで おんがく（仮称）

クラシックの 音楽に あわせて、テレビの 画面に でる **ひかる 線を ゆびで なぞって** あそぶ アプリです。
先生が Chromebook で ひらいて テレビに うつし、子どもたちは 立って、空中で ゆびを うごかします。

- 画面に うすい 線（これから なぞる ところ）が でて、**音楽が すすむと 線の さきから いろが つく**。ひかる 玉が「いま ゆびが ある ところ」
- **線の うごきは 録音から つくって いる**（音楽と 連動）
  - **リズム**：録音の なかで **音が なった 瞬間** に、玉が 線の かど・はね・まがりめに とどく
  - **はやさ**：こまかい 音が つづく ところは 小きざみに、のびる 音の ところは ゆったり 大きく
  - **大きさ**：音が 大きい ほど 大きく うごき、線も ふとく、ひかりも つよい。小さい 音の ところは 小さく
  - **高さ**：メロディー・かいだん・やま では、音が 高い ほど 上、低い ほど 下
  - 玉は 音の 大きさで ふくらみ、音が なる たびに わが ぱっと ひろがる
  - 玉の すぐ さき（0.8秒ぶん）は 線が すこし あかるく なって、つぎの うごきが わかる
- うごきかたは 16しゅるい：ギザギザ・やま・なみ・メロディー・かいだん・ぴょんぴょん・くるくる・まる・うず・8の字・ほし・しかく・さんかく・いなずま・すいーっ・ジャン！（点）。短い もの・長い もの・まるい もの・かくばった ものを 曲に あわせて くみあわせる
- サーバー・ログイン なし。先生 だけが つかう（子どもの 名前などは あつかわない）

## つかいかた

| そうさ | なにが おきるか |
|---|---|
| **▶ はじめる**（<kbd>スペース</kbd>） | 3・2・1 の あと 音楽が はじまる。カウントの あいだに さいしょの 線が でるので、ゆびを はじまりの ●に あわせて まつ |
| **むずかしさ** | **かんたん**：つよい 音 だけを えらんで（0.42秒 いじょう あける）、うごきが へる ／ **ふつう**：音が なる たびに うごく（0.19秒 いじょう あける） |
| **はやさ** | **ゆっくり**：0.85ばいの はやさ（音の 高さは かわらない） |
| **❚❚ とめる／▶ つづける**（<kbd>スペース</kbd>） | とめて、つづきから |
| **◀◀ 5秒**（<kbd>←</kbd>）・<kbd>→</kbd> | 5秒 もどる・すすむ。したの ほそい バーを おすと その ばしょへ |
| **⟲ はじめから** | カウントから やりなおす |
| **✕ おわる**（<kbd>Esc</kbd>） | はじめの 画面へ |

- 先生の ボタンは、マウス（タッチパッド）を うごかすと でて、2.5秒 うごかさないと きえる（テレビに うつらない ように）
- 線の 見かた：うすい 灰色＝これから／ぴかぴか する ●＝つぎは ここから／点線の ○＝ここを「ジャン！」で つつく

### 音と 線が ずれる とき

テレビや Bluetooth スピーカーに よっては、音が すこし おくれて きこえます。
はじめの 画面の「**先生むけ：音と 線の ずれを なおす**」で 0.05秒ずつ なおせます（この パソコンに おぼえます）。

## 譜面の つくりかた（うごきを かえる・曲を ふやす とき）

```
pip install numpy scipy librosa soundfile
cd yubi-de-ongaku
python3 tools/make_song.py
node tests.js
```

1. 録音を しらべる：はく（拍）の 時間・音が なった 瞬間と つよさ・音の 大きさ・音の 高さの うごき
2. `make_song.py` の なかの **`PLAN`**（どの はくから どの はくまで・どの うごきかた・画面の どこ・いろ）に そって、
   音が なった 瞬間ごとに 点を おき、音の 大きさ・高さ・はやさで 点の ばしょを きめる
3. `song-tengoku.js` に 書きだす（はく・音の 大きさ 0.05秒ごと・音が なった 瞬間・がめんごとの 線の 点）

うごきかたを かえたい ときは `PLAN` を なおして、もういちど つくります。
