# ゆびで おんがく（仮称）

クラシックの 音楽に あわせて、テレビの 画面に でる **ひかる 線を ゆびで なぞって** あそぶ アプリです。
先生が Chromebook で ひらいて テレビに うつし、子どもたちは 立って、空中で ゆびを うごかします。

- 画面に うすい 線（これから なぞる ところ）が でて、**音楽が すすむと 線の さきから いろが つく**。ひかる 玉が「いま ゆびが ある ところ」
- 線の かたちは 音楽に あわせて かわる（ギザギザ・くるくる・なみ・ぴょんぴょん・にじの 弧・うずまき・ジャン！の 点）
- 線の かど・わ・やま は **はく（拍）に ぴったり** あう ように つくって ある
- サーバー・ログイン なし。先生 だけが つかう（子どもの 名前などは あつかわない）

## ひらきかた

**https://hirocelica0307-sketch.github.io/kobako/yubi-de-ongaku/**

Chromebook の Chrome で うごきます。テレビに うつす ときは **⛶ 画面いっぱい**（<kbd>F</kbd>）が おすすめ。

## つかいかた

| そうさ | なにが おきるか |
|---|---|
| **▶ はじめる**（<kbd>スペース</kbd>） | 3・2・1 の あと 音楽が はじまる。カウントの あいだに さいしょの 線が でるので、ゆびを はじまりの ●に あわせて まつ |
| **むずかしさ** | **かんたん**：ギザギザや くるくるの かずが はんぶんに なり、大きく ゆっくり うごく ／ **ふつう**：1はくで 1つ |
| **はやさ** | **ゆっくり**：0.85ばいの はやさ（音の 高さは かわらない） |
| **❚❚ とめる／▶ つづける**（<kbd>スペース</kbd>） | とめて、つづきから |
| **◀◀ 5秒**（<kbd>←</kbd>）・<kbd>→</kbd> | 5秒 もどる・すすむ。したの ほそい バーを おすと その ばしょへ |
| **⟲ はじめから** | カウントから やりなおす |
| **✕ おわる**（<kbd>Esc</kbd>） | はじめの 画面へ |

- 先生の ボタンは、マウス（タッチパッド）を うごかすと でて、2.5秒 うごかさないと きえる（テレビに うつらない ように）
- 線の 見かた：うすい 灰色＝これから／ぴかぴか する ●＝つぎは ここから／点線の ○＝ここを「ジャン！」で つつく

### 音と 線が ずれる とき

テレビや Bluetooth スピーカーに よっては、音が すこし おくれて きこえます。
はじめの 画面の「**先生むけ：音と 線の ずれを なおす**」で 0.05秒ずつ なおせます（この パソコンに おぼえます）。

## 譜面の しくみ（曲を ふやす とき）

- `beats` … 録音の なかの **はくの 時間（秒）** の ならび。録音は テンポが すこし ゆれるので、1はくずつ 時間を もつ
- `scenes` … がめんの ならび。がめんごとに 線（`strokes`）を 1〜6本
- 線は `{ k: かたち, b: [はじまりの はく, おわりの はく], per: 何はくで 1くぎり, c: いろ, …ばしょ }`
- 画面は よこ 1600 × たて 900 で かんがえる

## たしかめて ほしい こと

- 実機（Chromebook ＋ テレビ）で、うしろの 席から 線が 見えるか・音と 線が あって いるか
- 線の かたち・はやさが 子どもに ちょうど よいか
