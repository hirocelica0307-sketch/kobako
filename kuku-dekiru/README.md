# くくが できるまで（仮称）

2年生の **九九づくり**（教科書「かけ算(1)」5・2・3・4のだん…）で、
**ボタンを おすたびに ブロックの まとまりが 1つずつ ふえて、九九の 表が できあがっていく** 様子を 見せる 提示用アプリです。

- 5のだんなら「5この まとまりが 1つ → 5×1＝5」「2つ → 5×2＝10」…と、**まとまり（1つ分）× いくつ分** で 考えさせる
- 表の 右に「**+5 ふえる**」の やじるしが 出て、「こたえが 5ずつ ふえる」きまりが 見える
- 教科書と おなじ 色の やくそく：**かけられる数＝きいろ**、**かける数＝みずいろ**、ブロックは しろい ますに だいだいの まる
- **index.html 1ファイル** だけで うごきます（サーバー・ログイン・外部API なし）

## つかいかた

| そうさ | なにが おきるか |
|---|---|
| **つぎ ▶**（ぶたいを タップ・<kbd>→</kbd>・<kbd>Space</kbd>・<kbd>PageDown</kbd>） | まとまりが 1つ おちてきて、しき・こたえ・となえかた・「+○ ふえる」が 出る |
| **◀ もどる**（<kbd>←</kbd>・<kbd>PageUp</kbd>） | 1つ もどす |
| **⏮ はじめから**（<kbd>Home</kbd>） | まとまり 0 に もどす |
| **⏩ じどう** | 2.6びょう ごとに 自動で すすむ（もう いちど おすと とまる） |
| **👆 まとまりで かぞえる** | まとまりを 1つずつ 光らせて、上に 5、10、15 … と 出す（まとまりを タップすると そこまで かぞえる） |
| **🗣️ となえる** | できた 九九を 上から じゅんに 光らせる（よみあげ オンなら 声も） |
| **だん 1〜9**（キーの <kbd>1</kbd>〜<kbd>9</kbd>） | だんを かえる（はじめからに なる） |

### せってい（うえの 右）
- **❓ こたえは あとで**：つぎ を おすと まとまりと「5×4＝？」だけ 出る。もう いちど おすと こたえが 出る（子どもに よそうさせる とき）
- **🖐️ 5で くぎる**：6〜9のだんで、5こ めの あとに すきまを あける（数図ブロックの 5の まとまり）
- **🔈 よみあげ**：こたえが 出た とき「ごさん じゅうご」と よむ（ブラウザの 音声。Chromebook の Chrome で うごく）
- **⛶**（<kbd>F</kbd>）：画面 いっぱい

せっていと さいごの だんは ブラウザに おぼえます。

## しくみ

- 9つ ならんでも はいる ように、ブロックの 大きさは さいしょに 画面と だんから きめる（ふえても 大きさが かわらない）
- あたらしい まとまりは きいろの わくで 光り、ブロックが 上から 1こずつ おちてくる。おちおわってから こたえが 出る
- 電子黒板・テレビ（1920×1080）と Chromebook（1366×768）では スクロールなし。スマホでは ぶたい → ボタン → 表 の じゅんに たてに ならぶ
