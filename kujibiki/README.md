# くじびき ひろば（仮）

教室で つかえる、**派手な 演出の くじびき** を 8しゅるい あつめた アプリです。
番号・名前・ことばを 入れて、ルーレット・あみだくじ・ビンゴ・おみくじ などで きめます。

- 対象：小学生（先生が 電子黒板・テレビに うつして つかう／タブレットで 子どもが さわる）
- 電子黒板・Chromebook の よこ画面が 基準。タブレット・スマホの たて画面でも うごきます（タッチ・マウス どちらも OK）
- インストールも ログインも いりません。音も プログラムで 作るので 音声ファイルは ありません
- 入れた 名前・せっていは **その 端末の ブラウザに だけ** 保存します（どこにも おくりません）

## ひらきかた

**https://hirocelica0307-sketch.github.io/kobako/kujibiki/**

```
cd kujibiki
python3 -m http.server 8000    # → http://localhost:8000
```

`index.html` を ブラウザで ひらくだけでも うごきます。`#roulette` のように うしろに つけると、その くじが すぐ ひらきます
（`#roulette` `#amida` `#bingo` `#omikuji` `#gacha` `#bomb` `#team` `#order`）。

## 画面の きほん

- 上の バー：**メニュー**（もどる）・**中身・せってい**（くじごとの 中身を かえる）・**音 オン／オフ**・**大きく 表示**（全画面）
- テレビに うつして いる あいだ、画面が 暗く ならない ように します（つかえる ブラウザ だけ）
- 「大あたり」「1等」「大吉」と いう ことばは ものすごく 派手に、「はずれ」「凶」は ざんねんな 演出（おばけ）に なります

## くじの 公平さ

どの くじも「だれが・なにが 当たるか」は **さきに 乱数で きめ**、演出は その けっかに むかって うごく だけ です。

- ルーレット：どの 項目も おなじ 確率（ばんの とまる 場所は その 項目の 中で ランダム。3わり くらいは「ギリギリ 入る」）
- あみだくじ：ふつうの あみだ（よこ線を 見れば だれでも たしかめられる）。かならず 1人 1つの ゴール
- ビンゴ：のこりの 玉から おなじ 確率。75こ なら 75回で ぜんぶ 1回ずつ
- おみくじ・ガチャ：本数を きめる ときは のこりの 本数に あわせて、かぎりなし の ときは 出やすさの わりあいで
- チームわけ：人数の ちがいは 1人 いない
