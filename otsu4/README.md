# おつよん（危険物取扱者 乙種第4類 試験対策アプリ）

スマホの ブラウザで 動く、乙4の 学習アプリです。
インストールも ログインも 通信も いりません。`index.html` を ひらくだけで 使えます。

## つかいかた

`otsu4/index.html` を ブラウザで ひらく。以上です。
学習の きろくは この端末の中（localStorage）だけに 保存されます。

## 4つの ページ

| ページ | なかみ |
|---|---|
| 📖 **おぼえる**（`oboeru.html`） | 知識カード **171枚**。おもてを見て 思い出す → めくる → 自己評価。覚えたカードは 表示から 消えていきます |
| ✏️ **れんしゅう**（`renshuu.html`） | 練習問題を 少しずつ。1問ごとに 答えあわせと 解説。**「計算問題だけ」モード**あり |
| ⏱️ **ほんばん**（`honban.html`） | 35問・2時間の 本番形式。①公式の過去問35問　②ランダム模試35問 |
| 🔥 **にがてノート**（`nigate.html`） | まちがえた問題＋**正解でも自信がなかった問題**を あつめ、同じテーマの 類似問題で つぶします |

## おぼえるための しくみ（科学的に 効果が 確かめられている 方法）

| 方法 | このアプリでの やりかた |
|---|---|
| **想起練習** | 知識カードは かならず うらを かくして 出し、思い出してから めくる |
| **間隔反復** | 箱（0〜5）が 上がるごとに つぎに出る日が のびる（きょう→1日→3日→7日→16日→35日） |
| **自己評価の記録** | 答えを見る前に 自信を 聞く。**正解でも 自信が なければ にがてノートへ** |
| **交互練習** | 同じテーマが 続かないように 並べかえて 出す |
| **即時フィードバック** | 1問ごとに 正解・なぜそうなるか・ひっかけの狙いを すぐ表示 |
| **分散学習** | ホームに「きょうの分」だけ 出す（既定：カード20枚・問題10問） |
| **望ましい困難** | 選択肢の ならびを まぜる設定（練習のみ・既定はオフ） |
| **段階的な手がかり** | 計算問題は 途中式を **1行ずつ** ひらける。最後に「いちばん ラクな解き方」が 出る |

**にがてノートの 卒業条件**：同じ問題に **自信あり で 2回続けて 正解**。まぐれ正解では 卒業しません。

## テスト

`otsu4/tests.html` を ひらくと、しくみが 正しく 動くかを 自動で たしかめます（37項目）。
端末に node が あれば `node otsu4/tests.js` でも 走ります。
※テストを 走らせると 学習データは 消えます。

## 出典と ことわり

- 公式の過去問35問は、一般財団法人 消防試験研究センター
  「[過去に出題された問題（乙種第4類）](https://www.shoubo-shiken.or.jp/kikenbutsu/exercise.html)」に 掲載の 問題です。
  解説は このアプリで 作成した ものです。
- そのほかの 問題・知識カード・解説は すべて このアプリで 作成した ものです。
- 法令や 試験制度は 変わることが あります。受験のときは 必ず 公式サイトで 最新情報を 確認してください。
