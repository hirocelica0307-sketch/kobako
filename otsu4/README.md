# おつよん（危険物取扱者 乙種第4類 試験対策アプリ）

危険物取扱者 **乙種第4類（乙4）** の試験対策アプリです。

## じょうたい

**段階1／調べもの・情報整理**（アプリ本体はまだありません）

いまは「どんな試験で、何が出て、どう解くか」を調べて `docs/` にまとめている段階です。
ここに集めた内容が、そのまま出題データ・解説文のもとになります。

## 書きかたのきまり

- 中学生〜高校入学ぐらいの学力でも読めることばで書く
- 1つの項目は「これだけ覚える」→「なぜそうなるか」→「ひっかけ」の順
- 数字は表にする。文章の中に数字を埋めない
- 出やすさは ★1〜★5 で表す（★5＝ほぼ毎回出る）
