# 過去問・練習問題はどこにあるか（出典一覧）

## 0. 大前提：乙4に「市販の完全な過去問」は存在しない

- 消防試験研究センターは**本試験の問題を公開していません**（回収されます）。
- 公開しているのは「**過去に出題された問題**」という**例題のPDF数ページ**のみ。正答はありますが**解説はありません**。
- 世の中の「過去問集」は、受験者の記憶や傾向分析をもとに作られた**再現・類題**です。

**→ このアプリでも、他社の問題文をそのまま写すのではなく、出題範囲と傾向にもとづいて自前で作問します。**

## 5. このアプリでの作問方針（メモ）

1. **公式PDFの例題を「出題形式のお手本」にする**（言い回し・選択肢の作り方）。
2. 問題文は**自前で書く**。他サイトの文章はコピーしない。
3. 1問につき必ず持たせるデータ：
   - `subject`（法令／物理化学／性質消火）
   - `theme`（指定数量、保安距離…）
   - `star`（1〜5：出やすさ）
   - `question` / `choices`（5つ） / `answer`
   - `explain`（なぜそれが答えか）
   - `why_others_wrong`（他の選択肢がなぜ違うか）
   - `need_knowledge`（この問題を解くのに必要な知識へのリンク）
4. 「**誤っているものはどれか**」型も必ず混ぜる（本番で最も間違えやすいため）。
5. 計算問題には**途中式を1行ずつ**表示するモードをつける。
