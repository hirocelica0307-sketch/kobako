# アプリの設計（おつよん）

## 1. 画面の構成

```
index.html    ホーム
              ├ 今日やること（3つだけ提示）
              ├ 科目ごとの到達度メーター
              └ 各ページへの入口

kougi.html    ⑥ 講義（眺めて おぼえる）
              ・テーマごとに ①なぜ そうなっている？ ②表で くらべる
                ③おぼえ方（語呂合わせ・となえ歌・イメージ・ひとこと）
                ④これだけは 覚える（そのテーマのカード一覧）⑤ひとこと
              ・科目タブ／ぜんぶひらく／読んでいないものだけ
              ・「読んだ！」の しるし（48テーマ中 いくつ読んだかを 表示）
              ・各テーマから カード・問題へ そのまま 飛べる

oboeru.html   ① おぼえる（知識ページ）
              ・カードを1枚ずつ「思い出す→めくる→自己評価」
              ・おぼえたカードは表示から消えていく
              ・テーマごとに「たしかめミニテスト」がすぐ打てる

renshuu.html  ② れんしゅう（ドリル）
              ・テーマ／科目をえらんで少しずつ解く
              ・1問ごとに即・解説
              ・答えたあと「自信あり／なんとなく／あてずっぽう」を記録

honban.html   ③ ほんばん（本番形式）
              ・公式過去問35問モード（消防試験研究センターの公開問題そのまま）
              ・ランダム35問の模擬試験モード
              ・2時間タイマー、科目ごとの合否判定（15/10/10・各6割）

kiroku.html   ⑤ きろく（グラフ）
              ・つづけた日数・14日の正答率・卒業カード数などの数字タイル
              ・毎日の学習量（たて棒・カードと問題の2系列）
              ・正答率のうつりかわり（折れ線・合格ライン60％つき）
              ・科目ごとの到達度（よこ棒・値を直接ラベル）
              ・カードの箱の分布（積み上げ1本・青の濃淡）
              ・模試の点（3科目を正答率％でそろえた折れ線＝たて軸は1本だけ）
              ・にがてテーマ上位8（よこ棒）
              ・「表で見る」で 同じ内容を 数字でも 出せる

nigate.html   ④ にがてノート
              ・×だった問題 ＋ ○でも自信がなかった問題 が自動で集まる
              ・同じテーマの「類似問題」を続けて出す
              ・克服したら自動で卒業していく
```

## 2. 科学的に効果が確かめられている方法と、その実装

| 方法 | 中身 | このアプリでの実装 |
|---|---|---|
| **想起練習（Active Recall / Testing Effect）** | 読み返すより「思い出す」ほうが記憶に残る | 知識ページも**必ず裏面を隠して出す**。「思い出せた？」を押してからめくる |
| **間隔反復（Spaced Repetition）** | 忘れかけた頃にもう一度やると定着する | SM-2を簡略化した復習間隔（1日→3日→7日→16日→35日）。自己評価で伸び縮みする |
| **自己評価の記録（Metacognition / JOL）** | 「わかったつもり」を見つける | 4段階（ばっちり／まあまあ／あやしい／わからない）。**○でも「あやしい」は苦手ノート行き** |
| **交互練習（Interleaving）** | 同じ種類を続けるより混ぜるほうが伸びる | ドリルは同テーマ連続を避け、科目をまぜて出題 |
| **即時フィードバック** | 誤りはその場で直すと定着する | 1問ごとに正解＋なぜ他が違うかを即表示 |
| **分散学習（Distributed Practice）** | 1日にまとめるより毎日少しずつ | ホームで「今日の20枚・今日の10問」だけ提示。やりすぎ防止 |
| **精緻化（Elaboration）** | 「なぜ？」を言語化すると強くなる | 解説は「答え」だけでなく**なぜそうなるか／ひっかけの狙い**まで書く |
| **読んで つかむ（体系化）** | ばらばらの事実より、つながった話として読んだほうが入りやすい | 講義ページ。テーマ単位で「なぜ→表→覚え方→要点」の順に読み切れる形にした |
| **理由とセットで 覚える（意味づけ）** | 単独の事実より、理由や体系の中に位置づけたほうが記憶に残る | カード171枚すべてに `why`（なぜそうなるの？）。答えあわせでは そのテーマの全体像（`notes.js`：なぜその決まりなのか＋仲間の比較表）を ひらける。問題にも `deep`（もう一歩ふみこむと）を102問に付与 |
| **エラー訂正の即時ループ** | まちがいは、その場で「もとの知識」に戻すと定着する | まちがい／自信なしのとき、同テーマの知識カードをその場に表示し、**そのカードを今日の分に自動で戻す**（due を今日に引き戻す） |
| **進み具合の可視化** | 伸びが見えると続く | きろくページ。続けた日数・正答率・箱の分布 |
| **段階的な手がかり（Fading）** | 答えを一度に見せず、手がかりを少しずつ出す | 計算問題は途中式を**1行ずつ**ひらく。全部見たあとに「いちばんラクな解き方」を出す |
| **望ましい困難（Desirable Difficulty）** | 簡単すぎると身につかない | 選択肢のならびをまぜる設定（練習のみ・既定オフ。まぜたときは答えあわせで「もとの番号」を表示）。連続正解したカードは出題間隔を大きく空ける |

## 3. 覚え具合の管理（カード・問題 共通）

各カード／問題は次の状態を持つ。

```js
{
  box     : 0..5,      // 0=未学習, 5=卒業。正解で+1、まちがいで0に戻す
  due     : '2026-09-25',  // つぎに出す日
  streak  : 0,         // 連続正解
  conf    : 'low',     // 直近の自信（high/mid/low）
  wrongN  : 0,         // まちがえた回数
  lastAt  : 1758...    // 最終学習
}
```

**復習間隔（box → 日数）**：0→当日、1→1日後、2→3日後、3→7日後、4→16日後、5→35日後（卒業扱い）

**苦手ノートに入る条件**
- まちがえた（box が 0 に戻った）
- または **正解したが自信が「あやしい／あてずっぽう」** だった

**苦手ノートを卒業する条件**
- 同テーマの問題で **自信「ばっちり」で2回続けて正解**

## 4. データの形

### 問題（data/questions.js）
```js
{
  id:'off-01', src:'official', subject:'law', theme:'teigi', star:4,
  q:'…', choices:['…','…','…','…','…'], a:3,
  why:'正解の理由', others:'ほかの選択肢がちがう理由', ref:'HOUREI#1'
}
```
- `src:'official'` … 消防試験研究センター「過去に出題された問題（乙種第4類）」より（出典明記）
- `src:'original'` … 同じテーマで自作した類似問題（苦手つぶし用）
- `theme` が同じ問題どうしが「類似問題」になる

### 知識カード（data/knowledge.js）
```js
{ id:'k-029', subject:'law', theme:'hoankyori', star:5,
  front:'学校・病院からの保安距離は？', back:'30m以上',
  hint:'が(3)っこう30', note:'高圧ガス施設は20m。ここが入れ替えのひっかけ',
  why:'学校・病院・劇場は 大勢が いて すぐには 逃げられない。だから 住宅の3倍の30m' }

// テーマの全体像（notes.js）— 答えあわせのときに ひらける
'hoankyori': { title:'保安距離は「まわりを守る」、保有空地は「消火の場所をあける」',
               body:'…なぜ その距離なのか…', table:{head:[...], rows:[[...]]}, tip:'…' }
```

## 5. グラフの きまり（データ可視化のガイドラインに準拠）

- **たて軸は1本だけ**。模試の3科目は満点がちがう（15／10／10）ので、**正答率％にそろえて**1本の軸に載せる（2軸グラフは作らない）。
- 色は**系列（科目）にひもづけ**、並び順では変えない。法令＝青 `#2a78d6`、物理化学＝アクア `#1baf7a`、性質消火＝オレンジ `#eb6834`（ダークは `#3987e5` / `#199e70` / `#d95926`）。
  この3色は色覚多様性の検証スクリプトでライト・ダーク両モードとも合格（最小ΔE 9.2／9.4）。
- 2系列以上には**必ず凡例**。値は選んだ所だけに直接ラベル（全点には付けない）。
- 棒は24px以下・端を4px丸め・となりと2pxあける。線は2px、点は直径10px＋地色の2pxリング。目もりは細い実線。
- **「表で見る」**を用意し、グラフと同じ内容を数字でも読めるようにする（色だけに頼らない）。
- ダークモードは自動反転ではなく、**ダーク用に選び直した色**を使う。

## 6. 保存
- `localStorage` に保存（キー接頭辞 `otsu4/`）。
- 端末の中だけで完結。ログイン不要。
- 「学習データの書き出し／読み込み」ボタンでJSONを退避できる（機種変更用）。
