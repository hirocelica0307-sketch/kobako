# 試験の概要（乙種第4類）

## 1. ひとことで

**35問を2時間で解く5択マークシート。3科目すべてで60%以上とれば合格。**

## 2. 問題数と内訳

| 科目（正式名） | 略称 | 問題数 | 合格に必要な正解数 |
|---|---|---|---|
| 危険物に関する法令 | 法令 | **15問** | **9問以上** |
| 基礎的な物理学及び基礎的な化学 | 物理・化学 | **10問** | **6問以上** |
| 危険物の性質並びにその火災予防及び消火の方法 | 性質・消火 | **10問** | **6問以上** |
| **合計** | | **35問** | — |

## 3. 試験時間

- **2時間（120分）**
- 1問あたり約3分25秒。見直しの時間はじゅうぶんにとれる。
- 途中退室ができる会場が多い（開始後35分以降など。会場の指示に従う）。

### 時間配分のおすすめ

| 段階 | かける時間 | やること |
|---|---|---|
| 1周目 | 約45分 | 迷わない問題だけ答える。迷ったら印をつけて飛ばす |
| 2周目 | 約30分 | 飛ばした問題・計算問題をじっくり |
| 3周目 | 約20分 | マークのずれチェック＋全問見直し |
| 余り | 約25分 | 予備 |

## 4. 形式

- **五肢択一式**（5つの選択肢から1つ選ぶ）のマークシート。
- 記述・計算の途中式を書く欄はない。**電卓は使えない**（筆算で解く）。
- 「正しいものはどれか」「**誤っている**ものはどれか」の両方が出る。
  → **設問の最後を必ず読む**。乙4でいちばん多い失点原因がこれ。

## 5. 合格基準（いちばん大事なルール）

- **3科目それぞれ60%以上**。合計点ではない。
- 例：法令15/15、物理・化学10/10、性質・消火**5**/10 → **不合格**。
- つまり「苦手科目を他でカバー」ができない。**3科目とも6割を確保する**のが戦略。

## 6. 受験資格・手数料・申込み

| 項目 | 内容 |
|---|---|
| 受験資格 | **なし**（年齢・学歴・実務経験いっさい不問。だれでも受けられる） |
| 受験手数料 | **5,300円**（乙種。令和6年5月1日改定。非課税） |
| 申込み方法 | 電子申請（インターネット）または書面申請 |
| 電子申請 | 消防試験研究センターのサイトから。クレジット／コンビニ／ペイジー／PayPay等で支払い |
| 試験地 | 47都道府県ごとに実施。**都道府県で日程がちがう** |
| 試験回数 | 東京・大阪など大都市は毎月〜月数回。地方は年数回のことも |
| 持ち物 | 受験票（写真貼付）、HBまたはBの鉛筆、消しゴム。**電卓・定規は不可** |

> **裏ワザ**：住んでいる都道府県で日程が合わなければ、**他県で受験してもよい**（受験地の制限なし）。急ぎのときは近県の日程も見る。

## 7. 科目免除

| 持っている資格 | 免除される科目 | 受ける科目 | 試験時間 |
|---|---|---|---|
| 他の類の乙種危険物取扱者免状 | 法令・物理化学 | **性質・消火10問のみ** | **35分** |
| 火薬類製造保安責任者などの一部資格 | 物理・化学の一部 | ― | ― |

※乙4を最初に取る人には関係なし。乙4合格後に他の類（乙1〜乙6）を取ると、この免除で**10問35分**で受けられる。

## 8. 合格率・難易度

| 項目 | 数字 |
|---|---|
| 合格率 | おおむね **30〜40%**（例：令和2年度 受験200,876人／合格77,466人＝**38.6%**） |
| 他の乙種（乙1・2・3・5・6） | 65〜70%（※免除ありの受験者が多いため高い） |
| 必要な勉強時間の目安 | **40〜60時間**（1日1時間なら1.5〜2か月／1日2時間なら3〜4週間） |

### 合格率が低めに見える理由
- 受験資格がないので、**準備なしで受ける人が多い**。
- 会社や学校でまとめて受験することが多く、記念受験層が混じる。
- 「科目ごとに6割」のルールを知らずに、苦手科目を捨てて落ちる人がいる。

→ **過去問を回した人の実感難易度はそれほど高くない**。出題は過去問の言い回し違いが中心。

## 9. 合格発表・免状

- 発表は試験日から**2〜4週間後**が目安（都道府県による）。センターのサイトで受験番号が公表され、はがきも届く。
- 合格したら**都道府県知事**に免状交付を申請する（申請しないと免状は来ない）。
- 免状は**全国で有効**。

## 10. この試験で「できるようになること」

- **ガソリン・灯油・軽油・重油など引火性液体（第4類）**の取扱いと、無資格者への立会いができる。
- ガソリンスタンド、タンクローリー、化学工場、ビル管理などで必要。
- いわゆる「ビルメン4点セット」の1つ。
