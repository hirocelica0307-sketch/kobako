# 科目1：危険物に関する法令（15問・9問以上で合格）

法令は**暗記だけで満点がねらえる**科目。数字と「誰に何をするか」を表で覚える。

---

## 1. 危険物の定義 ★★★

**これだけ覚える**
- 消防法でいう危険物＝**別表第1**に載っている物品だけ。
- 危険物は**固体か液体**のみ。**気体は危険物ではない**（プロパン・水素などは高圧ガス保安法）。

| 類 | 性質 | 状態 | 代表例 |
|---|---|---|---|
| 第1類 | 酸化性固体 | 固体 | 塩素酸カリウム、過マンガン酸カリウム |
| 第2類 | 可燃性固体 | 固体 | 硫黄、赤りん、マグネシウム |
| 第3類 | 自然発火性物質・禁水性物質 | 固体・液体 | ナトリウム、カリウム、黄りん |
| **第4類** | **引火性液体** | **液体** | **ガソリン、灯油、軽油、重油** |
| 第5類 | 自己反応性物質 | 固体・液体 | ニトログリセリン、TNT |
| 第6類 | 酸化性液体 | 液体 | 過酸化水素、硝酸 |

**ひっかけ**
- 「それ自体が燃える」のは第2・第3・第4・第5類。**第1類と第6類は自分では燃えない**（他を燃えやすくする）。
- 第5類は**自分の中に酸素を持っている**ので、窒息消火がきかない（＝大量の水で冷却）。

## 2. 指定数量と倍数計算 ★★★★★

**これだけ覚える（第4類の指定数量）**

| 品名 | 区分 | 指定数量 | 代表物質 |
|---|---|---|---|
| 特殊引火物 | — | **50 L** | ジエチルエーテル、二硫化炭素、アセトアルデヒド、酸化プロピレン |
| 第1石油類 | 非水溶性 | **200 L** | ガソリン、ベンゼン、トルエン |
| 第1石油類 | 水溶性 | **400 L** | アセトン、ピリジン |
| アルコール類 | — | **400 L** | メタノール、エタノール |
| 第2石油類 | 非水溶性 | **1,000 L** | 灯油、軽油、キシレン |
| 第2石油類 | 水溶性 | **2,000 L** | 酢酸、アクリル酸 |
| 第3石油類 | 非水溶性 | **2,000 L** | 重油、クレオソート油、ニトロベンゼン |
| 第3石油類 | 水溶性 | **4,000 L** | グリセリン、エチレングリコール |
| 第4石油類 | — | **6,000 L** | ギヤー油、シリンダー油 |
| 動植物油類 | — | **10,000 L** | アマニ油、ヤシ油 |

**覚え方**
- 骨組みは **50 → 200 → 400 → 1000 → 2000 → 6000 → 10000**（2倍・2.5倍…と増えていく）。
- **水溶性は非水溶性の2倍**（水で薄まる分だけ危険が減るから）。アルコール類だけは水溶性しかないので400L。
- 語呂：「**ご（50）とくしゅ、に（200）いち、よ（400)んアル、せん（1000）に、に（2000）さん、ろく（6000）よん、いち（10000）まん動植物**」

**品名の分け方（引火点で決まる）**

| 品名 | 引火点の範囲 |
|---|---|
| 特殊引火物 | 発火点100℃以下、または 引火点-20℃以下**かつ**沸点40℃以下 |
| 第1石油類 | 引火点 **21℃未満** |
| アルコール類 | 炭素数1〜3の飽和1価アルコール（引火点では決めない） |
| 第2石油類 | 引火点 **21℃以上70℃未満** |
| 第3石油類 | 引火点 **70℃以上200℃未満** |
| 第4石油類 | 引火点 **200℃以上250℃未満** |
| 動植物油類 | 引火点 **250℃未満** |

> 重油は実際の引火点が60〜150℃だが、試験では**第3石油類**として扱われる。

**倍数の計算（→ 詳しくは KEISAN.md）**
```
倍数 = 貯蔵量 ÷ その品名の指定数量
品名が複数あるときは、それぞれの倍数を出してから足す
合計が 1以上 → 消防法の規制（許可が必要）
合計が 1未満 → 市町村の条例で規制
```
**ひっかけ**：数量を全部足してから割ってはいけない。**必ず品名ごとに割ってから足す**。

## 3. 製造所等の区分（12区分）★★★★

| 大分類 | 区分名 | かんたんな意味 |
|---|---|---|
| 製造所（1） | 製造所 | 危険物をつくる工場 |
| 貯蔵所（7） | 屋内貯蔵所 | 建物の中に容器で置く |
| | 屋外貯蔵所 | 屋外に容器で置く（**置けるのは限られた物だけ**） |
| | 屋内タンク貯蔵所 | 建物の中のタンク |
| | 屋外タンク貯蔵所 | 屋外の大きなタンク |
| | 地下タンク貯蔵所 | 地面の下のタンク（GSの地下タンク） |
| | 簡易タンク貯蔵所 | 600L以下の小さいタンク |
| | 移動タンク貯蔵所 | **タンクローリー** |
| 取扱所（4） | 給油取扱所 | **ガソリンスタンド** |
| | 販売取扱所 | 容器のまま売る店（第1種＝15倍以下、第2種＝15倍超40倍以下） |
| | 移送取扱所 | パイプライン |
| | 一般取扱所 | 上のどれでもない取扱所（ボイラー室など） |

**屋外貯蔵所に置ける第4類**：**第1石油類（引火点0℃以上のものだけ）・アルコール類・第2石油類・第3石油類・第4石油類・動植物油類**
→ **特殊引火物は置けない。ガソリン（引火点-40℃）も置けない**。これが定番のひっかけ。

## 4. 申請・届出（許可・承認・届出の使い分け）★★★★★

| やること | 手続き | 相手 | 時期 |
|---|---|---|---|
| 製造所等の**設置** | **許可** | 市町村長等 | 着工前 |
| 位置・構造・設備の**変更** | **許可** | 市町村長等 | 着工前 |
| 完成後の使用開始 | **完成検査** | 市町村長等 | 使用前 |
| タンクの水張・水圧検査 | 完成検査前検査 | 市町村長等 | 埋設前など |
| 変更工事中に他の部分を使う | **仮使用**の**承認** | **市町村長等** | 工事前 |
| 製造所等以外で10日以内の仮の貯蔵 | **仮貯蔵・仮取扱い**の**承認** | **消防長または消防署長** | 事前 |
| **品名・数量・指定数量の倍数の変更** | **届出** | 市町村長等 | **変更の10日前まで** |
| 譲渡・引渡（持ち主が変わる） | 届出 | 市町村長等 | **遅滞なく**（事後） |
| 用途の廃止 | 届出 | 市町村長等 | **遅滞なく**（事後） |
| 保安監督者の選任・解任 | 届出 | 市町村長等 | **遅滞なく**（事後） |

**覚え方**
- **「仮貯蔵・仮取扱いだけが消防長・消防署長」**。それ以外は全部「市町村長等」。
- **「10日前までは品名・数量の変更だけ」**。ほかの届出は全部「遅滞なく」。
- **許可＝工事系／承認＝仮の話／届出＝事後報告**。

**ひっかけ**
- 「仮使用」と「仮貯蔵」を入れかえる問題が定番。
  - 仮**使用**＝すでにある施設の一部を工事中に使う → **市町村長等の承認**
  - 仮**貯蔵**＝施設でない場所で10日以内だけ置く → **消防長・消防署長の承認**

## 5. 危険物取扱者と免状 ★★★★★

| 種類 | 扱える危険物 | 無資格者への立会い |
|---|---|---|
| 甲種 | **全部（第1〜6類）** | できる |
| 乙種 | **免状を取った類だけ** | **その類だけできる** |
| 丙種 | 第4類のうちガソリン、灯油、軽油、重油など指定された物のみ | **できない** |

- 丙種は**保安監督者になれない**・**立会いできない**。（定番のひっかけ）
- 指定数量**未満**でも、危険物取扱者以外が扱うには**有資格者の立会い**が必要（製造所等の場合）。

**免状の手続き**

| 手続き | 相手 | ポイント |
|---|---|---|
| 交付 | **都道府県知事**（試験を行った知事） | 合格＝自動ではない。申請が必要 |
| **書換え** | 交付した知事、居住地・勤務地の知事 | **氏名・本籍が変わったとき**、および**写真が10年たつ前** |
| 再交付 | 交付・書換えをした知事 | 亡失・滅失・汚損・破損のとき |
| 亡失した免状を見つけたら | — | **10日以内**に再交付を受けた知事へ提出 |
| 返納命令 | 都道府県知事 | 法令違反のとき |

**ひっかけ**
- 住所が変わっただけでは**書換え不要**（本籍・氏名は必要）。
- 免状は**全国で有効**。都道府県ごとに取り直す必要はない。

## 6. 保安講習 ★★★★

**これだけ覚える**

| 状況 | いつまでに受講 |
|---|---|
| 継続して従事している人 | **前回の受講日以後の最初の4月1日から3年以内** |
| 新たに従事することになった人 | **従事日から1年以内** |
| ただし、従事前2年以内に免状交付または講習受講した人 | その日以後の最初の4月1日から3年以内 |

**ひっかけ**
- 受講義務があるのは**危険物の取扱作業に従事している危険物取扱者**だけ。
  → **免状を持っていても従事していなければ不要**。**従事していても免状がなければ不要**。
- 講習を行うのは**都道府県知事**。受講は**全国どこでもよい**。

## 7. 保安監督者・統括管理者・施設保安員 ★★★★

| 役職 | 資格 | 選任する人 | 届出 |
|---|---|---|---|
| **危険物保安監督者** | 甲種または乙種（該当類）で**実務経験6か月以上** | 所有者等 | **必要**（遅滞なく市町村長等） |
| 危険物保安統括管理者 | **資格不要** | 所有者等 | **必要** |
| 危険物施設保安員 | **資格不要** | 所有者等 | **不要** |

**覚え方**：**「施設保安員だけ届出がいらない」**。

**保安監督者が必ず必要な施設**：製造所、屋外タンク貯蔵所、給油取扱所、移送取扱所（＝数量に関係なく必要）
**不要な施設**：**移動タンク貯蔵所**（タンクローリーには保安監督者を置かない）

## 8. 予防規程 ★★★★

- **火災予防のために、施設ごとに自分たちで作る社内ルール**。
- 作成・変更したら**市町村長等の「認可」**が必要（許可でも届出でもない）。
- 対象：製造所・屋内貯蔵所・屋外貯蔵所・屋外タンク貯蔵所・一般取扱所（一定倍数以上）＋**給油取扱所・移送取扱所（数量に関係なく全部）**

**覚え方**：**保安距離がいる5施設＋給油取扱所＋移送取扱所**

---

## 9. 定期点検 ★★★★

| 項目 | 内容 |
|---|---|
| 回数 | **1年に1回以上** |
| 記録の保存 | **3年間** |
| 実施できる人 | 危険物取扱者、危険物施設保安員、**または危険物取扱者の立会いがある無資格者** |
| 記録すること | 点検した製造所等の名称、方法・結果、年月日、実施者 |

**必ず定期点検が必要な施設（倍数に関係なく）**
- **地下タンクを持つ施設**（地下タンク貯蔵所・地下タンクのある製造所/給油取扱所/一般取扱所）
- **移動タンク貯蔵所**（タンクローリー）
- **移送取扱所**

**覚え方**：**「地下・移動・移送は無条件」**

## 10. 保安距離・保有空地 ★★★★★

### 保安距離＝施設から**外の**守るべき建物までの距離

| 相手（保護対象物） | 距離 |
|---|---|
| **一般の住居**（敷地外） | **10 m以上** |
| **学校・病院・劇場・福祉施設など多数の人が集まる施設** | **30 m以上** |
| **重要文化財・国宝** | **50 m以上** |
| **高圧ガス・液化石油ガスの施設** | **20 m以上** |
| 特別高圧架空電線（7,000V超〜35,000V以下） | **水平距離3 m以上** |
| 特別高圧架空電線（35,000V超） | **水平距離5 m以上** |

**覚え方**：**「い(1)え10、が(3)っこう30、ぶん(5)かざい50、ガス20、電線3と5」**

### 保安距離が必要な5施設

**製造所・屋内貯蔵所・屋外貯蔵所・屋外タンク貯蔵所・一般取扱所**
語呂：**「せい（製造所）・おくない（屋内貯蔵所）・おくがい（屋外貯蔵所）・おくがいタンク・いっぱん（一般取扱所）」**

### 保有空地＝施設の**まわりに**あける何もない空き地

- **保安距離の5施設 ＋ 簡易タンク貯蔵所（屋外設置）＋ 移送取扱所（地上設置）**
- 広さは**指定数量の倍数**で決まる（例：屋内貯蔵所で10倍以下なら壁が耐火構造なら0m、など）

| 区分（製造所・一般取扱所） | 空地の幅 |
|---|---|
| 指定数量の倍数 **10以下** | **3 m以上** |
| 指定数量の倍数 **10を超える** | **5 m以上** |

**ひっかけ**
- 保安距離**も**保有空地**も**いらない施設：**屋内タンク貯蔵所・地下タンク貯蔵所・移動タンク貯蔵所・給油取扱所・販売取扱所**
- 保有空地だけ必要（保安距離は不要）：**簡易タンク貯蔵所・移送取扱所**

## 11. 構造・設備の基準 ★★★

- 建築物の**床**は危険物がしみこまない構造にし、**適当な傾斜**と**ためます**を設ける。
- 蒸気がたまらないよう**屋根は軽量な不燃材料**、**窓・出入口には防火設備**。
- **避雷設備**は**指定数量の10倍以上**の製造所等に必要。
- 可燃性蒸気が滞留するおそれのある場所の電気設備は**防爆構造**。
- 地階は設けてはならない。

## 12. タンクの基準 ★★★★

| 種類 | 覚える数字 |
|---|---|
| 屋外タンク貯蔵所の**防油堤** | 容量はタンク容量の**110%以上**（2基以上なら最大のタンクの110%以上）、高さ**0.5m以上** |
| 地下タンク | タンク上部まで**0.6m以上**の覆土、タンク間**1m以上** |
| **簡易タンク** | 1基**600L以下**、1か所に**3基まで**（同一品質のものは1基まで） |
| 移動タンク（ローリー） | 内部は**4,000L以下**ごとに間仕切り、**底弁・非常レバー**、**接地導線**、**「危」の標識** |
| タンクの**空間容積** | 内容積の**5〜10%**（＝容量は内容積の90〜95%） |
| 通気管 | 圧力タンク以外は**無弁通気管**（大気弁付きも可）、先端は地上**4m以上** |

## 13. 給油取扱所の基準 ★★★

- **給油空地**：間口**10m以上**、奥行**6m以上**のコンクリート等の空地。
- 給油ホースの長さは**5m以下**（固定給油設備）。
- 地下専用タンクの容量制限は**なし**（廃油タンクは**10,000L以下**）。
- 給油中は**エンジン停止**。自動車の一部でも空地からはみ出してはいけない。

## 14. 貯蔵・取扱いの基準 ★★★★

- 原則、**類のちがう危険物は同じ貯蔵所で貯蔵しない**（ただし1m以上離すなど条件付きで可の組合せあり）。
- 容器の**積み重ねは3m以下**（屋外貯蔵所の架台は6m以下）。
- **みだりに火気を使用しない**、**係員以外を立ち入らせない**。
- 危険物の**くず・かす**は**1日1回以上**、安全な場所で廃棄する。
- 廃棄するとき、**海中や水中に流してはいけない**。
- タンクの計量口・元弁は**使用時以外は閉める**。

## 15. 運搬の基準 ★★★★★

**運搬＝容器に入れてトラック等で運ぶこと。指定数量未満でも法令が適用される**（ここが移送とのちがい）。

| 項目 | 基準 |
|---|---|
| 容器の収納率（液体） | **内容積の98%以下**、かつ**55℃で漏れない空間**を残す |
| 積み重ね高さ | **3 m以下** |
| 容器の向き | **収納口を上**に |
| 標識 | **0.3m平方の「危」**の標識（黒地に黄色の反射文字）を前後に掲げる |
| 日光の直射をさけるもの | 特殊引火物など → 遮光性の被覆 |
| 消火設備 | 指定数量以上を運搬するときは適応する消火設備を備える |

**混載（いっしょに積む）ルール（指定数量の1/10を超える場合）**

| 第4類と一緒に積める | 積めない |
|---|---|
| **第2類・第3類・第5類** | **第1類・第6類**（強い酸化剤だから） |

**覚え方**：**「4類は 2・3・5 と仲良し、1・6 とはケンカ」**

**容器の表示**：危険物の品名、危険等級、化学名、水溶性（第4類の水溶性のみ）、数量、**注意事項（第4類は「火気厳禁」）**

## 16. 移送の基準 ★★★★

**移送＝移動タンク貯蔵所（タンクローリー）で運ぶこと。**

- 移送する危険物を扱える**危険物取扱者が乗車**し、**免状を携帯**する。
- 長距離（連続4時間超／1日9時間超）の運転は**2人以上**の運転要員。
- 出発前に**底弁・マンホール・注入口のふた・消火器**などを点検。
- 移送経路を事前に**消防機関へ連絡**（アルキルアルミニウム等の場合）。

**ひっかけ**：免状は「携帯」であって「掲示」ではない。また**乗務員全員が有資格者である必要はない**（1人乗っていればよい）。

## 17. 標識・掲示板 ★★★

| 表示 | 色 |
|---|---|
| 「危険物製造所等」の標識 | **白地に黒文字** |
| **「火気厳禁」**（第4類） | **赤地に白文字** |
| 「火気注意」（第2類） | 赤地に白文字 |
| 「禁水」（第3類の禁水性物品・第1類の無機過酸化物） | **青地に白文字** |
| 「注意」（第1類その他・第6類） | 青地に白文字 |
| 移動タンク貯蔵所の「危」 | **黒地に黄色の反射塗料** |

**掲示板に書くこと**：危険物の**類・品名・貯蔵最大数量・指定数量の倍数・危険物保安監督者の氏名**

## 18. 消火設備・警報設備 ★★★★

| 種別 | 設備 |
|---|---|
| **第1種** | 屋内消火栓設備、屋外消火栓設備 |
| **第2種** | **スプリンクラー設備** |
| **第3種** | 水蒸気・水噴霧、**泡**、不活性ガス（CO2）、ハロゲン化物、**粉末**の各消火設備 |
| **第4種** | **大型消火器** |
| **第5種** | **小型消火器**、水バケツ、水槽、**乾燥砂**、膨張ひる石・膨張真珠岩 |

- 第4類（油火災）に**第1種・第2種（水系）は基本的に不適**。
- 所要単位：危険物は**指定数量の10倍＝1所要単位**。
- 警報設備：指定数量の**10倍以上**の製造所等に必要（自動火災報知設備、拡声装置、非常ベル、消防機関に報知できる電話、警鐘）。**移動タンク貯蔵所は不要**。

## 19. 命令・取消し ★★

| 処分 | 誰が | いつ |
|---|---|---|
| 許可の取消し・使用停止命令 | 市町村長等 | 無許可変更、完成検査前使用、基準適合命令違反、保安監督者未選任など |
| 危険物の貯蔵・取扱基準遵守命令 | 市町村長等 | 基準違反のとき |
| 移動タンク貯蔵所の停止・免状提示要求 | **消防吏員・警察官** | 走行中の検査 |
