## 1. 燃焼の3要素 ★★★★★

**これだけ覚える**

| 要素 | 中身 | 消火との関係 |
|---|---|---|
| ① 可燃物 | 燃えるもの（ガソリン、木、紙） | 取り除く＝**除去消火** |
| ② 酸素供給源 | 空気（酸素21%）、酸化剤 | ふさぐ＝**窒息消火** |
| ③ 点火源（熱源） | 火花、静電気、高温体 | 冷やす＝**冷却消火** |

- この3つが**同時にそろったときだけ**燃える。1つでも欠ければ燃えない。
- ＋**連鎖反応**を入れて「燃焼の4要素」ということもある。これを止めるのが**抑制（負触媒）消火**。

**燃えないもの（不燃物）の例**：二酸化炭素、窒素、水
→ **すでに酸素と結びついて安定している**から燃えない。「CO2は燃えない」は定番。

### 燃焼の仕方（4種類）

| 種類 | 説明 | 例 |
|---|---|---|
| **表面燃焼** | 固体の表面だけが赤熱して燃える。炎が出ない | 木炭、コークス |
| **分解燃焼** | 熱で分解して出たガスが燃える | 木材、紙、石炭 |
| **蒸発燃焼** | 液体・固体から出た**蒸気**が燃える | **ガソリン・灯油など第4類ぜんぶ**、硫黄 |
| **自己燃焼（内部燃焼）** | 自分の中の酸素で燃える | ニトロセルロース（第5類） |

**超重要**：**第4類は液体そのものが燃えるのではなく、蒸発した蒸気が燃える**（蒸発燃焼）。
→ だから「蒸気をためない・拡散させる」が火災予防の基本になる。

### 燃焼の難易（燃えやすい条件）

燃えやすい ＝ **酸素と触れる面積が広い／熱が逃げにくい／水分が少ない／発熱量が大きい／熱伝導率が小さい**
**ひっかけ**：熱伝導率が**大きい**ほど熱が逃げるので**燃えにくい**。

## 2. 引火点・発火点・燃焼範囲 ★★★★★

**3つの区別が最頻出**

| 用語 | 定義（中学生向け） | ポイント |
|---|---|---|
| **引火点** | **火を近づけると燃え出す最低の液温** | 「その温度まで液が温まると、燃える濃さの蒸気が出る」という温度 |
| **発火点** | **火を近づけなくても、自分から燃え出す最低の温度** | 引火点より**ずっと高い**のがふつう |
| **燃焼範囲（爆発範囲）** | **空気中の蒸気の濃さのうち、燃える範囲**（vol%） | 下限値と上限値がある |

**例（ガソリン）**：引火点 -40℃以下、発火点 約300℃、燃焼範囲 1.4〜7.6vol%

**理解のコツ**
- 引火点＝「**燃焼範囲の下限**の濃さの蒸気が出る液温」。だから引火点と燃焼範囲下限はつながっている。
- **濃すぎても燃えない**（上限より濃い＝酸素が足りない）。
- 危険なのは：**引火点が低い・発火点が低い・燃焼範囲が広い・燃焼範囲の下限が低い**もの。

**ひっかけ**
- 「引火点が低い物質は発火点も低い」→ **誤り**。関係ない（二硫化炭素は発火点90℃と異常に低いが、ガソリンの発火点300℃より低い）。
- 「発火点＝引火点＋何度」のような関係は**ない**。

## 3. 消火の4要素と消火剤 ★★★★★

| 消火法 | やること | 例 |
|---|---|---|
| **除去消火** | 燃えるものを取り除く | ガスの元栓を閉める、ろうそくを吹き消す |
| **窒息消火** | 酸素を断つ（**酸素濃度を約14〜15%以下に**） | 泡、二酸化炭素、粉末、砂をかける、ふたをする |
| **冷却消火** | 温度を下げる | 水をかける |
| **抑制（負触媒）消火** | 燃焼の連鎖反応を止める | ハロゲン化物、粉末 |

### 消火剤と第4類（油火災）への適応

| 消火剤 | 油火災（B火災） | 主な消火作用 | 備考 |
|---|---|---|---|
| **水（棒状・霧状）** | **×（不適）** | 冷却 | 油が水に浮いて**燃え広がる**。※霧状は一部の第3石油類等で可 |
| **強化液（棒状）** | × | 冷却 | |
| **強化液（霧状）** | **○** | 冷却＋抑制 | 霧状なら可 |
| **泡** | **◎** | 窒息＋冷却 | 油面をおおう。第4類の代表 |
| **二酸化炭素** | **◎** | 窒息 | 狭い場所では**酸欠の危険**、汚損が少ない |
| **ハロゲン化物** | **◎** | 抑制＋窒息 | |
| **粉末（ABC・BC）** | **◎** | 抑制＋窒息 | 速効性が高い |
| 乾燥砂 | ○ | 窒息 | 全類に使える |

**水溶性の危険物（アルコール類・アセトン・酢酸など）には、ふつうの泡は消えてしまう**
→ **水溶性液体用泡消火剤（耐アルコール泡）**を使う。**これは超頻出**。

**火災の区分**

| 区分 | 種類 | 表示色 |
|---|---|---|
| A火災 | 普通火災（木・紙） | 白 |
| **B火災** | **油火災（第4類）** | **黄** |
| C火災 | 電気火災 | 青 |

## 4. 静電気 ★★★★★

**これだけ覚える**
- 静電気は**2つの物が接触して離れる（摩擦・はく離）ときに発生**する。
- **ガソリンなど第4類は電気の不導体**なので、発生した電気が逃げず**たまりやすい**。
- たまった電気が**放電したときの火花が点火源**になる → 給油中の火災原因の代表。

### 発生・蓄積を防ぐ方法（○＝正しい対策）

| 対策 | 理由 |
|---|---|
| **接地（アース）する** | たまった電気を大地に逃がす |
| **流速を遅くする** | 速く流すほど摩擦で発生が増える |
| **湿度を高くする（おおむね75%以上）** | 表面の水分を伝って電気が逃げる |
| **導電性の高い材料を使う** | 電気が流れて逃げる |
| **帯電防止服・帯電防止靴を着る** | 人体の帯電を防ぐ |
| **除電剤（静電気防止剤）を加える** | 液の導電性を上げる |
| 摩擦を少なくする | 発生そのものを減らす |

**ひっかけ**
- 「湿度を**低く**する」→ **誤り**（乾燥するほどたまる）。
- 「流速を**速く**する」→ **誤り**。
- 「合成繊維の衣服がよい」→ **誤り**（綿など帯電しにくいものを選ぶ）。
- 静電気は**物質の種類の組合せ**や**接触面積・圧力・速度**で量が変わる。

## 5. 熱（比熱・熱量・熱の移動・熱膨張）★★★★

### 用語

| 用語 | 意味 | 単位 |
|---|---|---|
| **熱量** | 熱のエネルギーの量 | J（ジュール）、kJ |
| **比熱** | **物質1gの温度を1℃上げるのに必要な熱量** | J/(g・K) |
| **熱容量** | **その物全体**の温度を1℃上げるのに必要な熱量（＝比熱×質量） | J/K |
| 融点・沸点 | 固体→液体／液体→気体になる温度 | ℃ |

- **水の比熱は約4.2 J/(g・K)** ＝ とても大きい → だから水は冷却消火に向く。
- 比熱が**大きい**ほど**温まりにくく冷めにくい**。

### 公式（→ 計算の練習は KEISAN.md）
```
熱量 Q ＝ 質量 m × 比熱 c × 温度差 Δt
熱容量 ＝ 比熱 × 質量
```

### 熱の移動（3つ）

| 種類 | 説明 | 例 |
|---|---|---|
| **伝導** | 物の中を熱が伝わる | 金属棒の端を熱すると反対側も熱い |
| **対流** | 液体・気体が動いて熱を運ぶ | ふろの湯、エアコン |
| **放射（ふく射）** | 熱線で直接伝わる。**間に物がなくてよい** | たき火にあたる、太陽の熱 |

**ひっかけ**：真空中でも伝わるのは**放射だけ**。

### 熱膨張
- 温度が上がると体積が増える。液体は**体膨張率**で計算する。
- 危険物をタンクや容器いっぱいに入れてはいけないのは、**温まって膨張してあふれる／内圧が上がる**から。
```
増加体積 ＝ もとの体積 × 体膨張率 × 温度差
```

## 6. 物理変化と化学変化 ★★★

| 変化 | 意味 | 例 |
|---|---|---|
| **物理変化** | 見た目や状態は変わるが、**別の物質にはならない** | 氷→水→水蒸気、砂糖が水に溶ける、ガラスが割れる、金属が膨張する |
| **化学変化** | **別の物質になる** | 燃焼、鉄がさびる、紙が焦げる、電気分解、中和 |

**ひっかけ**：「ドライアイスが気体になる（昇華）」は**物理変化**。「ガソリンが燃える」は化学変化。

### 物質の分類

| 分類 | 意味 | 例 |
|---|---|---|
| 単体 | 1種類の元素だけ | 酸素O2、鉄Fe、硫黄S |
| 化合物 | 2種類以上の元素が結びついたもの | 水H2O、メタノールCH3OH、二酸化炭素CO2 |
| **混合物** | 複数の物質が混ざっただけ | **ガソリン、灯油、軽油、重油、空気、食塩水** |

**ひっかけ**：**ガソリン・灯油は混合物**。だから沸点や引火点が「○℃〜○℃」と幅で表される。

## 7. 酸化と還元 ★★★★

| | 酸化 | 還元 |
|---|---|---|
| 酸素 | **受け取る**（結びつく） | **失う** |
| 水素 | 失う | 受け取る |
| 電子 | **失う** | 受け取る |

- 酸化と還元は**必ず同時に起こる**。
- **酸化剤**＝相手を酸化させる（自分は還元される）。第1類・第6類。
- **還元剤**＝相手を還元させる（自分は酸化される）。
- **燃焼は激しい酸化反応**（熱と光を伴う）。
- ゆっくりした酸化でも熱がたまると**自然発火**する（動植物油のしみた布）。

## 8. 酸・塩基・中和・pH ★★★

- **pH7＝中性**、7より小さい＝酸性、7より大きい＝アルカリ（塩基）性。
- 酸＋塩基 → **塩＋水**（中和）。中和のとき**熱が出る**（中和熱）。
- 酸性・塩基性の強さは「濃さ」ではなく**電離度**で決まる。

## 9. 有機化合物 ★★★

- 炭素を含む化合物（CO2などは除く）。**第4類はほとんどが有機化合物**。
- **完全燃焼すると二酸化炭素CO2と水H2Oになる**。酸素が足りないと**一酸化炭素CO**（有毒）やすすが出る＝不完全燃焼。
- 一般に**水に溶けにくく、有機溶剤に溶ける**。静電気をためやすい（不導体）。
- 炭素の数が多い（分子が大きい）ほど、**沸点・引火点が高く、粘り気が増し、燃えにくくなる**。
  → ガソリン(C4〜C10)＜灯油(C9〜C18)＜軽油＜重油 の順に引火点が上がるのはこのため。

## 10. 金属・腐食 ★★★

- **イオン化傾向**が大きい金属ほどさびやすい（K > Ca > Na > Mg > Al > Zn > Fe > Ni > Sn > Pb > H > Cu > Hg > Ag > Pt > Au）。
- **異なる2種類の金属が接触**して水分があると、イオン化傾向の大きいほうが腐食する（電池ができる）。
- 地下タンクや配管が腐食しやすい場所：**湿った土、酸性の土、迷走電流のある場所、異種金属の接触部**。
- 防ぐ方法：**塗装（コーティング）、電気防食、乾燥した場所**。

## 11. 密度・比重・蒸気比重 ★★★★

| 用語 | 意味 | 基準 |
|---|---|---|
| 密度 | 1cm3あたりの質量 | g/cm3 |
| **液比重** | 水と比べた重さ | **水＝1** |
| **蒸気比重** | 空気と比べた蒸気の重さ | **空気＝1** |

```
蒸気比重 ＝ その気体の分子量 ÷ 29（空気の平均分子量）
```
- **第4類の液体はほとんど液比重1より小さい（水に浮く）**。
  例外で水より重いもの：**二硫化炭素1.26、酢酸1.05、ニトロベンゼン1.2、グリセリン1.3、クレオソート油1以上**
- **第4類の蒸気はすべて空気より重い（蒸気比重1より大）**。
  → 蒸気は**低いところにたまる**。地面近く・くぼみ・排水溝が危険。換気口は**低い位置**にも必要。

## 12. 気体の法則 ★★

- **ボイルの法則**：温度一定なら、圧力×体積＝一定（押すと縮む）。
- **シャルルの法則**：圧力一定なら、体積は絶対温度に比例（温めると膨らむ）。
- **絶対温度 K ＝ 摂氏℃ ＋ 273**
