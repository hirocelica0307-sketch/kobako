# ひらがなキーボード

小学校の子どもが、ひらがなを押して短い文を書くためのキーボードです（Chromebook・タブレット向け）。
Google Apps Script（GAS）のウェブアプリとして動きます。書いた文はその端末の中だけにあり、どこにも送りません。

## ファイル

| ファイル | なかみ |
|---|---|
| `Code.gs` | サーバー側（画面を返す・スプレッドシートの辞書とことばパレットを読む） |
| `index.html` | 画面と動き |
| `辞書.html` | 辞書（1〜6年の漢字を使うことば） |
| `henkan.html` | 変換のしくみ（学年別漢字配当表・1語ずつの候補・文ごとの変換・音声入力の漢字を学年に合わせる） |
| `tests.js` | 辞書と変換のテスト（`node hiragana-keyboard/tests.js`。`-v` を付けると結果をすべて表示） |

## 入れかた

1. script.google.com で新しいプロジェクトを作る（スプレッドシートの「拡張機能」→「Apps Script」からでもよい）。
2. `Code.gs` の中身を、エディタの `コード.gs` にまるごと貼り付ける。
3. 「＋」→「HTML」で次の3つのファイルを作り、それぞれの中身を貼り付ける。
   名前は**拡張子なし**で `index`・`辞書`・`henkan` にする（エディタが自動で `.html` を付ける）。
4. 「デプロイ」→「新しいデプロイ」→ 種類「ウェブアプリ」。
5. 前の版から入れかえるときは、「デプロイを管理」→ 編集 →「新バージョン」で更新すると URL は変わらない。

先生がスプレッドシートで辞書やことばパレットを増やすときは、`Code.gs` の `SHEET_ID` にスプレッドシートの ID を入れる（シートの書きかたは `Code.gs` の説明を参照）。

## 変換のしくみ

- **1語ずつの候補**：打っている読みと同じことば・その読みで始まることば・先の部分だけ（「ここまで」）を出す。
- **文ごとの変換（「まとめて」）**：打った文全体を、辞書のことばの組み合わせで区切って、一度に漢字にする。
  例：「きょうはてんきがいい。」→ 2年「今日は天気がいい。」・1年「きょうは天気がいい。」
  - 区切りが少ない組み合わせを選ぶ。助詞（は・が・を…）は区切りになりやすく、漢字のことばが助詞なしで続く区切りは選ばれにくい。
  - 「した・です・ある・いる」などは、かなのまま残す（`辞書.html` の `F`）。
  - 1文字の読みのことば（て→手・め→目）は、まちがえやすいので文ごとの変換では使わない（1語ずつの候補には出る）。
  - 動詞・形容詞は活用した形も自動で作る（かく→かいた・かきます・かかない、たのしい→たのしかった など）。
  - 「、。？！」は、打っている途中なら候補の中に入る（文の最後まで打ってから「まとめて」で変換できる）。
  - 辞書にないことばは、近い読みのことばになることがある（例：「とまりました」→「止まりました」）。そのときは「そのまま」を選ぶ。
- **学年**：せっていで 1〜6年を選ぶと、その学年までに習う漢字だけを出す（文部科学省「学年別漢字配当表」・2020年度からの 1026字）。
  - **まぜがき する**（はじめの設定）：習っていない字だけひらがなにする（家族 → 2年「家ぞく」）。
  - **まぜがき しない**：習っていない字が1つでもあることばは、ぜんぶひらがなのまま。
- **音声入力**：入ってきた漢字のうち、辞書にあることばは学年に合わせてひらがなにもどす。辞書にない漢字の熟語はそのまま残る。

## 辞書の書きかた（`辞書.html`）

漢字のすぐうしろに `( )` で読みを書く。ひらがな・カタカナはそのまま。

```
家(か)族(ぞく)   学(がっ)校(こう)   今日(きょう)   ラーメン
```

- 2字以上をまとめて読むことば（熟字訓）はまとめて書く：`今日(きょう)`・`大人(おとな)`
- 動詞は `V5`（五段：かく・よむ）・`V1`（一段：たべる・みる）、形容詞は `A` に、言い切りの形で書く
- 前に `^` を付けると同じ読みの中で先に、`_` を付けるとあとに出る。`~` は候補の一覧（打ちかけの予測）に出さない
- 配当表にない漢字（掃除の「掃」など）は使わず、ひらがなで書く（`tests.js` が見つける）

## データ量

| | 大きさ |
|---|---|
| `辞書.html` | 約27KB（ことば 約1400。活用した形を入れて 約6300） |
| `henkan.html` | 約18KB（1026字の配当表をふくむ） |
| `index.html` | 約57KB |

起動時に辞書を読みこむのは 0.03秒ほど、文ごとの変換は 1回 0.001秒ほど（パソコンで計測）。
辞書を10倍にしても 300KB 弱なので、GAS のウェブアプリでも Chromebook でも問題ない大きさ。
スプレッドシートの辞書は、とても大きくすると GAS のキャッシュ（1つ 100KB まで）に入らず、毎回シートを読むので少し遅くなる。

## この版で直したこと

- カタカナタブで ✓・Enter・「、。」を押すと、ひらがなで入っていた → カタカナで入る（候補に「ひらがな」も出る）
- 10キーを1回タップしたとき、指のぶれで「あ」が入ったり入らなかったりした → いつもポップアップが開いたままになる（すべらせたときだけ選ぶ）
- 打ちかけの文字があるときに、うしろの字をタップしたり ← を押したりすると、カーソルがずれた
- 再読みこみで書いた文が消えた → タブを閉じるまでは残る（sessionStorage）
- 長い文のとき、入力らんの横スクロールの位置がずれることがあった
- 辞書のまちがい（かようし→画用紙・じゅんばん→番・ノートの読み・家出 など）を、辞書を作り直して修正
- スプレッドシートのことばパレットで、入れる文字の最後の空白（「きょうは␣」）が消えていた
- せっていの「とじる」が、画面が低いとスクロールしないと押せなかった

## まだのこと

- 実機（Chromebook のタブレットモード）での確認：音声入力の2つめの方法で、かくれた入力らんにフォーカスすると画面キーボードが出るかもしれない
- 文ごとの変換は辞書にあることばだけが対象。よく使うのに変換されないことばは `辞書.html` に足す
