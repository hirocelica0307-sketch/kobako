# ドレミ がっき（仮称）

タブレット・Chromebook・電子黒板で ひける、**けんばん（鍵盤ハーモニカ）・もっきん・てっきん・バス・リコーダー** の れんしゅうアプリです。
「バーチャル鍵ハ Doremiia（ドレミーア）」の ような 画面の けんばんに、学校の 合奏で つかう がっきを あわせて、授業で つかいやすく しました。

- **がっき 5つ**：けんばん（ねいろ：けんばんハーモニカ／ピアノ／リコーダー）・もっきん・てっきん・バス（ねいろ：ベース／オルガン）・リコーダー
- **リコーダー**：けんばんを おすと リコーダーの 音が なって、ひだりの リコーダーの 図で **その 音を 出す ために おさえる あなが くろく なる**（ソプラノ・ジャーマン式）。図は **ふく人から 見た 向き（てまえ＝画面の した が ふきぐち）／ むかいから 見た 向き（ふきぐちが うえ・左右 はんたい）** を きりかえられる
- **リズム**：2拍子・3拍子・4拍子・6/8拍子を カチカチ か ドラムで ながして、あわせて ひける。おてほんも 小節の あたまから はじまる
- **さいだいか**：がっき だけを 画面 いっぱいに 大きく する
- **メニューは ふだん かくす**：うえは ほそい バー（☰ メニュー・がっき・リズム・さいだいか）だけ
- もっきん・てっきんは 本物と おなじ **バーの ならび**（うしろに ♯・♭の バー、ひくい ほど ながい）
- **ガイドつきの きょく**：つぎに ひく ところが 光る。まちがえても 音は 出て、正しい ところを おすと すすむ。さいごまで ひくと「できたね！」
- **じぶんで きょくを つくる**：ドレミを 文字で 打つ・**けんばんを ひいて 入力**（リズムに あわせて ひくと のばす 音・やすみも 自動で きまる）・**がくふファイル（MusicXML・MIDI）を よみこむ**。**リンクを つくって Classroom などで くばれる**（ひらくと その きょくと がっきで はじまる）
- **ろくおん**して じぶんの えんそうを きける
- **index.html 1ファイル** だけで うごく（サーバー・ログイン・外部API・音の ファイル なし。音は その場で つくる）

### リズム（メニューの 🥁 の だん）

- **拍子**：2拍子・3拍子・4拍子・6/8拍子（6/8 は 8分音符ごとに カチ、1と4が つよい）
- **おと**：カチカチ（1はくめが たかい）／ドラム（2拍子 ドン・タン、3拍子 ドン・タン・タン、4拍子 ドン・タン・ドン・タン、6/8 ドン・チ・チ・タン・チ・チ）
- **はやさ**：♩＝50〜160。きょく・おてほん・けんばんの 入力 と おなじ はやさ
- きょくを えらぶと その きょくの 拍子に なる（`3拍子` と かいて ある きょく）

パソコンの キーボードでも ひけます：<kbd>A</kbd><kbd>S</kbd><kbd>D</kbd><kbd>F</kbd><kbd>G</kbd><kbd>H</kbd><kbd>J</kbd><kbd>K</kbd> が ドレミファソラシド（いちばん ひだりの ド から）、<kbd>W</kbd><kbd>E</kbd><kbd>T</kbd><kbd>Y</kbd><kbd>U</kbd> が ♯・♭。

### リコーダー

- ソプラノリコーダー・**ジャーマン式** の ゆびづかい。けんばんは ド〜高いラ（13けん と ♯・♭）
- けんばんを おしている あいだ、その 音の おさえかたが 出る。はなすと さいごに おした 音の まま のこる
- **くろ＝ふさぐ、しろ＝あける、はんぶん くろ＝サミング**（うらの おやゆびを すこし あける）
- うらの おやゆびの あな（0）は 見えない ので、リコーダーの よこに 点線で つないで 出す。6・7は 2つ あな（大きい あな と 小さい あな）
- ガイドの ときは、ひいていない あいだ「**つぎは ○**」の おさえかたを 出す
- 図は 画面の たかさ いっぱいに 大きく 出して、けんばんは のこりの はば（小さく なる）。けんばんを おしても 図の 大きさは かわらない
- **ふく人から 見た 向き**：じぶんが ふいている ときに 見える 向き。てまえ（画面の した）が ふきぐち、むこうが あしぶ。左手（1・2・3）が した、右手（4〜7）が うえ
- **むかいから 見た 向き**：むかいに いる 人から 見た 向き。ふきぐちが うえで、左右が はんたい
- 音は 本物と おなじ く、かいて ある 音より 1オクターブ うえで なる

**運指表で たしかめて ほしい 音**：ソ♯・シ♭・高いド♯・高いレ♯・高いファ♯・高いソ♯ の 6つ。ド〜高いラ の ♯・♭の ない 音と、ド♯・レ♯・ファ♯（0123 567）・高いファ（サミング 1234）は ジャーマン式の 運指表と あわせて いれた。ちがって いたら `index.html` の `FING`（1つの 音が 1行）を なおすと 図も かわる。

### きょくの れんしゅう（🎵 きょく）

- **▶ おてほん**：はやさ に あわせて じどうで ひいて、ひく ところと 音ふを 光らせる。リズムを ながして いる ときは つぎの 小節の あたまから はじまる
- **🔈 おとも ならす ／ 💡 ひかる だけ**：ひかる だけ に すると、おてほんの 音を 出さずに けんばんだけ 光る（リズムに あわせて じぶんで ひく れんしゅう）
- **👆 ガイド**：つぎに ひく けんばん・バーが オレンジに 光る。正しい ところを おすと つぎへ。見えない ところに ある ときは けんばんが じどうで うごく
- **⏮**：はじめから
- メニューを とじて いる ときは きょくの なまえ・おてほん・⏮・音ふ だけ 出る（きょくを かえる・ガイド・つくる は メニューを ひらく）
- がっきの はんいに はいらない ときは、オクターブを じどうで うごかす（バスなら 1オクターブ した など）
- 入っている きょく（作曲者が なくなって 70年 いじょう たった もの。かしは のせない）：
  ドレミの かいだん／ミ・レ・ド（3つの おと）／かえるの うた／メリーさんの ひつじ／きらきらぼし／フレール・ジャック／ロンドン橋／よろこびの うた／ジングルベル

### じぶんで きょくを つくる（✏️ つくる）

教科書の きょくは 著作権が あるので 入れて いません。先生が ドレミを 打ちこんで つかって ください。

| かきかた | いみ |
|---|---|
| `ド レ ミ`（ひらがな `ど れ み` でも OK。くぎりは スペース・読点、くっつけて `ドレミ` でも OK） | 1はくずつ |
| `ドー` `ドーーー` | ー 1つで 1はく のばす（2はく・4はく） |
| `ド0.5` `ド1.5` | ながさを 数で（はんぶん・1はんぶん） |
| `高ド` `低ソ` `高高ド` | 1オクターブ うえ・した（まんなかの ド が `ド`） |
| `ファ#` `シ♭` `シb` | ♯・♭ |
| `休` | やすみ |
| `C D E` | アルファベットでも かける |
| `3拍子` `6/8拍子`（はじめに） | その きょくの 拍子（リズムが それに なる） |

- **🎹 けんばんで ひいて 入力**：ダイアログが とじて、けんばんで ひいた 音が 音ふに なる。**✓ できた** で もとの 文の うしろに たされる
  - **リズムに あわせる（チェック あり）**：リズムが ながれて、1小節 カウントの あとで ひく。おした・はなした タイミングを 8分音符に そろえて、**つぎの 音までの ながさ ＝ その 音の ながさ**（のばす 音）。はなしてから つぎの 音まで 1はく いじょう あくと **やすみ**。小節の とちゅうから はじめると さいしょに やすみが はいる。同時に おした ときは たかい 音
  - **チェック なし**：1つ おすごとに 1はく。**ー のばす**（さいごの 音を 1はく ながく）・**休 やすみ**・**⌫ 1つ けす**
- **📄 がくふファイルを よみこむ**：MusicXML（.musicxml .xml .mxl）と MIDI（.mid）から ドレミの 文を つくる。1ばんめの パートの メロディ（1ばんめの こえ。和音は 1つ）・タイは つなぐ・拍子と きょくの なまえ も よむ
  - **しゃしん・PDF の がくふは よめません**（音ふを 画像から よみとるには 大きな しくみ（OMR）が いる ため）。MuseScore（無料）の「PDF を インポート」や スマホの がくふ よみとり アプリで MusicXML に して から よみこんで ください
- よみとった 音が その場で 下に ならぶ。よめない 文字は「○こめの あたりの『X』が よめないよ」と 出る
- **💾 ほぞんして つかう**：この ブラウザに おぼえる（ほかの 端末には うつらない）
- **🔗 リンクを つくる**：きょくの なまえ・ドレミ・いまの がっき が 入った リンクを コピーする。子どもが ひらくと その きょくで はじまる（ドレミは URL の 中に だけ 入り、どこにも 送らない）

## しくみ

- 音の ばんごうは MIDI（まんなかの ド＝60）。がっきに かいてある ドレミ（かく 音）に たいして、じっさいに なる 音は **もっきん ＋1オクターブ・てっきん ＋2オクターブ**（本物の 木琴・グロッケンと おなじ）
- がっきの はんい：けんばん F3〜C6（32けん の 鍵盤ハーモニカ と おなじ）・もっきん F3〜C6・てっきん G3〜C6・バス E1〜C4・リコーダー C4〜A5（なるのは 1オクターブ うえ）
- 音は Web Audio で つくる：けんばんハーモニカ＝のこぎり波＋く形波＋息の 音、もっきん＝木の 倍音（×4・×9）と みじかい 減衰、てっきん＝金ぞくの 倍音（×2.76・×5.4・×8.93）と ながい 減衰＋ひびき、ベース＝はじいた 音＋ちいさな スピーカー でも きこえる 上の 倍音
- オクターブの 点：まんなかの ド より うえは 点が うえ、したは 点が した（バスは 2オクターブ した の ド を きじゅん）
- せってい・見える はんい・じぶんの きょくは ブラウザ（localStorage）に おぼえる
- iPad で 音が でない ときは マナーモードの スイッチと 音量を たしかめる（Safari 16.4 いじょう なら マナーモードでも なる ように している）
