# ひっさんモンスター

小学校2年生の **たし算・ひき算の ひっ算（筆算）** を、
タブレットや スマホで「数字を ポチポチ おすだけ」で 練習できる 学習ゲームです。

- **くり上がり / くり下がり の 小さい数字まで じっさいに 入力します**
  （たし算＝くり上がりの「1」、ひき算＝くり下がりで 1 へらした 数）
- **入力する場所は 正しい ひっ算の 手順で 自動的に 選ばれます**
  （一の位 → くり上がり → 十の位 …）。どこに 書くか 迷いません
- 数字は 画面いっぱいに **大きく** 表示されます
- まちがえても 先に すすまず、ヒヨコ先生が だんだん くわしく 教えてくれます

## あそびかた

`index.html` を ブラウザで ひらくだけです。インストールも 通信も 不要（オフラインで うごきます）。

```
git clone <このリポジトリ>
cd my-app4
# index.html を ダブルクリック、または
python3 -m http.server 8000   # → http://localhost:8000
```

タブレットで つかう場合は、ブラウザの「ホーム画面に追加」を すると アプリのように ひらけます。

## ゲームの ながれ

1. ホームで ステージを えらぶ
2. 1ステージ ＝ **5問**。オレンジ色に 光っている マスに 数字を 入れる
3. 5問 おわると **たまごが かえって モンスターが 1ぴき 仲間になる**（ぜんぶで 24ひき）
4. ノーミス ＝ ★★★ ／ 2回までのミス ＝ ★★ ／ それ以上 ＝ ★
5. ★を 1つでも とると つぎの ステージが ひらく

| # | ステージ | ないよう |
|---|---|---|
| 1 | たしざん① | 2けた＋2けた　くり上がり なし |
| 2 | たしざん② | 2けた＋2けた　くり上がり あり |
| 3 | たしざん③ | 2けた＋2けた　ミックス |
| 4 | ひきざん① | 2けた−2けた　くり下がり なし |
| 5 | ひきざん② | 2けた−2けた　くり下がり あり |
| 6 | ひきざん③ | 2けた−2けた　ミックス |
| 7 | たしざん④ | 3けたの たし算（答えは 3けたまで） |
| 8 | ひきざん④ | 3けたの ひき算（くり下がり 2回・100−58 のような 0 からの くり下がりも） |
| 9 | ちょうせん | たし算・ひき算 ぜんぶ ミックス |

## おうちの方へ（せってい ⚙️）

- **ヒントを だす**：ON だと「7 ＋ 8 は？」「6 から 9 は ひけない！」のように
  手順を ことばで 案内します。OFF にすると「じゅうの くらいの こたえを かこう」だけになります
- **おと を ならす**：正解音・ファンファーレ（音声ファイルは 使わず ブラウザで 合成）
- **ステージを ぜんぶ ひらく**：順番に関係なく 好きな ステージで 練習できます
- **きろくを けす**：★・モンスター・せいせき を 初期化します
- まちがえた 回数は 1ステップにつき 1回だけ 数え、3回 まちがえると
  正解の キーが 光ります（できた！で 終われるように しています）
- 記録は その端末の ブラウザ（localStorage）にだけ 保存されます。通信は しません

## ファイル構成

```
index.html   画面の骨組み
style.css    見ため（大きな数字・カラフルなボタン・たて／よこ画面 対応）
app.js       問題作成・ひっ算の手順づくり・入力判定・ゲーム進行
```

外部ライブラリ・ビルド・サーバーは 不要です。

### ひっ算の 手順づくり（`buildPlan`）

`a`・`b`・演算子から、**入力する順番**のリスト（`steps`）を 作ります。

- `ans` … 答えのマス
- `carry` … くり上がりの 1（一の位の 和が 10以上のとき、次の位の 上に）
- `borrow` … くり下がりで へらした 数（`132−58` なら 十の位の上に 2、
  `100−58` のように 0 が つづく ときは 百→0、十→9 と 順に 書きます）

2けたの 全組み合わせ（たし算・ひき算）と 3けたの ランダム 4万件で、
桁ごとの 値・並び順が 正しいことを 確認しています。

## これから 決められること（拡張の アイデア）

- くり上がりが「あるか ないか」を 子ども自身に ボタンで 選ばせるモード

- 時間制限モード／おうちの人の パスワードつき せいせき画面
- 九九・かけ算の ひっ算（3年生）への 拡張
- モンスターを 絵文字から オリジナルイラストに さしかえ
