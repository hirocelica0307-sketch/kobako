# ひっさんモンスター

小学校2年生の **たし算・ひき算の ひっ算（筆算）** を、
**数字をポチポチ押すだけ**で練習できる学習ゲームです。Chromebook での利用を想定しています。

- **くり上がり / くり下がり の小さい数字まで実際に入力します**
- **入力する場所は正しい筆算の手順で自動的に選ばれます**（一の位 → くり上がり → 十の位 …）
- **くり上がりが「あるか・ないか」の判断も児童が行います**（初期設定。設定で自動にも切替可）
- 数字は画面の高さいっぱいに **大きく** 表示されます
- 正解すると **花まる＋ピンポン**。5問クリアで **モンスターが1ぴき仲間に**（全24種・オリジナルSVG）
- 記録は **Google スプレッドシート**（Apps Script）に児童アカウントごとに自動保存できます

## 2つの使い方

### A. Apps Script 版（おすすめ・学校アカウント運用）
児童が学校の Google アカウントで URL を開くだけで、**前回の続きから**遊べます。
端末が変わっても、電源を切っても記録は残り、先生はスプレッドシートで全員の状況を確認できます。

→ 手順は **[docs/SETUP-GAS.md](docs/SETUP-GAS.md)**（初回15分ほど）

### B. ファイルをそのまま開く（お試し・家庭用）
`index.html` をブラウザで開くだけ。通信もインストールも不要。
記録はその端末のブラウザにだけ保存されます。

```
python3 -m http.server 8000    # → http://localhost:8000
```

## ゲームのながれ

1. ホームでステージを選ぶ
2. 1ステージ ＝ **5問**。オレンジ色に光っているマスに数字を入れる
3. 5問終わると **たまごがかえってモンスターが仲間になる**
4. ノーミス ＝ ★★★ ／ 2回までのミス ＝ ★★ ／ それ以上 ＝ ★
5. ★を1つでも取ると次のステージが開く

| # | ステージ | ないよう |
|---|---|---|
| 1 | たしざん① | 2けた＋2けた　くり上がり なし |
| 2 | たしざん② | 2けた＋2けた　くり上がり あり |
| 3 | たしざん③ | 2けた＋2けた　ミックス |
| 4 | ひきざん① | 2けた−2けた　くり下がり なし |
| 5 | ひきざん② | 2けた−2けた　くり下がり あり |
| 6 | ひきざん③ | 2けた−2けた　ミックス |
| 7 | たしざん④ | 3けたのたし算（答えは3けたまで） |
| 8 | ひきざん④ | 3けたのひき算（くり下がり2回・`100−58` のような0からのくり下がりも） |
| 9 | ちょうせん | たし算・ひき算 ぜんぶミックス |

## 設定（⚙️ 右上）

| 項目 | 初期値 | 内容 |
|---|---|---|
| くり上がり・くり下がりの はんだん | **じぶんで えらぶ** | 一の位を書いたあと「くり上がり あり／なし」を児童が選びます。ひき算は「借りるか」を先に判断します。**じどう** にすると、必要なときだけ小さい数のマスが開きます |
| ヒントを だす | **オフ** | オンにすると「7 ＋ 8 は？」のように手順を言葉で案内します。オフでも 💡ヒント ボタンで1回ずつ出せます |
| こうかおん | オン | ピンポン・ファンファーレなど（音声ファイル不要・ブラウザで合成） |
| BGM を ながす | オン | ゆっくりした短いループ。教室では音量にご注意ください |
| ステージを ぜんぶ ひらく | オフ | 順番に関係なく好きなステージで練習できます |
| きろくを けす | — | ★・モンスター・成績を初期化（設定は残ります） |

まちがえたときは先に進まず、1回目「おしい！」→ 2回目 くわしいヒント → 3回目 正解のボタンが光る、
と段階的に手助けします（ミスは1ステップにつき1回だけ数えます）。

## そうさ

- マウス／タッチ／キーボード（数字キー）のどれでも入力できます
- 「あり／なし」の判断は ← → キーでも選べます

外部ライブラリ・ビルド・依存パッケージはありません。

### ひっ算の手順づくり（`buildPlan`）

`a`・`b`・演算子から **入力する順番**のリスト（`steps`）を作ります。

- `ans` … 答えのマス
- `carry` … くり上がりの1（その位の和が10以上のとき、次の位の上に）
- `borrow` … くり下がりで減らした数（`132−58` なら十の位の上に2、
  `100−58` のように0が続くときは 百→0、十→9 と順に書きます）
- `judgeC` / `judgeB` … くり上がり・くり下がりが「あるか ないか」の判断（じぶんで えらぶモード）

2けたの全組み合わせ（たし算・ひき算）と3けたランダム4万件で、
桁ごとの値・並び順・判断ステップの位置が正しいことを確認しています。

## これから決められること

- ステージの追加（2けた＋2けた＋2けたの3口、答えが4けたになる計算 など）
- 学年・クラス列をスプレッドシートに追加して集計しやすくする
- 苦手な型（くり下がりだけ など）を自動で多く出す出題調整
- かけ算のひっ算（3年生）への拡張
