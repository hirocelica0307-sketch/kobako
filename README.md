| フォルダー | なかみ | じょうたい |
|---|---|---|

## きまり

- **1つの アプリ ＝ 1つの フォルダー**
- フォルダーの 中だけで 完結させる（隣の フォルダーの ファイルは 読みこまない）
- あたらしく つくったら、この表に 1行 たす
