# 評価ノート

小学校の先生のための評価記録アプリです。**テストの点**と**授業中の見取り**を記録して、観点ごと（知技・思判表・主体）の A・B・C を出します。
Google スプレッドシートに付いた Apps Script（GAS）のウェブアプリとして動き、データはそのスプレッドシートに入ります。

## ファイル

| ファイル | なかみ |
|---|---|
| `Code.gs` | サーバー側（読み書き・合言葉・バックアップ・Excel出力・古い形式からの移行） |
| `index.html` | 画面（見た目と動き。アイコンも中に入っている） |
| `assets/icons/` | アイコン（Phosphor Icons duotone・MIT）。出どころは `assets/README.txt` |
| `tools/build-icons.js` | `assets/icons/` のアイコンを `index.html` に書きこむ道具 |
| `tests/` | 自動テスト（GAS のまね・サーバーのテスト・ブラウザで画面を動かすテスト） |

## 入れかた（はじめて）

1. 新しいスプレッドシートを作り、「拡張機能」→「Apps Script」を開く。
2. `Code.gs` の中身を、エディタの `コード.gs` にまるごと貼り付ける（最後の行が `HYOKANOTE-GS-END` になっているか確かめる）。
3. 「＋」→「HTML」で `index` という名前のファイルを作り、`index.html` の中身をまるごと貼り付ける（最後の行が `HYOKANOTE-HTML-END`）。
4. 「デプロイ」→「新しいデプロイ」→ 種類「ウェブアプリ」。
   - 次のユーザーとして実行：**自分**
   - アクセスできるユーザー：**自分のみ**（いちばん安全）。ほかの端末から自分のアカウントで開くときもこれで使えます。
5. 表示された URL を、**スプレッドシートの持ち主のアカウントで**開き、合言葉（数字4〜6桁）を決める。

最初の合言葉は、持ち主のアカウントで開いたときだけ決められます（URL を知っているだけの人には決められません）。
持ち主のアカウントで開いても決められないときは、エディタで `allowPinSetup` を実行すると、15分のあいだ画面から決められます。

## 前の版から入れかえるとき（これまでのデータはそのまま使えます）

1. `Code.gs` と `index` の中身を、新しいものに**まるごと**貼りかえる。
2. 「デプロイを管理」→ いまのデプロイを編集（えんぴつ）→「バージョン：新バージョン」→「デプロイ」。URL は変わりません。
3. アプリを開き、**これまでと同じ合言葉**を入れる（入れかえた直後だけ、もう一度聞かれます）。

- データの移しかえの作業はいりません。新しい版を最初に開いたとき、1回だけ自動で整理します（何度走っても同じ結果になります）。
  - 設定シートにあった「教科対象外」（その教科を受けない児童）を「履修除外」シートへ移す
  - さらに古い版の名残（素点に入った「欠」・設定に入った所見・非表示教科）も、これまでどおり整理する
- 元の版で作ったバックアップも、新しい版でそのまま読み込めます。

## この版で直したこと

**不具合・安全**
- Excel出力で「45/50」が日付に、「=」で始まる名前が数式に化けていたのを直した
- 教科が多いと、観点別の Excel 出力が「範囲がシートの外」というエラーで出せなかったのを直した（新しいシートは26列しかないため）
- 同じ秒に2回出力するとエラーになっていたのを直した
- 合言葉を決める前は、URL を知っている人が誰でも中を見られ、合言葉も決められたのをふさいだ（持ち主だけが決められる）
- 間違えた回数を全員で1つにしていたため、ほかの人がわざと5回まちがえると持ち主も締め出されたのを、アカウントごとに数えるようにした
- 合言葉の変更にも、間違えた回数の制限と通行証の確認を付けた。合言葉を変える・外すと、ほかの端末の通行証も使えなくなる
- まとめて消すとき「全部消してから書き戻す」2段階だったのを1回の書き込みにした（途中で止まっても記録がまとめて消えない）
- バックアップの読み込みを「先に全部読む → 今の状態を自動で控える → 1回で書く → 古い形式なら移行」にした。古いバックアップにないシートが混ざって残ることもなくなった
- 「その教科を受けない児童」の置き場所が2つあった（使われていない「履修除外」シートと設定のJSON）のを、「履修除外」シートの1つにまとめた
- 入力中に通行証が切れると、保存していない点が画面上で古い値に戻って見えたのを直した（もう一度合言葉を入れると、元の画面に戻って続けて保存する）
- 画面の中で使う ID を、どんな文字が入っても壊れない形で埋めこむようにした

**軽く**
- 起動時に送るデータを約5分の1にした（35人・12教科・記録6300件で 1688KB → 340KB）
- 毎回の通信で合言葉のシートを読みに行かないようにした（点1つの保存：スプレッドシートの呼び出し 28回 → 16回）
- 番号の振り直し・基準の一括変更・並べかえは、1行ずつでなく1回で書く（62回・104回 → 15回）
- 同じ集計を何度もくり返さないようにした（ホーム 約25ms → 約10ms、観点別 約600ms → 約380ms）
- 入力中に表がガクッと動かないようにした（スクロール位置を保つ）

**使いやすく**
- ホームに「はじめにやること」（名簿 → 単元とテスト → 入力 → バックアップ）を出す。終わると消える
- 編集ボタンを常に見えるようにした（前はマウスを乗せないと出なかった）。削除は編集画面の中へ移し、うっかり消しにくくした
- 設定のタブを7つから5つに（名簿・教科と基準・評価のルール・データ・合言葉）
- 同じタブなら再読み込みしても合言葉を聞かない。合言葉はキーボードでも入力できる
- **表も裏も同じ観点**のテストを作れるようにした（「＋ 面を追加」）
- 「全員に同じ点」は「取消」1回でまとめて戻せる
- 個人シートに「前の子・次の子」
- 学期の初期値を今日の日付から決める（4〜8月→1学期、9〜12月→2学期、1〜3月→3学期）
- スマホで入力パッドが表を隠さないようにした。横にはみ出さない
- アイコンを Phosphor Icons（duotone）にそろえた

## テストの動かし方

```sh
# サーバー(Code.gs)のテスト
node --test hyoka-note/tests/server.test.js

# 画面のテスト(Chromium と Playwright を使う)
NODE_PATH=$(npm root -g) node --test --test-concurrency=1 hyoka-note/tests/ui.test.js

# でたらめ操作のテストを長く回す(シード5つ×300操作)
HN_MONKEY=5 NODE_PATH=$(npm root -g) node --test --test-concurrency=1 hyoka-note/tests/ui.test.js
```

- `tests/gas-mock.js` … SpreadsheetApp などを手元で再現する。セルに文字を書いたときの自動変換（日付・数式）や、シートの外を指したときのエラーも本物と同じように出す
- `tests/fixtures/old-v2.json` … 元の版の `Code.gs` で作ったデータ（合言葉 1234）。これまでのデータが読めるかを確かめるのに使う
