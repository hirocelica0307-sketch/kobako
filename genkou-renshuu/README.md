# げんこうようし れんしゅう

2年生 こくごの 作文で つまずきやすい **たて書きの 原稿用紙の きまり** を、
**ずかん → クイズ → マスに 書く れんしゅう** の じゅんに おぼえる アプリです。
かみに 書く 前に ここで きまりを たしかめて おくと、かみの 作文の なおしが へります。

- 対象：小学2年生（こくご。作文・日記・かんさつ文 など 文を 書く 単元）
- Chromebook（タッチ・マウス・キーボード）・タブレットで つかえます
- **index.html 1ファイル** だけで うごきます。サーバー・ログインは いりません（字の フォントだけ Google Fonts から よみます）
- 点数の ランキングは ありません

## ひらきかた

**https://hirocelica0307-sketch.github.io/kobako/genkou-renshuu/**

`index.html` を Chrome で ひらくだけです（ファイルとして ひらいても うごきます）。

## あつかう きまり（9つ）

| きまり | ないよう |
|---|---|
| ⬜ だんらくの はじめ | だんらくの はじめは 1マス あける。あたらしい だんらくは 行を かえる |
| ⭕ 「。」「、」の ばしょ | マスの 右上に 書く |
| ⤴️ 行の 上に「。」が 来たら | 行の いちばん 上には 書かない。まえの 行の さいごの マスに 字と いっしょに |
| 🔹 小さい 字 | 「っ」「ゃ」「ゅ」「ょ」も 1マス。マスの 右上に |
| 〰️ のばす 音「ー」 | たて書きでは たての ぼう |
| 🔲 かぎ「　」の むき | たて書きの かぎの むき |
| 💬 かいわの 文 | 行を かえて 1マス目から。かいわの あとの 文も 行を かえる |
| 🤝 「。」」は いっしょに | 1つの マスに いっしょに 書く |
| 🏷️ だいめいと なまえ | だいめいは 1行目・上を 2〜3マス（せっていで 2・3 にも）。なまえは 2行目の 下（下を 1マス） |

きまりは となりの [`genkou-youshi/`](../genkou-youshi/)（[docs/RULES.md](../genkou-youshi/docs/RULES.md)）と
おなじ 考え方です。文の とちゅうの「」（思ったこと・引用）は 行を かえません。

## つかいかた（子ども）

### 📖 きまり ずかん
9つの きまりを、○（ただしい 書き方）と ×（まちがった 書き方）の 原稿用紙で くらべて 見ます。
はじめに みんなで 大きい 画面に うつして 見るのにも つかえます。

### 🧩 きまり クイズ
1回 5もん（せっていで 10・15もん）。もんだいは まい回 かわります。

| かたち | やること |
|---|---|
| どっちが ただしい？ | 2つの 原稿用紙から ただしい ほうを えらぶ |
| どれが ただしい？ | 「。」や 小さい 字の 書く ばしょを 3つから えらぶ |
| まちがい さがし | まちがって いる マスを タップする |
| どこに 書く？ | 「。」や「「」、だんらくの さいしょの 字を 書く マスを タップする |

こたえると、きまりの せつめいと ただしい 書き方（みどりの マス）が 出ます。
さいごに きまりごとの ◎・△ が 出て、「まちがえた きまりを もういちど」で にがての きまりだけ やりなおせます。

### ✏️ マスに 書いて みよう
おてほんの 文（よこ書き）を、**じぶんで 原稿用紙の マスに ならべます**。
字は じゅんばんに 出て くるので、子どもは **どこに 書くか** だけを 考えます。

| ボタン | キー | すること |
|---|---|---|
| ✏️ かく | ↓ | いまの マスに つぎの 字を 書く（行の さいごまで 来たら つぎの 行へ） |
| ⬜ 1マス あける | スペース | マスを 1つ あける |
| ↩️ 行を かえる | Enter | つぎの 行の いちばん 上へ |
| 🤝 まえの マスに いっしょに | ↑ | 「。」」や、行の 上に 来た「。」を まえの マスに 入れる |
| ⏪ もどす | BackSpace | 1つ もどす |

- **✅ たしかめる** … きまりと ちがう マスが 赤く なり、なにが ちがうかが 出ます。さいごまで 書くと 自動で たしかめます
- **さいしょの まちがいから やりなおす** … まちがえた 字の ところまで もどります
- **💡 ヒント** … つぎに おす ボタンの じゅんばん（れい：↩️ 行を かえる → ⬜ 1マス あける → ✏️ かく）
- **👀 こたえ** … きまりどおりに 書いた 原稿用紙
- 1行は **10マス**。もんだい（おてほん）は **32もん** で、むずかしさごとに ならびます

| むずかしさ | もんだい | ないよう |
|---|---|---|
| ★ | 5もん | だんらくの 1マス・「。」「、」 |
| ★★ | 12もん | 10マスで 書くと「。」や「、」が **行の いちばん 上に 来る**（まえの マスに いっしょに 入れる れんしゅう） |
| ★★★ | 15もん | かいわ。**かぎが いくつも** ある 文（「…。」「…。」と つづく かいわ・だんらくが かいわで はじまる・「。」」が 行の 上に 来る・文の とちゅうの「」（思った こと）など） |

### 🏅 メダル（せんせいが 見て わかる）
さいごまで きまりどおりに 書けたら（クリア）、その もんだいに メダルが つきます。

| メダル | クリアまでの まちがい |
|---|---|
| 🥇 金メダル | なし |
| 🥈 銀メダル | 1つ（なおして クリア） |
| 🥉 銅メダル | 2つ（なおして クリア） |
| ざんねんメダル | 3つ いじょう、または「こたえを 見る」を つかった |

- まちがいは「たしかめる」や さいごの たしかめで 見つかった ところを 1か所 1つと かぞえます（おなじ 字の おなじ まちがいは 1つ）。
  「1字 書く たびに」の せっていでは、まちがえた たびに かぞえます。**「ヒント」を つかうと まちがい 1つ** と かぞえます
- もんだいの 一覧で、どの もんだいに どの メダルが ついたか・クリアした 日・クリアした かいすうが 見られます。
  いちばん 上に「クリア ◯／32もん」と メダルごとの かずが 出ます
- 1つの もんだいでは **いちばん よい メダル** が のこります（もういちど ちょうせんして 金を ねらえます）
- きろくは その パソコンの ブラウザに のこります。⚙ の「メダルの きろくを けす」で けせます

## せんせいの せってい（⚙️）

| こうもく | はじめ | ないよう |
|---|---|---|
| クイズの もんだいの かず | 5もん | 5・10・15 |
| クイズに 出す きまり | ぜんぶ | ならって いない きまりを はずせます |
| まちがいを おしえる とき | たしかめる とき | 「1字 書く たびに」に すると、まちがえた ところで すぐ おしえて もどります |
| 字の 入れかた | ボタンで おく | 「キーボードで うつ」に すると、おてほんの 字を じぶんで 打ちます（ちがう 字は 入りません。タイピングの れんしゅうにも なります） |
| ヒントと こたえ | 出す | 出さない ことも できます |
| だいめいの 上を あける マス | 2〜3 | 2マス・3マス に きめる ことも できます |
| せんせいの おてほん | なし | 教科書の 文などを 入れると「マスに 書いて みよう」の いちばん 上に 出ます（1行＝1だんらく。かいわは そのまま つづけて 書く） |
| こうかおん | オン | |

- せっていは その パソコンの ブラウザに のこります
- **「URL を コピー」** で、せっていと せんせいの おてほんを のせた URL を 作れます。
  その URL を 子どもに くばると、おなじ せっていで ひらきます

## おすすめの すすめかた

1. 📖 ずかんを 大きい 画面に うつして、みんなで ○と × を くらべる
2. 🧩 クイズで おぼえる（にがての きまりは「もういちど」）
3. ✏️ マスに 書いて みよう で、きまりを つかう
4. **かみの 原稿用紙に 書く**。プリントは「[たのしい プリント こうぼう](../purinto/)」の
   「げんこうようし まちがい さがし」「げんこうようしに うつそう」「書いたら たしかめ カード」が つかえます
5. 自分の 文を キーボードで 書く ときは「[げんこうようし](../genkou-youshi/)」の **れんしゅうモード**
   （段落の 1マスと 会話の 行がえを 自分で する）

## 字の ばしょ

- 「。」「、」と 小さい 字（っ・ゃ・ゅ・ょ など）は、つかって いる フォントの 字の かたちを はかって、**マスの 右上** に おきます
- 「。」」は 2つとも **ふつうの 大きさ** で 1つの マスに 書きます（「。」は 右上、「」」は 左下）

## ファイル

```
genkou-renshuu/
├── README.md    このファイル
├── index.html   アプリ ぜんぶ（見ため・きまり・うごき）
└── tests.js     きまりの たしかめ（node tests.js）
```

`index.html` の 中の「`// ==LOGIC==`」〜「`// ==/LOGIC==`」が 画面を つかわない ぶぶん
（マスに ならべる きまり・子どもの ならべかたの たしかめ・クイズ・おてほん）で、
`tests.js` は そこだけ とりだして たしかめます。

- **おてほんを ふやす**：`TEXTS` に `{ id, title, body }` を たします（だいめいは 6字まで・空白なし・1行＝1だんらく）。
  ★（だんらく）・★★（行の 上に「。」「、」）・★★★（かいわ）は 10マスで ならべた ときの かたちから 自動で きまります
- **クイズの 文を ふやす**：`POOL` に たします
- **アプリの 名前**：いまは「げんこうようし れんしゅう」（仮）。`<title>` と `<h1>` を かえます
