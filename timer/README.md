# タイマー・ストップウォッチ

教室の テレビや 電子黒板に うつして つかう **タイマー（のこり じかん）と ストップウォッチ** です。
もとは Google Apps Script（GAS）の ウェブアプリ として つくった ものを、GitHub Pages で うごく ように うつしました。

- **index.html 1ファイル** だけで うごきます（サーバー・ログイン・外部API なし）
- 計時は すべて ブラウザの 中。スタートした 時刻との 差で はかるので、ずれません
- **ほかの タブを 見て いても、終わりの 音は 時間どおりに 鳴る**（スタートした ときに 音を 予約して おく）
- **一度 ひらけば、インターネットに つながって いなくても ひらける**（`sw.js`）

## できること

| こうもく | なかみ |
|---|---|
| タイマー | プリセット（はじめは 1・3・5・10・15分）・分と 秒で セット・＋1分（終わった あとに おすと、そのまま つづく）。さいだい 99分59秒 |
| プリセットの へんしゅう | 「へんしゅう」で じかんを かえる・ふやす（6こ まで）・けす・はじめの 5こに もどす。ボタンの 名まえは じかんから 自動（2分30秒 など） |
| のこりの 表示 | **バー** または **えん**（時計の はりの ように まわって、上に もどったら おわり。時計が まだ 読めない 子 向け）。いろは みどり → だいだい（のこり 50%）→ あか（のこり 20%） |
| よこく の 音 | のこり 1分（ぜんぶで 75秒より 長い とき）で ピッ、のこり 30秒（45秒より 長い とき）で ピピッ |
| 終わりの 音 | チャイム・ベル・ピピピ・音なし。音と 点滅が 1分 つづく（画面を クリックすると とまる） |
| ストップウォッチ | 1/10びょう を 出す／出さない。ラップは 画面の 下に さいごの 3つ（大きい 字が 区間、小さい 字が 通算）。パネルの 表に ぜんぶ（3つ いじょうで いちばん はやい 区間が みどり、おそい 区間が だいだい）。さいだい 99分59秒 |
| 活動名 | 画面の 左上に 出る（20文字まで）。右上は いまの 時刻 |
| 背景を 変える | くろ ／ クリーム色 |
| 大きく 表示 | 画面 いっぱい。上に スタート・ストップ・リセット・もどす の ボタンが 出る |
| 画面の スリープ防止 | うごいて いる あいだは Chromebook の 画面が くらく ならない |

## キーボード

| キー | なにが おきるか |
|---|---|
| <kbd>スペース</kbd> | スタート／ストップ（音が なって いる ときは 音を とめる） |
| <kbd>R</kbd> | リセット |
| <kbd>F</kbd> | 大きく 表示／もどす |
| <kbd>Esc</kbd> | 大きく 表示を やめる |
| <kbd>L</kbd> | ラップ（ストップウォッチ） |
| <kbd>1</kbd>〜<kbd>6</kbd> | プリセット（タイマーの とき） |

## せっていの 保存

じかん・プリセット・活動名・終わりの音・背景・のこりの 表示・1/10びょう は、**その ブラウザ（localStorage）** に おぼえます。
Chromebook は 先生の アカウントで ログインして つかうので、先生ごとに べつの せっていに なります。
（GAS 版では サーバーの PropertiesService に 先生ごとに 保存して いました）

## GAS 版から かわった ところ

- 終わりの 音を スタートの ときに 予約する ように した（Chrome は 見て いない タブの タイマーを 間引くので、GAS 版では 音が おくれる ことが あった）
- ストップウォッチで ラップが ある とき、0.1びょう ごとに レイアウトを 計算しなおして いたのを、ラップが ふえた ときだけに した（Chromebook が おもく ならない）
- 終わった あとの「＋1分」で、そのまま つづく ように した
- 画面の スリープ防止を たのんで いる あいだに やめた とき、あとから 効いて しまう ことが あったのを なおした
- のこりの 表示「えん」・1/10びょう・ラップの 区間と 表・プリセットの へんしゅう・オフライン を たした
- GitHub Pages では ページが ふつうに ひらく（GAS の ように べつの サイトの 中に うめこまれない）ので、画面の スリープ防止と 全画面が きちんと 効く

## はじめの プリセットを かえる

画面の「へんしゅう」で 先生ごとに かえられます。だれかが はじめて ひらいた ときの プリセットを かえたい ときは、`index.html` の `<script>` の さいしょに ある `DEFAULT_PRESETS`（びょう）を 書きかえます。
