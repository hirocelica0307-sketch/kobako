# タイマー・ストップウォッチ

教室の テレビや 電子黒板に うつして つかう **タイマー（のこり じかん）と ストップウォッチ** です。
もとは Google Apps Script（GAS）の ウェブアプリ として つくった ものを、GitHub Pages で うごく ように うつしました。

- **index.html 1ファイル** だけで うごきます（サーバー・ログイン・外部API なし）
- 計時は すべて ブラウザの 中。スタートした 時刻との 差で はかるので、ずれません

## ひらきかた

**https://hirocelica0307-sketch.github.io/kobako/timer/**

## できること

| こうもく | なかみ |
|---|---|
| タイマー | プリセット（1・3・5・10・15分）・分と 秒で セット・＋1分。さいだい 99分59秒 |
| のこりの バー | みどり → だいだい（のこり 50%）→ あか（のこり 20%） |
| よこく の 音 | のこり 1分（ぜんぶで 75秒より 長い とき）で ピッ、のこり 30秒（45秒より 長い とき）で ピピッ |
| 終わりの 音 | チャイム・ベル・ピピピ・音なし。音と 点滅が 1分 つづく（画面を クリックすると とまる） |
| ストップウォッチ | ラップ（さいごの 3つを 下に 出す）。さいだい 99分59秒 |
| 活動名 | 画面の 左上に 出る（20文字まで）。右上は いまの 時刻 |
| 背景を 変える | くろ ／ クリーム色 |
| 大きく 表示 | 画面 いっぱい。上に スタート・ストップ・リセット・もどす の ボタンが 出る |
| 画面の スリープ防止 | うごいて いる あいだは Chromebook の 画面が くらく ならない |

## キーボード

| キー | なにが おきるか |
|---|---|
| <kbd>スペース</kbd> | スタート／ストップ（音が なって いる ときは 音を とめる） |
| <kbd>R</kbd> | リセット |
| <kbd>F</kbd> | 大きく 表示／もどす |
| <kbd>Esc</kbd> | 大きく 表示を やめる |
| <kbd>L</kbd> | ラップ（ストップウォッチ） |
| <kbd>1</kbd>〜<kbd>5</kbd> | プリセット |

## せっていの 保存

じかん・活動名・終わりの音・背景は、**その ブラウザ（localStorage）** に おぼえます。
Chromebook は 先生の アカウントで ログインして つかうので、先生ごとに べつの せっていに なります。
（GAS 版では サーバーの PropertiesService に 先生ごとに 保存して いました）

## プリセットを かえる

`index.html` の `<script>` の さいしょに ある `PRESETS` を 書きかえます（さいだい 6こ。キーボードの 1〜5 は さいしょの 5こ）。
