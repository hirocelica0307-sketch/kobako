# たのしい プリント こうぼう

小学生が **あそび かんかくで たのしく とりくめる プリント** を えらんで、
そのまま **A4 で いんさつ** できる アプリです。
「ことば かいだん」「ものがたり めいろ」「けいさん めいろ」「ビンゴ」「すごろく」など、
こくご・さんすう・せいかつ・どうとく・たいいく・ずこう・あたまの たいそう（コグトレふう）の
**31しゅるい** が あります。

- もんだいは その ばで つくるので、**「🎲 べつの もんだい」を おす たびに なかみが かわります**
- 「まいすう」を ふやすと **1まいずつ ちがう もんだい**（ビンゴなら ひとりずつ ちがう カード）
- **こたえの ページ** も つけられます（まとめて さいごに でるので、ぬきやすい）
- せっていと たね（seed）は URL に のるので、**おなじ URL を ひらけば おなじ プリント** が でます
- イラストは えもじ・ドットえなので、ダウンロードも ログインも いりません

## ひらきかた

**https://hirocelica0307-sketch.github.io/kobako/purinto/**

`index.html` を ブラウザ（Chrome）で ひらくだけ。ファイルとして ひらいても（`file://`）うごきます。

```
cd purinto
python3 -m http.server 8000    # → http://localhost:8000
```

## つかいかた

1. ひだりで 教科を えらび、プリントの カードを おす
2. うえの せってい（むずかしさ・テーマ など）を きめる
3. 「🎲 べつの もんだい」で なかみを かえる。「まいすう」「こたえの ページ」も えらべる
4. 「🖨️ いんさつ」。いんさつ がめんで **よはく「なし」・倍率 100%** に すると ぴったり A4 に なります（あのね にっきは よこむきで でます）
   （PDF に ほぞん しても おなじ）

### あのね にっき の くふう

- お題を えらぶと、その お題の **なかま**（じゅんばん・くらべる・わけ・なかま分け・もしも・かいけつ・せつめい・5つの かんかく など）に あわせて
  ① の **ふきだしの ヒント**（れい：くらべる →「Aの いい ところ」「おなじ ところ」「ちがう ところ」…）と、
  ② の **組み立て図**（れい：わけ →「言いたい こと」→「わけ①②③」→「まとめ」）が かわります
- **つかえる ことば**（まず・つぎに／しかし・どちらも／なぜなら・だから など）と **きもちの ことば** を のせて、書きはじめを たすけます
- ふりかえりの ポイントに「つなぎことばを つかう」を たしました
- 漢字には ぜんぶ ふりがな（オフにも できる）。お題は「じぶんで きめる」「くじ」「ばんごうで えらぶ」
- お題は `sakubun.js` に たすだけで ふえます（漢字は `{漢字|かんじ}` と 書く）

しらべた ネタと、これから ふやせそうな アイデアは **[docs/IDEAS.md](docs/IDEAS.md)** に まとめて います。

## ふやしかた

- **おはなし めいろ・ビンゴ・すごろく・ことば** は `data.js` に たすだけで ふえます
  - おはなし めいろの わかれみち `{ ok, ng }` は、1もじめが ちがう もじに して ください
- あたらしい しゅるいの プリントは `sheets.js` の `SHEETS` と `CATALOG` に たします
- たしたら `tests.html`（または `node tests.js`）で たしかめます
  （めいろが できるか・こたえが 1つか・データの まちがい など）
