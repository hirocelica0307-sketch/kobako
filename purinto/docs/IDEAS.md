# たのしい プリントの アイデア集

インターネットで しらべた「小学生が たのしく とりくめる プリント」の ネタを、
教科ごとに まとめました。✅ は この アプリで もう つくれる もの、
💡 は これから ふやせそうな ものです。

えらぶ ときの めやす（ユーザーさんの ご要望から）：

- **ルールが たんじゅん**（やりかたは 3行 いない）
- **イラストが ある**（えもじ・ドットえ・かおの え など）
- **あそびの かたち**（めいろ・ビンゴ・すごろく・パズル・クイズ）で、まなびが かくれて いる
- **まい回 ちがう もんだい**が つくれる（くりかえし あそべる・ひとりずつ ちがう カードを くばれる）

## あたまの たいそう（コグトレふう）

コグトレは「おぼえる・かぞえる・うつす・みつける・そうぞうする」の 5つの ちからを
きたえる トレーニングです（宮口幸治 せんせいたちが かいはつ）。
この アプリの ものは **コグトレの かんがえかたを さんこうに した オリジナル** です
（ほんものの コグトレ教材では ありません）。

| | なまえ | どんな もの | ちから |
|---|---|---|---|
| ✅ | きごう さがし | ならんだ えの なかから きめられた えを かぞえる。「🍌の すぐ みぎの 🍎は かぞえない」の きまりも えらべる | かぞえる |
| ✅ | てん つなぎ | おてほんと おなじ かたちを てんを つないで うつす | うつす |
| ✅ | かがみ てんつなぎ・さかさま | かがみに うつした かたち／180ど まわした かたちを かく | うつす・そうぞう |
| ✅ | まちがい さがし | 2つの えを くらべて ちがう ところを みつける | みつける |
| ✅ | かがみ ぬりえ | はんぶんの かたちを かがみの ように ぬる | うつす・そうぞう |
| 💡 | さいしょと ポン（プリント ばん） | よみあげた ぶんの 1ばんめの ことばを おぼえて かく。とちゅうで どうぶつが でたら てを たたく | おぼえる・きく |
| 💡 | かたち さがし | たくさんの ばらばらの かたちの なかから おてほんと おなじ くみあわせを さがす | みつける |
| 💡 | ちがいは どこ？（ぶぶん） | 3つの えの うち 1つだけ ちがう ものを えらぶ | みつける |
| 💡 | ものがたり づくり | ばらばらの 4コマの えを ならべかえて おはなしに する | そうぞうする |
