# めあてカード（たのしい プリント こうぼう の なか）

> もとは `mokuhyou-card/`（めあてカード こうぼう）でしたが、「たのしい プリント こうぼう」に まとめました。
> ページは `purinto/meate.html`、JS は `purinto/meate/` に あります。まえの URL を ひらくと 自動で ここへ うつります。

新学期・学期の はじめ・運動会・音楽発表会・学期の おわり・係決め など、**節目に 子どもが 書く カード** を
えらんで、そのまま **A4 で いんさつ** できる アプリです。

- **白黒の 線画だけ**。書いた あとに 子どもが **色を ぬって 完成** させます
- ただの わくでは なく、ずかん・さくら・たからの ちず・メダル・ステージ・だるま・しんぶん・SNS・ゲームがめん などの **デザインに 書きこむ** かたち
- **17カテゴリ × 低学年むけ 5 ＋ 高学年むけ 5 ＝ 170デザイン**（じこしょうかいは 6＋6、＋ 係 いちらん表）＋ **なわとびカード 低・中・高 × 5 ＝ 15デザイン**
- かおは てんせんの まるに **じぶんで かく** ように して あります
- イラストは すべて その場で かく SVG なので、画像ファイルも ログインも サーバーも いりません（`meate/` の JS を `meate.html` が よみこむ）

## ひらきかた

**https://hirocelica0307-sketch.github.io/kobako/purinto/meate.html**

（プリントの ページ https://hirocelica0307-sketch.github.io/kobako/purinto/ の 上の「✏️ めあてカード」タブからも ひらけます）

`meate.html` を ブラウザ（Chrome）で ひらくだけ。ファイルとして ひらいても（`file://`）うごきます。

## つかいかた

1. ひだりで **カテゴリ** を えらぶ
2. うえで **ぜんぶ／低学年むけ／高学年むけ** を えらび、ならんだ デザインから 1つ えらぶ
3. 「学年」「組」を えらぶと、なまえらんに いんさつ されます（空らんの ままでも よい）
4. 「🖨️ この デザインを いんさつ」（まいすうも えらべる）／「🖨️ 〇〇 10しゅるいを 1まいずつ」（見本づくりや えらぶ ときに）
5. いんさつ がめんで **よはく「なし」・倍率 100%** に すると ぴったり A4 に なります（PDF に ほぞん しても おなじ）

### 係カードの くみたて

- **のせる こうもく**：メンバー／めあて／仕事内容（①②③…）／当番表／係の マーク（絵）／クラスの みんなへ／工夫したい こと／ふりかえり（星を ぬる）
  - えらんだ こうもくが すくないほど、のこりの はこが 大きく なり、書く 線が ふえる
  - 仕事内容と 当番表、係の マークと クラスの みんなへ は、りょうほう えらぶと よこに ならぶ
- **おすすめ**：当番表あり／当番表なし（マークつき）／シンプル（メンバー・めあて・仕事内容）／ぜんぶ
- **当番表 3しゅるい**：曜日ごと（月〜金）／週ごと（1〜4しゅうめ）／できたら ○（4しゅう × 月〜金）
- **メンバーの 人数**：2〜6人 ／ **係名（いんさつ）**：入れると かんばんに いんさつ
- この せっていは 係カード 10デザイン ぜんぶに きく

### ばめんの ある デザイン（絵の 中に 書く）

かおを 子どもが かく「うごく 子ども」の 絵（`figure.js`：はしる・のぼる・ばんざい・リコーダー・けんばんハーモニカ・たいこ・うたう・本を よむ・なわとび・旗を たてる・水やり など 20ポーズ）を つかい、
カードに あった 場面の 中に 書く ところを 組みこんだ デザイン（`scenes.js`）を 37まい ついか しました。画面では いちばん さきに ならびます。

### ウェブで しらべた こと

学級で よく つかわれて いる カードの しゅるい（読書カード・なわとびカード・音読がんばりカード・二分の一成人式・6年生を 送る会の メッセージ など）と、
自己紹介カードの はやりの かたち（トリセツ・WANTED・トレカ・SNS ふう など）を しらべて カテゴリと テーマを ふやしました。
絵や わくは ぜんぶ ここで あたらしく かいた もので、ほかの サイトの 素材は つかって いません。

## メニューの え

がめんの カテゴリの ボタンには Fluent Emoji 3D の え（`../assets/emoji/`）を つけて います。
いんさつ する カードの なかの え は、子どもが 色を ぬれる ように 白黒の 線画の ままです。

## せってい

- **学年・組**：なまえらんに いんさつ。じぶん ずかん・アルバムの「〇年生に なったら」や 係 いちらん表の 見出しにも つかう
- **学期**：しょうじょう だけ。「第〇学期」に はいる
- **ふりがな**：「低・中学年むけ だけ」（ふつう）／「いつも つける」／「つけない」
- **手がき ふうの 線**：線を すこし ゆらして 手で かいた ような あじを だす（けすと まっすぐな 線）

せっていと さいごに えらんだ デザインは ブラウザに おぼえます。URL の うしろに `#g2-H1`（デザイン）や `#undo`（カテゴリ）を つけて ひらく ことも できます。

## しくみ

- ファイル（どれも `meate/` の なか）：`core.js`（文字・図形の 部品）／`themes.js`・`themes2.js`（テーマ＝わく・タイトル・はこの かたち・絵わく）／`heroes.js`・`heroes2.js`（カテゴリの 絵）／`figure.js`（うごく 子ども）／`scenes.js`（ばめんの ある デザイン）／`scenecat.js`（カテゴリへの ついか・かざりの いれかえ）／`extra.js`（ついかの こうもく〈天気・マス目・スタンプ・記録表・あゆみ・よせがき・グラフ〉・きりとり カード・ついかの カテゴリ）／`layout.js`（こうもくの ならべかた・しょうじょう）／`kakari.js`（係カードの こうもく・いちらん表）／`bespoke.js`（1まいずつ かいた とくべつ デザイン）／`catalog.js`（カテゴリと デザイン いちらん）／`app.js`（がめん）
- 1デザイン ＝ テーマ × ならべかた（stack・side・grid・around・hero）× カテゴリの 絵 × 低学年／高学年の こうもく。はこの 高さは 線の 数に あわせて 自動で わりふる
- 1まい ＝ `viewBox="0 0 210 297"` の SVG（1 ＝ 1mm）。線は くろ、ぬりは しろ だけ
- かざり（わく・イラスト）は `feTurbulence` + `feDisplacementMap` で すこし ゆらす。文字と 書く 線は ゆらさない
- ふりがなの いちは、ブラウザで 文字の はばを じっさいに はかって あわせる（フォントが よみこまれたら かきなおす）
- フォント：Mochiy Pop One（タイトル）・Zen Maru Gothic（ことば）・Klee One（学年・組）。ネットに つながって いない ときは パソコンの フォントで でる
