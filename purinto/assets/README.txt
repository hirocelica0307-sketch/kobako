たのしい プリント こうぼう ― つかって いる 素材（assets/）
==================================================================

この フォルダーの 素材は、すべて 下の ライブラリから ダウンロードして 保存した ものです。
ライセンスの 全文は リポジトリ直下の THIRD_PARTY_LICENSES.txt に あります（画面には 表示しません）。

1. emoji/*.webp … Microsoft Fluent Emoji「3D」（MIT License）
   入手もと: https://github.com/microsoft/fluentui-emoji （assets/<名前>/3D/*.png）
   ライセンス確認: https://github.com/microsoft/fluentui-emoji/blob/main/LICENSE（MIT）
   加工: 160×160 に 縮めて WebP（品質 0.9）に しました。ファイル名は えもじの コードポイント（例 1f351 ＝ 🍑）。
   どの えもじが どの ファイルか: emoji-map.js（えもじ → ファイル名）
   人の えもじは はだの いろ「Default」を つかって います。

2. icons.js … Phosphor Icons「duotone」（MIT License）
   入手もと: Iconify の アイコンセット データ https://github.com/iconify/icon-sets/blob/master/json/ph.json
             （Iconify の コレクション情報で ライセンスが MIT で ある ことを 確認）
   もとの プロジェクト: https://github.com/phosphor-icons/core（LICENSE: MIT）
   つかって いる アイコン: printer / dice-five / link / eye / eye-slash / pencil-simple / files / sparkle /
     book-open / calculator / plant / heart / person-simple-run / palette / brain / star（すべて -duotone）

3. emojify.js … がめんの えもじ を 1 の がぞうに おきかえる プログラム（このアプリの もの。素材では ありません）
