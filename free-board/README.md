# フリーボード

先生が Chromebook で つかう、**自由に 線・図形・文字を かける 板書ボード** です。
テレビや 電子黒板に うつして、算数の マス目や 国語の 罫線の 上に 書けます（児童は さわらない 前提）。

- **index.html を ひらく だけ** で うごきます（サーバー・ログイン なし）
- かいた ものは **その ブラウザ（localStorage）に 自動で 保存**。とじて ひらいても のこります
- **一度 ひらけば、インターネットに つながって いなくても ひらける**（`sw.js`）

## できること

| こうもく | なかみ |
|---|---|
| かく | ペン（フリーの 線）・蛍光ペン（すける）・文字 |
| 線・図形 | 直線・矢印・円（中心から ドラッグ）・だ円・四角・三角・直角三角。中を ぬらない／うすく ぬる／ぬる、ふつうの 線／点線。Shift を おしながらで 15°ごとの 直線・正方形・円 |
| ぬりつぶし | 線で かこんだ ところを おすと、その 中を ぬる（ぬった ところを もう一度 おすと 色を かえられる） |
| 消す | 消しゴム（なぞった ところだけ・大きさ 3だん＋スライダー）・線ごと消す（さわった 線や 図形を まるごと） |
| えらぶ・動かす | おして えらぶ／なにも ない ところから ドラッグで まとめて えらぶ。ドラッグで 動かす・消す・ふやす（コピー）・色を かえる・矢印キーで すこし 動かす。文字は ダブルクリックで 書きなおし |
| 文字 | おした ところに 入力（日本語入力 OK・Enter で 改行）。大きさ（小・中・大・特大＋スライダー）、書体（ゴシック・教科書体ふう・丸ゴシック・明朝）。かいた 文字を おすと 書きなおせる |
| 色・太さ | 12色＋ほかの 色。太さは ペン・蛍光ペン・図形・消しゴム で べつべつに おぼえる |
| 背景 | **無地・マス目・横の線・縦の線・点**。地の 色は 白・クリーム・黒・黒板（緑）。マスや 線の あいだの 大きさ（16〜160px）、十字の 点線（マス目）／線の あいだの 点線（罫線）、5マスごとに 太い 線、線の 色（水色・灰色・緑・オレンジ）と こさ。縦の線は 右の はしから ならぶ（たて書き 用） |
| マス目に あわせる | マス目・点の 背景では、直線・図形の 角が マス目（点）に ぴったり あう（切りかえ できる） |
| ページ | ページを ふやす・前・次・消す。背景は ページごと |
| もどす・やり直す | ページごとに 150回 まで |
| せってい の 表示 | 画面の **左 か 右** に たてながで 出す。「しまう」で かくすと、すみに 小さい ボタン（せってい・ペン・消しゴム・もどす）だけ のこる |
| ほか | 画像（PNG）で 保存・ぜんぶ 消す（もどせる）・全画面 |

## キーボード

| キー | なにが おきるか |
|---|---|
| <kbd>Ctrl</kbd>+<kbd>Z</kbd> ／ <kbd>Ctrl</kbd>+<kbd>Y</kbd> | もどす ／ やり直す |
| <kbd>P</kbd> <kbd>M</kbd> <kbd>T</kbd> | ペン・蛍光ペン・文字 |
| <kbd>L</kbd> <kbd>A</kbd> <kbd>C</kbd> <kbd>O</kbd> <kbd>R</kbd> | 直線・矢印・円・だ円・四角 |
| <kbd>B</kbd> | ぬりつぶし |
| <kbd>E</kbd> <kbd>X</kbd> <kbd>V</kbd> | 消しゴム・線ごと消す・えらぶ |
| <kbd>Backspace</kbd> ／ <kbd>Ctrl</kbd>+<kbd>D</kbd> | えらんだ ものを 消す ／ ふやす |
| <kbd>PageUp</kbd> <kbd>PageDown</kbd> | 前・次の ページ |
| <kbd>S</kbd> | せっていを 出す・しまう |
| <kbd>F</kbd> | 全画面 |
| <kbd>Esc</kbd> | 文字の 入力を おわる・えらぶのを やめる |

## しくみ

- かいた ものは 画像では なく「線・図形・文字」の データで おぼえて いるので、動かす・もどす・色を かえる が できます
- 背景・かいた もの・かいて いる とちゅう の 3まいの canvas を かさねて います（消しゴムで 背景の マス目は 消えません）
- ぬりつぶし だけは その ときの 形を 画像（PNG）で おぼえます。たくさん つかうと 保存の 容量（ブラウザ で 5MB ほど）が いっぱいに なる ことが あり、そのときは 画面に おしらせが 出ます
- `logic.js` … 画面に かかわらない ぶぶん（背景の 線・当たり判定・ぬりつぶし の 計算・保存データの たしかめ）
- `app.js` … 画面と そうさ
- `tests.js` … `node tests.js` で logic.js を たしかめる
