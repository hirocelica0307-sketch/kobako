# 速読ラボ（仮称）

**大人が一人で、スマートフォンで使う**読書トレーニングアプリです。
「理解したまま、少しずつ速く読む」ことを目標に、読む速さ（字/分）と理解度（%）をいつも一緒に測ります。

- サーバー・ログイン・外部API なし。記録と読みこんだ文章は、そのスマホのブラウザ（localStorage）だけに保存
- 一度ひらけば、インターネットにつながっていなくてもひらける（`sw.js`）
- ホーム画面に追加すると、アプリのように全画面で使える（`manifest.webmanifest`）

## 練習のモード

| モード | なかみ | ねらい（研究の裏づけ） |
|---|---|---|
| 速さチェック | ふだんどおりに読み、「読み終わった」で時間を止める → 確認問題 | 今の速さと理解度を知る。速さは「新しい5回の真ん中の値」を**ふだんの速さ**にする |
| ペース読み | 文章は全部見えたまま、読む場所が**文節ごとに色づけ**されて進む。− ＋ でペースを変える・文字をタップでそこへ戻る | 案内つきの黙読（Reading Plus の研究など）。読み返しは理解に必要なので、戻れるようにしている |
| くり返し読み | 同じ文章を3回読み、回ごとの速さを棒グラフで見る | 流暢さを育てる方法として裏づけがいちばん多い（Repeated Reading） |
| 要点読み | ふだんの40%の時間で目を通す。時間が来ると本文がかくれ、要点の問題だけ出る | 時間が足りないときの読み分け（Duggan & Payne 2009 など）。細部は落ちることも説明 |

- **実効速度** ＝ 速さ × 理解度。グラフと結果に出す
- **ペースの自動調整**：ペース読みのあと、理解度 80% 以上なら次のペースを 5% 上げる・60% 未満なら 10% 下げる・その間はそのまま。はじめのペースは、ふだんの速さの 1.1 倍
- **入れていない練習**：1語ずつ高速で出す方式（RSVP）・視野を広げる訓練・心の中の声を消す練習。理由はアプリの「このアプリの考え方」に書いた（Rayner ほか 2016 のレビューなど）

## 文章

| 種類 | なかみ |
|---|---|
| オリジナル（`texts.js`） | このアプリのために書いた説明文9本と短い小説1本（約750〜1000字・やさしめ／ふつう／むずかしめ）。それぞれに4〜5問の確認問題（要点・くわしく・読みとり）。選択肢は毎回ならびかえる |
| 青空文庫 | 作品の「テキストファイル(ルビあり)」の **zip（または .txt）をスマホに保存して選ぶ**。Shift_JIS のまま読める。ルビはそのまま表示し、注記・記号の説明は取りのぞき、末尾の底本・入力者などは作品の「情報」に残す |
| 自分の文章 | 題名と本文を貼りつける。《》のルビつきの青空文庫テキストを貼っても整える |

- 長い作品は、段落の切れ目で約1000／2000／3000字（設定）ずつの**区間**に分け、しおりで続きから読める
- 青空文庫・自分の文章には確認問題がないので、読んだあとは**思い出しチェック**（ひとことでまとめる＋手ごたえ1〜5）で理解度（自己評価）をつける

## 設定

文字の大きさ・行の間・ゴシック／明朝・横書き／縦書き・文節の区切り（なし／すき間／線）・ルビの表示・画面の色（自動／白／セピア／黒）・ペースガイドの形（色づけ／読んだ所をうすく）・目の休けいの合図（20分・30分ごとに「20秒遠くを見る」）・データの書き出しと読みこみ（機種変更用の JSON）

## ファイル

| ファイル | なかみ |
|---|---|
| `index.html` | 画面 |
| `style.css` | 見た目（色はテーマごとに `:root` の変数で入れかえ） |
| `app.js` | 画面の動き（読む・問題・結果・記録・文章の追加・設定） |
| `logic.js` | 画面を使わない処理（文字数・文節の区切り・青空文庫の整形・zip・速さ・ペース） |
| `texts.js` | オリジナルの文章と確認問題 |
| `tests.js` / `tests.html` | 自動テスト。`node tests.js` でも、`tests.html` をブラウザでひらいても動く |
| `sw.js` / `manifest.webmanifest` | オフラインでひらく・ホーム画面に追加 |

## 数え方

文字数は、空白・改行とルビのよみを除いた本文の字数（句読点・かぎかっこは数える）。
文節の区切りは「ひらがなの後に漢字・カタカナ・英数・開きかっこが来たら区切る／句読点・閉じかっこは前につける」というきまりで、長いひらがなの並びはブラウザの `Intl.Segmenter` でさらに分けます（辞書は持たないので、ときどき区切りがずれることがあります）。

## まだのこと

- 絵・アイコンは使っていません（ボタンは文字だけ）。ホーム画面のアイコンも、素材の候補を見てもらってから入れます（CLAUDE.md のきまり）
- 青空文庫の作品をアプリの中に最初から入れておくこと（作業した環境から青空文庫のサイトにつながらなかったため、今は自分で読みこむ形だけ）
- 実機（iPhone・Android）でのたしかめ
