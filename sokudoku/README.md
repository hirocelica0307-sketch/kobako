# 速読ラボ（仮称）

**大人が一人で、スマートフォンで使う**読書トレーニングアプリです。
「理解したまま、少しずつ速く読む」ことを目標に、読む速さ（字/分）と理解度（%）をいつも一緒に測ります。

- サーバー・ログイン・外部API なし。記録と読みこんだ文章は、そのスマホのブラウザ（localStorage）だけに保存
- 一度ひらけば、インターネットにつながっていなくてもひらける（`sw.js`）
- ホーム画面に追加すると、アプリのように全画面で使える（`manifest.webmanifest`）

## 練習のモード

| モード | なかみ | ねらい（研究の裏づけ） |
|---|---|---|
| 速さチェック | ふだんどおりに読み、「読み終わった」で時間を止める → 確認問題 | 今の速さと理解度を知る。速さは「新しい5回の真ん中の値」を**ふだんの速さ**にする |
| ペース読み | 文章は全部見えたまま、読む場所が**文節ごとに色づけ**されて進む。− ＋ でペースを変える・文字をタップでそこへ戻る | 案内つきの黙読（Reading Plus の研究など）。読み返しは理解に必要なので、戻れるようにしている |
| くり返し読み | 同じ文章を3回読み、回ごとの速さを棒グラフで見る | 流暢さを育てる方法として裏づけがいちばん多い（Repeated Reading） |
| 要点読み | ふだんの40%の時間で目を通す。時間が来ると本文がかくれ、要点の問題だけ出る | 時間が足りないときの読み分け（Duggan & Payne 2009 など）。細部は落ちることも説明 |

- **色づけはどの練習でも使える**：速さチェック・くり返し読み・要点読みでも、スタート前に「読む場所の色づけ」を「あり」にすると、ペース読みと同じ文節ごとの色づけで読める（要点読みは制限時間に合わせた速さ）。色づけを使った速さチェックの回は「ふだんの速さ」に入れない
- **実効速度** ＝ 速さ × 理解度。グラフと結果に出す
- **ペースの自動調整**：ペース読みのあと、理解度 80% 以上なら次のペースを 5% 上げる・60% 未満なら 10% 下げる・その間はそのまま。はじめのペースは、ふだんの速さの 1.1 倍
- **入れていない練習**：1語ずつ高速で出す方式（RSVP）・視野を広げる訓練・心の中の声を消す練習。理由はアプリの「このアプリの考え方」に書いた（Rayner ほか 2016 のレビューなど）

## 練習ごとに別の文章・いつも新しい文章

内容を知っている文章では、速さも理解度も正しく測れない。そこで入っている文章は**練習ごとに分けて**あり（各作品の `mode:`）、ある練習の文章がほかの練習に出てくることはない。

- 「新しい文章で始める」で、その練習の**まだ読んでいない区間**から順に出る（読みかけの作品があればその続き）。結果画面から「次の新しい文章で…」ですぐ次へ
- 読んだ区間は、端末の localStorage に「作品#区間」で記録する。読んだことのある区間をもう一度読むときは確認を出し、その回は「ふだんの速さ」に入れない（`reread`）
- 種類（小説・説明文・日本の名作・海外の名作）でしぼりこめる。読み終えた作品は「読み終えた文章」にまとまる

### 文章ファイルの形（`texts/<id>.txt`）

```
title: 走れメロス
author: 太宰治
kind: 名作          ← 小説・説明文・随筆・名作・海外名作
style: …            ← オリジナルの小説は「〇〇の書きぶりをまねたオリジナル」
level: 2            ← 1 やさしめ・2 ふつう・3 むずかしめ
mode: check         ← check・pace・repeat・skim（その練習専用）・long（長編）
order: 8            ← 一覧の順
source: 青空文庫
@@本文
（区間1）
@@区切り
（区間2）
@@問題
[1]
Q main 問題文      ← main（要点）・detail（くわしく）・infer（読みとり）
+ 正解
- まちがい（3つ）
@@底本
（底本・入力者など）
```

- 文章を足したり直したりしたら `node tools/build-catalog.js` で目録 `texts/catalog.js` を作りなおす（目録には一覧に出すことだけを入れ、本文は読むときに読みこむ）
- 青空文庫の作品を足すとき：`python3 tools/aozora_to_utf8.py 作品.txt 作品-utf8.txt` → `node tools/import-aozora.js 作品-utf8.txt c-なまえ check 2` → できたファイルの各区間に問題を書く → `node tools/build-catalog.js`

## 設定

文字の大きさ・行の間・ゴシック／明朝・横書き／縦書き・文節の区切り（なし／すき間／線）・ルビの表示・画面の色（自動／白／セピア／黒）・ペースガイドの形（色づけ／読んだ所をうすく）・目の休けいの合図（20分・30分ごとに「20秒遠くを見る」）・データの書き出しと読みこみ（機種変更用の JSON）・すべての文章を端末に保存（電波の届かない所用・約3MB）

## 数え方

文字数は、空白・改行とルビのよみを除いた本文の字数（句読点・かぎかっこは数える）。
文節の区切りは「ひらがなの後に漢字・カタカナ・英数・開きかっこが来たら区切る／句読点・閉じかっこは前につける」というきまりで、長いひらがなの並びはブラウザの `Intl.Segmenter` でさらに分けます（辞書は持たないので、ときどき区切りがずれることがあります）。
