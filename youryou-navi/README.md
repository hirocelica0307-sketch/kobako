# ようりょうナビ（仮称）

**小学校学習指導要領（平成29年告示）**を、先生が すぐに 見られるように した ツールです。
「この内容は何年生で習う？」「前の学年ではどこまで？」「ほかの教科とつなげたい」を、本をめくらずに 調べられます。

- サーバー・ログイン・外部API なし。本文は `data.js` に 入っていて、ひらいた あとは インターネットが なくても 動きます
- スマホ・タブレット・パソコンで 使える。登録なし

## できること

| 画面 | なかみ |
|---|---|
| 系統表（一枚で見る） | **全教科 × 1〜6年**の 一覧。2学年まとめの 教科（生活・音楽・図工・家庭・体育・道徳 など）は 2学年に またがった マスで 見せる。教科を えらぶと **その教科の 系統表**（算数なら Ａ 数と計算〜Ｄ データの活用 × 学年）。マスの ことばを 押すと 本文へ とぶ |
| 学年・教科でくわしく | 学年と 教科で しぼって、告示の **目標・内容・内容の取扱い・指導計画の作成と内容の取扱い** を そのまま 読む。学年を えらんで いる ときは「← 前の学年」「次の学年 →」で となりの 学年へ。項目ごとに「コピー」（出典つきの テキスト） |
| キーワード検索 | 全学年・全教科を 横断して 検索（スペースで 区切ると AND）。見つかった ことばに 色が つく。けっかは 項目（⑴ など）ごとに まとまり、「同じ言葉が出てくる教科」と 件数が 出る。学年・教科で しぼれる。「内容の取扱い」も 探すか えらべる |
| 教科横断のヒント | 電気・災害・環境・安全・健康・自然・地域・情報・伝統・家族・協力・食・水・生命・外国（どれも 3教科以上に 出てくる ことば）を ワンタッチで 検索 |
| まとめPDF（A4・1枚） | 教科ごとの 系統表、または 全教科の 一覧を、A4 よこ 1まいに 自動で 文字の 大きさを 合わせて 印刷する（印刷の 画面で「PDFに保存」）|
| 文部科学省へのリンク | 告示の 本文PDF（ページ番号つき）と、教科ごとの 解説PDF |

- 画面の 状態は URL の `#` に 入るので、そのまま リンクを 共有できる（例：`#q=電気`、`#v=detail&s=rika&g=3`）

## 本文データ

- もと：文部科学省「小学校学習指導要領（平成29年告示）」PDF
  https://www.mext.go.jp/content/20230120-mxt_kyoiku02-100002604_01.pdf （2026-10-24 に 取得）
- 入れた はんい：第2章 各教科（国語〜外国語）・第3章 特別の教科 道徳・第4章 外国語活動・第5章 総合的な学習の時間・第6章 特別活動。
  総則・別表「学年別漢字配当表」（原文では 図）は 入れて いない
- 告示は 著作権法 第13条で 著作権の 目的と ならない もの。**解説**（出版社の 著作物）の 本文は 入れず、文部科学省の ページへの リンクだけに した
- PDF から 取り出す ときに した こと
  - ふりがな・ページ番号・つめ見出しを のぞいた
  - 図に なって いる **分数**（1/2・1/10 など 9か所）は、原文の 画像を 見て 文字に した
  - 音楽の「音符，休符，記号や用語」の 図と、外国語の「文構造」の 図は、図の なかみを 文字で 書いた（そうと わかるように 書いて ある）
  - PDF の 本文の 行が すべて データに 入って いる ことを、行ごとに 照らしあわせて たしかめた（のこったのは 上の 図の 部分だけ）

## 系統表の 見出し

- 系統表の マスの 短い ことばは、本文を もとに **Claude が まとめた もの**（理科・家庭・体育・道徳・特別活動 などは 告示に ある 見出しを そのまま）
- ぜんぶの 見出しと、つながって いる 本文の 書き出しを [`midashi-ichiran.md`](midashi-ichiran.md) に 一覧に した。なおす ときは `tools/labels.py`

## データの つくりなおし

文部科学省の PDF が 新しく なったら（ためした のは Python 3.13・PyMuPDF）：

```sh
pip install pymupdf
curl -o shou.pdf https://www.mext.go.jp/content/20230120-mxt_kyoiku02-100002604_01.pdf
python3 -I tools/lines.py shou.pdf lines.json     # 1行ずつ 取り出す（ふりがな等を のぞく・分数を うめる）
python3 -I tools/parse.py lines.json raw.json     # 教科・学年・項目に 分ける
python3 -I tools/build.py raw.json data.js        # 見出し（labels.py）と あわせて data.js に
python3 -I tools/midashi.py data.js midashi-ichiran.md
```

ページの くみかたが かわると、`lines.py` の 分数の 場所（FRAC）や、`parse.py` の 図の 書きおこしは 合わなく なるので、たしかめて なおす こと。
