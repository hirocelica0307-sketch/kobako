ようりょうナビ ― つかって いる 素材（assets/）
==================================================================

この フォルダーの 素材は、すべて 下の ライブラリから ダウンロードして 保存した ものです。
ライセンスの 全文は リポジトリ直下の THIRD_PARTY_LICENSES.txt に あります（画面には 表示しません）。
2026-10-23 に 依頼者に 候補（素材名・ライブラリ・ライセンス）を 見せ、2026-10-24 に「アイコンは おまかせ」と
返事を もらって、この 一覧で きめました。

1. emoji/*.webp … Microsoft Fluent Emoji「3D」（MIT License）
   入手もと: https://github.com/microsoft/fluentui-emoji （assets/<名前>/3D/*_3d.png）
   ライセンス確認: https://github.com/microsoft/fluentui-emoji/blob/main/LICENSE（MIT）
   加工: 128×128 に 縮めて WebP（品質 90）に しました。
   ファイル名 ← もとの 素材名（つかう ところ）
     open_book.webp           ← Open book（国語）
     globe.webp               ← Globe showing Asia-Australia（社会）
     triangular_ruler.webp    ← Triangular ruler（算数）
     test_tube.webp           ← Test tube（理科）
     seedling.webp            ← Seedling（生活）
     musical_notes.webp       ← Musical notes（音楽）
     artist_palette.webp      ← Artist palette（図画工作）
     cooking.webp             ← Cooking（家庭）
     soccer_ball.webp         ← Soccer ball（体育）
     input_latin_letters.webp ← Input latin letters（外国語）
     red_heart.webp           ← Red heart（特別の教科 道徳）
     speech_balloon.webp      ← Speech balloon（外国語活動）
     compass.webp             ← Compass（総合的な学習の時間）
     handshake.webp           ← Handshake（特別活動）
     magnifying_glass.webp    ← Magnifying glass tilted left（検索）
     printer.webp             ← Printer（PDF・印刷の ボタン）
     light_bulb.webp          ← Light bulb（教科横断の ヒント）

2. app-icon.png（64×64・すきとおし）・app-icon-180.png（180×180・白い 地）
   もと: Microsoft Fluent Emoji「3D」の Books（上と おなじ ライセンス）
   入手もと: https://github.com/microsoft/fluentui-emoji/blob/main/assets/Books/3D/books_3d.png
   加工: 縮めた（180 は 白い 地に 140×140 で のせた）
