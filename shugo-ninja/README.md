# ことばにんじゃ道場

2年生 こくご「**主語とじゅつ語**」（東京書籍『新編 新しい国語 二下』p.30〜31・2学期）を、
**文の 中から 主語と じゅつ語を タップして えらぶ** 忍者の しゅぎょうで 学ぶ アプリです。

- 対象：小学2年生（学習指導要領 第1・2学年〔知識及び技能〕(1)カ「文の中における主語と述語との関係に気付くこと」）
- 授業で、児童が 1人1台の タブレット・Chromebook で つかう ことを 考えて います
- **index.html 1ファイル** と `assets/` で うごきます。サーバー・ログインは いりません
- 先生用の 画面で、**児童ごとの 記録**（しゅぎょうごとの ほし・正答率・まちがいの しゅるい・学習の 履歴）が 見られます

## つかいかた（子ども）

1. 出席番号を タップ（はじめての ときは 名前を 入れる。入れなくても よい）
2. しゅぎょうの ちずから しゅぎょうを えらぶ（どれからでも できる。「つぎは ここ！」が めやす）
3. 文は 教科書と 同じ **文節ごとの 分かち書き**。ことばを タップして えらぶ
   - まず **じゅつ語**（青い 2本線）→ つぎに **主語**（赤い 1本線）
   - じゅつ語を 見つけると「〇〇のは だれ？ なに？」と 主語を さがす 手がかりが 出る
   - まちがえると、えらんだ ことばが「いつ」「どこ」「なにを」などの ことばだと おしえる。2回 まちがえると こたえが 光る
   - 🔊 よむ で 文を 読みあげ・ヒントで にゃんじゃ先生が 手がかりを 出す
4. おわると ほし（1回目で 正解した わりあい 90%以上で 3つ・70%以上で 2つ）と まきものが もらえる。
   ほしの 合計で ランク（みならい にんじゃ → げにん → ちゅうにん → じょうにん → ことばにんじゃ マスター）

## しゅぎょう（ぜんぶで 60もん）

| | なまえ | なかみ | もんだい |
|---|---|---|---|
| その0 | しってる？ | 主語・じゅつ語の せつめい。「なく。」に だれが？を つける・線の ひきかた・ひみつの わざ（じゅつ語 → 主語の じゅん） | せつめい |
| その1 | ふたつの ことば | 「とりが とぶ。」など 2文節の 文 | 6 |
| その2 | ことばが ふえたよ | 「どんな」「どこで」「なにを」が 入った 文 | 8 |
| その3 | 「は」と「も」 | 主語が「〜は」「〜も」の 文 | 8 |
| その4 | 主語は どこ？ | 主語が 文の はじめに ない 文（「きのう、ぼくは…」「ケーキを 姉が…」） | 8 |
| その5 | じゅつ語の なかま分け | じゅつ語を 見つけて「どうする・どんなだ・なんだ」に 分ける | 10 |
| その6 | 文しょうに チャレンジ | 3つの 文が つづく 文しょう 4つ。1文ずつ じゅつ語と 主語を えらぶ | 12 |
| その7 | 文を つくろう | 主語に あう じゅつ語／じゅつ語に あう 主語の カードを えらぶ。あわないと「へんな 文」に なる | 8 |

- 例文は すべて オリジナルです（教科書の 本文は つかって いません）
- 漢字は 2年生までに ならう 字だけで、ぜんぶ ふりがなつき
- もんだいの じゅんばんは 毎回 かわります

## 先生用の 画面

ログイン画面の 下の「先生用の きろく」→ 4けたの 暗証番号（**はじめは 1234**。先生用の 画面の 設定で かえられます）。

- クラスの ようす：学習した 人数・1回目での 正答率・**まちがいの けいこう**（多い じゅん）と 指導の ヒント
- 児童ごとの 記録：番号・名前（ここで 書きかえられる）・しゅぎょうごとの ほしと 最高の 正答率・学習回数・よくある まちがい・最後の 学習
- 「くわしく」：しゅぎょうごとの 回数と 正答率・まちがいの 内訳・学習の 履歴
- 「表を コピー」：表計算ソフト（Excel・スプレッドシート）に そのまま はりつけられる 形で コピー
- 設定：クラスの 人数（1〜45）・暗証番号・記録を 消す

まちがいの しゅるい：主語を じゅつ語と まちがえた／「〜を」「いつ」「どこ」「どんな」「どのように」「だれと」を 主語に えらんだ／
じゅつ語の 型（どうする・どんなだ・なんだ）の まちがい／文を つくるときに あう ことばを えらべなかった。

### 記録の 保存について

記録は **その 端末の ブラウザの 中（localStorage）だけ** に 保存されます。

- ほかの 端末の 記録は、それぞれの 端末で 先生用の 画面を ひらいて 見ます（「表を コピー」で 1つの 表に まとめられます）
- 1台を 何人かで つかう ときは、番号を えらびなおせば 人ごとに 記録が わかれます
- ブラウザの 閲覧データを 消す・シークレット ウィンドウで ひらく と 記録は のこりません
- 暗証番号を わすれた ときは、その 端末の サイトデータを 消すと 1234 に もどります（記録も 消えます）
