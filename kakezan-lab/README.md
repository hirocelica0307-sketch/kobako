# ●ならべ かけ算ラボ（仮称）

2年生の **かけ算** で、●を たて・よこに ならべた図（アレイ図）を **自分で 区切ったり、まわしたり** して、
しきと 図を むすびつける アプリです。答えを 当てる ドリルでは なく、**そうさして 考える** ための 教材です。

- 対象：小学2年生（啓林館「わくわく算数2下」 11 かけ算(2)・13 かけ算のきまり・巻末「九九づくり」）
- Chromebook（タッチ・マウス）と 電子黒板・大型テレビ（1920×1080）の どちらでも つかえます
- **index.html 1ファイル** だけで うごきます。サーバー・ログイン・外部API・データの 保存は つかいません
- 点数・正解数・ランキングは ありません。効果音も ありません（よみあげは せっていで オン に したときだけ）

## ひらきかた

**https://hirocelica0307-sketch.github.io/kobako/kakezan-lab/**

`index.html` を Chrome で ひらくだけです（ファイルとして ひらいても うごきます）。

## モード

トップ画面に 大きな ボタンで ならんでいます。モードの 画面では、うえの タブで いつでも きりかえられます。

### 1「つくる」
- 「1つ分の 数」と「いくつ分」を ＋／− で かえる（1〜9）と、●の ならびが かわる。ふえた ぶんは ふわっと 出てくる
- 下に「□ × □ ＝ □」。答えは かくして あり、**こたえを見る** で 出る（九九の となえかた「さんし じゅうに」も 出る）
- ●を **タップ** すると、その 1つ分の まとまりに 色が つき、よこに **3、6、9 …** と たした 数が 出る（もう いちど タップで けす）
- **📈 ふえかた**：`3 × 1 ＝ 3` … `3 × 4 ＝ 12` と「かける数が 1 ふえると、こたえは 3 ふえる」（13 かけ算のきまり）

### 2「わける」（いちばん 大事な きのう）
- ●と ●の **あいだを タップ** すると 区切り線が 入る（**2本まで**。もう いちど タップで けす）
  - 行と 行の あいだ・列と 列の あいだの どちらも OK。●の まわりの うすい 目じるしを タップしても 入る
  - 指を おした まま ずらすと、線の いちを えらびなおせる。**入っている 線を ドラッグ** すると うごかせる
  - マウスの ときは、線が 入る ところが 点線で 先に 見える
- 区切った ぶぶんごとに 色（青・だいだい・みどり・むらさき）と **番号 ①②③④** が つき、線の ところは すきまが あく（色だけに たよらない）
- しきは **「つぎ ▶」で 1行ずつ**：`① 5 × 3 ＝ 15` → `② 2 × 3 ＝ 6` → `15 ＋ 6 ＝ 21` → `7 × 3 ＝ 21`。「ぜんぶ」「かくす」も あり
- **もとにもどす**（<kbd>Ctrl</kbd>+<kbd>Z</kbd>）・**ぜんぶけす**
- 下の **れい**：6×4・7×3・8×6・9×7・6×8（12まで の ときは 4×12・3×12 も）

### 3「くるっと」（交換法則）
- **くるっと** を おすと、●の ならび 全体が ゆっくり 90° まわる（1.8びょう）
- 「まわす まえ `3 × 4 ＝ 12`」「まわした あと `4 × 3 ＝ 12`」「こたえは おなじ 12」を ならべて 出す
- 左うえの **●の 数 12こ** は、まわして いる あいだも そのまま
- 1つ分 ずつ うすい わくが あるので、まとまりの むきが かわる ことが 見える

### 4「かたちの●」（L字型 など）
- もんだい 6つ：**Lの かたち・かいだん・でっぱり（凸）・へこみ（凹）・ずれた かたち・十字**
- **✂️ わける**：区切り線で 長方形に わける → ぶぶんの しき と たし算。
  長方形に なって いない ところは **赤い 点線の わく** で 知らせる
- **おぎなう**：たりない ところを タップ（なぞる）して **うすい 点線の ●** を おく →
  大きい 長方形に なったら `① 6 × 5 ＝ 30`・`② 3 × 2 ＝ 6`・`30 − 6 ＝ 24`
- とけたら **🔄 ちがう やりかたで やってみる**。さっきの やりかたの しきが のこり、「どちらの やりかたでも ●は 24こ！」
- **✏️ かたちを つくる**：先生が マスを タップ・なぞって、教科書と おなじ かたちを つくれる（よこ・たて 2〜12）。
  つくった かたちは リンク（⚙️ → リンクを コピー）で くばれる

### 5「せんせい」（提示用）
- トップの **せんせい**、または モードの 画面の **🧑‍🏫 せんせい** で、提示用の 画面に なる（もう いちど おすと もどる）
- ヒントなどを かくして、●と しきを 大きく。しき・答えは **クリック するたびに 1つずつ** 出る
  - しきの ところを クリック／「つぎ ▶」／<kbd>→</kbd>・<kbd>Space</kbd>・<kbd>PageDown</kbd>（プレゼンの リモコンも つかえます）
  - 1つ もどす：「◀」／<kbd>←</kbd>・<kbd>PageUp</kbd>
- 「わける」「くるっと」「かたちの●」（と「つくる」）を この 画面の まま そうさできる
- **⛶** で 画面 いっぱい（電子黒板・テレビに うつす とき）

## せってい（⚙️）

| こうもく | はじめ | ないよう |
|---|---|---|
| ●の ならべ方 | よこ | **よこ**：1つ分を よこ 1れつ に ならべる（3 × 4 は よこ 3こ・4だん）<br>**たて**：1つ分を たて 1れつ に ならべる。教科書の 図に あわせて えらんで ください |
| いくつ分の 大きさ | 9 まで | **12 まで** に すると「かけ算を 広げて」（4 × 12 を 4 × 10 と 4 × 2 に わける）に つかえる |
| よみあげ | オフ | オン に すると、しきを 出す ときに 九九の となえかた などを よむ |
| リンクを コピー | — | いまの モード・数・せってい（・つくった かたち）が 入った リンクを コピー |

**データは 保存しません。** そのかわり、いまの ようすは URL の うしろ（`#m=wakeru&a=7&b=3&muki=tate` など）に 入ります。
- その まま **ブックマーク** すれば、つぎも おなじ せっていで ひらけます
- **Google Classroom などに リンクを はれば**、子どもが おなじ がめん（たとえば「7 × 3 を わける」）から はじめられます

| URL の ことば | いみ |
|---|---|
| `m` | モード：`tsukuru`・`wakeru`・`kurutto`・`katachi` |
| `a`・`b` | 1つ分の 数・いくつ分 |
| `q` | かたちの● の もんだい（1〜6、`my` は じぶんの かたち ＋ `s`） |
| `w=o` | かたちの● を「おぎなう」で はじめる |
| `t=1` | せんせいの 画面 |
| `muki=tate`・`max=12`・`yomi=1` | せってい |

## 「ブロック おはじき」から とりいれた もの

まえに つくった [`kuku-block/`](../kuku-block/)（ブロック おはじき）で べんりだった ものを、この アプリの ねらいに あう 形で 入れました。

| ブロック おはじき | この アプリ |
|---|---|
| 九九の となえかた 81こ・よみあげ | こたえ・しきを 出す ときに となえかたを 表示（よみあげは せっていで オン の ときだけ） |
| まとまりで かぞえる（3、6、9 …） | 「つくる」で ●を タップすると 1つ分に 色と たした 数 |
| くくの だん「3 → 6 → 9（3ずつ ふえる）」 | 「つくる」の 📈 ふえかた |
| かこみを 90° まわす | 「くるっと」の まわる アニメーション |
| もどす（<kbd>Ctrl</kbd>+<kbd>Z</kbd>） | 区切り線・おぎなった ●を もとにもどす |
| テレビに うつす・ぜんがめん | 「せんせい」の 画面・⛶ |
| URL・コードで くばる | リンクを コピー（Firebase などは つかわず、URL だけ） |

## きめて ほしい こと（仕様書 9）

- **●の ならべ方の 向き**：はじめは「よこ」に して あります。教科書の 図が たてなら ⚙️ で「たて」に して ブックマーク してください
  （はじめから たて に したい ときは、`index.html` の `set: { muki: 'yoko'` を `'tate'` に かえます）
- **かたちの● の もんだい**：6つは 一ぱんてきな かたちです。教科書の 問題の 形は「✏️ かたちを つくる」で つくって リンクで くばれます
  （いつも 出したい ときは `index.html` の `SHAPES` に 1行 たします。`#` が ●、`.` が あき）
- **アプリの 名前**：いまは 仮称「●ならべ かけ算ラボ」。`index.html` の `<title>` と トップの `<h1>` を かえます
