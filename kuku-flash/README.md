# 九九フラッシュカード

テレビに うつして 子どもたちに 見せる **九九の フラッシュカード** です。
Chromebook の Chrome で ひらいて、テレビに つないで つかいます。

- しき（5×3）を 見せる → もう いちど おすと こたえ（15）が 赤で 出る → つぎの しき …
- しきの 上に **よみかた**（ごさん）。こたえを しきの となりに 出す ときは、こたえの 上にも よみかた（じゅうご・赤）が 出る。こたえだけ 出す（めくる）ときは、こたえに よみかたは つけない
- 白地に 黒、こたえ は 赤
- 数字と よみかたは **Kiwi Maru**（4 の 上が ひらいて いて、9 の たてぼうが まっすぐ。子どもが 書く 字の 形に ちかい）。テレビ用に ふちどりで 太く している
- 文字の 大きさは 画面に あわせて 自動で きまる（Chromebook 1366×768 でも テレビ 1920×1080 でも はみ出さない）。しきの いちは カードが かわっても うごかない
- 何まいめ かの 表示は 出さない（画面には カードだけ）
- **index.html 1ファイル** だけで うごきます（サーバー・ログイン・外部API なし）

## せってい

| こうもく | えらべる もの |
|---|---|
| だん | 1〜9 から いくつでも。**おした じゅんに 出る**（ボタンに 1・2・3 … と じゅんばんが つく。もう いちど おすと はずれる） |
| じゅんばん | **あがり**（5×1 → 5×9）・**さがり**（5×9 → 5×1）・**バラバラ** |
| どれだけ 出す | あがり／さがり：**− ＋ で 1〜10しゅう**　バラバラ：**10もん・20もん・30もん**　どちらも **じかんで**（1・2・3・5・10ぷん、その あいだ くりかえす） |
| しき を 見せる じかん | **手どう**（ボタンで すすめる）・1・2・3・5びょう |
| こたえ を 見せる じかん | **手どう**・1・2・3・5びょう |
| こたえの 出しかた | **しきの となりに**（5 × 3 = 15）・**めくる**（こたえだけ 大きく） |
| よみかた を のせる | オン（はじめは オン）／オフ |

せっていは ブラウザに おぼえます。バラバラは えらんだ だんを まぜて 出します（おなじ もんだいが 2かい つづかない）。

## よみかた

かけ算 九九表（いんいち が いち … くく はちじゅういち）と おなじ よみかた です。
こたえが 1けたの ときの「が」は しきの がわに つけて います。しき だけ 見せて いる ときも「ごいち が」と 出ます（こたえを 出すと その 上に「ご」）。
とくべつな よみ：ににん が し・さざん が く・さぶろく・さんぱ・しは・ごは・ごっく・ろくは・ろっく・しちは・はっぱ・はっく・くは

## そうさ（カードの とき）

| キー・ボタン | なにが おきるか |
|---|---|
| クリック・<kbd>スペース</kbd>・<kbd>Enter</kbd>・<kbd>→</kbd>・<kbd>PageDown</kbd> | つぎへ（じどうの ときも すぐ すすむ） |
| <kbd>←</kbd>・<kbd>PageUp</kbd> | 1つ もどる |
| <kbd>P</kbd>・⏸ とめる | じどうを いったん とめる／つづける |
| <kbd>F</kbd>・⛶ | がめん いっぱい |
| <kbd>Esc</kbd>・✕ おわる | せってい に もどる |

- プレゼン用の リモコン（PageDown／PageUp を おくる もの）でも すすめられます
- マウスを うごかさないと 2.5びょうで 下の ボタンと カーソルが きえます（うごかすと 出る）
- じどうで すすめて いる あいだは、Chromebook の 画面が くらく ならない ように します
- じかんで くりかえす ときは、じかんに なった あと、いま 出て いる カードの こたえを 見せてから おしまい に なります
