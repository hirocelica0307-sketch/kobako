# なみ麻雀（なみ マージャン）

（2026-10-12 に「雷鳴麻雀」から 名まえを かえました。ページの アドレス …/kobako/mahjong/ は そのままです）

スマホで あそぶ 4人麻雀です。**コンピューターと 対戦（つよさ 3段階）** と、**友だちと 対戦（合言葉で 部屋に 入る・2人＋コンピューター2人）** が あります。
ロンや ツモの とき、あがりの 大きさ（満貫・跳満・倍満・三倍満・役満）に あわせて **雷が だんだん 大きく おちる** 演出が あります。
ビルドは いりません（`index.html` を ひらくだけ）。
はじめての 人の ために、**妖精が 吹き出しで アドバイス**（どれを 切るか・作れる 役・リーチの ときの まもりかた）して くれます。メニュー画面と 対局中には **BGM** が 流れます。
Android・iPhone で **ホーム画面に 追加**すると、「中」の 牌の アイコンと「なみ麻雀」の 名まえで ならびます（`manifest.webmanifest`・`assets/icon/`）。

### 対局の はじまり（ルールどおりに サイコロで きめる）

1. **座席決め**：風牌（東南西北）を うらに して 1枚ずつ ひき、座る 席を きめる（毎回 ランダム）
2. **仮親決め**：東を ひいた 人（仮東）が サイコロを ふる → 出目で 仮親
3. **親決め**：仮親が もう一度 ふる → 出目で 起家（さいしょの 親）
4. 局ごとに 親が サイコロを ふり、**出目で 配牌を とる 山（わかれ目）** を きめる。王牌・ドラ表示牌・嶺上牌も その 位置から きまる

### 対局画面（たて向き。上から）

- メニュー・何局め・本場・供託・**ドラ表示牌**（カンで ふえる）・**妖精の アドバイスの オン/オフ**・音の オン/オフ
- **卓（緑）**：画面の あいて いる ところまで ひろがる（たて向きは たてに、横向きは 横に）。まん中の 遊ぶ ところは 正方形のまま、ひろがった ぶん 山・鳴き・名札は 外がわへ、**捨て牌は まん中に くっついた まま 大きく**（最大 1.3倍）なる。自分は いつも 下
  - まんなか：4人の 風と 点数（それぞれの 向き）・残り枚数・本場・供託、手番の 人が 光る。**自分の 点数を タッチすると ほかの 人との 差**（もう一度で もとに もどる）
  - 捨て牌（6枚ずつ 3段。リーチ宣言牌は 横むき）・さいごの 捨て牌が 光る・**ツモ切りの 牌は 少し くらい**・**きっちり そろって ならぶ**（設定で「手で 置いたように 少し ずらす」にも できる）
  - ポン・チー・カンの 牌（鳴いた 相手の 方向の 牌を 横むき、加槓は かさねる、暗槓は 両はしが うら）
  - あいての 手牌（うら：キャラメル色）・アバターと 名まえ・リーチ棒
- 待ちの 表示（テンパイの とき、のこり枚数つき。牌を えらぶと「これを 切ると 待ち…」・フリテン）と **あがったら 何点か（ロン ○○／ツモ ○○）**。押すと 待ちごとの 点数と 計算の しかた
- **自動和了／鳴きなし／ツモ切り** の 切りかえ（手で ならべる ときは「理牌」で 1回 きれいに ならべる）
- ボタン（ツモ・ロン・リーチ・ポン・チー・カン・九種九牌・スキップ）
- **鳴ける とき**：卓の ほかの 牌を うすく して、鳴ける 1枚だけを 金色に 光らせ「○○の 捨て牌」の ふきだしを 出す。卓の 下に「だれ（右・向かい・左）が 捨てた どの 牌か」と「ポン：手の この 2枚 ＋ その牌」の ように つかう 牌を 出し、手の 中の つかう 牌も 金色の わくで しめす
- **自分の 手牌**：卓の 上では なく、画面の はしから はしまで 大きく。ツモった 牌は 少し はなして 右に。
  **自動で ならべる**（萬→筒→索→字、同じ 数は 赤5が 先）か、**自分で ならべる**（配牌は くばられた じゅん。牌を 左右に ドラッグして 好きな 位置へ。ツモ牌も 列に 入れられる）

**スマホの 横向き**：卓を 高さいっぱいに して 横にも ひろげ（左右の 人の 捨て牌が 大きく なる）、左に 局・ドラ表示牌・待ちの 表示・切りかえ、右に ボタン（たてに ならぶ）、下に 手牌（はしまで）。ノッチの ある 機種は はしを よけます。右上の **全画面ボタン**（音の ボタンの となり）で ブラウザの バーを かくして 全画面に できます（もう一度 おすと もどる。できる 端末では 横向きに 固定）。iPhone の Safari には 全画面の しくみが ないので、おすと「共有 →ホーム画面に 追加」から ひらく 方法を 出します（ホーム画面から ひらくと 全画面で うごきます）。あがりの ときは キャラクターと「ロン／ツモ」を 卓の 左に 出して 卓の 雷が 見える ように し、結果は 左（手牌・ドラ）と 右（役・点数）の 2列で 出します。

**バイブ**：自分の 番が 来た とき（短く 1回）・ポン／チー／カン／リーチが できる とき（2回）・ロン／ツモが できる とき（長め）に ふるえます。設定 と 対局中の メニューで オン／オフ。Android の Chrome などは ふるえます。iPhone は ブラウザに バイブの しくみが ないので、iOS 18 いこうの「スイッチを おしたときの 小さな ふるえ」を つかいます（それより まえの iOS や 消音・設定で ふるえない ことが あります）。

**妖精の アドバイス**（`advisor.js`）：画面の すみの 妖精（男の子）が 吹き出しで 教えて くれます。上の 妖精の ボタンで いつでも オン／オフ、メニューで「いつも／だいじな ときだけ／なし」。妖精を タップすると もう一度 言います。吹き出しは タップで とじます。
- 自分の 番：**おすすめの 牌**（手牌で 水色に 光る）と 理由（テンパイまで あと 何枚・何種類 何枚で 手が すすむ・1枚だけの 字牌は 先に など）。テンパイなら 待ちと のこり枚数、リーチ する／しない、フリテンの 注意
- **作れそうな 役**：役牌・タンヤオ・ホンイツ／チンイツ・七対子・トイトイ（局ごとに 新しい ものを 1つずつ）。鳴いて 役が ない ときは 注意
- **だれかが リーチ**：「○○さんが リーチ！」と まもりかた（現物 → 壁・見えた 字牌 → スジ）。その あとは 手の 中の あんぜんな じゅん（現物・スジ・字牌・壁…）と、まもるか すすめるか
- 鳴ける とき：ポン／チー する（役牌・タンヤオ・ホンイツ…）か スキップ（役が なくなる・手が すすまない・リーチが いる）か。ロン できる ときも 教える
- 考えかたは コンピューター「よく考えて打つ」と 同じで、見えて いる 牌だけを つかう

**ふりかえり**：対局が おわったら「ふりかえり」で、妖精の おすすめと 同じ 牌を 切った 回数（％）と、とくに 見なおすと よい 場面（その ときの 手牌・あなたが 切った 牌 → おすすめ・理由〔テンパイから とおのいた／リーチの 人に あぶない／手が すすむ 牌が ○枚 少ない〕）を 見られます。

さわりかた

- 手牌を タップ → **少し 上に 上がって 黄色く かこまれる** → **もう一度 タップで 捨てる**（ほかの 牌を タップすると えらびなおし）
- リーチ：「リーチ」を おすと、リーチ できる 牌だけ 明るく なる → タップ 2回で 宣言して 捨てる。リーチの あとは 自動で ツモ切り
- チーの 形が いくつか ある ときや、カンする 牌が いくつか ある ときは、えらぶ 画面が 出る

### 音と 演出

- **BGM**（`bgm.js`。Web Audio で その場で 演奏）：メニュー画面は あかるく ゆったり（ハ長調）、対局中は おちついた 曲（イ短調）、**だれかが リーチ すると テンポが あがった ドキドキの 曲**に かわる。**オーラス（さいごの 局）だけは はりつめた 専用の 曲**（ニ短調・時計の ように きざむ ベースと 太鼓。オーラスは リーチが あっても この 曲の まま）。あがり・流局の 演出の あいだは 小さく なる。アプリを うらに すると 止まる
- 効果音（Web Audio で その場で つくる）：牌を えらぶ「カチッ」・卓に 打つ「タンッ」・リーチの 強打・ツモ・配牌・山を まぜる 音・サイコロ・鳴き・雷・役の「ドン」・点数の スタンプ・役満ツモの 暗転「ガン！」
- こえ（端末の 日本語 読みあげ）：ポン・チー・カン・リーチ・ロン・ツモ、局の 名まえ（トン イッキョク・ニホンバ）、あがりの 役（リーチ・タンヤオ・ダブトン…）、ドラ（ドラドラ・アカ・ウラサン）、マンガン・ハネマン など、流局（キュウシュキュウハイ など）。
  漢字の まま 読ませると まちがう（跳満 → とびまん など）ので、麻雀で じっさいに 言う 読みを カタカナで わたす。席ごとに こえの 高さを 少し かえる
- リーチ：光の 帯が 走り、大きな「リーチ」と アバターの カットイン
- ポン・チー・カン：その 人の 方向に 大きな 文字と 火花
- ロン・ツモ：画面が くらく なり、**まず あがった 人の アイコン**（名まえ・ロン／ツモ・だれから）を 大きく 出してから 雷。
  **満貫いじょうの ツモ**は その まえに、MJ の あがり演出を 参考に **半透明の 手**（白っぽく 光る）が あがった 人の 方向から のびて きて、山の 牌を つまんで 引いて きて、もちあげて 卓の まんなかに たたきつける（ドン！と ゆれて 火花）。
  **役満の ツモ**は「**ガン！**」と いきなり 画面が 暗転 → 暗やみに キラキラ 光る 牌が うかびあがり → 手が ゆっくり とりに きて、光を つれて 引いて きて 卓に たたきつけると 画面が まっしろに ひかって 明るく もどる。（演出「ひかえめ」では 手の 演出は 出ない）
  **ツモは 卓の まんなか（たたきつけた 牌）、ロンは ふりこんだ 人が 出した 牌に** 雷が おちる（その 牌が 赤く 光る）。あがりの 大きさに あわせて 雷の 本数・光・ゆれ が ふえる（満貫 1本 → 跳満 2本 → 倍満 3本＋光の すじ → 三倍満 5本 → 役満は 虹色の 雷の 嵐と 光の 雨）
- 結果画面：手牌・ドラ・**裏ドラを 1枚ずつ めくる** → 役が「ドン」と 1つずつ 出て 読みあげ → 符・翻 → **満貫・跳満…の スタンプ**（大きさで 色と 雷が かわる）→ 点数を かぞえあげ（「子の ロン：3900」など）→「**点数の 計算を 見る**」で ①翻 ②符の 内わけ ③基本点 ④はらう 点数 → 4人の 点数の うごき
- ドラと 赤ドラの 手牌は ときどき キラッと 光る

## 役を おぼえる（`yaku-lessons.js`・`yaku-player.js`）

- 一覧：1翻・2翻・3翻・6翻・役満・とくべつ（流し満貫）・はじめに（あがりの かたち）に わけて ぜんぶ ならべる。読みかた・翻・「門前のみ／鳴いても OK／鳴くと 1翻」・ポイント。見おわった 役に ✓
- **お手本の 再生**：配牌 → ツモ（上から 牌が 入る）→ 捨てる（捨て牌に とぶ）→ ポン・チー・カン（相手の 牌が とんで きて さらされる）→ リーチ → あがり（「ツモ！」「ロン！」）が 1コマずつ うごく。
  妖精が 吹き出しで 説明し、説明に 出てくる 牌は 絵で 出る。だいじな 牌は 光る。「テンパイまで あと ○まい」も その場で 計算して 出す。
  再生／とめる・もどる・つぎへ・さいしょから・はやさ（ゆっくり／ふつう／はやい）・**読みあげ**（説明を 声で。牌は「ごマン」、役は カタカナの 読みで 読む）
- さいごに **あがりの 手を 面子ごとに わけて**（順子・刻子・雀頭・ポン・暗槓）、evaluateWin で 計算した 役・翻・符・点数を 出す。「つぎの 役」で じゅんばんに 見て いける
- **役当てクイズ**：お手本の あがりの 手を 見て、つく 役を 4つから えらぶ（ほかの えらびは その 手に つかない 役だけ）
- たしかめ：`tests.js` で 42この お手本 ぜんぶを 再生して、ない 牌を 捨てて いない・同じ 牌が 5枚 ない・あがる まえは テンパイ・あがりで その 役が ほんとうに つく（evaluateWin）ことを 毎回 たしかめる

## 麻雀ドリル（`drill.js`・`drill-data.js`）

| しゅるい | 問題数 | なかみ |
|---|---|---|
| 何切る（基本） | 160 | 2〜3シャンテンの 手から 1枚 切る。手牌を タップ 2回で 答える |
| 何切る（1シャンテン） | 160 | テンパイまで あと 1枚の 手 |
| 何切る（テンパイ取り） | 130 | テンパイに とる とき 待ちの 枚数が いちばん 多く なる 1枚 |
| 何切る（清一色） | 150 | 1つの 色だけの 手（多面張の 形の 練習） |
| 何待ち？（清一色） | 140 | 多面張の 待ちを ぜんぶ ふくむ ものを 4つから えらぶ |
| 何待ち？（いろいろ） | 100 | 字牌も ある ふつうの 手の 待ち |
| 何シャンテン？ | 150 | テンパイ〜4シャンテン（一般手・七対子・国士の いちばん 小さい もの） |
| 何符？ | 333 | 20符〜110符（平和ツモ・七対子・暗槓 たくさん など）。符の 内わけ つきで 解説 |
| 何点？（あがった 手） | 260 | 役・ドラ・赤ドラ・符から 点数（1翻〜跳満、親・子・ロン・ツモ） |
| 何点？（翻と 符） | 176 | 早見表の ぜんぶの くみあわせ ＋ 満貫〜数え役満 ＋ 本場つき |
| 現物は どれ？ | 90 | リーチの 人に ぜったい あたらない 牌を 手牌から えらぶ |
| スジは どれ？ | 90 | 両面待ちに あたらない 牌（スジ）を 4つから えらぶ |

**こたえを まちがえない ための しくみ**
- 問題は `drill/gen.mjs` で つくり、こたえを **2とおりの 計算** で 出して、一致した ものだけを のこす（ちがったら その場で とまる）。
  ① アプリの エンジン（`hand.js` の シャンテン数・待ち・受け入れ、`score.js` の 役・符・点数）
  ② `drill/check.js`：エンジンとは べつに いちから 書いた 計算（シャンテン数・待ち・あがりの 分けかた・符・かんたんな 役の 翻）と、**本や サイトに のって いる 点数の 早見表を そのまま 書いた 表**
- 何切るは「シャンテン数を 下げない 打牌の 中で、手が すすむ 牌の のこり枚数が いちばん 多い 打牌」が こたえ（のこり枚数は 自分の 14枚を 見えて いる 牌と して かぞえる）。**1位と 2位が 2枚 以上 はなれて いて こたえが 1つに きまる 問題だけ**。
- 符は「あがりの 読みかた（分けかた・待ちの 形）が どれでも 同じ 符に なる 手」だけ。点数は「読みかたが 1とおり」で「立直・門前ツモ・平和・断么九・役牌・一盃口・混一色・対々和・ドラ・赤ドラ」だけで できた 手だけ（べつの 計算で 翻を たしかめられる 手）。
- 待ちは「待ちの 牌が 手の 中に 4枚 ない」手だけ。待ちの えらびは 1つ 足りない・1つ 多い・1つ ちがう もの。
- 同じ 形の 問題（色を 入れかえた・数字を 逆に した だけ）は 1つに まとめた。
- `node mahjong/tests.js` で 毎回 ぜんぶの 問題を もう一度 2とおりで たしかめる（1939問 ぜんぶ 一致）。
- このアプリの ルール：連風牌（場風と 自風が 同じ）の 雀頭は 4符、切り上げ満貫 なし（30符4翻・60符3翻は 7700／親 11600）、数え役満 あり。
- 符・点数の きまりは 次のような サイトの 説明とも 見くらべた：[麻雀の点数計算（choge blog）](https://www.choge-blog.com/hobby/majan-tensuu-keisan/)・[符（萌娘百科 中国語）](https://zh.moegirl.org.cn/%E7%B4%A0%E7%82%B9)・[麻雀点数計算（luft）](https://www.luft.co.jp/cgi/mahjong-calculator.php)・[雀魂の点数早見表（Game8）](https://game8.jp/jantama/614751)

## コンピューターの つよさ

コンピューターは 自分の 手牌と 見えている 牌（捨て牌・鳴き・ドラ表示牌）だけで 考えます。

| つよさ | 考えかた |
|---|---|
| 1 あまり考えない | シャンテン数が ふえない 牌の 中から ざっくり 切る。まもらない。鳴きは 役牌を ときどき |
| 2 ふつうに考える | シャンテン数と 受け入れ枚数で 切る。リーチが かかって 手が 遠いと 現物で まもる。役牌・役の ある 鳴き |
| 3 よく考えて打つ | 受け入れ・ドラ・役牌・字牌の 切りじゅん・危険度（現物・筋・壁・字牌の のこり）を 点数に して 切る。手の 高さと はやさで 押し引き。高い 手は ダマも |

コンピューターどうしで たしかめた 平均順位（東風戦 24回、相手は ぜんぶ つよさ1）：つよさ3 は 1.67位、つよさ2 は 2.13位。

|---|---|
| 対局の 長さ | 半荘戦（東風戦も） |

| 飛び（0点 未満で 終了） | あり |
| オーラスの あがりやめ | あり |

## 友だちと 対戦

1. ホスト：「友だちと 対戦」→ コンピューターの つよさと 長さを えらんで「部屋を つくる」→ **4けたの 合言葉** が でる
2. もう1人：「部屋に 入る」→ 画面の キーで 合言葉を 入れて「入る」
3. ホストの 画面に 名まえが 出たら「対局を はじめる」。座席は ランダム、親は サイコロで きまる
4. 局の 結果は ゲストが「OK」を おしてから ホストが「つぎの 局へ」。おわったら ホストの「もう一度」で つぎの 対局

- ルールは ホストの 設定です。2人とも 自分が 下に なる 向きで 見えます
- コンピューター2人の 手は ホストの 端末が きめます。手（どの 牌を 切ったか など）を 1つずつ ならべて おくり、2台で 同じ ルールエンジンを うごかします
- ページを 読みなおしても、同じ タブなら ホームの「合言葉 ○○○○ の 部屋に もどる」で 対局に もどれます（とちゅうまでの 手は すぐ おいつきます）
- 3時間 つかわれて いない 部屋の 合言葉は、つぎに 部屋を つくる 人が つかいまわします

### なかま と さそい（`friends.js`）

- **一度 同じ 部屋に 入った 人どうしは 自動で「なかま」に なる**（対局を しなくても、部屋に 入るだけで よい）。この 端末の「なかまID」は ずっと かわらない（localStorage）
- なかまが アプリを ひらいて いると、ホームの 上の「なかま」に **●いま ひらいて います**（対局中は「対局中」）と 出る
- 「**さそう**」を おすと 部屋が できて、相手の 画面に「**○○さんから 対戦に さそわれて います！ 対戦しますか？**」が 出る（ホーム・コンピューター対戦中・ドリル など どの 画面でも。音と バイブ つき）
- 相手が「対戦する」を おすと、合言葉を 入れなくても その 部屋に 入り、**すぐに 対局が はじまる**。「あとで」を おすと さそった 人に「いまは 対戦 できない みたい」と 出る。さそいは 90秒で 消える
- 友だちと 対局中の 人には さそいは とどかない（「対局中」と 出る）
- **アプリを とじて いる 人には とどかない**（スマホの 通知には ならない。通知に するには ストアで くばる アプリと 通知用の サーバーが いる）
- 知らない 人には 見えない：2人だけの 通り道 `rooms/{4けた}/nami/{なかまID_なかまID}/`（on＝ひらいて いる しるし・inv＝さそい）を つかい、なかまの IDを 知らない 人には 場所が わからない。`rooms/{4けた}` は いまの Firebase ルールの まま 書ける 場所なので、ルールの はりかえは いらない
- ためす とき：`?fake&profile=a` と `?fake&profile=b` の タブ 2つで べつの 人に なる

## Firebase の 設定

「花札 こいこい」などと **同じ Firebase プロジェクト（`hiro-kobako`）** を つかいます（`firebase-config.js` は 同じ なかみ）。
**やることは ルールの はりかえ 1つ だけ**：Realtime Database の「ルール」タブの 中身を ぜんぶ `database.rules.json` に おきかえて「公開」。

ルールを まだ はりかえて いなくても 部屋は つくれます：`mahjong/rooms` が ことわられた ときは、
どの 版の ルールにも ある `rooms/{合言葉}/mahjong`（「かいて あてて」の 部屋の 場所の 下。あちらは きまった 名まえ だけ さわるので ぶつからない）に しまいます。
ホストも ゲストも 同じ しらべかたを するので、2人は かならず 同じ 場所を つかいます。はりかえた あとは `mahjong/rooms` に もどります。
つながらない ときは、部屋の 画面の 名まえの 下に 理由が 日本語で 出ます。`?fake&deny=mahjong` を つけると「はりかえて いない」ときを タブ 2つで ためせます。
（ほかの 4つの アプリの `database.rules.json` も 同じ なかみに そろえて あります。`mahjong` の ぶぶんが ふえただけ です。）

```
mahjong/rooms/{合言葉4けた}/
  meta              ホスト・ゲスト・名まえ・ルール・CPUの つよさ・種・何回めの 対局か・さいごに さわった 時こく
  online/host|guest いま つながっているか
  log/{n}/{00000}   n 回めの 対局の 手（ホストが 1つずつ 書く。上書き できない）
  req/{n}/{key}     ゲストが ホストへ おくる 手
  ready/{n}/{局}    ゲストが 局の 結果を 見おわった しるし
```
