# タイピング つなひき

ローマ字で ことばを 打って、つなを 引っぱりあう **2人たいせん**の タイピングゲームです。
へやに あつまった 人を **2人ずつ 組にして、いっせいに** たいせんします。
Chromebook の キーボードで あそぶ ことを 考えて 作っています。

## あそびかた

1. 先生が **「へやを つくる」** → 4けたの ばんごうが 出ます
2. 子どもは なまえを 入れて、その ばんごうで **「へやに はいる」**
3. 先生が せっていを えらんで **「はじめる」**
4. **まっている 人が 2人 そろった 組から、すぐに たいせんが はじまります**
   - 3・2・1 の あと、同じ ことばが 2人に 出ます
   - ことばを 打つと、1文字（かな）ごとに つなを じぶんの ほうへ 引っぱります
5. **けっか** が 出たら「つぎの たいせんへ」（15びょうで じどうで すすみます）
   → また まつ 人に もどり、**つぎの 2人組が できしだい** たいせんが はじまります

### かちまけ

| こうなったら | かち |
|---|---|
| あいてより **「かつための さ」ぶん 多く** 打てた（つなを 引ききった）| その時点で かち |
| **じかん ぎれ** | 打った かなが 多い ほう（おなじなら ひきわけ）|
| あいてが **いなく なって 5びょう** たった | のこった ほう（かち数には かぞえません）|

まちがえた キーは つなを うごかしませんが、けっかに「まちがい」の 数が 出ます。

### 2人組の つくりかた

- 組を 作るのは **へやの ぬし（先生）の タブ だけ**です
- まっている 人が 3人 いじょう いれば **くじびき**で 組みます
- **さっき たいせんした 相手とは なるべく 組みません**
  （ほかに だれも こないまま 8びょう たったら、同じ 相手とも 組みます。
  2人しか いない へやで ずっと 待たされない ように）
- 人数が 奇数の ときは、1人が 「あいてを さがしています…」で まちます
- **「やすむ」** を おすと、組に 入らなく なります（「たいせんに でる」で もどれます）
- 先生が **「あたらしい 組を とめる」** を おすと、あたらしい 組は 作られません
  （いま たいせん中の 組は さいごまで つづきます）

## 先生の せってい

| せってい | えらべる もの | はじめは |
|---|---|---|
| むずかしさ | やさしい（1・2年）／ふつう（3・4年）／むずかしい（5・6年）| やさしい |
| 1かいの じかん | 20〜180びょう | 60びょう |
| かつための さ | 5〜60もじ | 20もじ |
| ローマ字の おてほん | みせる／みせない | みせる |
| あなた（ぬし）は | あそぶ（いっしょに たいせん）／かんりする（見まもる）| あそぶ |

せっていは たいせん中は たたんでいます。かえる ときは「あたらしい 組を とめる」を
おすと また 出ます（かえた せっていは **つぎに できる 組から** つかわれます）。

**かんりする** に すると、先生の 画面に **「たいせんの ようす」** が 出ます。
組ごとに、打った 数・つなの いち・のこり時間 が ならびます。

## たいせんの 画面

```
┌──────────────────────────────────────────────┐
│ じぶん  ○━━━━━━━━━━━┳━━━━━━━━━━━○  あいて │ ← つな（リードすると じぶんの ほうへ）
│ 14もじ       かち┆     ▲     ┆かち       10もじ │
├───────────────────────────┬──────────────────┤
│ あと 56もじ で かち！   のこり 18びょう │ あいての ようす   │
│                           │  から|あげ       │ ← あいてが 打った ところ
│         しん|ぶん          │     r            │ ← あいてが 打ちかけの キー
│         sin|nbunn         │                  │
│      つぎ： たんぽぽ       │  まちがい 0      │
└───────────────────────────┴──────────────────┘
```

- **あいての ようす** には、あいてが いま 打っている ことばと、
  **打ちかけの ローマ字**（`ky` など）まで 出ます
- まちがえると ことばが すこし ゆれて、小さく 音が 鳴ります

## ローマ字の はんてい（`romaji.js`）

日本語入力（IME）は つかわず、キーを 1つ おすごとに この アプリが しらべます。
**打ちかたが いくつも ある 字は、どれでも 正解**に します。

| かな | 正解に なる 打ちかた（さいしょが おてほん）|
|---|---|
| し・ち・つ・ふ・じ | si／shi／ci、ti／chi、tu／tsu、hu／fu、zi／ji |
| しゃ・ちゃ・じゃ | sya／sha、tya／cha／cya、zya／ja／jya（ほか si＋xya なども）|
| っ | つぎの 子音を 2つ（`kka`・`tchi` も）／xtu／ltu／xtsu／ltsu |
| ん | nn／xn／n'。**つぎが 子音なら n 1つでも よい**（あいうえお・や行・な行の まえと、ことばの さいごは nn）|

- おてほんは **小学校で ならう 訓令式（si・ti・tu）** を 先に 出します
- 子どもが `shi` で 打つと、**つぎからの おてほんも `shi` に かわります**（その タブの あいだ おぼえます）
- 大文字（CapsLock）でも 打てます

### 日本語入力が オンの とき

キーボードの 入力が 日本語に なっていると、ローマ字が とどきません。
その ときは 画面の 上に **「キーボードの『英数』キーを おしてから 打ってね」** と 出します。

## おだいの ことば（`words.js`）

| むずかしさ | 数 | どんな ことば |
|---|---|---|
| やさしい | 110 | 2〜4文字。小さい 字（ゃゅょっ）と「ん」なし（いぬ・さかな）|
| ふつう | 100 | 3〜7文字。小さい 字や「ん」あり（がっこう・きゅうしょく）|
| むずかしい | 80 | ことわざ・むかしばなし・みじかい 文（いそがばまわれ・てをあらいましょう）|

2人には **同じ ことばが 同じ じゅんばんで** 出ます（「たね」から ならびを きめるため）。
ことばを 足すときの きまりは `words.js` の 先頭に 書いてあります。

`keypad.js`・`stepper.js`・`firebase-config.js` は「かいて あてて」から うつしました
（「1つの アプリ ＝ 1つの フォルダー」の きまりの ため、読みこまずに コピーしています）。

## Firebase の 設定

「かいて あてて」と **同じ Firebase プロジェクト（`hiro-kobako`）** を つかいます。
匿名サインインは もう 有効なので、**やることは ルールの はりかえ 1つ だけ**です。

### ルールを はりかえる（かならず）

Realtime Database の **「ルール」**タブを 開いて、中身を ぜんぶ
`database.rules.json` の 中身に おきかえて **「公開」**を おしてください。

```json
{
  "rules": {
    "rooms": { "$code": { ".read": "auth != null", ".write": "auth != null",
                          ".validate": "$code.matches(/^[0-9]{4}$/)" } },
    "tsuna": { "$code": { ".read": "auth != null", ".write": "auth != null",
                          ".validate": "$code.matches(/^[0-9]{4}$/)" } }
  }
}
```

`rooms` は「かいて あてて」、`tsuna` は この アプリの 場所です。
**これを わすれると、「へやを つくる」を おしても へやが できません**
（`tsuna` に 書きこむ ことが ゆるされて いないため）。

## この 作りに した 理由

**① あいての ようすは「数」だけ 送ります**

ことばの ならびは 2人とも 同じ ものを 持っているので、送るのは
「何こめの ことばの、何文字めまで 打ったか」と 打ちかけの キー だけです。
1回 数十バイトなので、30人が いっせいに 打っても 通信は かるい ままです。
送るのは 0.08びょうに 1回まで に まとめています。

**② よーい・どん は サーバーの 時計で そろえます**

Chromebook ごとに 時計は すこし ずれています。はじまる 時こくを
サーバーの 時計で きめて、各タブが「じぶんの 時計との ずれ」を なおして 数えるので、
2人の 3・2・1 が そろいます。

**③ かちまけは「さきに 書いた ほう」**

つなを 引ききった とき・じかん ぎれの とき、2人の タブが 同時に かちまけを
書こうと しても、Firebase の トランザクションで **さきに 書いた 1つだけ** が のこります。
じかん ぎれの ときは、さいごの すすみが とどくのを 1.5びょう まってから きめます。

**④ 組を 作るのは ぬしの タブ だけ**

みんなが かってに 組を 作ると、同じ 子が 2つの 組に 入って しまいます。
ぬしの タブだけが 組を 作り、しかも **組に した 子を 手もとで おぼえて**、
その 子が たいせんを おえて また まちはじめる までは 組に 入れません
（書きこみが 手もとに とどく 前に もう一度 さがしても、ぶつからない ように）。

**⑤ 止まったままに ならない 見はり**

| こうなったら | どうする |
|---|---|
| あいてが 5びょう いない（タブを とじた・通信が 切れた）| のこった 子の かち |
| じかんが すぎて 6びょう たっても きまらない（2人とも いない など）| ぬしが 打った 数で きめる |
| たいせん中に 画面を 開きなおした | つづきから（打ちかけの ことばは さいしょから）|

**⑥ なまえは 画面の ひらがなキーで**

キーボードで ひらがなを 打つには 日本語入力の 切りかえが いります。
小さい子が まよわない ように、なまえは「かいて あてて」と 同じ 画面の キーで 入れます。
へやばんごうは 画面の テンキーでも、キーボードの 数字でも 入れられます。

**⑦ キーを おすたびの 音は 出しません**

30台が いっせいに 鳴ると うるさいので、音は
3・2・1、ことばを 打ちおわった とき、まちがえた とき、けっか だけです（どれも 小さめ）。

## ためした こと

この 作業を した 場所からは 本物の Firebase に つながらなかったので、
**Firebase と 同じ うごきを する「にせもの」** を 作って、ブラウザを 何まいも 開いて ためしました。

- 先生（かんりする）＋ 子ども5人、タブごとに 時計を ±3びょう ずらして
  - はじめる → **2組 できて 1人 まつ**（同じ 子が 2つの 組に 入らない）
  - 打つ はやさの ちがう ロボットで たいせん → **はやい ほうが さ 20で かち**、かち数も つく
  - つぎへ → **さっきと ちがう 相手**と 組まれ、まっていた 子も 入る
  - たいせん中に 1人が タブを とじる → **あいてが 約7びょうで かち**
- 先生（あそぶ）＋ 子ども1人、20びょう・さ 60 で
  - **じかん ぎれで 打った 数が 多い ほうが かち**
  - たいせん中に 画面を 開きなおしても **つづきから** できる
  - 日本語入力の しらせが 出る
- ローマ字の はんてい … しんかんせん（sinkansenn／shinnkannsenn）、がっこう（gakkou／gaxtukou）、
  まっちゃ（mattya／maccha／matcha）、こんにちは（n 1つでは まちがい）など 40とおり いじょう
- おだい 290語 すべてが 打てること・おてほんどおりに 打つと おわること・きまり（文字数など）
- 画面の 大きさ 1024×768・1280×800・1366×768 で はみ出しが ないこと

**本物の Firebase では まだ ためして いません。** ルールを はりかえたら、
「かいて あてて」の ときと 同じ ように **タブを 3つ 開いて**（先生1・子ども2）
たいせんが はじまるかを たしかめてください。
