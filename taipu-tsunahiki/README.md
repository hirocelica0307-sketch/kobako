# タイピング つなひき

ローマ字で ことばを 打って、つなを 引っぱりあう **うんどうかいの タイピングゲーム**です。
Chromebook の キーボードで あそぶ ことを 考えて 作っています。
**へやばんごうも 先生の そうさも いりません。** ひらいて ボタンを おすだけです。

## あそびかた

タイトル画面の 2つの ボタンから えらびます。

| ボタン | ながれ |
|---|---|
| **たいせん あいてを さがす** | あいてが 見つかる → 2人とも むずかしさを えらぶ → **じゃんけん ぽん**（声つき）→ かった 子の むずかしさで たいせん |
| **コンピューターと たいせん** | コンピューターの つよさ（5だんかい）を えらぶ → たいせん |

さいしょの 1回だけ なまえを 入れます（画面の ひらがなキー）。なまえと これまでの
かち・まけは その 端末に のこるので、つぎからは すぐ あそべます。

### たいせん

- 3・2・1 の あと、2人に **同じ ことばが 同じ じゅんばん**で 出ます
- かなを 1文字 打つごとに、つなを じぶんの ほうへ 引っぱります
- あいてより **20もじ 多く** 打てたら（つなの リボンが ゴールの 線まで きたら）その時点で かち
- **60びょう** たったら、打った かなが 多い ほうの かち（おなじなら ひきわけ）
- あいてが いなく なって 5びょう たったら、のこった ほうの かち（せいせきには かぞえません）

### たいせん画面で 見える もの

```
┌─ ●あおい 19もじ ─────── レベル2 やさしい [54] ─────── 14もじ はると ○ ─┐
│            ( がんばれ！ )  ← おうえん（つなの ようすで かわる）           │
│   あかぐみ ≡≡≡≡≡≡≡≡≡≡≡≡▲≡≡≡≡≡≡≡≡≡≡≡≡ しろぐみ                        │
│           ゴール                ゴール                                     │
├──────────────────────────────┬──────────────────────┤
│          ぶ|らんこ              │ あいての ようす        │
│          bur[a]nnko             │   はちまき ← 打った ところ │
│          つぎ： まつり           │   h        ← 打ちかけの キー │
├──────────────────────────────┴──────────────────────┤
│   Q W E R T Y U I O P    ← つぎに おす キーが 黄色く 光る           │
│    [A] S D F G H J K L     キーは ゆびごとに 色わけ、F と J に しるし   │
│      Z X C V B N M        つぎは A ・ ひだりの こゆび              │
└─────────────────────────────────────────────────┘
```

- **おうえん**：もうちょっと！ あと ○もじ／いいぞ！ その ちょうし！／がんばれ！／
  まけるな！／ふんばれ！ まだ いける！／あぶない！／ぎゃくてん！
- **つぎに おす キー**を 画面の キーボードで 光らせ、**どの ゆびで おすか**も 出します。
  ローマ字の おてほんでも、つぎの 1文字に 黄色い しるしが つきます
- **あいての ようす**：あいてが いま 打っている ことばと、打ちかけの ローマ字
- じぶんは いつも **あかぐみ（ひだり）**、あいては **しろぐみ（みぎ）** です

## むずかしさ（5だんかい）

| レベル | なまえ | ことば | めやす | コンピューター |
|---|---|---|---|---|
| 1 | はじめて | 2〜3文字。てんてん・小さい 字・「ん」なし（いぬ・さかな）| ローマ字 はじめたて | 1ぷんに 12もじ |
| 2 | やさしい | 3〜4文字。てんてん・「ん」あり（うさぎ・ごはん）| 1・2年生くらい | 20もじ |
| 3 | ふつう | 小さい 字（ゃゅょっ）あり（がっこう・きゅうしょく）| 3・4年生くらい | 30もじ |
| 4 | むずかしい | 6〜9文字。ながい ことば・みじかい ことわざ | 5年生くらい | 42もじ |
| 5 | そつぎょう | 10〜16文字。ことわざ・みじかい 文 | 6年生・そつぎょう | 58もじ |

ことばは ぜんぶで 379語（うんどうかいの ことばも 入れました：つなひき・たまいれ・はちまき など）。
足すときの きまりは `words.js` の 先頭に あります。
コンピューターの はやさは `words.js` の `LEVELS` の `cpu` で かえられます。
コンピューターも ときどき まちがえます（レベルが ひくいほど 多め）。

## 人との たいせんの くわしい ながれ

1. 「たいせん あいてを さがす」を おすと、さがしている 子の ならびを 見ます。
   - だれか いれば、その子と 組みます（2人 いじょう いれば くじびき。さっきの あいては あとまわし）
   - だれも いなければ ならんで まちます（「コンピューターと たいせん」にも すぐ かえられます）
2. 組に なったら、2人とも **むずかしさを えらびます**（20びょう。えらばないと、まえに えらんだ レベル）
3. 2人とも えらんだら **じゃんけん**。「じゃんけん、ぽん！」「あいこで、しょ！」と 声が 出ます
   （あいこは 4回まで。5回めは かならず きまります）
4. かった 子の えらんだ むずかしさで たいせん
5. けっかの あとは「もういちど さがす」か「タイトルへ」

| こんな とき | どうなる |
|---|---|
| あいてが むずかしさを えらぶ まえに いなく なった・10びょう こない | 「あいてが いなく なったよ」→ じどうで また さがす |
| 「やめる」を おした | あいてにも 同じ しらせが 出て、また さがします |
| たいせんの とちゅうで 画面を 開きなおした | つづきから（打ちかけの ことばは さいしょから）|

## 日本語入力が オンの とき

キーボードの 入力が 日本語に なっていると、ローマ字が とどきません。
その ときは 画面の 上に **「キーボードの『英数』キーを おしてから 打ってね」** と 出します。

## ローマ字の はんてい（`romaji.js`）

**打ちかたが いくつも ある 字は、どれでも 正解**に します
（し＝si／shi、つ＝tu／tsu、ふ＝hu／fu、じ＝zi／ji、しゃ＝sya／sha、っ＝kka／xtu、
ん＝nn／xn、つぎが 子音なら n 1つでも）。
おてほんは 小学校で ならう 訓令式（si・ti・tu）で 出し、子どもが shi で 打つと
つぎからの おてほんも shi に かわります。

├── app.js                画面の ながれ（さがす・じゃんけん・コンピューター・けっか）
├── game.js               たいせん画面（打つ・つな・おうえん・けっか）
├── keyboard.js           画面の キーボード（つぎの キーを 光らせる・ゆびの 色わけ）
├── cpu.js                コンピューターの あいて

├── words.js              ことば（5だんかい）と、2人で そろう ならびかた
├── keypad.js             なまえを 入れる ひらがなキー

## Firebase の 設定

「かいて あてて」と **同じ Firebase プロジェクト（`hiro-kobako`）** を つかいます。
匿名サインインは もう 有効なので、**やることは ルールの はりかえ 1つ だけ**です。

Realtime Database の **「ルール」**タブを 開いて、中身を ぜんぶ
`database.rules.json` の 中身に おきかえて **「公開」**を おしてください。
（まえの はんで はった `tsuna` は もう つかいません。このファイルには 入っていないので、
はりかえると 消えます。`rooms` は「かいて あてて」の ぶんです）

**これを わすれると「たいせん あいてを さがす」が うごきません**
（コンピューターとの たいせんは、つうしんを つかわないので うごきます）。

## データの かたち

```
tsunahiki/
  lobby/
    queue/{ID}    さがしている 子（name・t＝さいごに「まだ いるよ」を 出した 時こく）
    assign/{ID}   「あいてが きまったよ」の しらせ（mid・t）
  matches/{mid}
    a／b・na／nb        2人の ID と なまえ
    createdAt            組んだ 時こく
    here/{ID}            画面に きている しるし（タブを とじると 消えます）
    choice/{ID}          えらんだ むずかしさ（1〜5）
    janken               rounds（[[a の 手, b の 手], …]）・winner・at（はじまる 時こく）
    level／seed          じっさいの むずかしさ・ことばの たね
    startsAt／endsAt     はじまる・おわる 時こく（サーバーの 時計）
    winner／reason／done／endedAt   かちまけ（reason は goal・time・left）
    cancel               とりやめ
    left/{ID}            けっかを 見おわって ぬけた しるし
  prog/{mid}/{ID}  n（打った かな）／w（何こめの ことば）／k（その 何文字め）／buf（打ちかけ）／miss／keys
```

2人とも けっかから ぬけると、その たいせんの データは 消します。

## この 作りに した 理由

**① へやばんごうの かわりに「1つの ならび」**

さがしている 子は みんな `lobby/queue` に ならびます。「ならびを 見て、だれか いれば 組む。
いなければ ならぶ」を **1回の トランザクション**で するので、同じ 子が 2人に とられません。
ならんでいる あいだは 5びょうごとに「まだ いるよ」を 出し、15びょう 出さない 子
（タブを とじた 子）は ならびから はずします。

**② じゃんけんは 1回だけ きめて、2人で 同じ ものを 見る**

2人とも えらんだら、先に 気づいた ほうが 手と「はじまる 時こく」を 書きます
（トランザクションなので 1回だけ）。2人の 画面は その 時こくに あわせて うごくので、
「じゃんけん…ぽん！」が 2人で そろいます。

**③ よーい・どん と のこり時間は サーバーの 時計**

Chromebook ごとに 時計は すこし ずれているので、サーバーの 時計との ずれを なおして 数えます。

**④ かちまけは「先に 書いた ほう」**

引ききった とき・じかん ぎれの とき、2人が 同時に 書こうと しても 1つだけ のこります。
じかん ぎれの ときは、さいごの すすみが とどくのを 1.5びょう まってから きめます。

**⑤ コンピューターは つうしんを つかわない**

ネットが ない ときや、あいてが いない ときでも れんしゅう できます。
コンピューターも 人と 同じ ローマ字の はんていで 1キーずつ 打つので、
「あいての ようす」に 打ちかけの キーが 同じ ように 出ます。

**⑥ どの 画面も スクロールしない**

画面の 高さを いっぱいに つかい、ことば・キーボード・つなの 大きさを
のこりの 場所に あわせて きめます。Chromebook の ブラウザの 上の バーの ぶん
ひくく なっても おさまるように、高さ 620 でも たしかめました。

**⑦ キーを おすたびの 音は 出さない**

30台が いっせいに 鳴ると うるさいので、音は 3・2・1、ことばを 打ちおわった とき、
まちがえた とき、じゃんけん、けっか だけです。右上の 🔊 で その 端末だけ 切れます。

## ためした こと

本物の Firebase には この 作業場所から つながらなかったので、**Firebase と 同じ うごきを する
「にせもの」**を 作って、ブラウザを 何まいも 開いて ためしました。

- **コンピューター**：タイトル → なまえ → レベル → 3・2・1 → たいせん → けっか → せいせき
  - 5だんかいの はやさを はかった（1ぷんあたり 12.5／20.8／29.8／42.6／59.3もじ。めやすどおり）
- **人と 人**（タブごとに 時計を ±2.5びょう ずらして）
  - さがす → 組む → 2人が ちがう レベルを えらぶ → じゃんけん → かった 子の レベルで たいせん（2人とも 同じ レベルが 出る）
  - 引ききって かち／60びょうで 数で きめる（ひきわけも 出た）
  - 3人が ほぼ 同時に さがす → 2人だけ 組んで 1人は まつ
  - だれも えらばない → 20びょうで じどうで えらぶ
  - えらんでいる とちゅうで あいてが タブを とじる → 「あいてが いなく なったよ」→ また さがす
  - 「やめる」で ならびから ぬける
  - たいせん中に 開きなおす → つづきから
  - 2人とも ぬけたら データが 消える
- **画面の 大きさ** 1366×768・1366×620・1280×680・1024×620 で、どの 画面も はみ出しなし

**まだ ためして いない こと**

- 本物の Firebase（ルールを はりかえたら、タブを 2つ 開いて たしかめてください）
- 「じゃんけん ぽん」の 声（ためした 場所には 声の しくみが なかったので、声が 出ないときに
  止まらない ことだけ たしかめました。Chromebook では 日本語の 声で 読みあげます）
