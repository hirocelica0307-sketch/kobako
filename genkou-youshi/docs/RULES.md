# このツールが 守る「原稿用紙の きまり」

ここに 書いてある とおりに、よこ書きの 文章が たて書きの 原稿用紙へ 組まれます。
**★印**の ついた ものは、先生の 設定（⚙）で 切りかえられます。

`tests.html` を ブラウザで ひらくと、きまりが 正しく はたらいているかを
その場で たしかめられます（27こ の たしかめ）。

---

## 紙の かたち

| 設定 | 既定 | いみ |
|---|---|---|
| `charsPerColumn` | 20 | 1行に 入る 字数（たて） |
| `columnsPerPage` | 20 | 1まいの 行数（よこ） |

**まい数は きめません。** 1まい目の さいごまで 書いて つぎの 字を 打つと、
自動で 2まい目が ふえます。3まい目も 同じです。

いんさつは **A4 たて**。マスの 大きさは 字数・行数から 自動で 計算し、
用紙に おさまるように 組みます。

## ① 数字の 書き方　★`numbers`

たて書きなので、算用数字は **漢数字**に なおします。既定は **使い分け**です。

| 打った もの | 組まれる もの | なぜ |
|---|---|---|
| `12人` | 十二人 | 数量は **位取り** |
| `350円` | 三百五十円 | 数量は **位取り** |
| `10000人` | 一万人 | 数量は **位取り** |
| `2026年` | 二〇二六年 | 年は **並べ** |
| `6年2組` | 六年二組 | 組・番・号は **並べ** |
| `080-1234-5678` | 〇八〇－一二三四－五六七八 | つながった 番号は **並べ** |

ほかに `positional`（いつも 位取り）／`serial`（いつも 並べ）／`keep`（算用数字のまま）に できます。

## ② 句読点・とじかぎが 行の はじめに 来るとき　★`hangPunctuation`

**前の行の いちばん 下の マスに、前の字と 一緒に** 入れます。

```
… た の し か っ た 。   ← 「た」と「。」で 1マス
```

`。` `、` `，` `．` `」` `』` `）` `〕` `】` `〉` `》` `｝` `］` `？` `！` が この あつかいです。
1つの マスに 入るのは **3字まで**で、それを こえる ときは つぎの行の はじめに 置きます。

## ③ 会話の おわりの 「。」」　★`combineKutenBracket`

`。」` と `、」` は **1つの マスに まとめて** 書きます。

## ④ 会話文の 書き出し　★`dialogueNewline`

- 会話は かならず **行を かえて、1マス目から** 書きます（段落の 1マスあけは しません）
- 児童が `ぼくは言った。「おはよう。」` と 1行で 打っても、`。「` の ところで 自動的に 行を かえます

## ⑤ 「」が とじた あと　★`newlineAfterQuote`

`」` で とじた **つぎの 字からは、行を かえて 1マス目から** 書きます。

```
「 お は よ う 。」          ← 会話の 行
と ぼ く は 言 っ た 。      ← つぎの 行の 1マス目から
```

## ⑥ 題名　★`title`

- **1行目**に 書きます
- 上を **3マス** あけます（`indent`）
- `align` を `center` に すると 行の まんなかに そろえます
- `enabled:false` で 題名なしに できます

## ⑦ 名前　★`name`

- **2行目**に 下づめで 書きます
- 下を **1マス** あけます（`bottomGap`）
- 姓と名の あいだを **1マス** あけます（`gapBetween`）

## ⑧ 本文の はじまり　★`bodyGapColumns`

題名・名前の つぎに 何行 あけてから 本文を はじめるか。

| 設定 | 本文が はじまる 行 |
|---|---|
| `0`（既定） | すぐ つぎの行（**3行目**）から |
| `1` | 1行 あけて（**4行目**）から |

## ⑨ 段落の はじめ　★`paragraphIndent`

**1マス** あけます。会話文（`「` で はじまる 行）は あけません。

## ⑩ 小さい字が 行の はじめに 来るとき　★`hangSmallKana`

`っ ゃ ゅ ょ ぁ ぃ ぅ ぇ ぉ ー` なども、**句読点と 同じ あつかい**です。
行の はじめに 来る ときは **前の行の 最後の マスに 一緒に** 入れます。

```
… う れ し か っ         ← 「か」と「っ」で 1マス
```

`false` に すると、そのまま 行の はじめに 書きます。

> 世の中では「小さい字は 行の はじめに 来てもよい」と する 考え方の ほうが
> よく 見られます。どちらも 正しい 書き方と されているので、
> 学校の 指導に 合わせて 切りかえて ください。

## ⑪ `！` と `？`　★`spaceAfterBangQuestion`

1マスに 書き、その あとを **1マス あけます**。
ただし つぎが `」` などの とじかぎの ときと、行の おわりの ときは あけません。

## ⑫ `……` と `——`　★`ellipsisTwoCells`

**2マス** つかいます。`...`／`…`／`。。。` は `……` に、`--`／`—`／`―` は `——` に なおします。

## ⑬ 行の おわりの `「`　★`pushOpenBracket`

`「 『 （ 〔 【 〈 《 ｛ ［` が 行の いちばん 下に 来る ときは、
そのマスを あけて **つぎの行の はじめ**に 送ります。

## ⑭ そのほか

- 半角の 字・記号は **全角**に なおします（`ABC` → `ＡＢＣ`、`!` → `！`）
- アルファベットは **1字 1マス**で たてに ならべます
- ことばの あいだの **空白は とります**（原稿用紙では 空けないため）
- 空の行（2回 改行）は 段落の 切れ目と して あつかい、空の行は 作りません

## ⑮ ふりがな（ルビ）

いまは **入れていません**。必要に なったら 足します。
