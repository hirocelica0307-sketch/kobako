# 書いた 原稿を Google スプレッドシートに 保存する（Apps Script 版）

Chromebook は、学校の 設定に よっては **ログアウトや 電源を 切った ときに
ブラウザの 中の 記録（localStorage）が 消えます**。
別の 端末で ひらいた ときも、前回の つづきは 出てきません。

卒業文集のように **何週間も かけて 書く もの**は、
**Google Apps Script の ウェブアプリとして 配る**ことを おすすめします。
児童が 学校の アカウントで URL を ひらくだけで、**前回の つづきから** 書けます。

## しくみ

```
児童の Chromebook                       先生の Google ドライブ
┌──────────────────┐   google.script.run   ┌────────────────────────┐
│ げんこうようし       │  ──────────────▶   │ Apps Script (Code.gs)    │
│ （ウェブアプリ）      │  ◀──────────────   │   ↓ 読み書き              │
└──────────────────┘   その児童のぶんだけ   │ スプレッドシート          │
   学校アカウントで                        │  げんこう / きまり シート │
   ログイン済み                            └────────────────────────┘
```

- 児童を 見分ける キーは **学校アカウントの メールアドレス**（`Session.getActiveUser()`）。
  なまえの 入力も 出席番号の 選択も いりません。
- ウェブアプリは **先生の アカウントとして 実行**されるので、
  児童に スプレッドシートの 共有権限は いりません（ほかの子の 原稿は 見えません）。
- **原稿用紙の きまりを 書きかえられるのは 先生だけ**です。
  児童の 画面には ⚙ せってい ボタンが 出ません。
- 保存は **打つのを やめて 約1.4秒後**。通信が できない ときは 端末に ためておき、
  つながった ときに 自動で 送りなおします（画面に「ほぞんまち」と 出ます）。

---

## 手順（はじめの1回だけ・15分ほど）

### 1. 記録用の スプレッドシートを 作る
Google ドライブ →「新規」→ Google スプレッドシート。
名前は「げんこうようし 記録」など。**シートは 空のままで OK**
（`げんこう` と `きまり` は 初回アクセス時に 自動で 作られます）。

### 2. Apps Script を ひらく
その スプレッドシートで **拡張機能 → Apps Script**。

### ★ はるのは この 2つだけ

| Apps Script の ファイル | はる 中身（このリポジトリ） | 大きさ |
|---|---|---|
| `コード.gs`（はじめから ある） | `genkou-youshi/gas/Code.gs` | 133行 |
| `Index`（自分で 作る HTML） | `genkou-youshi/gas/Index.html` | 1296行・52KB |

ほかに はる ものは ありません。`index.html` や `style.css`、`app.js` などは
**すでに `gas/Index.html` の 中に まとめて 入っています**。

**コピーの しかた**：GitHub で ファイルを ひらき、右上の **Raw**（生データ）を おしてから
`Ctrl + A`（ぜんぶ 選ぶ）→ `Ctrl + C`（コピー）。
Apps Script の エディタでは `Ctrl + A` → `Ctrl + V` で 中身が 入れかわります。

### 3. サーバー側の コードを はる
左の「エディタ」で `コード.gs`（`Code.gs`）を ひらきます。
はじめは `function myFunction() {}` だけが 入っているので、**中身を 全部 消して**
このリポジトリの **`gas/Code.gs`** の 内容を はりつけ。

はれたか どうかは ここで たしかめます。

- 1行目が `/**` で はじまっている
- `function doGet(){` が ある
- `function gyLoad(){` `function gySaveDoc(` `function gySaveSettings(` の 3つが ある

> **関数の 名前は 変えないで ください。**
> アプリ側が `gyLoad` `gySaveDoc` `gySaveSettings` という 名前で よびに 行きます。

### 4. アプリ本体（HTML）を はる
- 左の「ファイル」の **＋** → **HTML** → 名前を **`Index`** にする。
  - 拡張子 `.html` は 自動で つきます（`Index.html` と 打つ 必要は ありません）。
  - **I は 大文字**です。`Code.gs` の中の `createHtmlOutputFromFile('Index')` と
    名前が ちがうと 画面が 出ません。
- できた ファイルには ひな形の HTML が 入っています。**中身を 全部 消して**、
  このリポジトリの **`gas/Index.html`** の 内容を はりつけ。

はれたか どうかは ここで たしかめます。

- 1行目が `<!DOCTYPE html>`
- 2行目あたりに `このファイルは tools/build-gas.mjs が 自動生成します` と 書いてある
- いちばん 下が `</html>`

> `gas/Index.html` は `node tools/build-gas.mjs` が 自動で 作る ファイルです。
> Apps Script の 上で 直接 直しても、次に 作りなおすと 消えます。
> 直したい ときは もとの `index.html` / `style.css` / `*.js` を 直してから
> `node tools/build-gas.mjs` を もう一度 走らせて、また はりなおして ください。

- 💾 保存（プロジェクト名は「げんこうようし」などに）。

### 5. デプロイする（★ここが いちばん 大事）
右上 **デプロイ → 新しいデプロイ → 種類の選択（⚙）→ ウェブアプリ**

| 項目 | 設定する 値 |
|---|---|
| 説明 | げんこうようし v1 |
| **次のユーザーとして実行** | **自分（先生の アカウント）** |
| **アクセスできるユーザー** | **〇〇（学校の ドメイン）内の 全員** |

- 「全員（匿名を含む）」には しないで ください。だれが 書いたか わからなく なります。
- 「**ウェブアプリケーションに アクセスしている ユーザー**」として 実行に すると、
  児童に スプレッドシートの 共有が 必要に なって しまいます。

はじめての デプロイでは **アクセスの 承認**を もとめられます。

1. 「アクセスを承認」→ 先生の アカウントを えらぶ
2. 「このアプリは Google で確認されていません」と 出たら
   **詳細 →「（プロジェクト名）に移動」** を おす
3. 「許可」を おす

これは 先生が 作った スクリプトに、先生の スプレッドシートを
さわる 許可を あたえる 画面です。児童側では 出ません。

デプロイすると **ウェブアプリの URL** が 出ます。これを 児童に 配ります
（Classroom に はる、ブックマークに 入れる など）。

**まず 先生が その URL を ひらいて ください。** このとき
`げんこう` と `きまり` の シートが 自動で 作られ、
画面に **⚙ せってい** ボタンが 出れば 成功です。

### 6. 先生が きまりを 決める
先生の アカウントで その URL を ひらくと、**⚙ せってい** ボタンが 出ます。

- 1行の 字数・1まいの 行数（まい数は 書いた ぶんだけ 自動で ふえます）
- 題名と 名前の 位置、本文の はじまり
- 原稿用紙の きまり（数字の 書き方、句読点や 小さい字の 詰め方 など）

ここで 決めた ことは **`きまり` シートに 保存され、児童ぜんいんに そのまま 行きわたります**。
児童の 端末で 設定する 必要は ありません。

## 先生の 見かた・回収

`げんこう` シートに、**児童 × だいめい ごとに 1行**ずつ たまります。

| 列 | なかみ |
|---|---|
| メールアドレス | だれが 書いたか |
| なまえ | 児童が 入れた なまえ |
| だいめい | 題名 |
| 字数 | いまの 字数 |
| まい数 | いま 何まいに なっているか |
| さいごに 書いた 日時 | 進み具合が わかります |
| 本文 | 原稿そのもの |

だいめいを かえると **別の 行**に なります。
つまり、べつの 作文を 書きはじめると 前の ものは のこったままに なります。
児童の 画面に 出るのは **さいごに 書いた もの**です。

- 並べかえや フィルタで「まだ 書いていない子」が すぐ わかります。
- 本文の 列を コピーすれば、文集の 版下づくりに そのまま つかえます。

## 先生を ふやす

もう1人 設定を さわれる 先生を 足したい ときは、
Apps Script の **プロジェクトの設定 → スクリプト プロパティ**で

| プロパティ | 値 |
|---|---|
| `TEACHERS` | `senseiA@school.jp, senseiB@school.jp` |

を 追加します（カンマ区切り）。

## うまく いかない とき

| ようす | みるところ |
|---|---|
| 「つながりません」と 出る | デプロイの「アクセスできるユーザー」が 学校ドメイン内に なっているか |
| ほかの子の 原稿が 見える | 「次のユーザーとして実行」が **自分（先生）**に なっているか |
| ⚙ が 出ない（先生なのに） | デプロイした アカウントと ログインしている アカウントが 同じか。ちがうなら `TEACHERS` に 足す |
| 「ほぞんまち」の まま | 通信が 切れています。つながれば 自動で 送ります。端末には のこっています |
| コードを 直した のに かわらない | **デプロイ → デプロイを管理 → 編集（鉛筆）→ バージョン「新バージョン」→ デプロイ** |
