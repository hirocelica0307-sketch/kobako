# げんこうようし

よこ書きで 打った 文章を、**原稿用紙の きまりどおりに たて書きへ 自動で 組む**
小学生むけの 入力ツールです。Chromebook での 利用を 想定しています。

- 左で **ふつうに よこ書きで 打つ**と、右の **原稿用紙に たて書きで** すぐ 組まれます
- 段落の 1マスあけ、行の はじめに 来た 句読点の 詰め、かぎかっこ、数字の 書き方など
  **原稿用紙の きまりを 自動で 守ります**（→ [docs/RULES.md](docs/RULES.md)）
- **なおした ところは 色が つき**、マスに さわると「なぜ そう なったか」が 出ます
- **まい数は きめません**。1まい目の さいごまで 書いて つぎの 字を 打つと、自動で 2まい目が ふえます
- **A4 たてに 実物大で いんさつ**できます（PDF 保存も 同じ）

## 2つの つかいかた

### A. Apps Script 版（おすすめ・学校アカウント運用）
児童が 学校の Google アカウントで URL を ひらくだけで、**前回の つづきから** 書けます。
端末が かわっても、電源を 切っても 原稿は のこり、
先生は スプレッドシートで **全員の 進み具合と 本文**を 見られます（回収も ここから）。
先生が きめた きまりは、児童ぜんいんに そのまま 行きわたります。

→ 手順は **[docs/SETUP-GAS.md](docs/SETUP-GAS.md)**（初回15分ほど）

### B. ファイルを そのまま ひらく（お試し・家庭用）
`index.html` を ブラウザで ひらくだけ。通信も インストールも いりません。

```
cd genkou-youshi
python3 -m http.server 8000    # → http://localhost:8000
```

記録は **その端末の ブラウザにだけ** 保存されます。
Chromebook は 設定に よっては ログアウトで 消えるので、
大事な 文章は A 版か、こまめな いんさつと 合わせて つかって ください。

1. **⚙ せってい**（先生用）で 1行の 字数・1まいの 行数を きめる
2. 「だいめい」「なまえ」「本文」を よこ書きで 打つ
3. 右の 原稿用紙が そのつど 組みなおされます
4. 「いんさつ」で A4 に 出す

## 先生の せってい（⚙）

| 項目 | なかみ |
|---|---|
| マス | 1行の 字数・1まいの 行数（まい数は 自動） |
| 題名 | つかうか・上を 何マス あけるか・まんなかそろえ |
| 名前 | つかうか・下を 何マス あけるか・姓と名の あいだ |
| 本文 | すぐ つぎの行から／1行 あけてから・段落の あけ |
| きまり | 数字の 書き方、句読点の 詰め、小さい字の 詰め、「。」」、会話文、「」の あと、！？、……、行末の「 |

きめた ことは、**「コードを 作る」で 出た 文字を 児童の 端末に 貼る**だけで
そろえられます（Apps Script 版では 自動で 行きわたるので ふようです）。

## きまりを たしかめる

`tests.html` を ブラウザで ひらくと、原稿用紙の きまり 20こ が
正しく はたらいているかを 一覧で 見られます。
