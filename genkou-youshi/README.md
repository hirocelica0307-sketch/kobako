# げんこうようし

よこ書きで 打った 文章を、**原稿用紙の きまりどおりに たて書きへ 自動で 組む**
小学生むけの 入力ツールです。Chromebook での 利用を 想定しています。

- 左で **ふつうに よこ書きで 打つ**と、右の **原稿用紙に たて書きで** すぐ 組まれます
- 段落の 1マスあけ、行の はじめに 来た 句読点の 詰め、かぎかっこ、数字の 書き方など
  **原稿用紙の きまりを 自動で 守ります**（→ [docs/RULES.md](docs/RULES.md)）
- **なおした ところは 色が つき**、マスに さわると「なぜ そう なったか」が 出ます
- **卒業文集**にも、**ふだんの 授業**にも つかえます（「かだい」で 切りかえ）
- **A4 たてに 実物大で いんさつ**できます（PDF 保存も 同じ）

## つかいかた

`index.html` を ブラウザで ひらくだけ。通信も インストールも いりません。

```
cd genkou-youshi
python3 -m http.server 8000    # → http://localhost:8000
```

1. 上の「かだい」を えらぶ（字数・枚数・題名や 名前の きまりが かわります）
2. 「だいめい」「なまえ」「本文」を よこ書きで 打つ
3. 右の 原稿用紙が そのつど 組みなおされます
4. 「いんさつ」で A4 に 出す

## かだい（はじめから 入っている もの）

| かだい | マス | 枚数 | 題名 | 名前 |
|---|---|---|---|---|
| そつぎょう文集 | 20字×20行 | 2まい | あり | あり |
| 読書かんそう文 | 20字×20行 | 1まい | あり | あり |
| 今日の ふりかえり | 20字×10行 | 1まい | なし | あり |

かだいは `config.js` の `GY_PRESETS` に 書いてあります。

## きまりを たしかめる

`tests.html` を ブラウザで ひらくと、原稿用紙の きまり 20こ が
正しく はたらいているかを 一覧で 見られます。

## ファイル

| ファイル | なかみ |
|---|---|
| `index.html` | 画面 |
| `style.css` | 見た目・いんさつの 設定 |
| `config.js` | **きまりの 既定値**と かだい |
| `normalize.js` | 打った 文章を なおす（数字 → 漢数字 など） |
| `compose.js` | 文章を **マスに わりつける**（禁則処理） |
| `app.js` | 画面の うごき |
| `tests.js` / `tests.html` | きまりの たしかめ |
| `docs/RULES.md` | **守っている きまりの 一覧** |

## これから

- 段階2 … 先生の 設定画面（字数・枚数・題名や 名前の 位置を その場で 変える）
- 段階3 … **Google スプレッドシート連携（Apps Script）**。
  学校アカウントで ひらくだけで 前回の つづきから 書け、先生は シートで 回収できます。
  いまは 端末の 中（localStorage）にだけ 下書きを 保存しています。
  Chromebook は 設定に よっては ログアウトで 消えるので、**段階3までは 大事な 文章を
  これだけに たよらないで ください**
- 段階4 … 字数の めやす表示、ふりがな など
