# ひこうき線バトル（仮）

1台の Chromebook を **2人で こうたいで つかう**、マス目の 上の たいせんゲームです。
ひこうきを 3きずつ おいて、**サイコロの 目の 数だけ 線を のばし**、あいての ひこうきを 先に 3き ぜんぶ げきつい した ほうの かち。

- 対象：小学2年生（2人たいせん）
- Chromebook の よこ画面（1366×768）が 基準。タブレットでも うごきます（タッチ・マウス どちらも OK）
- **index.html 1ファイル** だけ。ライブラリ・外部の フォント・画像・音声ファイルは つかいません（オフラインでも うごく）
- 保存するのは せってい（名前・ばんめんの 大きさ・音）だけ。localStorage が つかえなくても うごきます

## ルール（計画書 2 の とおり）

- 線は マス目の「線の 上」を 交点から 交点へ 1目盛りずつ（1目盛り ＝ 1歩）
- はいち：じぶんの じんち（左半分＝あか・右半分＝あお）だけ。外周・まん中の 線の 上・ほかの ひこうきから 2目盛り いないは だめ
- 1ターン：サイコロ → （線が なければ）ひこうきを えらぶ → 光っている 点を タップして 1歩ずつ → 目の 数だけ すすんだら「けってい」
- 通れる：何も ない 道・じぶんの 線の 上（今の 線・前の 線とも。1歩に かぞえる）・あいての 線と **点で 交わる だけ**
- 通れない：あいての 線と 同じ 道・じぶんの ひこうき・げきつい された ひこうき・ばんめんの 外
- あいての 生きている ひこうきに 入ったら **げきつい**。そこで ターンおわり（のこりの 歩数は すてる）・線も そこで おわり（かべとして のこる）
- ターンの はじめに 先っぽが 行き止まりなら「いきどまり！」→ その 線を あきらめて ひこうきから 出なおす
- どの ひこうきからも すすめなければ パス。2人 つづけて パスなら ひきわけ
- 3き目を げきつい した しゅんかんに けっか画面

やっては いけない ところを タップすると、その 点が 赤く 小さく ゆれる だけです（文章の けいこくは 出しません）。

## 計画書で きまって いなかった ところ（こう しました）

| ところ | こう した |
|---|---|
| 先攻の 表示 | 「スタート」を おした ときに きめて、はいちの あと たいせんが はじまる ときに 大きく 出す |
| はいち | じぶんの ひこうきを タップすると とりけせる。「おまかせ」は 3き ぜんぶ おきなおす（おす たびに ちがう おきかた） |
| 1歩 もどす | ひこうきから 出た ばかりの 線を ぜんぶ もどすと、ひこうきを えらびなおせる |
| ターンの 途中の 行き止まり | 「いきどまり！」と 出して、「けってい」を まつ（それまでは 1歩 もどせる） |
| 3き目の げきつい | すぐ けっか画面。けっか画面の ばんめんで、さいごの ひこうきが ゆれて × に なる |
| 手番の こうたい | 毎ターン「○○チームの ばん」を 大きく 出す（タップで とばせる） |
| turnEdges | 1歩ごとに 1つ 入れる（あたらしく 登録した 辺の キー、登録しなかった ときは `null`）。同じ 辺を 行き来しても 1歩 もどすが くるわない |
| のこり 歩数 | 「のこり 3ぽ」の かわりに「のこり 3歩」（2ほ・6ぽ の よみの ちがいを さけるため。歩 は 2年生の 漢字） |
| キーボード | <kbd>Space</kbd>／<kbd>Enter</kbd>：サイコロ・けってい、<kbd>Backspace</kbd>／<kbd>Ctrl</kbd>+<kbd>Z</kbd>：1歩 もどす |

## ファイル

```
hikouki-sen/
├── README.md    このファイル
├── index.html   アプリ ぜんぶ（見ため・ルール・うごき・音）
└── tests.js     ルールの たしかめ 61こ（node tests.js）
```

`index.html` の 中の「`// ==LOGIC==`」〜「`// ==/LOGIC==`」が 画面を つかわない ルールの ぶぶん
（`canMove`・`step`・`undoStep`・`beginTurn`・`placeValid`・`autoPlace` など。どれも state を うけとる）で、
`tests.js` は そこだけ とりだして、計画書「6-2 テスト項目」の 判定を たしかめます。

画面の 大きさ・タッチ／マウスは Chromium（1366×768・タッチ あり／なし・タブレット たて 800×1280）で
小・中・大 それぞれ はいち → たいせん → さいごまで あそんで たしかめました（ばんめんは はみ出さず、交点の 当たり判定は 50px いじょう）。
