# ことばの なかま

2年生 こくご「**ことばを まとめよう**」の ページを、**ことばカードを 手で うごかして** 学ぶ アプリです。
カードを はこに 入れて なかまに まとめ、はこに **なかまを まとめて よぶ ことば（なまえ）** を つけ、
さいごに **あつめた ことばを つかって 文を 作ります**。

- 対象：小学2年生（こくご「ことばを まとめよう」／ことばの広場）
- Chromebook（タッチ・マウス・ペン）・タブレット・スマホで つかえます
- **index.html 1ファイル** だけで うごきます。サーバー・ログイン・外部ライブラリは つかいません
- 点数・ランキングは ありません

## ひらきかた

**https://hirocelica0307-sketch.github.io/kobako/kotoba-nakama/**

`index.html` を Chrome で ひらくだけです（ファイルとして ひらいても うごきます）。

## つかいかた（子ども）

1. **カードを うごかす**
   - カードを **ドラッグ** して はこへ（指・マウス・ペン どれでも）
   - または カードを **タップ** して えらんでから、入れたい **はこを タップ**
     （えらんで いる ときに はこの 中の カードを さわっても、その はこに 入ります）
   - はこから カードおきば へ もどす ことも できます
2. **はこに なまえを つける**：はこの うえの「✏️ なまえを つける」を タップ。
   こうほから えらぶか、じぶんで 書きます（キーボード・手書き入力）
3. **✅ たしかめる**
   - ◎（花まる）… ことばも なまえも ぴったり
   - ○ … 大きな なかま（いきもの・たべもの など）や じぶんで 考えた なまえ、おなじ なかまの はこが 2つ ある とき
   - ！… なかまに なって いるけど なまえが ない
   - ？… ちがう なかまが まじって いる（まじった カードに **？** が つき、ゆれます）／なまえが あわない
   - ぜんぶ ◎・○ で カードが のこって いなければ「ぜんぶ なかまに まとめられたね！」
4. **✏️ 文を つくる**（▼あつめた ことばを つかって、文を 作りましょう。）
   - **かたを つかう**：3つの かたから えらんで、ひだりの ことばを タップして あなを うめます
     - 「＿＿の なかまには、＿＿や ＿＿が あります。」
     - 「＿＿は、＿＿の なかまです。」
     - 「＿＿と ＿＿は、どちらも ＿＿です。」
     - 「できた！」で リストへ。はこの ならべかたと あって いれば ◎、あって いなければ ？
   - **じぶんで 書く**：じゆうに 書けます（ことばを タップすると カーソルの ところに 入ります）
   - 🔊 で 文を よみあげ

## ことばの セット（⚙️ で きりかえ）

| セット | ことば | なかま |
|---|---|---|
| **きょうかしょ**（はじめ） | だいこん・さくら・しまうま … てんとう虫 の 18まい（ページと おなじ じゅん） | やさい・花・どうぶつ・さかな・虫 ＋ れい「くだもの」（メロン・みかん・いちご） |
| がっこう・くらし | でんしゃ・ピアノ・えんぴつ・シャツ など 16まい | のりもの・がっき・ぶんぼうぐ・ふく |
| いろ・きせつ・からだ・てんき | あか・はる・あたま・はれ など 16まい | いろ・きせつ・からだ・てんき |

セットごとに ならべた ようすと 文が べつべつに のこります。
URL の うしろに `#set=kurashi`（がっこう・くらし）・`#set=kotoba`（いろ・きせつ…）を つけると、その セットで ひらきます。

## たしかめの きまり

- ことばは それぞれ **なかま（タグ）** を もちます。はこの ことば **ぜんぶに 共通する なかま** が あれば「なかま」
  - さくら・うめ は「花」でも「木」でも OK（`extra`）
  - やさい・くだもの・さかな は「たべもの」、どうぶつ・さかな・虫 は「いきもの」、やさい・花・木 は「しょくぶつ」、がっき・ぶんぼうぐ は「どうぐ」にも 入ります（大きな なかま）
- 大きな なかまで しか まとまらない とき（だいこん と いわし など）は、なまえが「たべもの」なら ○、ちがえば ？
- はこの なまえは ひらがな・カタカナ・漢字（野菜・魚・動物 など）・「〜の なかま」「〜たち」を 同じと みなします。
  しらない なまえ（「うみの いきもの」など）は、ことばが なかまに なって いれば ○ に します

## せってい（⚙️）

| こうもく | はじめ | ないよう |
|---|---|---|
| ことばの セット | きょうかしょ | 上の 表 |
| れい「くだもの」の はこ | 出す | きょうかしょの れい（メロン・みかん・いちご が 入った はこ） |
| はこの なまえの こうほ | 出す | 出さない ときは じぶんで 書く（考える 力を 見たい とき） |
| なかまの 色（ヒント） | なし | おなじ なかまの カードを おなじ 色の わくに する（つまずいた 子の ささえ） |
| カードの ならび | きょうかしょ | 「まぜる」は「はじめから」の ときに ならびを かえます |
| こうかおん | オン | ブラウザで 合成した みじかい おと |
| カードを よみあげる | オフ | カードを えらんだ ときに こえで よむ |
| はじめから やりなおす | — | いまの セットの ならべかたと 文を けす |

ならべた ようす・なまえ・文は、その パソコンの ブラウザ（localStorage）に のこります。

## ファイル

```
kotoba-nakama/
├── README.md    このファイル
├── index.html   アプリ ぜんぶ（見ため・きまり・うごき）
└── tests.js     きまりの たしかめ 72こ（node tests.js）
```

`index.html` の 中の「`// ==LOGIC==`」〜「`// ==/LOGIC==`」が 画面を つかわない ぶぶん
（ことばの データ・なまえの よみかえ・はこの たしかめ・文の たしかめ・ほぞんデータの しらべ）で、
`tests.js` は そこだけ とりだして たしかめます。

## きめて ほしい こと

- **ことばを たす・かえる**：`index.html` の `SETS` に ことばを 1つ たす ときは、`groups` と `order` の 両方に 書きます
- **なまえの 書きかたを みとめる**：`CATS` の `alias` に たします（れい：`やさい` に「あおもの」）
- **アプリの 名前**：いまは「ことばの なかま」。`<title>` と `<h1>` を かえます
