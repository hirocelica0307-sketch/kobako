# むかしばなし文庫（ぶんこ）

2年生 こくご「かさこじぞう」→「むかしばなしを しょうかいしよう」で つかう、日本の むかしばなしの 本棚アプリです。
Chromebook や タブレットで ひらいて、たて書きの 本を 右から 左へ めくって 読みます。

**https://hirocelica0307-sketch.github.io/kobako/mukashi-banashi/**

- 名前は 仮称です。
- `index.html` を ひらくだけで うごきます（サーバーも ログインも いりません）。

## できること

- **本だな**：むかしばなし **40わ**。「ゆうめいな おはなし・どうぶつ・おに／ようかい・ふしぎ・わらいばなし・とんち・おんがえし」で しぼりこめる。読みおわった 本には「よんだ」の はんこ（その 端末だけに 記録）。
- **1つの おはなしに 2つの 長さ**
  - **えほん**（みじかい）：1わ 6〜7ばめん・やく 130〜210字。見開きの 右に 絵、左に 大きな 字（分かち書き）。字を 読むのが にがてな 子 むけ。
  - **よみもの**（ながい）：1わ やく 640〜1160字（3〜5分）。教科書と おなじ たて書き・分かち書き なし。ばめんごとに 絵。
- **漢字は 2年生までに ならう 漢字だけ**（学年別漢字配当表の 1年 80字・2年 160字）。漢字には **ぜんぶ よみがな**。3年生 いじょうの 漢字の ことばは ひらがなで 書いて いる。
- **むかしの ことば**：本文の 中の むかしの ことば・方言・むかしの もの（〜じゃ・〜のう・じさま・どっとはらい・いろり など）に 色と 点線が ついて いて、おすと「いまの ことばで いうと」と せつめい、その ことばが 出てくる ほかの おはなしの 文が 出る。
- **むかしことば じてん**：約 220語を 10の なかまに わけた。はじまりの ことば（むかしむかし・とんとむかし・むかしあったずもな・いまはむかし）、おわりの ことば（めでたしめでたし・どっとはらい・どんとはれ・とっぴんぱらりのぷう・いちごさけた・それきり）、人の よびかた、「わたし」「あなた」、文の おわりかた、あいさつ・かけごえ、むかしの もの、むかしの いいかた、おとの ことば。
  おはなしごとに ちがう 地方の はじまり・おわりの ことばを つかって いるので、くらべて 読める。
- **字の 大きさ** 4だんかい・ゆびで すべらせて めくる／← → キー。音声（よみあげ）は つけて いない（依頼者の きぼう）。
- **絵**：9わ（ももたろう・うらしまたろう・したきりすずめ・かちかちやま・はなさかじいさん・さるかにかっせん・かぐやひめ・くらげ ほねなし・こぶとりじいさん）は、著作権の 切れた 明治の 昔話の 本の 絵（尾崎『The Japanese Fairy Book』1908年・長谷川武次郎の ちりめん本の ひょうし）。ほかは Fluent Emoji 3D。画風が まざって よい ことは 依頼者と きめた。
- おはなしの さいごの ページに「この おはなしに 出て きた むかしの ことば」の 一覧（しょうかいの 学習で つかう）。

## おはなし（40わ）

ももたろう／うらしまたろう／つるの おんがえし／したきりすずめ／かちかちやま／はなさかじいさん／さるかにかっせん／いっすんぼうし／きんたろう／かぐやひめ／ねずみの よめいり／おむすびころりん／わらしべちょうじゃ／ぶんぶくちゃがま／こぶとりじいさん／てんぐの かくれみの／さんまいの おふだ／ききみみずきん／三年ねたろう／へっぴりよめさま／ふるやの もり／えとの はじまり／ねずみの すもう／うりこひめ／だいくと おにろく／かもとりごんべえ／ふくろうの そめものや／くらげ ほねなし／きつねと たぬきの ばけくらべ／あめは どく／ちゃ・くり・かき／かっぱの おれい／たにしちょうじゃ／しおふきうす／天に のぼった おけやさん／ちからたろう／まめと すみと わら／うしかたと やまんば／ゆめかいちょうじゃ／さるじぞう

- 「かさこじぞう」は 教科書で 読むので 入れて いません（依頼者と きめた）。
- 文は すべて、日本の 民話（作者の いない むかしばなし）を もとに、この アプリの ために あたらしく 書いた もの です。絵本や 教科書の 文を うつしては いません。
- こわすぎる ところ（したきりすずめの したを 切る・かちかちやまの ばあさまが ころされる など）は、2年生 むけに やわらげて います。

## ファイル

| ファイル | なかみ |
|---|---|
| `index.html` | アプリ（画面・ページわけ・じてん） |
| `parse.js` | 本文の 書き方を よみとる（アプリと テストで つかう） |
| `stories/s01.js`〜`s08.js` | おはなしの 本文（1ファイル 5わ） |
| `kotoba.js` | むかしことば じてん |
| `assets/` | 絵と アイコン（`assets/README.txt` に 入手もと と ライセンス） |
| `tests.js` | `node tests.js` で、漢字が 2年生までか・よみがなが ぜんぶ あるか・じてんに のって いない ことばが ないか・絵が あるか を たしかめる（`-v` で おはなしごとの 字数） |
| `tools/` | 絵の 一覧 `assets/images.js` を つくる スクリプト など |

### 本文の 書き方（`stories/*.js`）

```
漢字《よみ》        よみがな（すぐ前の 漢字の ならびに つく）
〔ことば〕          むかしの ことば（じてんの みだしと おなじ とき）
〔見せる 字=みだし〕  むかしの ことば（「おったそうな」→ じてんの「そうな」など）
#え peach water-wave  ここから あたらしい ばめん。絵の なまえ（assets/images.js）
空の 行             だんらくの くぎり
```

えほんの 文（`ehon`）は 分かち書き（ことばの あいだに 半角スペース）で 書く。
