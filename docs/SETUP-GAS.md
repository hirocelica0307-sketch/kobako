# 児童ごとの記録を Google スプレッドシートに保存する（Apps Script 版）

Chromebook は 電源を切ったり 別の端末を使ったりすると、ブラウザ内の記録（localStorage）が
消えることがあります。**Google Apps Script のウェブアプリとして配布**すれば、
以前お使いだった「スプレッドシート＋GAS」と同じしくみで、
**児童が自分の学校アカウントで開くだけで、前回の続きから遊べます**（セーブ操作は不要）。

## しくみ

```
児童の Chromebook                     先生の Google ドライブ
┌─────────────────┐      google.script.run     ┌──────────────────────┐
│ ひっさんモンスター   │  ───────────────────▶  │ Apps Script (Code.gs)  │
│ （ウェブアプリ）     │  ◀───────────────────  │   ↓ 読み書き            │
└─────────────────┘   その児童のデータだけ      │ スプレッドシート        │
   学校アカウントで                            │  progress / log シート  │
   ログイン済み                                └──────────────────────┘
```

- 児童を見分けるキーは **学校アカウントのメールアドレス**（`Session.getActiveUser()`）。
  ログイン名の入力も、出席番号の選択も要りません。
- ウェブアプリは **先生のアカウントとして実行**されるので、
  児童にスプレッドシートの共有権限は不要です（他の子の記録は見えません）。
- 保存のタイミングは **ステージクリア時**と**設定変更時**、
  それに画面を閉じたとき。通信量をおさえています。

---

## 手順（はじめの1回だけ・15分ほど）

### 1. 記録用のスプレッドシートを作る
Google ドライブ →「新規」→ Google スプレッドシート。
名前は「ひっさんモンスター 記録」など。**シートは空のままで OK**
（`progress` と `log` は初回アクセス時に自動で作られます）。

### 2. Apps Script を開く
そのスプレッドシートで **拡張機能 → Apps Script**。

### 3. サーバー側のコードを貼る
- 左の「エディタ」で `コード.gs`（`Code.gs`）を開き、中身を全部消して
  このリポジトリの **`gas/Code.gs`** の内容を貼り付け。

### 4. アプリ本体（HTML）を貼る
- ファイルの「＋」→ **HTML** → 名前を **`Index`** にする（拡張子 `.html` は自動）。
- 中身を全部消して、このリポジトリの **`gas/Index.html`** の内容を貼り付け。
  - `gas/Index.html` は `node tools/build-gas.mjs` で自動生成されるファイルです
    （`index.html` + `style.css` + `monsters.js` + `app.js` を1つにまとめたもの）。
- 💾 保存（プロジェクト名は「ひっさんモンスター」などに）。

### 5. デプロイする（★ここが一番大事）
右上 **デプロイ → 新しいデプロイ → 種類の選択（⚙）→ ウェブアプリ**

| 項目 | 設定する値 |
|---|---|
| 説明 | ひっさんモンスター v1 |
| **次のユーザーとして実行** | **自分（先生のアカウント）** |
| **アクセスできるユーザー** | **〇〇（学校のドメイン）内の全員** |

- 「全員（匿名を含む）」にはしないでください。誰が遊んだか分からなくなります。
- 「**ウェブアプリケーションにアクセスしているユーザー**」として実行にすると、
  児童一人ひとりにスプレッドシートの編集権限が必要になり、他の子の記録も見えてしまいます。**選ばないでください。**

「デプロイ」→ 権限の承認（初回のみ。自分のアカウントで許可）→
表示される **ウェブアプリの URL（`https://script.google.com/a/macros/……/exec`）** をコピー。

### 6. 動作を確かめる
1. スクリプトエディタで関数 **`checkMe`** を選んで「実行」。
   実行ログに `OK: 先生のメールアドレス` と出れば、メールアドレスの取得はできています。
2. コピーした URL を自分で開いて、右上に自分の名前が出ること、
   1ステージ遊んでスプレッドシートの `progress` シートに行が増えることを確認。
3. できれば児童アカウント1つでも開いてみて、名前が出るか確認。

### 7. 児童に配る
URL を Google Classroom に貼る／ブックマークに登録する／QR コードにする など。
児童は開くだけ。**前回の続き（★・モンスター・成績）から始まります。**

## 記録の見かた

**progress シート**（児童1人 = 1行、いつでも最新）

| 列 | 内容 |
|---|---|
| メールアドレス / なまえ | 児童の識別 |
| さいごにあそんだ日時 | 最終プレイ |
| ★ごうけい / モンスター | 集めた数 |
| といたもんだい / まちがい / いっぱつ正解率(%) | 練習量と定着のめやす |
| ステージ別★(1〜9) | `3 2 0 1 …` のように 9ステージ分 |
| data(JSON) | アプリが読み書きする本体（さわらないでください） |

**log シート**：ステージをクリアするたびに1行追記（日時・ステージ・★・まちがい）。
ピボットテーブルやグラフで「いつ・どの単元でつまずいているか」が見られます。

> 記録を消したいときは、その児童の **progress の行を削除**してください（次回は最初から）。
> クラス替えなどで全部消すときは `progress` シートの2行目以下を削除。

## アプリを更新するとき

1. 手元で `index.html` / `style.css` / `app.js` / `monsters.js` を直す
2. `node tools/build-gas.mjs` を実行して `gas/Index.html` を作り直す
3. Apps Script の `Index.html`（と、変えたなら `Code.gs`）に貼り直す
4. **デプロイ → デプロイを管理 → 鉛筆（編集）→ バージョン「新バージョン」→ デプロイ**

この手順なら **URL は変わりません**。児童の記録もそのまま残ります。
（「新しいデプロイ」を選ぶと URL が変わってしまうので注意）

## うまくいかないとき

| 症状 | 原因と対処 |
|---|---|
| 「⚠ きろくを ほぞん できません」と出る | メールアドレスが取得できていません。デプロイ設定（実行=自分／アクセス=ドメイン内の全員）を見直してください。児童が学校ドメイン外のアカウントでログインしている場合も同じです |
| 「⚠ つうしん エラー」 | ネットワークが切れた／スクリプトのエラー。そのままでも遊べます（その端末には記録が残り、次に通信できたときに送られます） |
| 他の子の記録が見えてしまった | 「アクセスしているユーザーとして実行」でデプロイしています。設定を変えて再デプロイしてください |
| 記録が混ざる | 共用端末で前の児童がログアウトしていない可能性があります |

**クォータの目安**：1ステージあたりのサーバー通信は2回程度です。
40人 × 1日10ステージでも 800 回ほどで、Google Workspace の実行時間の上限には十分おさまります。

## 保存方法の選択肢（まとめ）

| 方法 | 児童ごとの記録 | 先生が見られるか | 手間 |
|---|---|---|---|
| **Apps Script ＋ スプレッドシート（おすすめ）** | ◎ アカウントごとに自動 | ◎ 一覧・グラフ化も可 | 初回15分 |
| GitHub Pages など静的公開 | △ その端末のブラウザにだけ | ✕ | 5分 |
| ファイルを配って `index.html` を開く | △ 同上 | ✕ | すぐ |

学校アカウントで運用されるなら、**Apps Script 版**をおすすめします。
端末が変わっても、電源を切っても、続きから遊べます。
