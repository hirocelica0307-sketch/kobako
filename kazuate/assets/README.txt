ふたりで数字あて ― つかって いる 素材（assets/）
==================================================================

この フォルダーの 素材は、すべて 下の ライブラリから ダウンロードして 保存した ものです。
ライセンスの 全文は リポジトリ直下の THIRD_PARTY_LICENSES.txt に あります（画面には 表示しません）。

1. emoji/*.webp・icon-*.png・favicon.png … Microsoft Fluent Emoji「3D」（MIT License）
   入手もと: https://github.com/microsoft/fluentui-emoji （assets/<名前>/3D/*_3d.png）
   ライセンス確認: https://github.com/microsoft/fluentui-emoji/blob/main/LICENSE（MIT）を 2026-11-22 に 確認
   加工: emoji/ は 192×192 に 縮めて WebP（品質 90）に しました。
         icon-180/192/512.png は Input numbers を クリーム色（#fff4e8）の 正方形の まん中に おいた もの、
         favicon.png は 64×64 に 縮めた もの。

2. ボタンは 文字だけで、UI アイコン（Iconify など）は つかって いません。
