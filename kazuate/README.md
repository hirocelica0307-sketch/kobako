# ふたりで数字あて（名前は 仮称）

ふたりが **それぞれの スマホ** で あそぶ 数字あて（ヒット＆ブロー）です。待ち時間の ひまつぶし用。
ビルドは いりません（`index.html` を ひらくだけ）。1回 1〜3分。

## あそびかた

1. ふたりとも、0〜9 の ちがう 数字で 3けた（または 4けた）の **ひみつの 数字** を 決める（0 から はじまっても よい）
2. こうたいで 相手の 数字を **コール** する
3. 相手の スマホが 自動で こたえる：**ヒット**＝数字も 場所も あう／**ブロー**＝数字は あるが 場所が ちがう
   （例：ひみつ 427 に コール 472 → 1ヒット 2ブロー）
4. 先に ぜんぶ ヒットに した 人の 勝ち。先攻が 当てたら 後攻にも **最後の 1回** が あり、後攻も 当てたら 引き分け
5. 先攻は 1回ごとに こうたい

## 画面

| 画面 | なかみ |
|---|---|
| はじめ | 名前・部屋を つくる・番号で 入る・ひとりで 練習・遊び方 |
| 番号で 入る | 名前と 4けたの 部屋番号（招待リンクから 来たら 番号は 入って いる） |
| 部屋 | 部屋番号（大きく）・**招待リンクを 送る**（スマホの 共有 → LINE など。共有が ない ときは コピー）・ふたりの つながり・けた数（3／4）・はじめる |
| ひみつの 数字 | キーパッドで 入れる か「おまかせ」・先攻は どちらか・相手が 決めたか |
| コール | 上の 帯（メニュー・第何戦・通算）・いま だれの 番か・**あなたの コール／相手の コール** の タブ（相手の コールは、自分の 数字に たいして どこが あたったか 色で 見える）・**メモ**（0〜9 を タップで ✕→○→なし。キーの 色にも 出る）・**ひとこと**（6つの スタンプが 相手の 画面に 出る）・キーパッド（相手の 番でも 先に 入れて おける） |
| 結果 | 勝ち／負け／引き分け・何回で 当てたか・ふたりの 数字・**答えに まちがいが なかったか の たしかめ**・通算・ふりかえり（両方の コール）・つぎの けた数・もう1回 |
| ひとりで 練習 | コンピューターの 数字を 当てる。けた数ごとの じこベスト |

そのほか

- 自分の 番に なると 少し ふるえる（ふるえる 機能の ある Android など）
- 相手の 接続が 切れると 知らせる。ページを 読みなおしたり アプリを とじたり しても、同じ 部屋・同じ 勝負に もどる
- メニュー：遊び方・こうさん・部屋を 出る（ホストが 出ると 部屋が なくなる。ゲストが 出ると ホストは 部屋で つぎの 人を 待つ）
- スマホの ダークモードに あわせて 暗い 色に なる

## ずるが できない しくみ

ひみつの 数字は **自分の スマホの 中だけ**（localStorage）に あり、つうしんでは
SHA-256 の ハッシュ（数字＋ランダムな 塩。数字は わからない）だけを 先に おくります。
コールへの こたえは、コールされた 人の スマホが 自動で 計算して 書きます。
勝負が おわったら 数字と 塩を 見せあい、ハッシュと これまでの こたえが あって いるかを
相手の スマホが たしかめて「答えに まちがいなし」と 出します。

## Firebase の 設定

「花札 こいこい」「なみ麻雀」などと **同じ Firebase プロジェクト（`hiro-kobako`）** を つかいます
（`firebase-config.js` は 同じ なかみ）。やることは **ルールの はりかえ 1つ だけ** です。

Realtime Database の **「ルール」** タブを 開いて、中身を ぜんぶ `database.rules.json` に おきかえて「公開」。
（ほかの アプリの `database.rules.json` も 同じ なかみに そろえて あります。`kazuate` の ぶぶんが ふえただけ です。）

ルールを まだ はりかえて いなくても 遊べます：`kazuate/rooms` が ことわられた ときは、
どの 版の ルールにも ある `rooms/{番号}/kazuate` に しまいます（花札と 同じ やりかた）。

しまう 場所：

```
kazuate/rooms/{4けた}/
  meta            ホスト・ゲスト・名まえ・けた数・何回めの 勝負か・先攻・結果（results/g1 …）・さいごに さわった 時こく
  online/host     いま つながっているか（とじると きえる）
  online/guest
  log/{n}/{0000}  n 回めの 勝負の ログ（1つずつ。いちど 書いたら 上書き できない）
```

ログの しゅるい：ひみつの 数字の ハッシュ・コール・こたえ・こうさん・数字を 見せる・ひとこと。
ふたりの スマホは 同じ ログから `logic.js` の `reduce()` で 同じ じょうたいを つくります。

## ファイル

```
kazuate/
├── index.html           画面の わく
├── style.css            見ため（スマホの たて画面・ダークモード）
├── app.js               画面と さわった ときの うごき・自動で こたえる
├── logic.js             きまり（ヒット・ブロー・順番・勝ち負け・ハッシュ・たしかめ）
├── net.js               つうしん（部屋・ログ）。?fake で にせものに なる
├── firebase-config.js   Firebase の 設定（ほかの アプリと 同じ）
├── database.rules.json  Realtime Database に はる ルール
├── tests.html / tests.js きまりの たしかめ（ブラウザ、または node kazuate/tests.js）
└── assets/              絵と アイコン（Fluent Emoji 3D。くわしくは assets/README.txt）
```

## ためしたこと

- `tests.html`（`node kazuate/tests.js`）：ヒット・ブローの 数え方、正しい 数字の きまり、番でない コール／
  ちがう 人の こたえを むしする、後攻が 先に 当てた／先攻が 当てて 最後の 1回／引き分け、こうさん、
  ログの ぬけ、ハッシュと こたえの たしかめ（ごまかしを 見つける）、ランダムな 対戦 300回 ― 14こ ぜんぶ OK
- ブラウザ（390×760・375×600、ライト／ダーク）で `?fake` の タブ 2つ：部屋を つくる → 招待リンクで 入る →
  ひみつの 数字 → コール・メモ・ひとこと → 先攻が 当てて 後攻の 最後の 1回 → 結果と たしかめ・通算 →
  4けたで もう1回（先攻が かわる）→ とちゅうで 読みなおして もどる → こうさん → ゲストが 出る、ひとりで 練習
- 本物の Firebase には この 作業場所から つなげないので、まだ ためして いません（実機 たしかめ まえ）
