# いきもの ひみつずかん

2年生 こくご「**ビーバーのひみつをつたえよう**」→「**本でしらべる**」→「**『どうぶつカード』を作ろう**」（東京書籍『新編 新しい国語 二下』p.8〜28）で、
**図鑑の かわりに つかう** アプリです。30しゅるいの いきものの ひみつを、しゃしんと 文で しらべます。

- 対象：小学2年生（書くこと：経験したことや想像したことなどから書くことを見つけ、必要な事柄を集めたり確かめたりして、伝えたいことを明確にすること）
- 授業で、児童が 1人1台の **Chromebook** で つかう ことを 考えて います（よこ向きの 画面・タッチと タッチパッドの どちらでも）
- まとめる・書く のは ぜんぶ 紙の ワークシートで します。この アプリは **よむ ための 本** です（メモや 入力は ありません）
- **index.html 1ファイル** と `assets/` で うごきます。サーバー・ログインは いりません

## ひらきかた

**https://hirocelica0307-sketch.github.io/kobako/ikimono-zukan/**

`index.html` を Chrome で ひらくだけです。ページの URL（例：`…/ikimono-zukan/#p4`）を くばると、その ページが ひらきます。

## 本の つくり

| ページ | なかみ |
|---|---|
| ひょうし | だい名・しゃしん・「さがす → よむ → 書く」の つかいかた・先生へ |
| 2ページ もくじ | なかまごとに しゃしんの カード（なまえ と ページ） |
| 4〜33ページ | いきもの 30しゅるい（1しゅるい 1ページ） |
| 34ページ さくいん | 「なまえで さがす（あいうえお じゅん）」と「知りたい ことで さがす」の 2しゅるい |

いきものの ページには、

- 大きな しゃしん（タップで 大きく 見られる）と なまえ・みじかい せつめい
- **大きさ・すむ ところ・たべもの** の 表
- 「カードに 書く とき　本の だい名：『いきもの ひみつずかん』　ページ：〇ページ」（ワークシートの「本の だい名・ページ」に 書く ため）
- 「**〇〇の ひみつ**」が 4〜5こ。見出しは「どうやって ねるの？」の ような **問いの 形** なので、ワークシートの「知りたい こと」から こたえを さがせます
  - ひみつには しゅるい（からだ・たべもの・くらし・赤ちゃん・そだちかた・みを まもる）が あり、さくいんの「知りたい ことで さがす」に つながります
  - ビーバーの 文章と 同じ ように、「まず・つぎに・それから・さいごに」の **じゅんじょ** の 文（貝の わりかた・あみの つくりかた・たまごの うみかた・すがたの かわりかた など）や、**数字** の ある 文を 入れました
  - 🔊「よむ」で ひみつを 読みあげます（Chromebook の 日本語の 声）

## 文と 文字

- 文は すべて この 図鑑の ための **オリジナル** です（教科書の 本文は つかって いません）
- 漢字は **2年生までに ならう 字だけ** で、ぜんぶ ふりがなつき。教科書と 同じ **分かち書き** です
- 右上の「もじ」で、ふりがなの あり／なし と 文字の 大きさ（3だんかい）を かえられます（その 端末に おぼえます）
- 本文は 教科書体に ちかい Klee One で 表示します（書きうつす とき 字の 形が わかりやすい ように）
- 数字などの 内容は、ふつうの 図鑑や 動物園・水族館の 説明で よく 書かれて いる ことを もとに しましたが、授業の まえに 一度 お目通しください

## そうさ

- 下の「まえの ページ」「つぎの ページ」・キーボードの ← →・よこに スワイプ で ページを めくる
- 上の「もくじ」「さくいん」で すぐ とべる。左上の だい名で ひょうしへ
- さくいんの「知りたい ことで さがす」で えらぶと、その ひみつの ところまで とびます

## しゃしん・アイコン

- しゃしんは Wikimedia Commons の **CC0・パブリックドメイン** の ものだけ（表記は いりません）。どの しゃしんを どこから とったかは `assets/README.txt`
- カブトムシは おとなの しゃしんが 見つからなかったので、メインは ようちゅうの しゃしんです（おとなの すがたは 文で せつめい）
- フグの「ふくらむ」ひみつは、しゃしんが 見つからなかったので 文だけです
- ボタンの アイコンは Phosphor Icons（MIT）。ライセンスは リポジトリ直下の `THIRD_PARTY_LICENSES.txt`
