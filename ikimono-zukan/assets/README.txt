==================================================================

この フォルダーの 素材は、すべて 下の ところから ダウンロードして 保存した ものです。
画面には クレジットを 表示しません（CLAUDE.md の きまり）。
2026-10-22 に 依頼者に 候補（しゃしん・ライブラリ・ライセンス）を 一覧で 見せて きめました。

1. photos/*.jpg … Wikimedia Commons の しゃしん（CC0 または パブリックドメイン）
   入手もと: https://commons.wikimedia.org/
   ライセンス確認: Commons の API（prop=imageinfo の extmetadata）で 1まいずつ、
     LicenseShortName が「CC0」か「Public domain」で、AttributionRequired が false（表記は いらない）
     で ある ことを たしかめました。たしかめられない ものは つかって いません。
   加工: メインは よこ 1100px、ひみつの しゃしんは よこ 800px に 縮めて JPEG（品質 80）に しました。
         *-thumb.jpg は メインの しゃしんの まん中を 360×270 に 切りぬいた もの（もくじ・ひょうし 用）です。
         penguin-s1.jpg は、下の はしに 入って いた 文字（さつえいした 人の 説明）を 切りとりました。
         beetle-main.jpg は、カブトムシの おとなの しゃしんが 見つからなかったので、ようちゅうの しゃしんです
         （依頼者と きめました。Fluent Emoji の Beetle は カブトムシに 見えないので つかって いません）。
