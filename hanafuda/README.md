# 花札 こいこい

スマホの 縦画面で あそぶ 花札（こいこい）です。
**ルールを 1から おぼえる 入門**、**コンピューター 10段階**、**友だちと 対戦（4けたの 部屋番号）** が あります。
ビルドは いりません（`index.html` を ひらくだけ）。

## はじめて ひらいた とき

「はじめて／すこし わかる／なれている」から えらぶと、ヒントなどの 表示が まとめて きまります。
つぎの 画面で 1つずつ オン・オフと、ルールを えらべます（あとから「設定」で いつでも かえられます）。
「はじめて」を えらぶと、そのまま 入門に すすみます。

## 画面

| 画面 | なかみ |
|---|---|
| ルールを おぼえる | レッスン 8つ（下の 表）。おわった ものに ✓ が つく |
| コンピューターと 対戦 | つよさ 1〜10 と 局数（1・3・6・12）を えらんで 対局。レベルごとの 勝ち負けを のこす |
| 友だちと 対戦 | 部屋を つくる（4けたの 番号が でる）／番号を 入れて 入る |
| 役の 一覧 | いまの ルールでの 役と 点数（札の 絵つき） |
| 設定 | 表示（ヒントなど）・ルール・うごきの はやさ・音 |

### 入門（ルールを 1から おぼえる）

| レッスン | すること |
|---|---|
| 1 花札って なに？ | 48枚・12か月×4枚、12か月の 札の 一覧、「同じ 月どうしで とる」 |
| 2 札の しゅるい | 光・たね・短冊・かす、赤短／青短／ふつうの 短冊の 見わけかた、しゅるい クイズ |
| 3 月を おぼえよう | おぼえかたの こつ、月 クイズ、同じ 月の 札を さがす クイズ |
| 4 あそびかた | くばりかた、じぶんの 番で する こと、場に 2枚・3枚 あるとき、役と こいこい、勝ち負け |
| 5 とってみよう | 手札の 札で とれる 場の 札を タップ する れんしゅう（1枚・2枚・3枚・とれない） |
| 6 役を おぼえよう | 光の 役・一杯の 役・3枚の 役・かずの 役、役 クイズ |
| 7 こいこいと 点数 | いまの 設定の 点数の きまり、こいこい する？ あがる？、強く なる こつ |
| 8 コーチと 対局 | いちばん やさしい コンピューターと、ヒントを ぜんぶ 出して 3局 |

クイズは 毎回 もんだいが かわります。

### 対局画面（上から）

- ☰ メニュー（役の 一覧・表示の 設定・ルールの かくにん・やめる）／ 第○局 ／ **役** ボタン
- あいての 名まえ・点・親／こいこい の しるし、あいての 手札（うら）
- あいての とった 札（光・たね・たん・かすに わけて、枚数つき）と、あいての **ちかい 役**（赤い しるし）
- 場（左に 山）
- じぶんの **できそうな 役**（「赤短 2/3」など）と とった 札
- ひとこと（いま する こと・コーチの アドバイス）
- 手札、じぶんの 名まえ・点、**💡 おすすめ**

さわりかた

- 手札を タップ → 持ちあがり、とれる 場の 札が 光る → **もう一度 タップ**（または 光る 札を タップ）で 出す
- 場に 同じ 月が 2枚 あるときは、とる ほうの 場の 札を タップ
- 山から めくった 札が 2枚に あうときも、とる ほうを タップ
- 札を **長おし** すると、大きく して 名まえ・月・しゅるい・つかう 役を 出す
- とった 札の ところを タップすると 役の すすみぐあいを 出す

うごき：札は 48枚 ずっと 同じ ものを つかい、手札 → 場 → とった 札 へ すべって うごきます。
くばる ときは 1枚ずつ とんで いき、めくる 札は うらがえり、局が おわると 山に あつまります。
役が できると 大きな 文字で 出て、「こいこい！」などを 読みあげます（日本語の こえが ある 端末）。

### 表示の 設定（はじめの 設定・設定画面・対局中の メニュー）

| 設定 | はじめて | すこし わかる | なれている |
|---|---|---|---|
| 「役」ボタン | ○ | ○ | ○ |
| できそうな 役（あと 何枚） | ○ | ○ | － |
| とれる 札を 光らせる | ○ | ○ | － |
| 札の 名札（月の 数字・しゅるい） | ○ | － | － |
| 「おすすめ」ボタン | ○ | － | － |
| ひとこと アドバイス | ○ | － | － |

ほかに「1回 タップで 出す」「うごきの はやさ（ゆっくり・ふつう・はやい）」「効果音」「こえ」。
コーチつき 対局では ヒントは いつも ぜんぶ 出ます。

### ルールの 設定

| 設定 | はじめ |
|---|---|
| 局数 1・3・6・12 | 12 |
| 花見で一杯・月見で一杯 | あり |
| 菊に盃を かすにも かぞえる | はい |
| 7点以上で 2倍 | あり |
| こいこいの 倍（なし／あいてが こいこい中に あがると 2倍／じぶんの こいこい 1回ごとに +1倍） | あいてが こいこい中なら 2倍 |
| 手役（手四・くっつき 6点） | あり |

役と 点数：五光 10・四光 8・雨四光 7・三光 5・花見で一杯 5・月見で一杯 5・猪鹿蝶 5・赤短 5・青短 5・
たね 5枚で 1（1枚ごとに +1）・たん 5枚で 1（+1）・かす 10枚で 1（+1）。
場に 同じ 月が 4枚 くばられたら くばりなおし。2人とも 役なしで 手札が なくなったら 流局（点なし・親は そのまま）。
勝った 人が つぎの 親。役が できた とき 手札が もう ない ときは そのまま あがり。

## コンピューターの つよさ

コンピューターは じぶんの 手札・場・とった 札 しか 見ません（山の じゅんばんや あいての 手札は 見ない）。

| レベル | 考えかた |
|---|---|
| 1 はじめて | でたらめ |
| 2 のんびり | とれる ときは とる。こいこい しない |
| 3〜7 | 札の ねうち・役の すすみぐあい・あいての じゃま・とられる きけん を 点数に して えらぶ。上がるほど 見る ことが ふえ、まよいが へる。4から こいこい する |
| 8〜10 | 見えない 札を 何十回も ならべなおして 局の おわりまで ためす（8：36回・9：70回・10：140回）。こいこいも ためして きめる |

コンピューターどうしで たしかめた、1つ 上の レベルが 勝つ わりあい（3局勝負を 400〜500回）：
1→2 は 約82%、2→3・4→5・5→6 は 約53%、3→4 は 約56%、6→7 は 約56%、7→8 は 約60%、7→9 は 約68%。
（花札は 運も 大きいので、つよい ほうが いつも 勝つ わけでは ありません。）

## 友だちと 対戦

1. ホスト：「友だちと 対戦」→「部屋を つくる」→ 4けたの 番号が でる
2. もう1人：「部屋に 入る」→ 画面の キーで 番号を 入れて「入る」
3. ホストの 画面に 名まえが 出たら「対局を はじめる」
4. 対局が おわったら、ホストの「もう一度 たいせん」で つぎの 対局

- ルールは ホストの 設定です。2人とも 自分が 下に なる 向きで 見えます
- 手（どの 札を 出したか など）だけを 1つずつ おくりあい、2台で 同じ ルールエンジンを うごかします
- ページを 読みなおしたり とじたり しても、同じ タブなら ホームの「部屋 ○○○○ に もどる」で 対局に もどれます（とちゅうまでの 手は すぐに おいつきます）
- あいての つうしんが 切れると 画面の 上に しらせが 出ます。ホストが 部屋を 出ると 部屋は きえます
- 3時間 つかわれて いない 部屋の 番号は、つぎに 部屋を つくる 人が つかいまわします

## Firebase の 設定

「かいて あてて」「タイピング つなひき」「ブロック おはじき」と **同じ Firebase プロジェクト（`hiro-kobako`）** を つかいます
（`firebase-config.js` は 同じ なかみ）。匿名サインインは もう 有効なので、**やることは ルールの はりかえ 1つ だけ**です。

Realtime Database の **「ルール」** タブを 開いて、中身を ぜんぶ `database.rules.json` に おきかえて「公開」。
（ほかの 3つの アプリの `database.rules.json` も 同じ なかみに そろえて あります。`hanafuda` の ぶぶんが ふえただけ です。）

しまう 場所：

```
hanafuda/rooms/{4けた}/
  meta            ホスト・ゲスト・名まえ・ルール・種・何回めの 対局か・さいごに さわった 時こく
  online/host     いま つながっているか（とじると きえる）
  online/guest
  log/{n}/{0000}  n 回めの 対局の 手（1つずつ。いちど 書いたら 上書き できない）
```

ルールで きめて いる こと：サインインした 人だけ 読み書き できる・部屋番号は 4けたの 数字・
手は 上書き できない・部屋は まるごと けせる（ホストが 出るとき／古い 部屋の かたづけ）。

## ためしたこと

- `tests.html`（`node hanafuda/tests.js`）：札の 枚数、役 ぜんぶ、手役、くばりなおし、札の とりかた（1枚・2枚・3枚・めくり）、
  こいこいと 倍、300ゲームで 札が きえない／かならず おわる、手の ならびを おくれば 2台で 同じ 結果、
  どの レベルも ルールどおりの 手、レベル7 が レベル1 に 勝ちこす ― 48こ ぜんぶ OK
- ブラウザ（スマホの 大きさ 390×760・375×560・430×860、パソコン 1280×720）：
  はじめの 設定 → コンピューターと 対局を さいごまで（こいこい・あがり・局の 結果・最終結果・もう一度）、
  入門の 8レッスン ぜんぶ（クイズ・とる れんしゅう・コーチつき 対局）、役の 一覧、札の 長おし
- 友だちと 対戦：本物の Firebase には この 作業場所から つなげないので、`?fake`（同じ ブラウザの タブどうしで
  つうしんする にせもの）で タブを 2つ ひらいて、部屋を つくる → 番号で 入る → 対局を さいごまで（2台で 点数が 一致）
  → もう一度 → とちゅうで 読みなおして もどる → ゲストが 出る、を たしかめました
