# かさ はかせ（仮称）

2年生の **「水の かさの たんい」**（L・dL・mL）を、**水が そそがれる アニメーション** を 見ながら
一問一答で まなぶ ゲームです。単位の かんさん（1L＝10dL＝1000mL・1dL＝100mL）と、
**量感**（みのまわりの ものに どれくらい 入るか）を いっしょに みにつける ことを ねらって います。

- 対象：小学2年生（啓林館「わくわく算数」2年「水の かさの たんい」）
- 子どもの **Chromebook**（よこ画面）で つかう ことを 中心に つくりました。タッチ・マウス・キーボード（0〜9・⌫・Enter）
- サーバー・ログイン・外部API は つかいません。ファイルを ひらくだけで うごきます
- 音は「おと：なし」が はじめの せってい（授業で しずかに つかえる ように）

## あそびかた（6しゅるい ＋ ぜんぶ まぜる）

| モード | 身に つけたい 力 | 問題の れい | アニメーション |
|---|---|---|---|
| はかろう | ますで はかって よみとる | 1Lます 2はい と 1dLます 3ばい → **2L3dL**／1Lますの 目もりを よむ／目もりを mL で よむ（300mL） | ますに 水が 1つずつ そそがれる |
| たんいを かえよう | 1L＝10dL・1L＝1000mL・1dL＝100mL | 2L3dL＝□dL・23dL＝□L□dL・40dL＝□L・3dL＝□mL・500mL＝□dL | その かさの 水が ますに 入る |
| どっちが 多い？ | たんいを そろえて くらべる | **3dL と 280mL**・1L2dL と 15dL・1L と 900mL（「おなじ」も ある） | こたえた あと、おなじ ますに 2つ どうじに そそいで くらべる |
| どれくらい？ | 量感・たんいを えらぶ | おふろ 200〔L〕・コップ 2〔dL〕・ジュースの パック 200〔mL〕・スプーン 5〔mL〕／1L は コップ（2dL）で 何ばい分？ | こたえた あと、その かさを ますで 見せる／コップで 1ぱいずつ そそいで かぞえる |
| かさの 計算 | L は L どうし、dL は dL どうし | 2L5dL＋1L3dL・3L5dL＋2L・4L8dL−2L・4dL＋3dL・300mL＋400mL（くりあがり・くりさがり なし） | 2つの かさを ならべて 見せ、こたえた あと あわせる／へらす |
| ぴったり つくろう | ますで はかりとる | 「1L3dL に しよう」「13dL に しよう」「700mL に しよう」 | 「1Lます で 入れる」「1dLます で 入れる」を おすたびに 水が 入る |
| ぜんぶ まぜる（おすすめ） | 上の 6つを まぜて 出す | | |

- 1かいは **5・10・15もん**（はじめの 画面で えらぶ）。はじめての こたえで あたると **ほし** が 1つ ふえる
- **mL を まだ ならって いない** ときは「mL：まだ ならって いない」に すると、mL の 問題が 出なく なる
  （教科書は dL → L → mL → 計算 の じゅんばん）
- 「たんいの ひょう」で 1L＝10dL＝1000mL・1dL＝100mL と、1Lます＝1dLます 10ぱい の 図を 見られる
- アニメーションの とちゅうで 図を タップすると はやおくり

### 1Lます と 1dLます の 大きさ

図の 1dLます は、1Lます の **1/10 の 面積** に して あります。
1Lます と 1dLます が ならぶと、見た目でも「1dL は 1L より ずっと すくない」ことが わかります。
1Lます には 1dL ごとに 目もりが 10こ（まんなかの 5dL は ながい 目もり）。

## まちがえた とき

- まちがえた わく だけ 赤く なり、**まちがいかたに あわせた ことば** を かえるが いいます（1かいめは ヒントも）
- 2かい まちがえると こたえと せつめいを 見せ、もういちど 水を そそいで 見せます
- まちがえた 問題は **3もん あとに「もういちど！」** で また 出ます
- おわりの 画面に「まちがえた もんだい」と こたえの いちらん

| まちがい | かえるの ことば（れい） |
|---|---|
| 2L3dL → 5dL | 1L は 1dL では ないよ。1L ＝ 10dL だから 2L ＝ 20dL。 |
| 2L3dL → 20dL | のこりの 3dL も わすれずに たそう。 |
| 23dL → 3L2dL | L と dL が いれかわって いるよ。10dL の まとまりが L に なるよ。 |
| 3dL → 30mL | 1dL は 100mL だよ。 |
| 3dL と 280mL で 280mL を えらぶ | 数が 大きい ほうが 多い とは かぎらないよ。たんいを そろえて くらべよう。 |
| 3L5dL ＋ 2L → 3L7dL | 2L は L だよ。L の ところで 計算しよう。 |
| コップ → 2L | 2L は 1Lますで 2はい分 だよ。そんなに 入るかな？ |
| ぴったり つくろう で 入れすぎ | 1dL 多いよ。 |

## 学習指導要領・教科書との つながり

学習指導要領（平成29年告示）算数 第2学年「C 測定」(1) の
- ア(ア) かさの 単位（mL・dL・L）に ついて 知り、測定の 意味を 理解する → **はかろう・たんいを かえよう・ぴったり つくろう**
- ア(イ) かさに ついて、およその 見当を つけ、単位を 適切に 選択して 測定する → **どれくらい？**
- イ(ア) 目的に 適した 単位で 量の 大きさを 的確に 表現したり、比べたり する → **どっちが 多い？・かさの 計算**

ことばは 啓林館「わくわく算数」2年の「水の かさの たんい」に あわせて「1Lます」「1dLます」「目もり」「何L何dL」と して います。
（啓林館の ウェブサイトは この 作業の かんきょうから 直接 ひらけなかったので、教科書の 紙面と ちがう ところが あれば なおします）
